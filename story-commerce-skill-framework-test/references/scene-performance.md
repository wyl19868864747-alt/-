# Scene / Performance Compiler

场景不是背景，表演不是情绪形容词。每个关键Beat都要发生一件看得见的事。

## Beat状态链

`刺激 → 感知 → 理解 → 可见反应 → 决定/行动 → 完成态`

不要求每次写满，但必须保证反应有原因、行动有结果。

## Blocking First

先写：
- 人物从哪里来、往哪里去
- 面向谁/什么
- 手里有什么
- 要接触什么
- 接触后什么状态改变

再写Camera如何看见。不要让运镜替代场面调度。

## 表演

只写当前情绪真正需要的少量动作：眼神落点、停顿、呼吸、嘴角/眉部变化、身体倾向、手部动作。FACS是动作来源，不在Prompt里堆AU编号。

强情绪不要从头维持到尾；优先有触发和变化。

## 抽象词必须落地

- “震惊” → 具体核对、停住、后撤、抬眼、再次确认等
- “荒诞升级” → 第二个行为必须比第一个更异常，并且可见
- “紧张升级” → 动作速度、呼吸、距离、失误或镜头稳定性发生明确变化
- “轻松释放” → 肩颈放松、呼气、放下道具、恢复正常动作节奏

## Proof Beat

产品证据镜优先让产品过程和结果可读，人物反应只能放大证据，不能替代证据。
