# Story Commerce Judge

Judge只检查失败，不参与创作自证。

## 商业Gate

- 一条广告是否只有一个核心购买判断？
- Best Proof是否清楚、可见、可被当前事实支持？
- 删除产品后故事是否仍完整成立？若是，判短剧漂移。
- Hook承诺是否在后文兑现？
- 产品出现后是否真正接管注意力？

## 执行Gate

- 每个关键Beat是否有状态变化，而不是只有台词和情绪词？
- 关键动作是否有起点、接触/作用与完成态？
- 人物是否因为看见/听见某件事才反应，而不是提前反应？
- 产品、道具、人物位置、手别、数量、开合状态是否连续？
- Camera是否服从Blocking，而不是为了炫技穿过不可能的位置？
- 光源是否有真实出处，人物/产品材质是否共享同一受光逻辑？

## Prompt Gate

- 开场总控有没有混入具体剧情？
- 有没有“荒诞升级、震惊、高级、电影感”等未落地抽象词？
- 有没有同一事实重复三次以上？
- 是否堆了过多设备、理论、负面限制，压掉动作和Proof？
- CTA是否与已确认文本一致？

## Repair

优先修最早出现或影响最大的一个失败点：
- 核心不清 → Commercial Core
- Hook弱/不兑现 → Hook Router
- 剧情抢产品 → Story / Proof
- 表演抽象/物理不通 → Scene / Performance
- Prompt过载 → Prompt Compiler
- 专项问题 → 调原 `story-commerce-skill` 对应模块

局部问题局部修，不整条重写。
