# Story Ad Prompt Compiler

目的：把商业决策、剧情和导演执行压成Seedance真正需要的内容。

## 开场总控

只写：广告类型、平台原生感、风格、调性、节奏、观感。

不写：具体剧情事件、角色动作、价格、产品Proof、镜头编号。

## 编译顺序

1. 主体、空间、参考资产
2. 人物目的与初始状态
3. 光影与成像基线
4. 分镜：按真实发生顺序写动作、接触、状态变化、反应、镜头响应
5. 产品Proof与结果
6. 声音节点
7. CTA
8. 少量反向限制

## 压缩原则

- 内部规则多，最终Prompt要少。
- 商业事实、人物动作、产品Proof是高权重；理论解释、管理话、重复形容词删掉。
- “荒诞升级/更紧张/更高级/更有冲击力”若后面没有具体动作或视觉证据，退回Scene / Performance重写。
- 每镜一个主任务，避免对白、表演、产品、运镜、特效同时抢注意力。
- 设备/光影一句概括主媒介，再写真实光源与可见层次；不堆摄影器材名。
- 对白能少则少，画面能证明的不要再让人物解释一遍。

## 产品接管

产品进入后，剧情逐步把注意力让给产品。后半段优先Proof、体验、结果和Decision，不继续发展与购买无关的长人物支线。

## CTA

CTA干净、明确、与用户已确认文本一致。不要在CTA阶段重新解释整条广告。
