# Commercial Core

每条剧情广告先收敛到一个核心购买判断。

## Decision Card

只填这些：
- PRODUCT / SKU
- AUDIENCE
- CORE DECISION QUESTION
- TOP HESITATION
- BEST PROOF
- PRODUCT CAUSAL ROLE
- CONVERSION GOAL
- EMOTIONAL PAYOFF

## Single Core Rule

一条广告最多一个主核心。价格、无会员费、免费配送、剂量不涨价、评价等可以同时是真事实，但不能都作为并列主线。

先选：
`这一条广告如果观众只记住一件事，必须记住什么？`

其他信息只能作为Proof、补充或CTA支撑。

## Product Centrality

剧情成立必须依赖产品：
`人物问题/欲望/误解 → 产品进入 → Proof发生 → 人物判断改变`

如果删掉产品后，故事仍然能完整成立，说明剧情抢走了广告。

## Proof First

先定义看得见、听得见、能被当前素材支持的Proof，再决定要不要反转。不能为了戏剧性牺牲产品事实。
