# Hook Router

目标：先选对Hook，再写Hook；不要把所有钩子同时塞进前3秒。

## 先问

`这条广告现在最硬的素材是什么？`

## 主Hook类型

- Benefit Shock：利益点本身足够强
- Price Shock：价格/数字是最强证据
- In-Media-Res Conflict：开场已经在事件或冲突中
- Visual Anomaly：第一眼出现明显异常/反常画面
- Misbelief Hook：让观众先形成一个明确错误预判
- Result-First：最强结果先出现，再解释怎么发生
- Reaction Hook：人物真实反应比事实陈述更抓人

一条只选一个主Hook，最多一个辅助Hook。

## Hook Judge要点

- 0–2秒不看标题能不能知道有事发生？
- 静音是否仍有可见信息？
- 有没有未解决的问题或期待？
- 有没有过早把答案全部讲完？
- 前5秒承诺的东西，后面能不能兑现？
- 如果只有形容词和台词，没有事件/证据，判弱。

Hook素材不足时，不硬写炸裂开头，先回Commercial Core或Story补事件/Proof。
