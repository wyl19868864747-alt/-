# TVC 生成运行控制与证据重试

只在 TVC 的直出/故事板取舍、强节奏钩子、30 秒或更长版本、旁白、包装/产品交互、成片复盘与局部重试中加载。UGC 继续使用 `ugc-ad-rules.md`；普通短剧不套用广告秒点；Seedance 2.0/2.5 的时间轴仍按 `seedance-2.5-workflows.md` 分流。旁白和精确对嘴的详细唯一源规则归 `voiceover-control.md`；跨商业/剧情的长时节奏、元素回收与返修归 `longform-rhythm-and-retake.md`，命中时叠加读取。

## 1. 直出与受控预览

- **直出**：适合单产品、单人物、简单动作链、创意探索和允许模型自然补切镜的任务。锁定核心命题、必须发生的节点、完成截止状态、产品身份和品牌收束；减少逐格构图与强制转场。
- **故事板/关键帧预览**：适合多人、复杂产品动作、严格因果、客户审稿、品牌构图必须对齐或局部重拍。先确认无索引文字的多宫格或独立关键帧，再编译视频提示词；故事板负责大致顺序，严格状态用独立关键帧。
- 时长、声音和生成方式彼此独立。优先读取用户或界面已选配置；只在缺失且会改变成片时一次性询问。开场总控仍不写界面可选的时长、画幅、平台和发布渠道。

## 2. 强节奏 TVC 的前三秒

用于时长不少于 3 秒、以社媒停留或直接转化为主要压力的 TVC：

1. 第一帧已经处于动作、决定、反应、冲突或产品造成的异常中，并提供最低限度情境。
2. 约 0.7 秒内发生触发，约 2 秒内出现决定性事件；3 秒时的主体状态、空间关系或人物决定与首帧明显不同。
3. 观众能说出一个“接下来想知道什么”的问题，且答案指向产品、质地、使用结果、痛点或传播命题。
4. 同一钩子资产不在中段按相同主体、动作、景别和功能重复；结尾只能用意义变化后的回收。

奢侈品、诗性品牌片或用户确认的克制慢节奏只参考这些秒点，但首个关键节拍仍要建立产品相关欲望、张力或未完成问题。UGC 使用主动招呼与同步产品动作，不强套本节。

## 3. 30 秒与长时新信息预算

- 每 4–6 秒增加其他段落没有的新信息：故事因果、产品证明、人物关系、感官体验、空间规则或品牌含义。
- 先选择 1、2 或 3 个因果相连的场景；只换机位、景别、光色或特效不算换场。
- 5–7 个叙事模块可作为 30 秒参考；模块规定新信息和截止状态，不等于单镜。实际镜头数由动作与表演决定。
- 最终 Packshot 之外，低运动画面约 2 秒内没有第二状态、主体运动、新商业信息或声音事件时，缩短、合并或替换。
- 不连续安排两个同功能的凝视、微笑、倒影、慢转身、液滴或产品旋转镜头。

## 4. 产品动作与完成态

复杂包装或产品交互按以下链路设计：

`初始结构 → 锚定点 → 施力点与方向 → 可见材料/主体反馈 → 明确完成态`

- 动作是核心证明：完整呈现链路，并把品牌正面识别留给独立 Hero/Packshot。
- 动作只负责进入使用：可用动作前状态、同步声音桥和动作后完成态，减少高风险手部过程。
- 参考图看不清开口、泵头、盒扣或内部结构：不猜结构；改用预先打开、画外操作、工具辅助或独立实拍插入。
- 关合、触碰、放下、入口、破裂、落下等结果在切镜前保留约 0.15–0.35 秒，或由下一镜第一帧清楚继承。若用未完成动作制造悬念，下一镜立即兑现。

## 5. 唯一声音真源

有旁白或必须逐字准确的对白时，先建立一张主声音清单：

`声音 ID｜说话者｜准确文本｜开始时间｜硬停止时间｜表演方式｜repeat_count=1`

- 每句完整文本只在主声音清单出现一次；时间轴只引用声音 ID，不再次粘贴原文。
- 主声音清单之外不写带引号的潜台词、完整口号或可能被朗读的句子。
- 到达硬停止点后不重启、不回声、不改写复述、不跨场景续念。
- 同时制作有声与无声版时，共享创意母题，但分别调整镜头停留、声音钩子和节奏，不能只删除音轨。
- 商业文案必须逐字准确时，把生成音轨视为导引轨，正式配音和精确文字交给后期。

## 6. 成片证据驱动重试

用户返回视频、截图或明确时间码后，先取证再改写：

1. 全片等间隔抽帧，建立镜头、人物、产品、声音和切点地图。
2. 对失败区间高频抽帧，记录动作从哪一帧开始偏离；有声音时取得带时间码转写。
3. 标出实际硬切、转场开始/完成点和失败动作的首尾状态。
4. 分层记录：`成功层`、`失败层`、`必须保留`、`唯一主修层`。主修层只选创意/结构、资产身份、动作物理、摄影连续、光影材质或声音中的一层。
5. 只重写主修层及必要的相邻镜尾/镜首；产品、人物、旁白、时长结构和成功镜头保持不变，除非证据直接指向它们。
6. 用同一验收条件复测；若同层连续两次失败，升级控制方式、减少变量或拆镜，不继续叠加同义禁令。

## 7. 运行检查

- 生成方式是否匹配控制难度，故事板是否被误当作严格关键帧？
- 强节奏前三秒是否有事件、状态差、未完成问题和产品关联？
- 长时版本是否持续增加新信息，而不是拉长 15 秒动作？
- 产品动作是否有真实结构、受力反馈和可读完成态？
- 旁白是否只有一个真源、唯一时码、硬停止点和单次播放？
- 复盘是否基于抽帧、切点和转写证据，并只修改唯一主修层？
