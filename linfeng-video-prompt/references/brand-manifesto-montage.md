# 品牌宣言式蒙太奇

本模块用于把无实体服务、教育项目、时尚／艺术品牌、平台愿景或品牌形象 Brief 转化为“现实入口—品牌世界—身份回归”的高密度TVC。它补充主技能的商业与执行规则，不替代产品证明、UGC、连续剧情或完整TVC创意流程。

## 启用边界

同时满足以下大部分条件时启用：

- 商业主目标是品牌认知、身份向往、行业愿景或圈层归属；
- 产品抽象、无实体，或功能无法用一次物理演示完整证明；
- 需要宣言型文案、混合媒介、时尚影像或高密度视觉蒙太奇；
- 观众需要先感到“我想进入这个世界”，再理解具体服务。

普通产品演示、真实使用型UGC、强功能对比、教程、连续对话或严格空间动作任务跳过本模块。若任务需要直接转化，必须补充理性 Proof，不能只用审美氛围代替事实。

## 核心结构

使用以下因果骨架，并按时长压缩：

`现实人物与未完成动作 Hook → 动作触发感官入口 → 地点／品牌身份确认 → 核心行业宣言 → 3–4组文案—视觉簇 → 能力或价值升级 → 回到人物并完成逆向动作 → 命题个人化 → 降速 CTA／品牌落版`

入口动作必须属于当前人物和品牌世界，例如戴上设备、打开包装、推门、触摸界面、按键、翻页、穿上服装或启动装置。结尾用同一动作的完成、停止或逆过程关闭品牌世界。不要照搬某条参考片的眼镜、人物、城市、台词或镜头排列。

## 双层连续性

区分两种连续性，不把所有镜头都强制成同一物理空间：

1. **外层因果连续**：现实人物的动作打开品牌世界；中段体验改变其认知或状态；人物回到现实并完成动作，随后进入CTA。
2. **内层语义连续**：中段允许人物、地点、媒介和时代跳变，但相邻镜头至少共享一项可读接力：中心轴、轮廓、动作方向、色块、明暗、材质、图形、声音节拍或同一句传播命题。

只在需要真实物理结果的镜头使用动作因果转场。时尚、艺术和愿景蒙太奇可用构图匹配、形态匹配、色彩对撞、声音接力或概念联想；切换必须推进语义，不能只是换一张更炫的图。

### 视觉母题接力

高风格化多镜广告先选 **1 个主母题 + 最多 1 个辅助母题**，再让母题更换载体而不是机械重复同一物体。母题可以是主色、轮廓、材质、高光、运动方向、身体局部、产品结构或与品牌命题直接相关的动作。

使用轻量链路：

`核心母题 → 3–6个不同载体 → 相邻镜头至少继承1项 → 当前镜尾再留下1项可被下一镜接走 → 产品/品牌英雄镜完成回收`

例如同一红色可以依次存在于鞋、服装、唇色、花、车辆和产品，但每次出现都要新增人物、环境、产品或情绪信息。不要把“统一色调”误当成母题接力，也不要为了凑接力让每镜都塞同一个颜色。

## 受控异质性

允许画面多样，先锁定3–5项全片视觉语法：

- 主体轴线与主要构图重心；
- 文案安全区与固定层级；
- 基础色、强调色及黑白／彩色切换逻辑；
- 反复出现的人体、产品、图形或材质母题；
- 统一黑位、对比度、颗粒、锐度或合成质感；
- 主要运动方向、节拍或转场形态。

每个新镜头可以改变场景、媒介或人物，但必须继承至少两项视觉语法。若只剩“先锋、未来、高级”等形容词而没有可见锚点，重新设计。

## 文案—视觉簇

先把传播内容压缩成最多四个递进命题，再为每个命题配置一组视觉簇：

1. **未来／变化**：观众将进入怎样的新世界；
2. **圈层／角色**：谁属于这个世界；
3. **能力／证据**：品牌、项目或平台具体赋予什么；
4. **身份／行动**：观众最终成为什么，并采取什么行动。

每组画面只服务一个命题，明确主体、媒介、色彩、运动和结束标点。不要从无分类素材池随机快切。跨簇切换时，用一次明显的颜色、尺度、声音或图形变化提示信息升级。

## 阅读带宽

把观众注意力视为有限带宽。长文案、复杂背景和快速剪辑三项不能同时处于最高强度：

- 极快画面只承载短口号或1个关键词；
- 完整项目名、能力句或利益句出现时，降低背景运动、减少切镜或扩大稳定负空间；
- 准确Logo、CTA、课程名、法务与长文案由后期替换，生成阶段预留清楚安全区和稳定文字载体；
- 文案停留时长按实际可读性安排，不因音乐节拍提前切走。

## 双重 Proof

区分两种证据：

- **情感 Proof**：视觉世界、人物气质、行业场景和审美质量证明“品牌属于这个未来”。
- **理性 Proof**：真实功能、流程、成果、作品、合作、课程、数据或使用结果证明“品牌能把承诺变成现实”。

品牌认知短片可以情感 Proof 为主；招生、订阅、购买或申请任务至少加入一个可验证的理性 Proof。没有可靠事实时不虚构数据，改为展示真实流程、界面、作品或可见结果。

## 节奏与 CTA

中段采用“建立—扩展—加速—释放”，不要全程维持同一强度。连续高密度蒙太奇后预留0.5–1.5秒完成注意力切换：

`回到现实人物 → 动作停止或完成 → 背景简化 → 核心命题个人化 → CTA → 品牌落版`

CTA画面降低主体数量和背景复杂度，保留一个稳定焦点。若中段已经使用大量文字，结尾只保留一个行动指令和品牌识别。

## 生成稳定性

- 15–20秒内优先使用3个视觉簇，不追求逐帧不同；每簇由2–4个可生成镜头组成。
- 混合媒介变化大时，用独立关键帧或故事板锁定每簇首帧、主色和构图，不用单段长提示词让模型随机补齐所有风格。
- 中段人物可以变化，但现实入口人物、服装、动作和环境必须在首尾一致；为首尾分别准备可对应的关键帧。
- 精确排版和文字交给后期；模型负责可替换载体、空间层级、光影、遮挡与运动。

## 后台验收

- 现实入口和身份回归是否构成完整开合动作；
- 每个视觉簇是否对应唯一传播命题；
- 是否存在清楚的主视觉母题，并通过不同载体推进而非机械重复；
- 每个关键镜头是否至少继承上一镜一项可读变量，同时留下下一镜可接走的视觉或声音出口；
- 异质镜头是否至少继承两项视觉语法；
- 微观切换是否具有构图、动作、色彩、声音或语义接力；
- 长文案是否获得足够负空间和停留时间；
- 转化任务是否同时具备情感 Proof 与理性 Proof；
- CTA 前是否真正降速，品牌和行动指令是否成为唯一焦点；
- 是否保留参考片的底层机制，同时重做人物、入口动作、场景、台词与镜头组合。
