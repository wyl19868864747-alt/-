# 黄金 3 秒 Hook 引擎

## 1. 目标与使用边界

本模块负责把“开头要抓人”变成可执行的导演决策。适用于短视频广告、UGC、短剧、剧情式商业片、产品能力展示、社媒内容、参考视频反推，以及任何明确依赖首 1–5 秒停留率的任务。

它不要求所有片子都快切、爆炸、巨物、吵闹或高信息密度。黄金 3 秒的目标是：**在可信世界中尽快制造一个观众能感知、但尚未得到完整答案的信息缺口，使观众主动预测下一步。**

Hook 默认不是独立噱头，应成为后续剧情、产品证明、人物关系或视觉事件的第一个因果节点。但当传播目标明确优先获取停留、品类允许延迟产品揭示时，可以启用 `attention-first-hook`：开场暂时弱化产品显性关联，先用一个独立成立的未完成事件购买注意力，再把该注意力转交给产品、品牌或正文。它不是伪造事实的许可。

本模块只控制注意力结构，不扩大产品事实、功效、法务或安全证据边界。

---

## 2. 核心定义

黄金 3 秒不是固定三秒钟，而是首个“必须继续看”的信息单元。它可以短于 1 秒，也可以延伸到 3–5 秒，但必须尽快完成以下链路：

`可信首帧 → 观众自然预测 → 预测偏差/信息缺口 → 具体问题 → 延迟答案 → Bridge → Payoff`

### 2.1 可信首帧
先让观众知道“这是一个什么世界”：人物、空间、对象、动作或声音至少有一个可读锚点。除非用户明确要纯抽象实验影像，否则不要在毫无现实参照的混乱奇观中开场。

### 2.2 观众自然预测
后台先回答：
- 看到首帧后，普通观众最可能预判下一秒发生什么？
- 同类创作者最常见的开头会怎么拍？
- 哪个信息是观众以为自己已经理解了的？

### 2.3 预测偏差
再设计一个**合理但意外**的偏差，让观众的第一预测失败。偏差必须可见、可听或可感知，不靠幕后解释成立。

### 2.4 具体问题
Hook 必须让观众形成至少一个可以用自然语言说出的具体问题，例如：
- 他为什么这样做？
- 这个东西为什么会出现在这里？
- 接下来会撞上吗？
- 哪一个是真的？
- 这个结果是怎么发生的？
- 她为什么突然停住？

“画面很酷”“看起来高级”“节奏很快”不算观众问题。

### 2.5 延迟答案
不能在制造问题的下一拍立刻完整解释。先让观众多看一个有因果价值的动作、反应、障碍、关系或证据，再给答案。延迟不是故意拖沓；如果新信息不增加张力、理解或证明，就直接揭示。

### 2.6 Bridge
Hook 必须有桥接动作，把异常/问题自然送进正文。桥接可以是：
- 人物继续同一动作；
- 物体状态变化；
- 第二人物反应；
- 视线/摄影机揭示原因；
- 产品真实介入；
- 声音来源被发现；
- 先前结果反推原因。

### 2.7 Payoff
后续必须回答或升级开头的问题。优先让产品、剧情、人物关系或核心内容本身成为答案，而不是另开一条无关叙事。

### 2.8 Attention-first Hook：纯停留型高冲击悬念

该模式的内部任务是“先钩停留，再转交注意力”，适用于创意平台、AI视觉工具、娱乐、时尚、消费品、品牌世界展示及用户明确把首屏停留置于产品解释之前的广告。它允许 Hook 与产品弱显性关联，但不等于可以虚构产品事实、功效、认证、危险或用户结果。

后台使用结构：

`可信世界 → 从事件中途进入 → 危险/动作/身份/结果未完成 → 每拍升级距离、受力、关系或未知 → 预测反转 → 视听或语义 Bridge → 产品/品牌正文`

启用条件：

1. 首帧在 0.5–1 秒内可读，并只建立一个主要未知；
2. 观众能用一句自然语言说出“接下来会怎样 / 为什么会这样”；
3. 延迟期间每一拍都升级事件，不用重复挣扎、尖叫、快切或音效拖时长；
4. Hook 本身至少承担成片能力证明、品牌情绪、欲望身份、结果世界或内容类型承诺之一；若连这些都不承担，只能在用户明确要求纯停留实验时作为低关联测试版，不得冒充高转化版本；
5. Bridge 在答案或反转后的 1–2 个有效节拍内出现，通过同一主体、结果画面、品牌物件、动作、颜色、形状、声音或“成片后拉为生成界面”等方式完成注意力接力；
6. 医药、健康、金融、安全、儿童及其他高风险领域默认不使用无关危险或奇观暗示功效，只能从真实用户摩擦、合规事实或明确虚构且不形成产品暗示的品牌叙事中建立 Hook。

“骗人钩子”只能作为团队内部俗称；正式规则和输出使用“纯停留型高冲击悬念钩子”或 `attention-first-hook`，避免把弱关联误写成事实欺骗。

## 3. 每次开场必须运行的“8 步 Hook 决策”

只要任务明确依赖短视频停留，或成片时长 ≤ 60 秒且没有用户指定慢开场，就在后台执行以下步骤：

1. **写出普通开头**：一句话描述这个题材最俗、最自然、最容易被划走的开场。
2. **删除说明欲**：去掉“大家好 / 今天给大家 / 这是我们的 / 先介绍背景 / 产品摆拍后讲卖点”等先解释后吸引结构，除非它本身就是反常事件。
3. **确定观众预测**：首帧后，观众最可能认为下一秒会发生什么？
4. **选择一个主要偏差机制**：从第 4 节选择 1 个主机制，必要时只叠加 1 个辅助机制。不要同时堆 4–5 个异常。
5. **写出观众问题**：必须具体；写不出问题就重做 Hook。
6. **设计未完成状态**：让动作、关系、危险、结果、身份或因果至少有一项暂时未完成。
7. **建立 Bridge**：明确这个 Hook 如何在 1–2 个节拍内进入正文/产品/核心冲突。
8. **判断 Hook 模式并验收**：若为标准 Hook，换成任意热门奇观后正文仍完全成立，说明相关性不足，应重做；若为 `attention-first-hook`，允许弱显性关联，但必须检查停留目标、具体未完成事件、逐拍升级、事实安全、视听 Bridge 与正文回收是否全部成立。

## 4. Hook 机制库

每个开场优先只选择一个高权重机制，避免“奇观大杂烩”。

### A. 行为异常
可信场景中出现无法立刻解释的动作。
- 关键问题：为什么他这样做？
- 最佳用途：剧情、UGC、生活方式、服务业、食品、人物广告。

### B. 动作中途进入
不拍“准备开始”，直接从正在发生的动作中进入。
- 关键问题：发生什么了？
- 规则：首帧必须已有动势、受力、速度、液体、身体反应或任务状态变化之一。

### C. 结果前置
先给结果，再追原因。
- 关键问题：这是怎么发生的？
- 规则：标准模式下结果必须与后文核心因果一致；`attention-first-hook` 可暂时弱显性关联，但结果必须承担能力、品牌世界、身份欲望或内容承诺，并按 2.8 回收。

### D. 结果悬置 / 即将发生
让观众看到一个已经启动、但尚未结束的事件。
- 关键问题：接下来会怎样？
- 适合：车辆、运动、烹饪、测试、冲突、竞赛、危险但安全可拍的场景。

### E. 常识违反
让一个可信世界里发生一件“正常情况下不会这样”的事。
- 关键问题：为什么规则失效了？
- 必须遵守安全与事实边界；医学、健康、金融等不可用虚假奇观伪装事实。

### F. 语义错位
把两个各自正常、组合后意外的对象/身份/场景放在同一因果里。
- 关键问题：这两个东西为什么会在一起？
- 规则：后文必须解释组合意义，不能只是随机猎奇。

### G. 身份错位 / 身份延迟
先让人物执行与身份不匹配的行为，或故意晚一点揭示身份。
- 关键问题：他到底是谁？
- 适合：剧情、品牌片、服务体验、真假对比、AI 能力展示。

### H. 人际关系异常
利用陌生人靠近、异常熟悉、角色权力反转、错误称呼、沉默对峙、意外请求等建立关系缺口。
- 关键问题：他们是什么关系 / 为什么这样对待对方？
- 规则：避免把骚扰、暴力或危险行为当廉价刺激。

### I. 尺度 / 空间错觉
不一定真的巨物化，可用近景遮挡、错误尺度参照、透视、突然入画、极近前景制造短暂尺度误判。
- 关键问题：这东西到底有多大 / 在哪里？
- 与 `grounded-surreal` 结合时仍遵守“一镜一个高权重幻想规则”。

### J. 声画错位
先听见不符合当前画面的声音，或画面发生事件但声源暂时未知。
- 关键问题：声音从哪里来 / 为什么是这个声音？
- 必须尽快给可信声源，不能无因音效轰炸。

### K. 视觉证据先行
先给功能产生的可见结果，不先念卖点。
- 关键问题：什么东西做到的？
- 适合产品演示、功能广告、电商、AI 能力展示。

### L. 二选一 / 真假判断
同时给两个相似对象，让观众必须判断差异。
- 关键问题：哪个是真的 / 哪个更强 / 差别在哪里？
- 适合真假 UGC、前后状态、模型能力、材质与质量演示；不得伪造用户结果或受限功效对比。

### M. 信息矛盾
画面与人物话语、身份、环境或常识暂时冲突。
- 关键问题：谁错了 / 哪个信息是真的？
- 规则：矛盾必须有后续解释，不制造品牌事实混乱。

### N. 反应先行
先给一个克制但明确的惊讶、迟疑、紧张、忍笑、不可置信等人物反应，再揭示刺激源。
- 关键问题：他看到了什么？
- 规则：避免 AI 式夸张表演；反应强度必须匹配事件。

## 5. Hook 强化顺序

Hook 不够强时，按下面顺序升级，禁止第一反应就“加爆炸、加快切、加特效”。

1. **把开场提前**：从准备动作切到动作已经发生。
2. **把解释往后挪**：先让观众看见，再解释。
3. **让状态未完成**：危险、动作、身份、结果或关系不要在首拍闭合。
4. **提高偏差幅度**：让“预期”和“实际”差异更清楚，但仍可信。
5. **缩短认知时间**：首帧减少背景杂讯，让异常一眼可读。
6. **提高个人利害**：让事件影响人物、任务、关系、时间或产品使用结果。
7. **增加第二层问题**：第一问题得到局部答案时，再产生一个更靠近主题的新问题。
8. **最后才考虑奇观升级**：只有普通物理和关系机制无法承载创意时，再使用尺度、超现实、微缩、巨物、复杂视效。

## 6. 黄金 3 秒的信息节拍模板

模板不是固定镜头数量，而是信息顺序。

### 模板 1：异常 → 反应 → 原因
`异常动作/结果 → 人物或环境确认它真的发生 → 揭示原因/产品/人物`

### 模板 2：结果 → 原因追踪
`强结果 → 摄影机/人物寻找来源 → 核心机制出现`

### 模板 3：未完成动作 → 风险升级 → 解答
`动作已启动 → 更接近完成/冲突 → 进入正文解答`

### 模板 4：反应 → 刺激源 → 意义
`人物先反应 → 看到他在看什么 → 发现这件事与产品/剧情有关`

### 模板 5：真假二选一 → 观察差异 → 揭晓
`并列对象 → 提示观众判断 → 给一个足以继续看的差异证据`

### 模板 6：普通世界 → 单一越界 → 现实回收
`可信现实 → 一个高权重异常 → 人物/产品真实接触证明 → 回到现实因果`

## 7. Hook 与镜头语言

### 首帧
- 优先让主体、异常或未完成动作在第一眼就可读。
- 不用建立镜头浪费 1–2 秒介绍完整空间，除非空间本身就是异常的一部分。
- 需要空间信息时，用前景、背景、移动路径或第二拍补齐。

### 景别
- 选择最短时间能读懂 Hook 的景别，而不是默认大特写。
- 行为异常常用中近景/中景保证动作关系；物体异常可用近景；关系异常需要同框或可读视线；结果前置可先特写后揭示。

### 运镜
- Hook 中的运镜必须服务“发现、追赶、揭示、等待结果、重新理解”。
- 如果固定镜头能更快看懂，不为了高能而运动。
- POV/FPV 只在它能提高在场感、未知感或行动风险时使用。

### 剪辑
- 不按每句话切镜。
- 第一切优先发生在“问题升级、视点改变、答案出现或反应成立”时。
- 高能不等于快切；一个持续推进的未完成动作可以比三次快切更强。

### 声音
- 可用动作声、突然停止、声源延迟、反应声或环境声制造信息缺口。
- 不用无因的撞击音、升调音效、警报声替代真实戏剧张力。

### 色彩与视觉主次
- 高冲击 Hook 必须在后台建立首屏色彩合同：`主环境色 → 轮廓锚点色 → 唯一强调色 → 肤色/产品色保护 → 高光与暗部分离`；详细方法唯一归属 `camera-light-quality-baseline.md`。
- 色彩冲击优先来自大面积统一色域与少量高对比锚点，不来自满屏多色、过饱和或整体压暗。
- 未完成事件的关键主体、威胁或异常必须与背景形成明度、冷暖、饱和度或轮廓中的至少一种清楚分离；0.5–1 秒内不能判断看哪里时，先删背景杂讯而不是追加特效。
- Bridge 优先继承 Hook 的主色、强调色、形状、高光或声音，让高冲击画面进入产品正文时不发生无因的审美断层。

## 8. 商业 Hook 的额外规则

商业片默认使用**产品因果型 Hook**，至少承担以下一个职责：
- 暴露首要犹豫；
- 先展示产品结果；
- 建立欲望或身份差；
- 建立会被产品解决的生活摩擦；
- 建立与品牌核心命题直接相关的关系/事件。

默认链路：
`Hook → Bridge → 产品/品牌因果介入 → 可见证明/剧情回报`

当用户或传播策略明确把首屏停留置于产品解释之前，且品类不属于高风险限制场景，可以改用**纯停留型高冲击悬念 Hook**。此时开场允许与产品弱显性关联，但必须让 Hook 成为成片能力、品牌世界、欲望身份、结果画面或内容风格的承诺，并使用：

`未完成事件 → 升级 → 反转/答案 → 视听接力 → 产品/品牌重新解释开场`

禁止：
- 把弱关联误当成虚构权限，编造产品功效、认证、用户结果或安全事实；
- 用事故、人物、动物、暴力或奇观制造停留后无回收地硬切产品；
- 为了前三秒强度牺牲产品比例、人物身份、空间连续性或事实；
- 把卖点文字卡当作主要 Hook，除非信息本身就是核心事件且用户明确允许文字。

**正向案例**：AI视觉生成平台先展示一段独立成立的高冲击商业成片；事件反转后，镜头沿同一画面后拉，揭示它是平台刚生成的结果，再进入操作和更多案例。Hook 与界面弱显性关联，但承担了成片能力证明，并由同一结果画面回收。

**混合案例**：时尚消费品先用未完成追逐或身份误判获取停留，反转时人物手中的产品、服装强调色或同一动作接力进入正文；既保留纯停留强度，又让品牌世界重新解释开场。

**反例**：医药价格广告先播放与服务无关的鲨鱼袭击，随后直接硬切价格卡。危险事件既不证明能力，也不承载真实痛点，并可能把危险感错误投射到医疗服务，不启用该模式。

## 9. 剧情与短剧 Hook 的额外规则

剧情 Hook 优先建立“关系或事件上的未完成”，而不是把最终高潮提前浪费。

优先顺序：
1. 事件已经发生一半；
2. 人物做了不符合当前关系的动作；
3. 某人知道观众不知道的信息；
4. 观众知道人物不知道的信息；
5. 一个结果先出现，但真正代价未揭示；
6. 反应先于刺激源；
7. 冲突即将发生，但先留一个细节让观众误判。

首 3 秒只需要建立一个主要未知，不要同时抛 4 个角色、3 个地点、2 条世界观和一堆字幕。

## 10. UGC Hook 的额外规则

UGC 的强 Hook 要保留“像真人顺手拍到”的可信度。

优先：
- 直接从正在发生的动作开始；
- 自然失误/停顿/重新看一眼；
- 先展示异常结果；
- 对镜头提出一个具体判断题；
- 手持镜头追随真实事件；
- 产品在真实使用路径中被发现，而不是正中央静态摆拍。

避免：
- 电影级巨物奇观和过度调度破坏 UGC 原生感；
- 人物一开口就完整报品牌+功能+价格；
- 夸张瞪眼、捂嘴、尖叫等模板 AI 反应。

---

## 11. 参考视频反推时的 Hook 蒸馏

分析参考视频时，不只记录“前三秒发生了什么”，还必须回答：

1. 第一帧给了什么确定信息？
2. 观众自然预测是什么？
3. 哪一拍打破了预测？
4. 具体制造了什么问题？
5. 答案延迟了几个有效节拍？
6. Bridge 用了动作、人物、声音、运镜还是剪辑？
7. Hook 与后文主题是什么因果关系？
8. 若替换行业/人物/产品，这个机制能否迁移？

蒸馏时只保留**机制**，不机械复制表面元素。不得总结成“钓鱼要放大鱼”“餐馆要陌生人靠近”“五金店要大扳手”之类案例模板。

正确抽象：
`表面案例 → 预测 → 偏差 → 观众问题 → Bridge → Payoff → 可迁移机制`

## 12. Hook 验收门槛

任何依赖黄金 3 秒的方案，在后台逐项检查：

- **首帧可读性**：0.5–1 秒内是否知道该看哪里？
- **预测存在**：观众是否有一个自然的“下一秒预期”？
- **偏差清晰**：实际发生的事是否明显偏离预期？
- **问题具体**：能否一句话写出观众想知道的问题？
- **未完成性**：开场是否留有尚未闭合的动作/身份/关系/因果/结果？
- **延迟有效**：答案是否没有过早说完，同时中间每拍都有新价值？
- **相关性/回收**：标准 Hook 是否与正文共享同一因果链；`attention-first-hook` 是否至少承担能力、品牌世界、身份欲望、结果画面或内容承诺，并由 Bridge 重新解释？
- **强度匹配**：Hook 的情绪、危险、奇观是否与正文承接能力匹配？
- **真实性**：是否为了抓眼破坏人物、产品、物理、空间或证据可信度？
- **记忆回收**：后文是否有回答、反转、证明或视觉回声，让开场值得存在？

若“具体问题”“所选模式的相关性/回收”“真实性”任一项失败，Hook 必须重做；不能靠更快剪辑、更响声音或更多特效补救。

## 13. 启发式强度模型

只用于后台比较候选 Hook，不作为对外数学结论：

标准模式：

`Hook 强度 ≈ 预测误差 × 问题强度 × 未完成性 × 答案延迟质量 × 主题相关性 × 首帧可读性`

`attention-first-hook` 模式：

`Hook 强度 ≈ 预测误差 × 问题强度 × 未完成性 × 答案延迟质量 × 视听回收质量 × 首帧可读性`

其中任何一项接近零，都可能让 Hook 失效。尤其：
- 标准模式中预测误差高、主题相关性低 = 假 Hook；注意力优先模式中预测误差高、视听回收低 = 无效诱饵；
- 问题强、首帧不可读 = 混乱；
- 延迟长、每拍无新增价值 = 拖沓；
- 奇观强、真实性低 = AI 噪音；
- 相关性高、预测误差低 = 信息正确但容易划走。

候选开场超过一个时，优先选择：**最短时间形成具体问题，同时最自然进入正文的版本。**

## 14. 输出纪律

本模块的“普通开头、观众预测、候选机制、评分、自检、为什么这样设计”等全部属于后台导演推理，默认不得原样写入最终视频提示词、创意大纲或分镜。

最终成品只呈现被选中的可见结果：
- 首帧状态；
- 正在发生的动作；
- 异常/信息缺口；
- 人物或环境反应；
- Bridge；
- 后续 Payoff。

用户明确要求“分析 Hook 思路/解释为什么”时，才外显该推理。
