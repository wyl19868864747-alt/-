# 摄影机与构图联合决策层

## 1. 作用

本层不是摄影术语词典，而是把叙事目的压缩为可执行的摄影选择。内部完整判断，最终提示词只保留真正影响画面的少量摄影信息，不让机位、景别和构图抢占主体动作、表演、环境与事件描述的带宽。

核心链路：

`镜头为什么存在 → 人物/产品/空间谁是主信息 → 观众应处于什么心理位置 → 景别 → 摄影机与主体关系 → 高度/角度 → 构图 → 必要焦段/透视 → 必要运镜 → 相邻镜头承接 → 摄影短标签`

禁止先随机选“电影感机位”或“高级构图”，再补叙事理由。

## 2. 每镜后台联合判断

每镜至少在后台快速检查以下六组变量，但不要求全部外显：

1. **景别**：大远景、远景、全景、中全景、中景、中近景、近景、大特写、插入特写。根据“人物与环境谁更重要、信息需要读到多细”决定，不把某景别机械绑定某情绪。
2. **关系机位**：正面、3/4正面、侧面、3/4背面、背面、A肩后拍B/OTS、POV、前景遮挡式观察/窥视。先回答“观众现在是平等交流者、旁观者、跟随者、参与者还是观察者”。
3. **高度/角度**：平视、肩高、腰/膝高、地面机位、轻低、高低角度、极低虫视、轻高、高角度、鸟瞰、正顶视、荷兰角。高度与角度不和固定情绪一一对应，必须结合主体占比、环境、距离、构图和剧情状态共同判断。
4. **构图**：三分、中央、对称、非对称平衡、负空间、填满画框、引导线、框中框、前景构图、深度构图、对角线/动态构图、几何/放射构图；同时检查 headroom、look room、lead room、主体尺度与视觉重量。
5. **焦段/透视**：只在它明显改变空间关系或视觉意义时强调。超广/广角用于强透视、环境与近距离冲击；自然区间用于生活、对话、观察；中长焦用于人物突出；长焦用于空间压缩与远观。不要为了专业感每镜强写毫米数。
6. **运镜**：先运行“是否真的需要动”。只有信息、关系、注意力、空间或证据发生变化时才运动；否则固定等待。

## 3. 机位与构图必须联合求解

机位决定“观众从哪里看”，构图决定“画面元素如何组织”；两者必须服务同一个叙事目标，而不是分别从两个术语表随机抽取。

常用联合方向：

- **平等自然交流**：平视 + OTS/3/4正面 + 中景/中近景 + 三分或非对称平衡。
- **人物获得优势**：轻低机位 + 主体视觉重量增加 + 稳定中央/偏中央构图；是否推进取决于关系是否正在变化。
- **人物孤立/环境压过人物**：高位或远距离 + 小主体 + 大负空间；不必机械使用俯拍。
- **主观体验**：POV + 与角色身体和视线一致的构图；不能只写“POV”却保留不可能的第三人称机位。
- **被观察/窥视**：远距离或长焦倾向 + 前景遮挡/框中框 + 偏侧构图；保留观察者与主体之间的空间证据。
- **巨大主体/产品奇观**：贴地或低机位 + 广角透视 + 引导/汇聚线 + 强主体尺度；高成本奇观时优先稳定摄影机。
- **秩序/仪式/精密产品**：平视或正顶视 + 对称/中央/几何构图；只有叙事需要时才追求绝对对称。
- **心理失衡/异常**：先由事件证明失衡，再考虑荷兰角、偏置或对角线；禁止把荷兰角当“电影感滤镜”。

## 4. 双人和多人构图

### 双人

先确定关系，再决定谁占视觉优势：

- 平等对话：OTS正反打、双人中景或侧面双人构图，保持视线方向、轴线和头顶/视线空间一致。
- 一方占优：通过主体尺寸、前景肩部比例、焦点、画面位置和轻微高度差建立优势，优先微调，不默认极端仰俯拍。
- 关系变化：当信息优势、情绪或权力真正变化时，才允许机位高度、距离、主体占比或构图重心随之改变。

### 三人以上

先决定镜头主信息是“群体关系”还是“某个人反应”：

- 群体关系：优先层次清楚的三角、前中后景、对称/非对称群组或深度构图，避免人物横向排队。
- 某人反应：先用群体镜建立空间，再用可承接的单人/双人构图切入；不要让每个人都获得无理由特写。
- 多人对话必须继承轴线、视线和屏幕方向；必要时先用建立镜或中性机位重置空间。

## 5. 运动主体与动态构图

运动中的构图不是固定模板，而是随主体目的变化：

- 主体向某方向移动时，通常给运动方向适量 lead room；故意压缩前方空间必须有“受阻、逼近、冲突或局促”的叙事理由。
- 摄影机跟随时，先决定领先、同步、落后还是反向对抗，再维持可读主体尺度和视觉重心。
- 人物从画面一侧进入、穿过、离开时，构图重心可随动作转移，但不要无事件地左右漂移。
- 产品操作、递接、开合、倒出等动作优先让接触点和结果进入最清楚的构图区域，不为了漂亮遮挡证据。

## 6. 相邻镜头的构图衔接

单镜漂亮不代表剪辑成立。相邻镜头额外检查：

- 视线匹配与180度轴线；
- 动作方向和屏幕方向；
- 景别是否有合理变化，避免无意义近似重复；
- 视觉重心是否发生过大跳变；
- 主体尺寸、头部位置和视线高度是否造成不必要跳切；
- 动接动、静接静，或明确设计的动静反差；
- 是否通过视线、动作、形状、前景遮挡、声音、颜色或空间位置完成承接。

若跨轴是必要叙事选择，必须通过摄影机可见移动、中性镜头、主体越轴或明确空间重建完成，而不是直接跳到错误侧别。

## 7. 摄影短标签输出协议

后台完整思考，前台极简表达。普通镜头只输出真正影响画面的 2–4 项摄影变量，通常控制在约 10–30 个中文字；特殊镜头才增加焦段、遮挡、透视或运动信息。

推荐顺序：

`（关系机位 + 景别 + 特殊角度/高度 + 核心构图 + 必要时焦段/运镜）`

示例：

- `（A肩后拍B，中近景，平视三分构图）`
- `（轻高机位远景，人物偏下三分，大面积负空间）`
- `（前景遮挡式长焦远观，人物偏右三分）`
- `（贴地低机位广角仰拍，汇聚线中央构图）`

短标签之后立即进入主体画面：人物动作、微表情、产品行为、环境反应、声音和结果。不得把构图理论、选择理由或完整摄影参数表写入最终可复制提示词。

若某项对画面没有决定性影响，省略它。固定思考六组变量，不固定输出六组变量。

## 8. 验收

- 机位、景别和构图是否都能回答同一个镜头叙事目的；
- 是否先判断观众心理位置，再选择摄影机位置；
- 是否避免“低角度=强、高角度=弱、近景=悲伤”等机械映射；
- 双人/多人是否保持轴线、视线、空间层次和视觉优势关系；
- 运动主体是否保留合理 lead room 与可读动作证据；
- 相邻镜头是否存在构图、重心、景别、视线和动作承接；
- 最终摄影短标签是否足够短，不抢占主体画面描述带宽；
- 删除摄影术语后若画面意义不变，是否可以进一步省略。
