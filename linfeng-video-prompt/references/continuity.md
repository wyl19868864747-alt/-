## 1. 空间坐标

选择模型能看见且不会变化的实体作为锚点：门、窗、墙缝、桌角、车道、灯具、建筑边缘。必要时先定义北南东西或画面左右，但最终动作仍落到实体上。

同一对象始终使用同一名称。不要在相邻镜头把“目标大厦”“同侧墙体”“右侧楼宇”混用。

## 2. 人物站位句式

复杂连续场景中的关键角色才按需包含；简单单人单动作直接写实体锚点、路径与完成态：

```text
人物A起始位于[实体锚点]的[相对位置]，身体朝向[对象/方向]；
从[画面边/门/远景]沿[路径]进入；
在[动作发生时刻]到达[停点]；
镜头结束时停留/离开于[位置]，下一镜从该位置承接。
```

多人场景额外说明人物关系：谁在前景、谁在背景、谁遮挡谁、谁与谁隔桌相对、摄影机位于轴线哪一侧。

## 3. 动作状态接力

多镜任务必须在写下一镜之前执行 `prompt-compilation-and-consistency.md` 第4节的六问与状态交接；后台状态表保留所有后续相关对象，出画不等于消失：

| 状态 | 镜尾必须明确 | 下一镜必须继承 |
| --- | --- | --- |
| 手别 | 哪只手持有/发射 | 同一只手仍在相同一侧 |
| 道具 | 数量、连接对象 | 不凭空新增或消失 |
| 运动 | 速度方向、身体朝向 | 首帧沿同方向继续 |
| 空间 | 与墙/桌/人物的距离 | 新机位仍保持同一几何关系 |
| 接触 | 是否已碰到、哪部分先接触 | 不重复接触动作 |
| 目标 | 目标相对锚点的位置及既定路径 | 不能与追逐主体换位或无因漂移 |
| 相机 | 镜尾世界位置、轴侧、观察方向与可见范围 | 据此决定下一首位，不能只换摄影标签 |

Movement Must Explain Position Change：位置变化须有走近/绕行/后退；朝向变化须有转头/转身；高度变化须有起身/跳下；持物变化须有拿起/放下/掉落/交接；房间变化须有门口、通道路径或明确的换场建立。先继承再转换，不能先写新位置后用“保持连续”解释。

固定锚点不随相机移动；画面左右可因投影改变，需从实际机位推出，不能误当世界位置变化。镜尾红毯歪挂在背部，下镜仍是同一块歪挂红毯，不能变成已穿好的披风。状态标签只在后台用，输出以相邻镜头中的自然动作体现。

阶段状态也必须继承：已湿、起泡、冲净、擦拭不能无因重置。开场处于使用中途，就继续当前阶段；冲净后不能在下一镜恢复未冲泡沫。对“同一次完整流程”的检查按时间轴实际发生顺序进行，不能只信最后的流程总结。

## 3A. 运动所有权与到达后接续

多人场景每镜先标明谁实际移动、谁保持原地；画外角色仍继承上一位置。只有看到某角色自己的起步、路径或成立的时间转场，才更新其坐标。不能因为主角向目标移动，就默认配角跟随。

跨区域／往返／一动一静的高风险移动段，具体执行 spatial-handoff-lock.md：优先使用连续观察走廊，让人物远离／返回造成的距离变化在画面里可见；到达后若切近景，保留一个同地地标、前景或受光方向证明角色仍处新地点。

## 4. 复杂镜头拆分

按 `director-information-control.md` 的默认切镜密度寻找动作节点，不平均等分秒数：

1. 建立状态。
2. 启动动作。
3. 产生不可逆结果。
4. 切镜并继承结果。

示例：下降 → 手腕特写发射 → 绷紧后切镜 → 大厦外墙固定等待 → 人物沿弧线入画 → 掠过后切镜 → 侧后方跟拍接近墙面 → 接触墙面后进入跑墙镜头。

若甩镜容易导致空间崩坏，可用动作匹配硬切代替。视觉张力不必依赖连续复杂运镜，可来自速度差、由小变大、近距离掠过和景别突变。

## 5. 物理检查

- 重力：无支撑时身体应持续下坠或沿既有惯性运动。
- 拉力：连接物绷紧后，运动方向应向锚点切线改变，不应瞬间直角转向。
- 接触：跑墙需要鞋底短暂压实墙面，步序明确，身体重心向运动方向推进。
- 释放：松开连接物后它不再继续牵引人物。
- 尺度：楼层、车辆、人物尺寸共同建立高度，避免只写“很高/不太高”。
- 摄影机：高速运动时优先保持单一轴线和稳定地平线，避免人物、墙面与摄影机同时旋转。

## 6. 一镜到底连续性

一镜到底不是把多个分镜删掉“硬切”二字，而是从首帧到末帧只有一条连续摄影机轨迹。先建立以下状态，再划分时间节拍：

| 连续状态 | 每个节拍必须说明或继承 |
| --- | --- |
| 摄影机 | 当前方位、高度、朝向、移动方向与速度 |
| 光学 | 同一物理镜头、焦距或明确的连续变焦、焦点距离 |
| 人物 | 站位、朝向、视线、手别、湿润/妆发/服装状态 |
| 产品/道具 | 在谁手中、相对人物的位置、朝向、是否接触台面 |
| 光线 | 世界空间中的主光方向、遮挡关系、人物受光面 |
| 时间 | 正常速度、速度坡度、慢动作区间和恢复点 |

相邻节拍若无法用一句可见动作解释状态怎样到达下一位置，就存在隐性切镜或瞬移。优先补过渡动作；补不出来时取消一镜到底或修改设计。

同一条连续拍摄默认只使用一个定焦镜头。若写两个定焦焦段，必须改为一个焦段配合摄影机移动，或明确使用变焦镜头并写出连续变焦过程。

## 7. 产品与道具轨迹

产品广告中，产品本身也是角色。全程锁定：数量、几何比例、瓶盖/标签/按钮位置、液体高度与颜色、朝向、持握手和接触面。

从“低握在手中”到“举至颈侧”再到“站在台面”的连续镜头，至少包含：手臂抬起 → 稳定持握 → 放下路径 → 瓶底接触台面 → 手指松开 → 手离开。若时长不足以展示放置动作，末段不要让产品凭空出现在台面；改为始终由人物持握或重新设计连续遮挡过渡。

玻璃、液体、金属等材质变化必须由光线、角度、冷凝或运动触发，不能让瓶体结构随着反射改变。

## 8. 焦点、曝光与速度连续

- **焦点**：先说明焦点当前落在哪里，再写焦点沿景深架到新主体；拉焦只改变清晰平面，不改变主体位置或尺寸。
- **曝光**：画面绽白必须由镜头进入直射光、反射面掠过或曝光呼吸触发；离开光轴后按同一路径恢复，不能无原因整片闪白。
- **光源**：摄影机绕到人物另一侧时，光在画面左右的位置可以改变，但光源在场景中的世界方向不变。
- **慢动作**：使用平滑速度坡度进入和退出；如果最终交付为 24fps，可把液滴/雾气写成高帧率质感，但不要让人物动作和摄影机运动无预警跳速。

## 9. 轴线、银幕方向与重建

轴线不是“永远把摄影机放在人物右侧”。同一行动段锁定：

- 人物或车辆的行进方向；
- 多人物在画面中的左右排序；
- 对话视线方向；
- 门、道路、桌面、墙体和入口出口的空间地理；
- 主光在世界空间中的方向。

摄影机可以在轴线同侧改变前后距离、景别、前景遮挡、侧前/侧后关系和固定等待，让镜头有变化又不破坏银幕方向。

默认同轴同侧切换观察角，不越轴；只有用户明确要求跨轴设计时，使用一种有动机的重建：摄影机连续可见地穿越；人物主动穿轴；经过正面/背面的中性机位；或换场后用建立镜重新确认人物排序、行进方向和主光。新轴成立前，不直接切到相反方向的紧景。

雨林队伍、追逐或多人行进不机械锁死单一右侧机位。先保持队伍前进方向和人物排序，再用同侧前方等待、侧后跟拍、前景遮挡、深景空间建立丰富视角；不主动用越轴凑变化。

## 10. 车门与上下车动作链

车门、上下车属于人物与大型道具的连续接触，按不可逆动作节点设计，不用遮挡或换景省略关键因果：

- **上车**：人物接近车辆 → 手触碰并操作门把手 → 手臂施力，门体绕真实铰链打开 → 人物转身或俯身，先让脚/腿和骨盆依次跨过门槛 → 身体重心落到座椅 → 另一只脚收进车内 → 手从车门内侧施力 → 门体闭合并锁止。
- **下车**：车内人物先操作内侧门把手 → 手臂推开车门 → 一只脚先落到有支撑的地面 → 身体重心移到该脚 → 骨盆和躯干跨出门框 → 另一只脚离开车内 → 人物站稳后转身拉门 → 门体闭合并锁止。
- 门体只能由人物手部、真实自动门机构或明确外力驱动；手与门把手、门内侧或门缘的接触点、施力方向和释放时刻可见，门体运动后人物与车辆产生相应遮挡、反射和身体避让。
- 按动作完成态切换景别：全景/中大全景建立人物、车辆、车门与地面关系；手部近景证明把手操作和施力；脚步近景证明跨门槛、落地或收脚；中景承接落座、起身、拉门或关门。相邻镜头继承同一手、同一脚、门体开合角度、身体朝向和重心状态。
- 遮挡转场只发生在上一动作已经形成可读完成态之后。车门覆盖画面可以连接“门已打开后的继续进入”或“人物已落座后的关门”，不能把尚未发生的开门、身体跨越或落座结果藏在遮挡内部。

当人物全程已在车内、车辆仅行驶，或车门动作不承担叙事、产品证明与空间变化时，不额外增加开门、上下车特写或完整动作链。

场景拓扑和身份只定义一次；各镜先继承既有状态，再写变化和当镜必需的位置、视线、接触关系。人物编号只锁身份，世界方位与当前画面左右分句表达。
