# 实拍可信度检查｜One-Error Reality Patch

用于实拍感不足、材质塑料化、动作失重、产品漂移、景深失控、环境空洞或超现实画面“像AI合成”的诊断。

本模块只做一件事：**找出当前镜头最可能暴露AI感的一个问题，并用最短可见结果修正。**

优先级低于主体、事件、动作和连续性，高于空泛“高级感”与装饰性摄影词。

核心判断不是“有没有写相机/景深/材质”，而是：

`REALITY = 摄影透视 + 信息层级景深 + 光线/材质反馈 + 动作重量/次级运动 + 空间接触 + 环境生活痕迹`

这些是内部诊断维度，不得机械全部写进最终Prompt。

## 1. 默认检查顺序

1. **接触**：脚、轮胎、产品、家具是否真正落在承载面上。
2. **比例/结构**：人物、产品、包装、道具是否在推进或运动中突然变形、变大、换结构。
3. **动作重量**：是否存在发力、接触、响应、惯性、次级运动和停止。
4. **空间视差**：摄影机移动时前中后景是否像真实空间，而不是一张平面贴图。
5. **材质 × 受光**：当前关键材质是否产生符合表面的反射、折射、漫反射、透光或微瑕疵。
6. **景深/焦点**：景深是否服务当前信息，而不是无脑全片大光圈虚化。
7. **环境生活痕迹**：真实场景是否像被使用过，而不是空舞台或样板间。
8. **环境互动光**：人物/产品是否真正处于同一光照世界。

## 2. 动作重量 + Secondary Motion

不要只描述主体主动作。高速转身、急停、拿取、奔跑、布料/毛发/挂件运动等镜头，必要时使用：

`Primary Motion → Secondary Motion → Settle`

例如：
- `人物快速转身，身体先完成方向变化，发梢和衣摆因惯性稍后跟随并自然回落。`
- `她把包放到桌上，包体先接触桌面，肩带随后滑落并停住。`

次级运动用于证明重量与惯性，不是额外炫技。静态或低风险镜头不强制补。

## 3. 景深服务信息层级

真实感不等于“浅景深”。景深先回答观众此刻需要读什么：

- 建立空间/多人关系：保留更多前中后景信息，不要把环境全虚掉；
- 人物理解/反应：中等或偏浅景深，把注意力收向人物；
- 产品、表情、材质特写：必要时浅景深，背景自然退焦；
- 关键空间证据/屏幕/操作：确保需要同时理解的信息处于可读焦平面。

禁止把“电影感”机械翻译成全片浅景深。焦点和景深只在它们改变信息层级时进入Prompt。

## 4. 材质必须写成「表面 + 光线反馈」

仅写“毛发细腻、金属真实、玻璃高级”信息不足。需要材质控制时优先压成可见受光结果：

- 毛发：`细碎毛束保留分离度，边缘逆光处有轻微透光。`
- 棉布：`柔和漫反射，受力处形成真实褶皱，不呈塑料高光。`
- 金属：`边缘出现窄而稳定的真实高光，随角度变化而移动。`
- 玻璃：`边缘透明折射可见，最亮处不过曝成死白。`
- 皮肤：`保留轻微毛孔、油脂与局部色差，不统一磨成蜡面。`

只描述当前最重要的1–2种材质，不做材质百科。

## 5. Lived-in Environment｜真实环境不是样板间

生活化、剧情、UGC或现实世界广告中，场景允许存在受控的不完美：

- 轻微使用痕迹；
- 非绝对对称的自然摆放；
- 少量真正属于这个空间的杂物/线缆/磨损；
- 背景人物或物体有自己的低权重状态；
- 光线可以存在局部暗部、遮挡与不完美分布。

这些细节只负责证明“这里真的有人生活/工作”，不能抢主体和产品。

高端不等于无生活痕迹；但棚拍、极简空间、无菌实验环境等任务不机械加入杂物。

## 6. 常见一条式补丁

默认**最多补1条**；复杂高风险镜头最多2条，但必须分别解决不同失败点。

- 漂浮 → `鞋底紧贴地面，保留轻微接触阴影。`
- 产品漂移 → `推进过程中瓶身尺寸和包装结构保持稳定。`
- 高速动作僵硬 → `身体先转向，头发和衣摆稍后跟随并自然停住。`
- 玻璃塑料感 → `玻璃边缘保持透明折射，高光不过曝成死白。`
- 横移贴图感 → `前景移动快于远景，形成自然空间视差。`
- 景深滥用 → `人物与关键环境关系同时可读，只有远背景自然退焦。`
- 环境空洞 → `保留少量真实使用痕迹与自然摆放，不做空舞台式背景。`
- 环境脱节 → `火光只轻微影响人物朝向火源的一侧。`

不要把以下术语机械全写进Prompt：
`接触阴影、反弹光、高光滚降、空气透视、景深、运动模糊、PBR、HDR、视差、次级运动`

先翻译成观众能看见的结果。

## 7. 超现实/奇观的现实底盘

如果只有一个元素违反现实规则，其余部分反而要更可信：

`异常强度越高 → 现实锚点越稳定`

保持：
- 熟悉且可信的空间；
- 稳定人物/产品身份；
- 一致受光和材质；
- 正常重力、遮挡、接触和惯性；
- 摄影机像真实摄影师在现场，而不是全知CG镜头。

奇观完成后，必要时让摄影机减速/稳定，让结果真正可读；具体节奏交给 `rhythm-function-control.md`。

## 8. 不需要补丁的情况

- 当前镜头本来就是动画、插画或明确非写实媒介；
- 主体和事件已经稳定，没有明显物理失败风险；
- 补丁只会重复全局或前文信息；
- 为了“更电影”“更高级”才想加入；
- 补丁文字开始比主体/动作描述更长。

最终原则：

**真实感不是相机参数套餐，而是现实世界对动作、光线、材质、景深和环境留下的共同证据。**
