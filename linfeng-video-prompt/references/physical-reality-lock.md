# 实拍可信度检查｜One-Error Reality Patch

用于实拍感不足、材质塑料化、动作失重、产品漂移或环境空洞的诊断。

本模块只做一件事：**找出当前镜头最可能出现的一个AI错误，并用最短可见结果修正。**

优先级低于主体、事件、动作和连续性，高于空泛“高级感”与装饰性摄影词。

## 默认检查顺序

1. **接触**：脚、轮胎、产品、家具是否真正落在承载面上。
2. **比例/结构**：人物、产品、包装、道具是否在镜头推进或运动中突然变形、变大、换结构。
3. **动作重量**：是否存在发力、接触、响应、惯性和停止。
4. **空间视差**：摄影机移动时前中后景是否像真实空间，而不是一张平面贴图。
5. **材质**：只检查当前最重要材质是否有可信受光/折射/反射。
6. **焦点/模糊**：只有视觉焦点混乱或高速动作僵硬时才控制。
7. **环境互动光**：只有人物/产品与环境明显脱节时才补。

## 输出纪律

默认**最多补1条**；复杂高风险镜头最多2条，但必须分别解决不同失败点。

不要把以下术语机械全写进Prompt：
`接触阴影、反弹光、高光滚降、空气透视、景深、运动模糊、PBR、HDR、视差`

先翻译成可见结果：
- 漂浮 → `鞋底紧贴地面，保留轻微接触阴影。`
- 产品漂移 → `推进过程中瓶身尺寸和包装结构保持稳定。`
- 玻璃塑料感 → `玻璃边缘保持透明折射，最亮处不过曝成死白。`
- 横移贴图感 → `前景移动快于远景，形成自然空间视差。`
- 对焦混乱 → `眼睛清晰，背景自然退焦。`
- 高速动作僵硬 → `快速转身时发梢短暂产生方向性模糊，停稳后恢复清晰。`
- 环境脱节 → `火光只轻微映到人物朝向火源的一侧。`

## 不需要补丁的情况

- 当前镜头本来就是动画、插画或明确非写实媒介；
- 主体和事件已经稳定，没有明显物理失败风险；
- 补丁只会重复全局或前文信息；
- 为了“更电影”“更高级”才想加入；
- 补丁文字开始比主体/动作描述更长。

最终原则：**真实感是修错层，不是固定装饰层。**
