# 实拍可信度检查

用于实拍感不足、材质塑料化、动作失重或环境空洞的诊断。优先级低于用户媒介和事实，高于空泛“高级感”与装饰。动画保留动画，超现实保留声明的幻想机制，只检查相容的局部物理。

1. **光有来源**：人物、产品和环境共享可定位的受光、阴影与反射。细则唯一归属 `camera-light-quality-baseline.md`。
2. **材质有区别**：皮肤、布料、金属和木材各有表面与受力证据；只写当前能看见的微小纹理或使用痕迹。新商品和无菌棚拍不强行做旧。
3. **摄影机有位置**：移动用于跟随、发现、关系或证据；固定、实体手持、追拍惯性按媒介选择。细则见 `director-camera-attention.md` 与 `observational-camera-authenticity.md`。
4. **动作有重量**：起始状态、发力、接触、响应、惯性与停止成立；复杂交互按 `spatial-optics-physics-control.md`，跨镜继承按 `continuity.md`。
5. **环境支持事件**：少量合理摆放、使用痕迹或背景活动说明世界存在；无需堆满物件，用户明确的极简与棚拍照常保留。
6. **光学符合媒介**：景深、模糊、颗粒、高光与曝光行为一致，不用全画面锐化代替细节。灯光、结构或动作错误时先修原因，再加风格。

本文件用于判断，不要求把六项全写进每段提示词。只输出当前最关键、尚未在资产/光影/分镜中表达的结果；它不另建通用负面词表。
