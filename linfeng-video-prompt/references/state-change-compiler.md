# State Change Compiler

目标：把导演层抽象概念编译成视频模型可见、可执行的变化，不增加无关理论。

## 何时调用
- 新写或重写视频提示词。
- 镜头里出现“荒诞升级、紧张、震惊、高级、超现实、压迫、失控、节奏加快”等抽象词。
- 用户反馈模型“看不懂要求”“只有感觉没有动作”。

## 最小结构
每个关键 Beat 至少明确：
`起始状态 → 触发 → 可见动作/接触 → 状态变化 → 反应/镜头响应 → 完成态`

不是每个镜头都要大幅运动；但关键叙事 Beat 不能只靠形容词或 fade/slide 代表变化。

## 编译规则
- 抽象情绪 → 眼神、呼吸、停顿、身体动作、与对象的互动。
- 抽象升级 → 新证据、新动作、新阻力或新状态，不重复上一层。
- 抽象“高级” → 光源、材质、构图、景深、运动稳定度和色彩关系。
- 抽象“超现实” → 现实起点 + 单一异常机制 + 可读传播过程 + 现实人物反应 + 完成态。
- 抽象“电影感” → 具体摄影媒介、世界光源、明暗层次、焦点与运动，不靠设备名堆叠。

## 删除条件
如果一句话删掉后，主体、动作、空间、摄影、光线、材质、时间、声音或可见结果都没有变化，删除。

## 例
❌ `她越来越震惊，荒诞程度升级。`

✅ `她先看见第一块屏幕停在89.97，停半秒；立刻抽出第二台计算器重新输入。两块屏幕同时停在89.97。她左右核对，眉头从紧皱变成愣住，最后缓慢抬头看向对方。`
