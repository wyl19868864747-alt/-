# 提示词编译与一致性｜High-Signal Video Compiler

本文件负责把导演判断压成模型真正需要的执行语言。最终格式归 `output-contract-and-validation.md`，光影细则归 `camera-light-quality-baseline.md`。

## 1. 核心原则

视频Prompt不是制作说明书，而是**时间中的可见事件**。

优先级：
`事件 > 动作/状态变化 > 结果 > 空间连续 > 必要镜头响应 > 光影变化 > 技术术语`

任何一句如果删掉后，事件、动作、空间、镜头、光色、材质、时间、文字或声音都不变，就删除。

## 2. Global Once, Shot Specific

全局信息只定义一次：
- 片型/媒介/调性
- 人物、产品、空间真源
- 主摄影质感
- 主光/色彩基线
- 持续声音规则

分镜只写当前发生的变化。人物没有换衣、产品没有变、空间没有变化、主光没有变化时，不重复介绍。

同一事实禁止同时出现在开场、资产、光影、分镜多个位置。

## 3. 保留用户强表达

用户已经给出有效的事件或镜头概念时，优先保留原意，不为了“专业”机械展开。

例如：
- `她看到价格后愣住，再看一眼。`
- `真实场景突然被产品接管。`
- `镜头后拉，发现刚才的真实场景其实是一张图片。`

这些本身已经是高信号。只有为了因果、连续性或高风险错误才补必要细节。

“电影感、超现实、高级、压迫、原生UGC”等可作为总控概念保留一次；后续只补最关键的可见兑现，不逐镜重复解释。

## 4. Beat编译

关键Beat默认使用最短可读链：

`起始状态 → 触发 → 可见动作/变化 → 完成结果 → 必要镜头响应`

不要求每次写满五项。简单镜头可压成一句。

示例：
`她看到价格后动作停住，低头重新核对，再抬头看朋友；镜头快速推近，在确认数字的一刻停住。`

复杂物理交互只保留必要因果：
`接近 → 接触 → 响应/变化 → 完成态`

只有穿戴、交接、液体、机械结构、连续变形等容易失败时，才补关键中间态。

## 5. 表演压缩

情绪优先转成短动作链，不默认展开面部肌肉清单：
- 震惊：`停住 → 核对 → 抬头`
- 怀疑：`盯住证据 → 迟疑 → 再确认`
- 紧张：`动作变小 → 呼吸收紧 → 视线快速确认出口`
- 松弛：`肩膀放下 → 呼吸变慢 → 轻笑`

只有面部特写、表演为主任务或用户要求FACS时，读取面部表情库展开。

## 6. 镜头压缩

镜头只写它对当前事件的**必要响应**。

优先使用一个明确动作：
- 推近
- 后拉
- 跟随
- 固定等待
- 甩镜
- 环绕
- 快速横移

如果事件本身已经清楚，不必额外规定焦段、景深、构图百分比、摄影机高度与运动速度。

只有以下情况才展开摄影细节：
- 透视决定叙事
- 多人轴线/空间易错
- 产品比例或边缘易变形
- 复杂一镜到底
- 参考复刻
- 用户明确指定

## 7. 光影与设备

先在后台读光影基线，最终只留下当前片真正需要的可见结果。

通常：
- 一句媒介/成像身份
- 一句主光/色彩关系

设备名只在能带来明确可见结果时出现。不把 IMAX、ARRI、UE5、Octane、VFX、8K、HDR 叠成通用高级词包。

分镜只写光线变化，例如开灯、闪光、屏幕照亮脸、从室内进入室外；全局光不重复。

## 8. 复杂度决定长度

### 简单片段
单场景、单主体、一个主动作：一段或几句即可。

### 中等片段
多Beat、少量人物关系：总控 + 锁定 + 时间轴 + 必要声音/限制。

### 高控制片段
多人换位、复杂空间、产品连续、一镜到底、多场景光线切换、长片生产：才展开表演、空间、光影、声音等独立块。

**不是时长越长Prompt就必须越长；控制难度增加才增加文字。**

## 9. 最小状态账本

跨镜只继承真正会影响下一镜的变量：

`人物位置/朝向/认知｜手别与道具归属｜产品/环境状态｜相机/焦点｜主光｜声音｜完成态`

下一段从上一完成态继续。没有变化就不重复写。

## 10. 冲突与污染检查

直接修正：
- 同时固定与环绕、同时前推与后拉等互斥镜头；
- 双手被占却执行第三个手部动作；
- 人物未到达却完成接触；
- 产品无因换款、换手、变大；
- 灯光无因随镜头换侧；
- 对结果提前反应；
- 精确对白重复出现；
- 同一个风格/质感词在多个分镜重复。

Prompt Pollution Audit：
1. 这句话是否直接影响视频结果？
2. 是否已在全局定义？
3. 是否只是解释一个模型已经懂的概念？
4. 是否只是为了显得专业？
5. 是否把可自由完成的实现锁得过细？

命中重复、解释性、低价值内容就删。

最终目标：**视频可以详细，但详细必须花在事件、动作、变化和承接上。**
