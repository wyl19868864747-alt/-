# 提示词编译、创意幅度与全文一致性

本文件是所有新写、重写和分镜转视频提示词任务的核心编译层。它只解决三件事：先形成清楚且有力度的导演判断，再把判断压缩成一读成像的提示词，最后消除总控、资产、时码、镜头和声音之间的矛盾。

## 1. 六项全片导演合同

写分镜前，后台先锁定六项；不能用形容词占位：

1. **成片任务**：片型、首要验收对象、观众最终记住什么。
2. **核心画面**：全片最值得看的一个具体视觉事件。
3. **视觉母机制**：重复或升级的运动、变化、揭示或转场规则。
4. **摄影与质感**：摄影媒介身份，以及它实际造成的透视、稳定度、焦点、运动、光线和材质结果。
5. **节奏曲线**：怎样起、哪里停、如何升级、何时释放、怎样收束。
6. **创意幅度**：克制、强化、高概念或极限奇观；同时记录不可改变的事实与允许越界的视觉变量。

内部一句话：

`这是一支[片型]，让观众通过[核心画面/事件]理解或感受[唯一结果]；以[摄影与质感]呈现，使用[视觉母机制]，节奏从[起点]经[停顿/升级]到[收束]，创意幅度为[等级]，不可改变[事实/身份/物理锚点]。`

六项合同是后续分镜的上位基线。总控承诺的快慢、真实/CG关系、色彩、摄影身份、视觉奇观和产品/剧情重心必须在时间轴中得到可见兑现。

## 2. 创意幅度与高概念增幅

事实确定性和创意幅度分开判断。产品事实、人物身份、空间和物理需要可靠；视觉提案可以大胆。不得因为用户不能准确描述脑中画面，就自动采用最保守、最常见的实现。

当用户说“视觉奇观、超现实、惊艳、大胆、有创造力、高概念、像脑海中的画面但说不清”，默认把创意幅度设为高；UGC、纯纪实或法规演示等明显不适合奇观的片型除外。后台至少快速探索三种不同机制，再只交付最适合的一种：

- 尺度、重力或空间规则被单点突破；
- 材质沿明确起点和路径连续蜕变；
- 产品、界面、包装或原料成为可进入的世界；
- 熟悉现实动作触发不可能但可读的结果；
- 屏幕、镜面、门框、摄影机取景框等边界接管现实；
- 多个元素按同一力场、轨道、形状或声音规律重组。

选择标准：`任务关联度 × 新鲜度 × 画面可读性 × 情绪强度 × 模型可执行性`。物理、连续性和模型容量是奇观的护栏，不是把奇观缩成普通漂浮、发光、粒子和无因旋转的理由。

高概念镜头必须写出：

`正常首帧 → 熟悉动作/异常触发 → 变化起点 → 传播路径与中间态 → 超预期完成态 → 产品、人物或信息落点`

“高级、高能、年轻、视觉奇观、电影感、科技感、丝滑、震撼、梦幻”只能作为后台意图。进入成品前必须转译为构图、尺度、速度、动作、材质、光线、摄影反应或声音；删除抽象词后画面仍须完整。

## 3. 成品信息预算

### 开场总控

最多三句，只回答：

1. 生成什么片，核心目的或体验是什么；
2. 使用什么视觉风格、摄影媒介和画面质感；
3. 节奏曲线和视觉母机制怎样推进。

不在总控重复平台、画幅、设备清单、风险、事实表、创作理由和逐镜细节。总控不能只说“快节奏、高能”，必须说明快来自哪些运动/剪辑/信息变化，哪里短暂停稳，怎样再次提速或收束。

### 主体、空间与参考锁定

- 每份实际素材只用一句：`[素材编号]：只锚定[唯一职责]；[仅在容易误用时补一句不参考什么]。`
- 同一素材不得同时承担身份、动作、摄影、场景和风格等互相干扰的多种职责。
- 不复述参考图里与当前镜头无关的装饰；没有素材时不虚构编号。
- 无参考素材时只用一句锁定核心主体、空间和有依据的相对比例。

### 全片视觉与技术基线

固定一句，优先写摄影身份、透视/运动、主光几何、色彩、材质与必要合成结果。只保留真正改变画面的2–4项摄影或成像信息，不列器材和软件清单。

### 时间轴/分镜

每镜通常用2–4个高密度画面句，按观看顺序写：

1. **首帧构图**：主体、空间、前中后景、光线和当前状态；
2. **可见事件**：单一主动作、路径、接触/触发、变化和即时结果；
3. **摄影机反应**：因追随、等待、发现、躲避或产品证明而移动/停稳；
4. **完成态与承接**：观众最终看清什么，下一镜继承什么状态或变量。

每句话必须新增至少一种可见或可听信息。删除后主体、动作、构图、摄影、光线、材质、节奏和声音都不改变的句子属于废话。

## 4. 一读成像门

只读提示词一次，必须能连续回答：

- 第一眼看见谁/什么，位于哪里，画面重心和景深如何；
- 主体从什么状态开始，沿什么路径做什么；
- 接触或变化从哪里发生，怎样传播；
- 摄影机为何移动或等待，最终停在哪里；
- 这一镜形成什么稳定完成态，下一镜继承什么。

若只能复述“高级、高能、超现实、情绪强烈”，却画不出首帧、动作和结果，则判定失败并重写。先补画面，不用更多形容词补救。

## 5. 时间轴状态账本

两个及以上镜头、同镜多个时段、一镜到底、角色/产品反复出现或存在状态变化时，后台建立最小账本：

```text
时段｜人物位置/朝向/认知｜手部与道具归属｜产品/环境状态｜摄影机方位/运动/焦点｜光线/时间｜声音｜本段完成态
```

只记录会跨段继承或容易冲突的变量。下一时段默认继承上一完成态；改变变量时必须出现可见触发、动作桥梁、切镜重建或明确声音桥。

## 6. Consistency Gate｜全文一致性与矛盾门

正式输出前逐项检查，任何未解决矛盾都判为不合格：

### A. 总控对分镜

- 成片任务、首要对象、摄影媒介、画面质感、色彩、节奏曲线和视觉母机制是否在镜头中得到实际兑现；
- 总控说快节奏/高能时，时间轴是否具有相应的速度差、动作密度、切点、升级和结果释放，而非通篇慢叙事；
- 总控说真实摄影时，是否出现未声明的全知CG摄影、无重力或世界重构；总控承诺奇观时，是否退化为普通漂浮、发光或界面切换。

### B. 同一时段互斥

同一主体或摄影机在同一时段只能拥有一组可兼容状态。固定机位与360°环绕、同时推进与后拉、人物位于画面左右两处、双手被占用却执行第三个手部动作、产品完整与已拆解、闭口倾听与同步说话等均为硬冲突。若动作有先后，拆成明确节拍，不用“同时”掩盖。

### C. 跨时段继承

人物位置、朝向、视线、认知、手别、道具归属、产品数量/几何/开合状态、摄影机轴线、主光世界方向、声音和异常规则必须继承上一完成态。变化必须通过触发、路径、反应和新完成态成立；不得瞬移、重复开启、提前反应、重复第一次揭示或让已停止的声音无因重启。

### D. 单镜内部可成立性

景别、景深、光线、构图和时长必须能让主任务可读；浅景深不能同时保证远近十个对象全部清楚，固定自拍不能自行靠近人物，一个短镜不能让多个高成本变化同时争夺主任务。视觉和技术命令互相排斥时，保留最服务该镜唯一职责的一项。

### E. 叙事、证据、声音与资产

- 反应发生在触发之后，结果发生在操作之后，台词/旁白只陈述画面正在证明或已建立的信息；
- 同一产品功能、剧情事实或人物知情状态不能在不同段落得到互相排斥的结论；
- 精确语言只有一个文本与一个声音源，时码不重叠冲突；
- 资产在总控、锁定区和镜头中的职责一致，不让动作参考改写人物身份，不让风格参考改写产品结构。

### F. 有动机变化不是矛盾

全片快节奏可以有一次用于读结果、制造反差或情绪转折的短暂停顿；真实世界可以在明确触发后进入超现实；稳定摄影可以在事件撞击后短暂失稳。只有写清 `触发 → 目的/新增信息 → 持续区间 → 恢复或新规则建立` 才成立。不能为了机械一致而删除有效的节奏反差、剧情转折或世界变化。

## 7. 冲突裁决与修复

发现矛盾时按以下顺序裁决：

`用户本轮硬约束 → 已确认事实/素材 → 六项导演合同 → 时间轴因果与状态继承 → 单镜唯一任务 → 局部风格和装饰`

- Skill自己造成的矛盾直接重写，不向用户转嫁判断。
- 用户输入内部冲突但主次可由目标可靠判断时，采用能完成首要目标的一项并保持最小改动。
- 两个冲突项会实质改变成片且无法判断优先级时，只问一个最高杠杆问题。
- 不把冲突内容折中成两边都不清楚的模糊句；选定一项并让时间轴完整继承。

## 8. 最终编译顺序

```text
六项导演合同
→ 素材职责与最小资产
→ 必要的高概念机制探索
→ 一读成像的时间轴
→ 状态账本
→ Consistency Gate
→ 模型容量与物理连续性
→ Duration Gate
→ 删除空话并输出
```

所有后台合同、候选机制、账本和检查表默认隐藏；用户只看到经过裁决后的单一最佳成品。
