# 提示词编译与一致性

本文件负责导演判断、自然语言编译和状态冲突；最终格式唯一归属 `output-contract-and-validation.md`，光影唯一归属 `camera-light-quality-baseline.md`。

## 1. 大脑负责判断，执行器收到结果

编写模型完成事实核实、参考分析、审美选择与能力判断，再交给视频模型可见、可听的执行描述。删掉“仔细分析、一次即可交付、为目标用户优化”等管理话。风格名可在开场概括一次，后续要用摄影、表演、光线、材质与节奏兑现；设备名也要配可见效果。

正向句优先采用 `主体＋准确动作＋对象/位置＋完成结果`。例如，把“禁止手部穿模”先改为“右手握住杯柄，杯底落稳桌面后松手”；把“不要越轴”先改为“相机留在门这一侧看向沙发，反打仍在对话连线同侧”。仍需排除的严重误读再进反向栏。

每句至少改变画面主体、动作/表演、空间/构图、摄影/焦点、光线/色彩、材质/物理、时间、可见文字或声音之一；删掉后这些均不变，就删除。同一事实只在对应层定义一次，镜头只写变化、必要承接和关键接触。

## 2. 六项后台导演合同

写分镜前简要确定：**成片任务**（首要验收对象）、**核心画面**（最值得看的具体事件）、**视觉母机制**（贯穿的运动/揭示规则）、**摄影与质感**（媒介及可见光学结果）、**节奏曲线**（起、停、升级、释放）、**创意幅度**（克制到高概念及事实边界）。简单片段可紧凑合并，不展开六张表。

这些是后台决策，不塞进【开场总述】。开场只定大概念，事件在分镜，成像在光影块，资产和空间各写在自己的位置。快节奏通过动作速度差、切点、停顿和结果释放兑现，不靠形容词。

## 3. 保住创意，再控制执行难度

用户要大胆奇观时，后台快速比较几种真正不同的机制再选最佳：尺度/空间单点突破、材质沿路径蜕变、熟悉动作触发异常、边界接管现实、产品世界化等。事实确定性与创意幅度分开；可信不等于平淡。

高概念变化写成 `正常起点 → 触发 → 变化起点与传播路径 → 可读中间态 → 完成形态 → 叙事/产品落点`。粗糙手绘可以折叠、拉伸、崩散和重新描画；不强行变成平滑CG。连续变形可共享同一幻想机制与身份标记，不把每个新形态都判成新的违规魔法。

现实层保留支撑、接触、遮挡与可达空间；幻想层明确允许改变哪些属性。手持追拍的迟疑与抖动在有因时保留，关键接触、身份揭示和最终结果仍需可读。镜头先要有看点，再合理分配时间与注意力。

## 4. 先判断复杂度，再选长度

- **简单片段**：单场景、一个清楚主动作，没有复杂交接/轴线/跨镜继承，直接写起点、路径、结果和必要光线/摄影，通常一个短段即可。
- **结构化片段**：多人关系、正反打、连续换位、物品交接、复杂一镜到底或多种状态继承，使用完整输出结构；必要时按 `spatial-optics-physics-control.md` 建立“场景拓扑—身份映射—镜头局部变化”。编号只锁身份，世界方位与画面坐标分开。

长度取决于控制难度，不固定“几秒必须几镜”或“每镜几句话”。每镜一个主要任务，按观看顺序写起始状态、动作/接触、变化/反应、摄影机响应和完成态；让句子自然连贯，不逐镜展示工程表。

动作过载先定位是哪类竞争：连续变形、跨区域移动、多人独立动作、复杂接触、对白与证据互抢。保留核心看点，先减少同时动作、拉开先后、调整镜长/切点；仍无法表达时才升级关键帧、动作参考或拆生成单元。没有实际测试，不以某个动作数宣称Seedance的硬上限。

## 5. 情绪与光影怎么落地

全局表演状态写人物的目的、初始情绪和转变方向；分镜按 `刺激 → 感知 → 理解 → 可见反应 → 决定/行动` 写，少量相容的眼神、呼吸、停顿胜过眉眼鼻嘴清单。多人反应按各自认知错峰；产品Proof镜仍以产品证据为主。

先读光影入口，给每个场景/主要灯光状态建立短基线，再写分镜。局部光通常贴在受影响主体/动作之后；如果开灯、闪光等引发反应，就先写光再写反应。全局光源不随相机换侧漂移，换场景或关灯才建立新状态。

## 6. 最小状态账本

多镜或连续多节拍在后台只记需要继承的变量：

`时段｜人物位置/朝向/认知｜手别与道具归属｜商品/环境状态｜相机位置/焦点｜主光与时间状态｜声音｜完成态`

下一段从上一完成态继续。发生变化就交代触发、可达路径、切镜重建或明确时间转换。开合、穿戴、液位、数量和已揭示信息不因换镜恢复初始；遮挡不能替代尚未发生的关键动作。

## 7. 一致性检查与修复

按输出合同集中检查，下列冲突直接返修：

- 同时固定与环绕、同时前推与后拉、双手被占却执行第三个动作、闭口听与同步说话等互斥状态；有先后就写清先后。
- 人物未到达却伸手入近景、商品无因换款/换手/变大、灯随镜头转、对结果提前反应或精确台词重复。
- 景别、景深、焦点、光线或时间使主要证据看不清；一个短窗口里多重变化没有清楚完成态。
- 风格/节奏方向与实际镜头不一致，或动作参考抢走身份/商品真源。

有动机的反差可以成立：快片短暂停稳、真人场景进入手绘幻想、冲击后镜头短暂失稳，都写清触发与新状态或恢复，不为机械一致删除看点。

裁决沿用 SKILL.md 的优先级；事实和空间正确先于装饰，后台导演选择也不能覆盖用户要求。自己造成的冲突直接改，只有用户要求互斥且无法判断主次时才问一个关键问题。生成后的失败证据与文字检查分开记录。
