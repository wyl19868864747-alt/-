# 短剧表演与对白控制

## 适用范围

用于双人/多人短剧、剧情对话、品牌剧情、谈判、争执、亲密关系戏，以及任何以人物关系、情绪变化和对白推进为主的场景。目标是提高AI视频中的表演细腻度、抢话自然度、口型与动作连续性，同时避免把提示词写成冗长的演员教科书。

## 1. 剧情对话先锁180°轴线

剧情对话在拆镜前，默认先在整场总控中锁定：

`180°轴线｜人物左右站位｜视线方向｜主要动作方向｜关键空间锚点`

后续正反打、双人镜和反应镜默认继承，不逐镜重复。这样先稳定观众空间认知，再在轴线同侧自由变化景别、侧前/侧后关系、前景遮挡和焦段。

该规则只作为剧情对话默认值，不是所有片型的强制模板。产品TVC、视觉奇观广告、环绕展示、一镜到底、360°弧线、复杂空间揭示或明确需要穿越人物关系线的商业调度，可不锁“始终同侧”；只要跨轴过程本身可见可理解，或通过中性机位、人物主动穿轴、重新建立空间让新方向成立即可。不得为了守180°原则牺牲合理的大场面调度，也不得为了炫技无因越轴。

## 2. 先建立表演状态，再写表情

核心人物先建立轻量 `Performance State`：

`此刻真正想要什么｜最怕什么发生｜用什么方式掩饰/保护自己｜什么刺激会让控制失效｜失效后语言/呼吸/动作怎样变化`

随后把状态转译为可见表演。不要直接用“很悲伤、很愤怒、很紧张、很绝望”代替因果。

当任务已经有故事大纲、剧情节拍或人物目的，并进入分镜/提示词细化时，完整读取 `facial-expression-action-library.md`。先由本节确定人物目标、掩饰与失控触发，再从表情库选择一个主状态和2–4个相容动作；只把精炼动作链补进发生反应的分段，不能把AU编号、情绪词典或整套表情公式前置到全片总控。

例如：

`想保护对方 → 不允许自己崩溃 → 回避持续直视 → 句子在关键词处失败 → 吞咽/改口 → 手抬起却失力`

这种因果链优先于形容词堆叠。

### 核心信息的目的—判断差—视听标点

商业剧情中的价格、Offer或Proof不是普通广告台词。先分别锁定：说话者想纠正/证明/推动什么，听者当前相信什么，哪个准确数字、动作或证据打破判断，以及理解后哪一项呼吸、视线、重心、手中动作、语言结构或决定改变。

价格反差可以表现为：说价者收住笑意、语速略慢、眼神稳定，把数字当成需要准确落地的事实；听者先准备反驳，数字到达后动作停住、重新核对，再用短句或身体前倾改变行动。不要让两人同时复制瞪眼、捂嘴或夸张点头。

同一核心信息点最多选择一种主视听标点，并允许一种低权重辅助：产品快速公开揭示与短促空间文字、从关系全景快速推进到稳定中近景、一次与核心词同步的手持余震/低频画面震动、焦点或构图重心反转。标点必须由人物认知或动作触发，随信息完成立即稳定；它只放大已经成立的表演，不替代人物目的和理解过程。

## 3. 微表演优先使用“未完成行为”

真实表演常来自人物想完成一件事却没有完全完成。优先使用：

- 想看对方，却在视线真正接触前后移开；
- 想说完整句子，却在关键词、名字或代词处启动失败；
- 吸气准备说话，但气息消失或被咽回；
- 手抬起后悬停、改变目的或失力落下；
- 想插话却找不到空隙；
- 嘴形成口型但声音没有出来；
- 想靠近，却停在最后一步。

失败动作必须来自人物内在冲突，并具有前后状态。不得机械循环吞咽、眨眼、摇头、喘气或重复结巴。

## 4. 抢话必须有语义触发

对白不默认整齐轮流。需要抢话、打断、退让或短暂重叠时，先找到触发点：

`某个词｜未完成句｜表情变化｜手势｜呼吸失败｜对方准备结束谈话的信号`

角色因为这个信号改变判断，才提前进入。

结构示例：

`A说到关键词/未完成句 → B判断事情将走向某个结果 → B提前进入 → 短暂重叠 → 一方退让或另一方继续`

重叠不是为了“显得真实”随机添加。先说者不能突然静音，后说者也不能像等待轮次。若模型容量有限，优先保证：

`说话人准确 → 台词顺序 → 口型 → 抢话触发关系 → 重叠精度`

亚秒级重叠时长属于低于对白正确性的软约束。

## 5. 情绪可以改变语言结构

情绪不仅影响音色，也可以改变语言本身：

- 语速突然加快或放慢；
- 句子中止；
- 启动失败；
- 重复；
- 改口；
- 寻找词；
- 吞咽后换句；
- 尾音失去声音。

只有当这些变化与人物目标和情绪阻力一致时才使用。结巴、哭腔、重复、破音不是通用“演技特效”。

## 6. 关键动作建立跨镜头状态线

重要动作不能在切镜后自动重置。后台建立最小动作状态线，例如：

`手垂下 → 抬起 → 悬停 → 失力 → 落下`

`靠近 → 停住 → 想再靠近 → 放弃`

`直视尝试 → 移开 → 再次尝试 → 彻底回避`

切镜只改变观察对象和景别，不自动改变身体朝向、手部状态、关系距离、湿润程度、呼吸状态和情绪阶段。

## 7. 表演提示词的控制优先级

复杂剧情对白按以下顺序分配控制权：

`准确对白/说话人/抢话顺序 → 核心情绪状态与表演因果 → 空间与动作连续 → 眼神/手部/呼吸细节 → 环境装饰`

不要让0.1秒级时序、一次眨眼或某个精确眼神落点与台词正确性拥有相同权重。发生冲突时，低层细节主动让位。

## 8. 前台输出保持克制

后台可以完整推演人物状态，但最终提示词只保留真正影响生成的表演结论。剧情对白镜头优先压缩为：

`当前内在状态 → 一个关键可见反应/未完成行为 → 台词或语言变化 → 对方触发/承接`

不要把所有心理解释、导演理由和同义限制重复写入每个镜头。一个规则若已经进入整场总控，后续只写发生变化的部分。

## 9. 验收

- 剧情对话是否在总控层先锁人物左右、视线和180°轴线；
- 跨轴是否有可读过程或空间重建；
- 表演是否来自人物目标与阻力，而非形容词堆叠；
- 是否存在至少一个有意义的未完成行为，而不是连续“表情动作”；
- 抢话/重叠是否有明确语义或动作触发；
- 情绪是否真正改变语言结构，而不只是“更悲伤地说”；
- 关键手部、视线、身体和情绪状态是否跨镜连续；
- 对白与说话人准确性是否优先于亚秒级微动作伪精确；
- 最终提示词是否只保留可见、可听、可执行结果，没有因为学习细腻表演而明显膨胀。
- 表情是否由当前镜头中的可见刺激触发，并按出现、峰值、释放或下一行动动态变化，而非静态挂脸；双人是否错峰反应、跨镜是否继承同一表情阶段。
