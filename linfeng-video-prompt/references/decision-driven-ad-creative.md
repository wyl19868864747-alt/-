## 1. 使用边界

本文件负责把消费者决策转成创意事件。商品事实、品类、尺度、素材角度和证据权限先以 `product-preflight-and-category-routing.md` 为准；本文件不能扩大证据边界。

在需要从产品卖点反推广告创意、建立 Hook、降低购买犹豫、强化信任/转化、设计功能证明，或用户只给产品而没有表现方式时加载本文件。它适用于转化型TVC、功能型TVC、UGC、电商广告、产品演示和承担商业目标的剧情式短片。

以下任务默认跳过或只做轻量检查：

- 用户已经确认完整创意、分镜或参考片结构，只要求执行、编辑或局部修改；
- 纯时尚、艺术、情绪或品牌宣言片，没有功能证明和直接转化任务；
- 普通短剧，产品不承担传播目标；
- 用户只要求摄影、转场、动作或技术参数修复。

本模块只决定“为什么这样创意、用什么证明”，不把策略分析原样塞进最终生成提示词。每条短片只选择一个主决策、一个首要犹豫和一个核心证明；其余内容降为辅助。

## 2. 核心创意链

先建立以下后台链路：

`商品事实 → 主决策 → 首要犹豫 → 所需证据 → 戏剧化Hook → 产品因果介入 → 可见证明 → 情绪/状态回报 → Hero Shot/CTA`

逐项判断：

1. **商品事实**：先锁定产品身份、真实功能、尺寸、结构、使用方式和声明边界。
2. **主决策**：观众购买时最需要确认什么，只选一个。
3. **首要犹豫**：什么具体不确定性最可能阻止行动；把宽泛痛点压缩为可拍事件。
4. **所需证据**：观众看见什么才有理由相信，不用形容词代替。
5. **戏剧化Hook**：让犹豫以反常结果、生活摩擦、未完成动作、倒计时、对比状态或人物反应进入首个节拍。
6. **产品因果介入**：产品通过真实使用、结构、材质或功能改变事件，不无因闪现。
7. **可见证明**：动作、环境、材料、身体或任务状态产生可观察结果。
8. **回报与收束**：用人物节奏、关系、空间或感官状态的变化完成情绪回报，再进入产品记忆和行动。

把创意价值作为启发式判断，而非数学打分：

`创意价值 ≈ 犹豫重要性 × 证据可视性 × 戏剧张力 × 品牌独占性 × 媒介适配`

某一项明显接近零时，先换创意机制，不用更炫的摄影掩盖。

## 3. 决策家族与首要犹豫

不要先按固定品类套场景，先判断产品属于哪种购买决策。同一商品在不同受众和用途下可以进入不同家族。

| 决策家族 | 典型犹豫 | 优先证明 |
| --- | --- | --- |
| 适配与兼容 | 放不下、装不上、不适合我的设备/身体/空间 | 尺度参照、安装过程、接口或穿戴关系 |
| 功能与效果 | 到底有没有用、效果是否明显 | 触发—过程—结果、状态前后对比 |
| 品质与耐用 | 是否廉价、易坏、寿命短 | 材料细节、结构受力、反复使用或可靠测试 |
| 易用与效率 | 会不会复杂、费时、学习成本高 | 最短操作链、步骤减少、任务完成时间 |
| 舒适与感官 | 会不会吵、闷、黏、刺、勒或难闻 | 人体反应、声音、纹理、温度、气流或贴合变化 |
| 安全与风险 | 是否伤人、漏液、过热、刺激或不稳定 | 防护结构、真实边界、稳定状态和可信验证 |
| 真实性与信任 | 是否货不对板、夸大、伪造评价 | 实物细节、自然使用、限制条件、可核验来源 |
| 价值与成本 | 值不值、是否浪费、是否需要额外配件 | 使用频次、替代步骤、耐用性或总体成本逻辑 |
| 场景与便利 | 出门、收纳、清洁、移动或应急时是否麻烦 | 单手操作、便携关系、收纳路径、现场解除摩擦 |
| 身份与审美 | 是否符合我的风格、圈层或理想自我 | 人物气质、品牌世界、搭配结果和情感 Proof |

常见首要犹豫可归纳为：不适配、没效果、效果看不见、难操作、不方便、不舒服、不安全、不耐用、尺寸失真、材质可疑、货不对板、不值价格、不适合当前场景、不适合“我”。选择能够最大幅度改变购买决定的一项，不按清单全部展示。

## 4. 证据阶梯

证据从弱到强分为五级，按任务选择足够且可信的一层：

1. **身份可读**：产品、包装、尺寸、结构、材质和使用对象清楚；只能证明“它是什么”。
2. **过程可读**：观众看懂怎样拿取、安装、开启、涂抹、穿戴或操作；证明“它如何工作”。
3. **即时结果**：声音、液体、气流、污渍、温度、形变、界面或任务状态出现可见变化；证明“刚才的动作产生了什么”。
4. **生活后果**：人物身体节奏、关系、环境或任务完成状态改变；证明“它对生活有什么意义”。
5. **外部验证**：规格、测试、认证、数据或第三方事实；只能使用可靠来源，精确文字与法务内容优先交给后期。

高层证据不能替代低层清楚度。观众若尚未看懂产品和动作，数据、情绪表演和视觉隐喻都不能独立建立信任。医学、健康、安全、金融、儿童、食品营养、比较级和长期功效不得通过虚构画面伪装成事实。

## 5. 从犹豫到广告事件

把抽象卖点改写为“可发生、可观察、可结束”的事件：

| 犹豫 | Hook/冲突 | 产品证明 | 回报 |
| --- | --- | --- | --- |
| 是否安静 | 易被惊扰的时刻已建立，声音可能破坏它 | 产品启动，气流或功能可见，重要环境声/人物状态保持稳定 | 紧张身体节奏放松 |
| 是否方便 | 人物腾不出手、赶时间或步骤堆积 | 一次真实操作完成原本多步任务 | 动作从忙乱转为从容 |
| 是否适配 | 狭小空间、接口、身体或收纳位置成为限制 | 尺度与安装/穿戴关系完整可读 | 产品稳定进入正确位置 |
| 是否有效 | 问题状态先清楚建立 | 产品触发后按物理顺序发生局部变化 | 结果停留足够时间供观看 |
| 是否舒适 | 人物先出现可见不适，但不夸张表演 | 接触、穿戴、气流、温度或声音变化可读 | 肩颈、呼吸、步态或表情自然改变 |
| 是否耐用 | 合理使用压力或重复动作产生风险预期 | 结构受力、材料反馈和完成状态清楚 | 产品保持完整且功能继续 |
| 是否值得 | 原有方案造成时间、空间或耗材浪费 | 产品减少一步、一个物件或一次重复行为 | 结果更整洁、快速或可持续 |

Hook 不等于随机奇观。首个反常画面、台词、动作或声音必须暴露首要犹豫、展示结果或建立欲望。产品证明不是“拿着产品说卖点”，而是产品参与一次有起点、触发、过程和完成态的因果事件。

## 6. 不同片型的转译

### 转化型/功能型TVC

使用：`犹豫张力 → 产品揭示 → 机制/材质证明 → 生活后果 → Hero Shot/CTA`。允许使用视觉隐喻，但至少有一个镜头把隐喻重新接回真实产品特征或使用结果。

### UGC/达人种草

使用：`真实怀疑或困扰 → 为什么愿意试 → 亲手体验 → 即时证据 → 有分寸的推荐`。人物可以说“原本不相信”，但必须在画面中给出让态度改变的证据；不要制造虚假用户证言。

### 产品演示/平台能力展示

使用：`任务或障碍 → 功能触发 → 过程可读 → 明确完成状态 → 下一步行动`。界面和精确文字由可靠资产或后期完成，不用动态模糊掩盖逻辑缺口。

### 剧情式商业短片

使用：`犹豫进入人物事件 → 代价被观察 → 事件升级 → 产品因果介入 → 状态改变 → 品牌收束`。产品解决的是前面已经建立的问题，不在故事末尾强行植入。

### 品牌宣言/时尚情绪片

只使用轻量版本：把主决策理解为身份、审美或归属，把证据理解为一致的品牌世界、人物气质和一个可验证的理性 Proof。不要把所有品牌片改成理性功能演示。

## 7. 与剧情式TVC的衔接

在“事件—观察—理解—反应—升级—反转”结构中，先给每个事件一个商业职责：

- **事件**：暴露或加剧首要犹豫，不随机制造麻烦；
- **观察/理解**：让人物和观众看懂问题及代价；
- **反应**：用表演证明事件改变了人物状态；
- **升级**：提高同一犹豫的代价，不另开无关卖点；
- **产品介入**：通过真实功能或体验改变因果；
- **反转**：可以制造幽默或记忆，但不能否定已经建立的产品价值；
- **结尾**：回到产品、品牌命题或明确行动。

多事件广告中，每个事件可以表现同一犹豫的不同侧面；不能让多个事件分别推销互不相关的卖点。

## 8. 品类延伸方法

遇到新类目时不新增固定场景模板，按以下顺序向下推导：

1. 商品在现实中由谁、在什么场景、以什么动作使用；
2. 哪个错误尺寸、错误结构或错误使用关系会立即破坏可信度；
3. 购买前最大的不确定性属于哪个决策家族；
4. 观众需要静态、过程、即时结果、生活后果还是外部验证；
5. 哪一种证据最适合视频，哪些信息应交给产品页、图文、规格或第三方；
6. 如何把该证据改写为一个有起点和完成态的事件；
7. 哪个品牌特征能让事件不只是通用品类广告。

只要产品共享同一种决策结构，方法即可跨品类迁移；场景、人物和视觉风格随商品事实重做，不能把成功案例的具体画面当模板复制。

## 9. 输出与验收

最终提示词只保留创意推导后的可见结果，不输出“决策家族、首要犹豫、证据等级”等后台标签。用户要求创意分析或方向提案时可以简洁展示理由。

输出前确认：

- 是否只选择一个主决策和一个首要犹豫；
- Hook 是否暴露真实犹豫、展示结果或建立欲望，而非随机奇观；
- 产品是否通过动作、结构、材质或使用结果提供可见证据；
- 证据是否足以支持结论，结论是否超过事实边界；
- 产品进入是否改变因果，而非后置贴片；
- 情绪变化是否由证据触发；
- Hero Shot/CTA 是否完成产品、品牌或行动记忆；
- 创意是否具有品牌或产品独占性，而非更换Logo仍成立的通用场景。
