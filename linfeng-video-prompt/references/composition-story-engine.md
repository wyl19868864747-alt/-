# 构图叙事引擎｜Composition Story Engine

## 目标

构图不是脚本完成后的装饰，而是创意阶段的轻量视觉预演。先判断剧情功能、注意力主体、人物/产品关系和情绪，再选择构图；不得为了“电影感”机械套构图术语。

核心链路：

`剧情功能 → 观众第一注意点 → 人物/产品权力与关系 → 情绪稳定度 → 视觉重量 → 构图母型 → 主体位置 → 空间关系/视觉路径 → 前后镜头构图变化`

## 构图母型与叙事功能

- **三分法**：自然、生活化、对话、视线关系。适合日常交流、UGC、朋友聊天和多数承接镜头。
- **中心构图**：权威、重要、凝视、Hero、CTA。适合关键宣告、产品英雄镜头、直视观众。
- **对称构图**：秩序、仪式、控制，也可制造荒诞或压迫。适合机构空间、正式对峙、冷幽默。
- **非对称平衡**：不稳定、冲突、权力失衡、异常发现。让较重的物体、人物或空间压力承担视觉权重。
- **负空间**：孤独、等待、未知、悬念。空白必须有叙事用途，如等待人物/物体进入、强化视线或制造缺失。
- **引导线**：控制观看顺序。道路、桌边、账单、墙线、光带、动作轨迹等把视线导向人物、产品或证据。
- **框中框**：被观察、受限、私密、隔离。门框、窗、镜子、车窗、货架等形成第二层视觉边界。
- **前中后景层次**：空间深度、现场感、人物关系。优先用于避免“人物贴背景墙”的二维感，也可形成观察式摄影。
- **对角线**：运动、不稳定、危险、冲击。适合动作进入、追逐、争执和失衡时刻。
- **极端特写/填充画面**：Hook、证据、材质、关键动作、情绪爆点。必须明确它新增了什么信息，不能只为“高级”。
- **双人平衡/过肩**：关系、亲密、疏离、对峙和空间连续。人物间距离、中间物体和前景肩部都可表达关系。
- **一点透视/强消失点**：秩序、宿命、压迫、空间揭示。适合走廊、道路、建筑和仪式性空间，不机械滥用。

## 剧情到构图的选择规则

1. 普通生活对话优先三分法、过肩或前中后景，保持自然关系。
2. 强势宣告、Hero、CTA优先中心构图，但只有剧情权力真的集中时才居中。
3. 平等对峙可用双人平衡或对称；权力失衡改用非对称和视觉重量差。
4. 孤独、等待、悬念优先负空间；空白方向应对应人物视线、未知入口或剧情缺失。
5. 发现异常时可用非对称、负空间、框中框，让异常有进入或被发现的空间。
6. 强Hook可用极端特写、引导线、中心或非对称，但构图必须服务具体观众问题，不以“炸”为目标。
7. 动作、追逐、失衡可用对角线；动作完成或真相落定后应回到更稳定构图形成视觉回收。
8. 产品进入、证据揭示优先引导线、前景层次或中心Hero；先控制观看顺序，再谈漂亮。
9. 温馨、信任、认知统一可逐步转向更平衡的双人或稳定三分法。
10. 被困、被观察、私密时刻优先框中框或遮挡前景。

## 构图弧线

不要逐镜随机选“好看构图”。整片应检查构图是否随剧情关系变化。

常见但非固定的弧线示例：

`Hook：非对称/引导线/极端特写 → 正常关系：三分法/过肩 → 冲突：非对称/更紧视觉重量 → 认知统一：双人平衡 → CTA/产品记忆：中心构图`

只保留对当前剧情有意义的变化。若连续镜头使用相同构图，必须有动作、信息、景别、视点或情绪上的新增；不得为了变化而变化。

## 脚本阶段的轻量构图括注

当用户要求创意、脚本、剧情大纲或时间轴，且画面呈现会影响下游视频提示词稳定性时，在主要视觉段落后附一条简短构图括注：

`（构图类型｜主体位置 + 关键空间关系/视觉路径）`

示例：
- `（三分法构图｜Sarah位于左1/3，右侧给Lisa保留视线空间）`
- `（引导线构图｜长账单从前景一路指向后景Sarah手中）`
- `（负空间构图｜人物位于左侧，右半画面留空等待未知主体进入）`
- `（双人平衡构图｜两人分居左右，中间产品成为关系焦点）`

括注必须短，只提供视觉骨架；脚本阶段不要提前塞入焦段、光圈、设备型号和复杂运镜。正式分镜/提示词阶段再根据导演任务深化机位、景别、视点、运镜、光影与连续性。

## 黄金3秒联动

黄金3秒先运行 `golden-3s-hook-engine.md` 决定观众问题，再由本模块决定这个问题如何被构图放大：

- 结果前置：让结果占据视觉重量或直接填充前景。
- 信息缺失：利用负空间、遮挡、框中框保留未知。
- 物体异常：用引导线、尺度占比或非对称把异常设为第一注意点。
- 人际异常：用双人距离、视线空间和权力不平衡表达关系。
- 动作中途进入：用对角线、前景侵入或被截断的动作路径制造未完成状态。

Hook构图必须继续服务Bridge与Payoff。若开场构图制造了一个视觉问题，后续必须通过动作、反应、空间变化或构图回收偿还它。

## 自检

- 第一注意点是否与本镜头的信息任务一致？
- 构图是否表达人物/产品关系，而不是只标了术语？
- 括注是否包含主体位置或视觉路径，而非只有“三分法”三个字？
- 空白、遮挡、对称、中心、对角线是否有剧情理由？
- 构图是否帮助视频模型理解空间，而没有过早抢占摄影提示词带宽？
- 前后镜头是否形成合理的构图弧线？
- 删除构图选择后，情绪、关系或注意力是否明显变弱？若没有，简化它。
