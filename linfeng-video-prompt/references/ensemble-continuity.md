# 多人物、群像与手部归属控制

用于三人以上同框、多人逐一登场后集结、多人围桌、递接商品、多双手进入近景或人物/肢体容易串位的任务。双人普通对话使用基础连续性即可。

## 1. 群像拓扑

先锁精确人数、角色ID、画面左右/顺时针座次、前后景、朝向，以及桌面物件数量、位置与归属。每人至少保留三个可见区分信号：脸型或年龄感、发型、服装颜色/袖口、体态/姿势、唯一定义道具。

逐一登场还要建立视觉签名：`角色ID + 主色/轮廓 + 唯一道具 + 专属效果 + 动作气质`。最终集结继承相同人数、排序、道具和效果归属；参考图若只负责排列，不得反向改写角色身份。

## 2. 手部所有权

关键手内部标记：

`角色ID + 左/右手 + 袖口/饰品 + 入画侧 + 接触对象 + 动作终点 + 退出/返回侧`

同一只手不得无过渡换边、换袖口、换肤色或换主人。递接必须看见旧持有者释放、新持有者承重，商品数量、朝向和标签面连续。

## 3. 复杂度预算

- 单镜最多两名角色承担精确手部动作，其余人物只做低幅反应。
- 复杂手部动作与复杂运镜二选一；手部精确时相机稳定，运镜复杂时动作简化。
- 多人同时触碰小物件、交叉手臂或遮挡标签优先拆镜或动作匹配硬切。
- 集结镜头主要证明“全部到场与关系可读”，只保留呼吸、发丝、衣料和重心微动；高速招式在稳定集结前完成。

## 4. 验收

- 全景到局部是否继承人数、座次、袖口、进入方向和物件位置？
- 每只关键手能否回答“谁、哪只手、从哪来、碰什么、到哪里”？
- 递接是否包含释放与承重，而不是物件瞬移？
- 角色签名与个人效果是否在最终集结保持归属？
