## 1. 启用边界与目标

凡创建、改写、分析或反推两个及以上镜头、故事板、分镜表、时间轴或一镜到底连续节拍，完整读取并逐镜执行本文件。单镜任务在用户询问“为什么这样拍”“镜头应该怎么设置”时也执行。

本模块先控制观众何时知道、看见、感到和相信什么，再反推景别、机位、焦点、声音与运动。不得先写“超近景、长焦、环绕、甩镜、浅景深”，再为这些形式补一个牵强理由。

默认在后台运行。用户只要提示词时，只输出设计后的有效画面；用户要求分镜、导演分析或参考反推时，展示每镜的核心表达与承接。

## 2. 整片信息设计

逐镜前先锁定六项：

1. **核心问题**：观众为什么继续看；问题必须指向人物冲突、产品证明、空间未知、身份、结果或下一行动。
2. **知情曲线**：观众与人物在每个段落分别知道什么；每段新增什么，哪些误解被纠正，哪些信息仍保留。
3. **揭示计划**：哪些主体立即完整出现，哪些延迟揭示；隐藏必须产生悬念、身份、尺度、关系或产品证据价值，不能只为“电影感”。
4. **视点策略**：客观观察、角色POV、贴身伴随、无主身体视点、产品视点或可控混合；视点变化必须有信息理由。
5. **空间秩序**：动作轴线、行进方向、人物排序、视线方向、入口出口、关键锚点和主光世界方向。
6. **注意力接力**：视线、动作、焦点、遮挡、形状、颜色或声音如何把观众从上一镜的落点带到下一镜的首个信息。

同时建立影片及必要分段的氛围曲线、主色/辅助色/唯一强调色、光源世界方向、肤色与产品色保护、成像触感与声音触感。信息设计不能破坏这些母规则。

## 3. 逐镜第一轮：为什么必须有这一镜

按顺序回答：

`上一镜遗留什么问题 → 观众和人物当前分别知道什么 → 本镜暂时隐藏什么 → 本镜唯一职责是什么 → 什么事件触发镜头 → 镜尾新增什么信息、关系、感知或产品证据 → 人物、产品材质或环境怎样反应 → 本镜回答什么之后又留下什么问题`

镜头主职责只选一个：

- 钩子
- 建立空间
- 给线索
- 揭示
- 产品证明
- 人物反应
- 作出决定
- 关系转折
- 转场
- 回收
- 有意呼吸

“好看、很电影、很有气场、增加节奏”不是主职责。若删除镜头后，故事、人物关系、产品证据和观众感受完全不变，删除、合并或重新设计。

有意呼吸镜也必须改变感知：让观众消化刚发生的信息、感受环境压力、等待人物决定、建立产品触感，或为下一次节奏升级蓄力。

## 4. 逐镜第二轮：这一镜应该怎样拍

根据第一轮答案再确定：

1. 视点属于谁，或是否为客观/无主视点；
2. 需要全景、中景、近景、特写还是极特写；
3. 机位高度、侧别、前后关系、遮挡和主体占比；
4. 观众先看 A 还是 B；
5. 注意力由视线、动作、声音、摇镜、拉焦、遮挡还是入画完成；
6. 摄影机应该固定等待还是移动；
7. 摄影机与人物是提前等待、领先引导、同步陪伴、落后追赶、反向对抗还是主体掠过后停留；
8. 谁先行动、谁先看见、谁先理解、谁先反应；
9. 镜头最终停在哪里，最后清楚主体是谁；
10. 在什么完成态获得切镜许可；
11. 下一镜继承视线、动作方向、速度、焦点、遮挡、声音、形状或颜色中的哪一项。

景别只由信息任务决定：空间地理用全景或中大全景；关系变化用双人/中景；理解与反应用近景；操作、线索和材质证据用特写。极特写必须新增身份、命令、决定、触感或证据，不连续重复同一种“气场”。

## 5. 最小导演记录与删镜规则

内部逐镜只记录：

`遗留问题｜唯一职责｜已知/隐藏｜触发事件｜新增结果｜视点/景别/机位｜注意路径｜反应/决定｜落幅/切点｜下一镜承接`

记录用于约束选择，不默认整表外显。每镜必须同时满足：

- 新增一项可说清的信息、关系、感知或产品证据；
- 有可见或可听触发；
- 镜尾形成可读完成态；
- 下一镜继承至少一个明确变量。

删除测试：

1. 删除后观众仍获得完全相同的信息；
2. 删除后人物关系和产品证据没有变化；
3. 删除后情绪节奏与下一镜理解不受影响。

三项均成立时删镜。只有构图不同、焦段不同或运镜更炫，不构成保留理由。

## 6. 问题—回答—新问题

使用结构：

`上一镜提出问题 → 本镜给出部分或完整答案 → 答案改变状态 → 新状态产生下一问题`

回答不必是台词。产品被打开、人物看见空椅子、门后出现脚印、质地完成涂抹，都可以回答问题。关键是答案必须改变人物、环境、产品状态或观众判断，不能在回答后恢复原状。

## 7. 延迟完整揭示

使用结构：

`痕迹或结果 → 身体/产品局部 → 具有身份意义的行为 → 反应或决定 → 完整主体与环境关系`

人物可先用手指、烟、服装、鞋、道具或动作出场；产品可先用声音、材质、使用结果或局部结构出场。每个局部必须增加不同信息：

- 手指：命令、控制方式或紧张状态；
- 弹烟：态度、等待结束或行动开始；
- 鞋/步态：方向、速度、阶层或任务；
- 起身：作出决定并改变权力关系；
- 完整出场：确认人物与环境、他人和目标的关系。

如果多个特写都只表达“很帅、很神秘、很有气场”，合并为一个最有信息量的镜头。

## 8. 运动主体接管视点

使用结构：

`无主或稳定视点前进 → 鸟、车、手、烟、布料或光影进入画面 → 接管观众注意力 → 摄影机因其动作改变方向和速度 → 抵达新目标 → 减速落幅`

接管物不是随机前景。它必须：

- 从可解释的空间进入；
- 形成清楚的运动方向或声音触发；
- 让摄影机的转向、速度变化或跟随有因；
- 最终把观众带到叙事目标；
- 在目标上减速并形成稳定落幅。

摄影机跟随海鸟抵达船，属于无主/稳定视点被运动主体接管，不自动等于角色POV或FPV。

## 9. 看者—所见—反应—决定

关键发现使用闭环：

`先建立谁在看 → 展示角色所见 → 返回人物如何理解 → 反应推动台词、决定或行动`

“所见”镜头回答对象是什么、距离与方向如何；“反应”镜头回答信息为什么重要。只有所见，没有反应，观众不知道意义；只有反应，没有所见对象，情绪缺少依据。

反应优先写理解过程，而非通用表情：视线停住、呼吸变化、嘴角收紧、手中道具停顿、身体重心改变、目光转向行动目标。反应后必须形成决定或下一动作，除非镜头职责是有意悬置。

## 10. 摇镜与拉焦的注意力接力

使用结构：

`A 先清晰并触发视线或动作 → 摄影机沿唯一方向摇向 B → B 进入构图 → 焦点从 A 或前景架到 B → 镜头在 B 上减速落稳`

只在 A 与 B 需要共享同一空间关系、动作或发现时使用。若切镜能更清楚地表达关系，不为连续感强行摇镜。

术语不得混写：

- 拉焦只改变清晰平面；
- 变焦改变焦距和视角；
- 推进改变摄影机位置并产生视差。

## 11. 片名与英雄镜的结构标点

片名、章节名或产品英雄镜只在以下内容阶段性成立后出现：

- 世界与空间规则已经建立；
- 人物身份、目标或核心问题已经成立；
- 一段行动或关系变化完成；
- 产品证明已足以支持品牌记忆。

它们表达“序幕结束、章节转换、证明完成或品牌记忆”，不是机械地“拉远后加字”。准确片名、Logo、CTA 与法务文字默认后期添加；生成阶段只预留稳定负空间、载体、光影和停留时间。

## 12. POV、FPV、反打、反应与光学术语

- **POV**：镜头近似呈现某个角色此刻实际所见。必须有明确拥有者，并与拥有者位置、视线高度和方向相容。
- **无主身体视点/沉浸式前进镜头**：摄影机持续向前但没有明确角色拥有者；不要误写为POV。
- **伴随/跟拍/运动主体接力**：摄影机追随海鸟、车辆或人物；不自动等于FPV。
- **FPV**：强调飞行器、载具或身体绑定视点及其惯性、倾斜和速度反馈。高速低空飞行不自动等于FPV。
- **反打**：描述相对机位与视线结构。
- **反应镜头**：描述人物如何理解刚发生的信息。一个镜头可以同时是反打和反应，但二者不是同义词。
- **望远镜所见**：用圆形遮罩、暗角、边缘轻微畸变或光学呼吸表达；没有明显桶形畸变时不称为鱼眼。
- **鱼眼**：极广视角与明显桶形弯曲；不因出现圆形遮罩而成立。

## 13. 轴线与空间重建

轴线不是“摄影机永远在人物右侧”。同一行动段保持：

- 行进方向；
- 人物排序；
- 视线关系；
- 空间地理；
- 世界主光方向。

可以在轴线同侧改变前后距离、景别、前景遮挡、侧前/侧后关系和固定等待。这样既保留银幕方向，也避免所有镜头机械复制同一机位。

需要越轴时，使用一种可读重建：

1. 摄影机连续可见地穿越轴线；
2. 人物主动穿过轴线；
3. 经过正面或背面的中性机位；
4. 换场后先建立新空间、人物排序和主光方向。

越轴后的第一镜必须让观众重新看懂方向；不要靠口头声明修复已经混乱的空间。

## 14. 不同片型的执行深度

### 短剧、冒险、悬疑、品牌剧情

完整执行整片信息设计与逐镜双层反问。优先控制知情差、人物诉求、关系变化、看者—所见—反应—决定、动作轴线与情绪落点。

### TVC与产品广告

把信息问题改写为：产品是什么、怎样自然进入、怎样使用、材质/功能如何被证明、为什么相信、最后记住什么。每镜只承担钩子、揭示、证明、反应、回报或品牌记忆之一。

### UGC与电商演示

轻量执行：首秒为什么继续看、产品怎样自然进入、一次操作证明什么、人物为何立刻改变态度、结尾记住什么。默认不强加复杂POV、反打、延迟揭示、环绕或多层悬念。

### 一镜到底

把每个连续节拍视为无切镜的信息镜头。逐节拍运行问答，但承接只能通过同一摄影机路径中的入画、视线、动作、遮挡、焦点、声音或空间变化完成；光线与镜头物理连续。

### 参考视频反推

除景别、机位、运镜、焦段和切点外，逐镜反推：控制了什么信息、情绪、关系和注意力；为什么此时揭示；落幅如何接下一镜。输出分为可迁移导演逻辑与原片专属人物、场景、美术、台词、品牌和镜头组合。

## 15. 输出转译与验收

用户只要直接生成提示词时，每镜只保留：

`首帧状态｜主体动作｜注意力路径｜视点与机位｜必要运镜｜人物/产品/环境反应｜可见完成态｜落幅与下一镜承接`

用户要求分镜表、导演分析或参考反推时，每镜额外输出：

- **镜头核心表达**：这一镜为观众新增了什么信息、关系、感知或产品证据；
- **承接**：它回答上一镜什么，并通过何种视觉或声音变量接向下一镜。

验收：

- 整片是否有清楚的核心问题、知情曲线、揭示计划、视点策略、空间秩序和注意力接力；
- 每镜是否先有唯一信息职责，再有景别、机位与运镜；
- 每个特写是否增加不同信息；
- 看者、所见、反应和决定是否闭环；
- POV/FPV/反打/反应/鱼眼等术语是否准确；
- 轴线是否保持空间可读，又没有机械锁死单一机位；
- 片名或英雄镜是否位于有效结构节点；
- 删除无因运镜和重复镜头后，叙事或产品证明是否更清楚。
