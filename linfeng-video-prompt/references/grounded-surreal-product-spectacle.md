# 写实超现实与产品视觉奇观

用于真假虚实结合、写实超现实、视觉奇观广告、真人与不可能事件、熟悉物体无外力异常运动、物体主导概念广告、微缩人物/工厂/产品世界、巨物原料世界、产品世界化、包装变建筑或工厂、产品拆解悬浮、卖点视觉隐喻，以及真实摄影与CG/AIGC合成。能力标签为 `grounded-surreal`。

本模块按画面机制触发，可跨TVC、UGC、品牌片、短剧和剧情片调用；它不属于食品或商业专用分支，也不自动把剧情任务广告化。加载后继续逐项叠加产品事实、消费者决策、食品风味、导演信息、复杂运镜、连续性、实体转场、画质和模型工作流。

内部判断问题：`是否把真人/实景与不可能事件、熟悉物体的异常行为、微缩人物/工厂、产品世界化、巨物原料或卖点视觉隐喻结合？` 命中任一语义即标记 `grounded-surreal`。尤其当参考视频的核心吸引力是“普通熟悉物体发生一个不可能但一眼能懂的行为，并通过未完成事件让观众继续看”时，即使用户没有明确说“超现实”，也要主动进入本模块判断。普通写实拍摄、常规CG Packshot或没有现实/异常关系的纯幻想世界不因“高级、电影感”自动触发。

## 1. 内部合同与适用边界

先在后台写：

`在[可信现实/材质世界]中，只让[一个不可能规则]越界；该异常通过[可见过程]证明[产品事实/体验/剧情意义]，最终回到[人物反应、实际使用、稳定空间、产品记忆或剧情落点]。`

核心原则：先建立绝对可信的现实，再只允许一个高权重物理规则失真；奇观负责表达产品证据或剧情意义，其余摄影、物理、光影、材质、人物反应和连续性继续服从现实。

目标不是把奇观做普通，而是让观众相信“不可能的事确实发生在这个现实世界里”。删除奇观后，产品理解、人物状态或剧情意义必须发生实质损失；否则删除奇观或重新设计其职责。

## 2. 现实底盘与唯一幻想规则

一个镜头或一次生成段的可见画面中只允许一个高权重幻想规则处于激活状态，例如分层悬浮、人物连同座椅坠入现实空间、微缩劳动、包装世界化、巨物原料，或一个核心熟悉物体在没有可见外力时自行运动。整条影片可以在相邻镜头依次使用不同规则，但不能在同一镜头同时要求失重、缩小、传送、变形、尺度突变和多种无因魔法；规则切换必须有完成态与握手变量。这里限制的是“同时可见、仍在生效的异常总数”，不只是每段新增加的异常数。

这是可执行性上限，不是可被“越奇幻越好”“全部同时发生”“必须一镜到底/全程360°”覆盖的审美偏好。发生冲突时，不删除用户想要的奇观类型，但把它们排序到相邻镜头/生成段：每段先完成一个状态，并让该异常退出画面、恢复现实或转译成普通场景事实，再用握手变量进入下一段；不得让上一段的失重、缩小、变形或传送持续生效并在片尾累计同框。复杂奇观期间摄影机固定、短跟随或单轴移动，完成后才恢复弧线/环绕；360°只能分摊为普通镜头间的累计观察路径，不能成为全程持续的高成本并发控制。用户要求直接生成时不阻断交付，简短说明已按可生成性重构后直接给一版方案。

幻想之外全部服从现实：

1. 人物、产品、原料的身份、数量、比例、几何、标签面、液位、部件顺序和材质稳定；
2. 空气阻力、水阻、惯性、碰撞、支撑、释放、承重、落地与反作用连续；
3. 实拍透视、景深、曝光、对焦、运动模糊、颗粒和光学畸变统一；
4. 数字主体具有正确的接触阴影、遮挡、反射、互动光、光包裹和运动模糊；
5. 主光保持世界方向，进入奇观后不无因重新布光；
6. 人物先看到、听到或感到异常，再产生眼神、呼吸、身体重心和动作反应；
7. 产品和人物跨景别只发生透视变化，实体尺度与结构不漂移。

## 3. 从产品事实或剧情意义推导奇观

禁止从“加什么特效”或“让小人做什么”开始。按以下顺序：

`已确认产品/剧情事实 → 观众需要理解或相信什么 → 最适合看见的物理过程 → 唯一不可能规则 → 现实反馈 → 可观察完成态 → 产品或剧情回收`

- 商业任务先读取商品预检与证据边界；奇观不能替产品证明未经确认的功效、成分、认证、参数或工艺。
- 剧情任务把奇观绑定人物认知、决定、关系变化或世界规则；没有商业目标时不强加Hero、CTA和卖点话术。
- 视觉隐喻只能表达感受或概念，不能被写成事实证明。
- 精确Logo、数字、工厂等级、认证、参数和说明文字使用可靠资产或后期图形完成。

## 4. 产品奇观转译

### 丰富结构

让产品沿同一中心轴分层、展开或重组；锁定原有部件数量、顺序、颜色、材质、间距变化和完整轮廓记忆。它是结构证明，不是随机爆炸或身份不明的漂浮物。

### 天然来源

让真实原料的生长环境成为产品世界，通过采摘、测量、运输和汇合建立来源联想。只有已确认原料可以进入，产地与种植方式未经确认不得写成事实。

### 原料复配或协同

让不同原料沿可读路径到达同一目标，形成一次合流、连接、保护或共同作用的完成结果。不得同时增加多种无因化学效果。

### 清洗、灭菌或锁鲜

用水流、温度、密闭、真空、透明管线或加工流程表现可观察状态变化；没有可靠依据时，不写具体温度、洁净等级、营养功效或认证。

### 透明工艺

把包装外轮廓转译为同形透明工厂或加工建筑，原料进入、加工、检验和输出形成闭环。包装轮廓、比例和强调色来自可靠资产；准确标签留给真实产品或后期。

### 实际使用

用相同流体、颜色、形状、方向或构图，把原料/奇观世界接入真实杯子、皮肤、衣物或生活空间。完成后回到真实接触、使用结果或人物反应。

## 5. 熟悉现实被单点突破

适用于真人荒诞广告、动作喜剧、产品拆解和现实世界中的不可能事件：

`正常现实与人物动机 → 产品/事件触发异常 → 摄影机迟半拍见证 → 异常达到最可读状态 → 人物/环境产生可信反作用 → 空镜/落地/接触重新确认现实 → 使用、品牌记忆或剧情落点`

采用实拍特技底盘：

- 衣服、头发、皮肤和松散物件受到真实风力、重力、惯性与碰撞影响；
- 摄影机不是全知CG镜头，而是提前等待、落后追赶、被主体掠过或有短暂反应延迟；
- 大型异常后安排稳定空镜、落地、接触或人物反应确认空间；
- 结构奇观完成后减速、停留或进入稳定焦平面，让产品可读；
- 拆解产品始终锁定唯一中心轴、原部件顺序/数量、间距、材质、颜色与完整轮廓。

高空坠落、复杂拆解和落地通常分段生成。人物下坠与产品分层若都必须出现，优先分别安排在相邻镜头/生成段，以共享速度、中心轴或声音接力，不在同镜叠加两套高成本三维控制。

### 5.1 物体主导的超现实视觉隐喻｜Object-led Visual Metaphor

当一条广告或概念短片不需要靠人物关系推动，而更适合让**普通物体自身完成Hook、悬念与Payoff**时，优先启用这一子模式。它尤其适合高级时尚概念广告、奢侈品式实验短片、品牌态度表达，以及可以把一个卖点压缩成清楚物理关系的商业任务。

后台创意链固定为：

`核心事实/品牌态度 → 一句话抽象概念 → 熟悉物体/关系 → 一个主异常规则 → 未完成事件 → 2—4级可见状态推进 → Payoff → 产品/品牌/CTA收束`

核心DNA：

1. **异常物体先于解释**：首帧或前1秒尽快让观众看见“哪里不对”，例如一个普通物体开始执行没有外力依据的动作；不先用对白解释概念。
2. **允许无外力运动，但必须被精确编译**：仅在本子模式启用后，允许被选中的一个核心物体自行移动、停止、转向、靠近、远离、上升、下沉或完成一个不可能行为；必须写清起始位置、第一次异常、运动方向、路径、速度/节拍、停顿、与目标物的空间关系、最终接触/错过/停止状态。其余物体和环境仍服从现实。
3. **状态变化制造节奏**：节奏优先来自物体状态变化，而不是靠疯狂切镜。每0.5—1.5秒可以出现一次有意义的新状态，但不机械追求频率；每次变化都要让观众的预测更具体，最终形成Payoff。
4. **超现实但不“魔法化”**：真实材质、重量、阴影、反射、景深、接触、惯性和空间关系保持可信。异常只破一条现实规则，不自动加入粒子、发光、传送、烟雾、能量波或游戏式CG特效。
5. **隐喻必须一眼可读，但不必解释**：去掉文案后，观众仍应能感到清楚的关系，例如“上涨/不涨”“靠近/被捕获”“不断增加/始终不动”“寻找/始终为空”。如果必须靠长文案才能明白，优先重做隐喻。
6. **视觉隐喻不等于事实Proof**：它可以表达价格稳定、自由、焦虑、吸引、拒绝、稀缺、控制等抽象关系，但不能把未经证实的功效、疗效、收益、认证或性能包装成真实证明。
7. **人物只在需要时接管**：人物可以最后出现、确认、拿走、拒绝、停止或重新定义物体，但不强制前置双人对话。人物进入后也必须服从现有空间、尺度和动作因果。
8. **调性参考是“克制高级的超现实”，不是大片堆词**：可使用冷峻、极简、神秘、高级、时尚概念片、奢侈品式视觉张力等抽象总控；具体画面仍由分镜负责。不要把“高级”自动翻译为史诗、东方奇幻、全程大场面或无意义VFX。

调用判定：

- 用户明确说“超现实、视觉隐喻、概念广告、物体自己动、物体主导、奢侈品式实验广告”时，必须进入判断；
- 用户上传参考视频，即使未说“超现实”，只要其核心DNA明显是“熟悉物体 + 不可能但可理解的行为 + 未完成事件 + Payoff”，也必须进入判断；
- 一个卖点能自然转成单一物理关系时主动探索，但不强制使用；
- 仅说“高级一点、电影感一点”不自动触发。

提示词编译时遵守主Skill信息权重：**开场总控只定整片基调与超现实程度；主体篇幅用于分镜中的具体物体状态、运动与Payoff；设备/成像只在 `【全片视觉与技术基线】` 用一句精确框定，不与分镜抢带宽。**

## 6. 产品世界化与微缩劳动

把产品、包装或原料转译为地形、建筑、工厂、机器、作业目标或运输路径。微缩人物只承担：

1. 建立宏观产品与微观人物的尺度；
2. 用一个明确劳动动作表达一个产品事实、工艺步骤或剧情功能。

每个角色只完成采摘、测量、运输、推入、连接、密封、清洗、检验或启动设备中的一个动作。提示词写清：

- 人物相对于果实、包装和工具的有依据比例；
- 站立面、鞋底/手部/车轮/工具接触点与接触阴影；
- 产品或原料的重量感、人物重心与受力；
- 工具路径、释放/承重关系与可观察完成态；
- 宏观产品的真实材质，以及人物皮肤、布料、金属工具和身体结构。
- 双手与工具的具体接触点、工具受力方向和人物/工具的动作路径；
- 统一服装、材质、太阳方向、植物生态和景深规律。

使用真实微距摄影、移轴或受控浅景深建立尺度，默认不做塑料玩具世界。跨多个微缩空间统一人物制服、工具/建筑材质、产品强调色、主光世界方向、植物生态、景深规律、颗粒和成像身份，避免随机抽卡。

微缩人物若只是可爱装饰、不改变流程或证明，删除角色或重写劳动职责。

## 7. 动作接触拓扑锁定

高风险互动不能只写“推、拉、拿、递、搬”。先锁定空间顺序和力链：

- 银幕从左到右的主体顺序，以及镜头结束时是否保持同一顺序；
- 人物位于工具前方或后方，工具正面/后方及把手朝向；
- 双手接触工具哪一端，脚底、车轮、工具和承载面的接触位置；
- 力从谁传递给谁，承重、释放、反作用与人物/工具的移动方向。

优先使用可见句式：`画面从左到右依次为[主体A—接触部件—工具—载荷]；[人物]始终位于[工具前/后方]，[双手接触点]向[方向]施力，[轮/脚/工具]贴住[承载面]移动；镜尾继续保持该顺序并形成[完成态]。`

审片分开检查：一是接触是否存在，二是接触拓扑是否正确。手碰把手、轮子贴地不等于前后位置、推拉方向和受力关系正确。

## 8. 原料判别与结尾证据分区

原料承担卖点时，不能只写颜色、大小或“巨大果实”。从完整外轮廓、分瓣/浅沟/表面结构、果皮纹理/果粉、果柄/萼片、叶形、连接方式、剖面/果肉中选择至少两至三项稳定正向特征；排除易混对象只作辅助，不能代替可见品类结构。例如针叶樱桃应锁定完整深红果实、清楚三瓣浅沟、绿色短柄与可辨叶片，而不是泛化红球。

“运输到达”不自动等于复配证据成立。结尾预先分配独立可读区域：原料A、功能角色、原料B各占一处，互不遮挡；通过停轮、起身确认、并列、汇合或卸料形成完成态，镜头减速停稳并保留读图时间。模型容量不足时，优先保留稳定清楚的双原料并列，不在最后一秒并发卸料、变形、液体化、粒子与产品Hero。

## 9. 真假世界的握手变量

现实与奇观不能只写“丝滑转场”。相邻镜头选择至少一个可见变量接力：

- 形状、颜色、材质；
- 运动方向、速度；
- 流体、构图中心；
- 遮挡物、声音。

上一镜先形成清楚完成态；下一镜从相同变量的位置、方向、速度、轮廓或声源成立。可使用产品完整形态接分层中心轴、坠落主体接地面空落点、原料轮廓接运输管线、包装轮廓接同形建筑、垂直果液接真实杯中液流等机制，但不得把这些示例固化为默认画面。

握手涉及满屏实体遮挡、玻璃/镜面或反射接管时叠加 `physical-takeover-transitions.md`。禁止用无因闪白、随机粒子、突然传送、甩镜或模糊遮挡掩盖动作桥梁缺失。

## 10. 提示词编译顺序

按观看顺序编译，最终仍服从主Skill的输出合同：

```text
【现实底盘】地点、时间、成像身份、主光、材质和摄影机行为。
【正常首帧】主体、产品、尺度、位置和现实状态。
【唯一幻想规则】允许越界的单一规则及空间/时间边界。
【物理展开】触发 → 路径/接触 → 惯性/阻力/承重/遮挡 → 可见变化 → 完成态。
【产品/剧情证据】因此新增的结构、原料、工艺、体验、认知或关系信息。
【镜头反应】摄影机为何等待、追随、迟疑、拉焦、减速或停稳以及最终落幅。
【现实回收】人物/环境反应、实际使用、稳定空间、产品Hero或剧情落点。
```

删除“电影感、真假结合、丝滑无缝、视觉奇观、高级CG、震撼特效”等没有转译为媒介身份、尺度、异常边界、受力、接触、遮挡、证据、镜头反应和完成态的抽象词。

## 11. 模型与素材工作流

1. 一个生成段只承担一个主奇观或一个不可逆完成态；复杂片按“正常建立—奇观—落地/使用—Hero/剧情回收”分段。
2. 产品与包装准备清洁参考、多角度图和可靠标签资产；真人荒诞片增加人物、服装、场景和动作参考。
3. 微缩世界按需准备原料、制服、工具与统一环境关键帧；每项素材只承担一个职责。
4. 严格空镜落点、拆解顺序、宏微尺度和首尾状态使用独立关键帧。
5. 复杂坠落、飞行、液体、群体运输和摄影机轨迹优先使用动作参考或白模。
6. 生成模型负责可见世界、负空间和可合成载体；精确数据、Logo、说明和法务交给可靠资产或后期。
7. 同类镜头两次出现漂浮塑料感、尺度漂移、无因换光、接触缺失或转场换素材时，减少幻想变量、拆镜、固定机位或升级素材，不继续堆形容词。
8. 用户要求多个幻想同时出现时，先做优先级排序与分镜分配；不得把“同时”当作同一生成镜头的硬约束，也不得让持续360°环绕与复杂变形、缩放、传送或液体模拟并发。每次切换前写清上一异常如何结束、退出画面或回归现实；结尾只回收主题、产品、人物或共享视觉变量，不汇总展示所有仍在生效的异常。

Seedance 2.5任务继续读取其工作流并使用连续整数秒；故事板只锁大致结构，严格状态用独立关键帧，复杂三维轨迹用动作参考或白模。

## 12. 完整成片审片与重设

不能只看首帧。检查完整成片或抽帧时间序列：开场、异常触发、中段动作、手脚/车轮/工具接触、推拉关系、人物前后与银幕顺序、原料/产品辨识、光源和尺度、完成态、结尾停留、支撑/漂浮、卖点遮挡、品类泛化、随机换光和无因运镜。先区分成功层与唯一失败层；修复时保留已经成立的光线、材质、尺度、场景和动作，只改一个主变量及必要承接。

出现任一项时重设镜头或机制：

出现任一项时重设镜头或机制：

1. 删除奇观后，产品理解、剧情意义和人物状态完全不变；
2. 微缩人物没有功能，只是装饰；
3. 同镜存在两个以上高成本幻想规则；
4. 数字主体与实拍的透视、光影、景深、遮挡、颗粒或运动模糊不匹配；
5. 产品结构、数量、标签、尺度、液位或材质漂移；
6. 动作没有受力、接触、反作用和完成态；
7. 奇观后人物、产品或空间状态被重新生成；
8. 摄影机无因环绕、滚转、甩镜、变焦或换焦；
9. 用随机粒子、闪白或模糊遮挡掩盖动作缺口；
10. 精确数据、功效、认证和工艺没有可靠来源。
11. 接触存在但人物前后、银幕顺序、把手方向或推拉受力拓扑错误；
12. 原料缺少稳定判别特征而泛化，或结尾元素互相遮挡、无法形成独立产品证据。
13. 物体主导视觉隐喻只写“高级超现实”，却没有明确异常物体、运动起点、路径、状态推进和Payoff；或同时让多个物体各自违反不同现实规则。

## 13. 跨模块装配检查

- 是否标记 `grounded-surreal`，同时继续检查商业/剧情、食品、美妆、群像、声音、长时、导演信息、复杂运镜、连续性、实体转场、画质和模型任务？
- 是否先建立产品事实/剧情意义，再选择视觉奇观，而不是反过来？
- 每镜是否只有一个高权重幻想规则处于激活状态，而非只是每镜只新增一个？跨镜规则变化是否有完成态、异常退出/现实回收和握手变量，结尾是否避免多种异常累计共存？
- 若命中物体主导视觉隐喻，是否由“熟悉物体 + 一个不可能行为 + 未完成事件 + 状态推进 + Payoff”构成，而不是依赖人物说明或特效词？
- 现实底盘、数字合成、人物反应和现实回收是否共同证明异常发生在同一世界？
- 是否避免把本模块的示例产品、原料、交通工具或微缩工厂固化为默认模板？
- 高风险互动是否同时锁定接触、银幕顺序、人物前后、把手方向、移动方向和力链？
- 原料是否用两至三项正向品类特征辨识，结尾是否通过分区与停稳建立独立证据？
