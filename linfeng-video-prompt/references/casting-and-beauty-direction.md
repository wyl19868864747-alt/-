# 人物选角、时代感与美妆表达

用于美妆、护肤、香氛、时尚及人物主导的生活方式广告，也用于人物显老、模板化、过度成熟、像旧式影楼或不符合目标市场的返修。高风格化社媒内容继续叠加 `stylized-social-beauty-ugc.md`。

## 1. 先定义人物功能

不要只写“年轻、漂亮、高级”。先确定可见年龄段与生活阶段、人物能量、时代和目标市场、与观众的距离，以及人物负责使用证明、情绪投射、身份向往还是专业信任。只使用与传播目标有关的可见特征，不凭年龄、族裔或身体特征推断性格、能力和社会身份。

## 2. 五层协同

人物时代感由五层共同建立：

1. 发型与妆容；
2. 服装、配饰与真实穿着状态；
3. 视线、呼吸、节奏、姿态和手势；
4. 空间、道具、字体占位与生活细节；
5. 焦段距离、肤色、对比度、亮部和纹理保留。

人物显老时先检查硬顶光、过度磨皮/锐化、保守发型、僵硬姿态、旧式服装、美术年代感和过慢表演，不只把年龄数字改小。

## 3. 皮肤与商品证明

保留毛孔、细纹、绒毛和微表情，控制蜡像磨皮、过度锐化和局部阴影加深。先用中性证明光稳定肤色和商品本色，再用产品相关高光或湿润度表现质地；彩色氛围光主要承担背景、轮廓和空间情绪。功效、肤质适配、成分和前后对比继续服从商品证据边界，漂亮人物不能替功效作证。

## 4. 验收

- 人物是否具有明确可见的年龄、能量、时代、市场与片中功能？
- 发妆、服装、表演、美术和光线是否支持同一定位？
- “显老/模板化”的修复是否落到真实可见原因？
- 是否保留真实皮肤结构，并避免凭外貌推断人格与身份？
