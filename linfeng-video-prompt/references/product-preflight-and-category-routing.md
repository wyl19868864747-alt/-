# 商品预检与品类决策路由

用于所有TVC、商业广告、UGC、电商和产品演示。它先确认商品事实、尺度、素材能力与消费者决策，再决定卖点和模块；不得凭品类常识替具体商品编造功效。

## 1. 商品预检

内部只传递会改变脚本的内容：

- 品类、商业子类型与核心目标；
- `已确认 / 可安全推断 / 无法确认` 的事实；
- 数量、几何、标签面、颜色、材质、按钮/接口/瓶盖、液位、朝向、持握和接触面；
- 商品相对手掌/身体、承载物和环境的真实比例；
- 参考素材支持的角度与不可见结构风险；
- 核心成交理由、头号犹豫、一个传播命题和最高风险。

功效、认证、成分、性能、兼容性、准确度、耐用性、售后和精确参数只有用户或可靠素材明确支持时才能写成事实。健康医疗、母婴、美妆、食品和宠物食品从严处理。

## 2. 尺度与素材能力

- XS 指尖佩戴；S 单/双手持；M 台面操作；L 推拉、坐卧或安装；XL 用人物与空间共同建立尺度。
- 相对等级只用于决定动作、景别和风险，不用于猜精确尺寸。
- 单张正面图默认只支持正面或轻微三分之四角度；侧背面、内部、接口、复杂拆装、液体流出和360°环绕需要对应素材。
- 素材不足时先降低镜头难度或补资产，不用“结构不变”假装模型知道不可见区域。

## 3. 品类决策检查

| 品类 | 常见成交理由 | 常见首要犹豫 | 候选证据 |
| --- | --- | --- | --- |
| 家具/家居 | 舒适、颜值、空间适配 | 尺寸、耐用、清洁 | 身体受力、回弹、人物/家具/房间比例 |
| 美妆护肤/香氛 | 功效、质地、成分、信任 | 刺激、肤质适配、效果 | 局部使用链、真实皮肤、包装已确认信息 |
| 服饰鞋包/珠宝 | 上身效果、版型、设计、材质 | 尺码、掉色过敏、工艺 | 人体线位、垂坠、佩戴位置、材质细节 |
| 3C/小家电 | 功能、效率、性能 | 兼容、稳定、操作、售后 | 可见操作、状态反馈、时间/空间结果 |
| 食品饮料 | 口感、原料、便利、品牌 | 成分、热量、安全、风味 | 包装事实、质地、制作/饮用、余韵反应 |
| 母婴/健康医疗 | 安全、省心、准确、易用 | 认证、适用范围、准确度 | 正确使用、稳定结构、真实认证资产 |
| 宠物 | 安全、适配、宠物接受 | 成分、体型/年龄适配 | 正确交互、真实使用、已确认信息 |
| 运动户外/水具 | 性能、耐用、便携、容量 | 重量、防漏、材料、适配 | 环境使用、持握尺度、状态或对照结果 |

品类表只决定“检查什么”，不证明当前商品拥有该能力。

## 4. 从决策到模块

内部按以下顺序：

`品类 → 成交理由 → 头号犹豫 → 当前证据 → 一个核心命题 → 有限内容模块 → 视觉证明 → Hero记忆`

常用模块：Hook、Hero、Usage、Performance、Material、Lifestyle、Trust、Dimension、Comparison、Before/After。5秒通常只容纳Hero加一个证明；10–15秒保留3–5个主要职责；20–30秒可以增加第二层证据或Trust，但仍只有一个核心命题。

只有缺失信息同时属于核心成交理由/首要犹豫并会改变命题或证据时，集中追问最高价值的1–3项；用户不回答则关闭对应功效、认证、参数、对比或前后效果模块，改走可见Usage、Material、Lifestyle和Hero的保守路线。

## 5. 验收

- 品类知识是否只用于提问与路由，而没有替商品作证？
- 比例、人物互动、景别和展示角度是否受素材支持？
- 是否只保留一个核心传播命题和当前证据能支撑的模块？
- 精确参数、认证、Logo、软件UI和CTA文字是否交给可靠资产或后期？
