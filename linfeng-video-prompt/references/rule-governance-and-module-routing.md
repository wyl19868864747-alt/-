# 全局规则治理与并行模块路由

每次调用完整读取本文件。它负责防止通用规则被埋在专用分支中，也负责让未来新增行业、模型和制作知识在换账号、换会话后仍能被完整调用。

## 1. 路由不是分叉树

先做双轴判断，但不要在得到“商业/剧情”结论后停止：

1. **第一轴**只决定最终验收对象：产品/品牌，或人物/剧情。
2. **第二轴**只决定提示词主要带宽：表演与关系因果，或氛围/体验/视觉证据。
3. **能力标签**决定还要读取什么：商品预检、消费者决策、UGC、食品风味、美妆选角、群像手部、`grounded-surreal`、`transformation-spectacle`、`observational-camera`、声音、长时节奏、连续性、复杂运镜、画质、模型工作流、编辑/延长、制作交付等。

能力标签是并列勾选项，不是互斥分支。命中多个条件时全部加载；专项模块可以跨第一轴调用。剧情式TVC可同时加载商业、人物表演、连续性与声音模块；带商品的短剧可以加载商品事实与连续性底线，但不得自动加入转化话术、Hero或CTA。

`grounded-surreal` 按画面机制触发，不按行业或片型触发：真人/实景与不可能事件、微缩劳动、产品世界化、巨物原料、产品拆解悬浮、卖点视觉隐喻或实拍与CG/AIGC合成都可命中。命中后只增加“让一个不可能规则可信并服务产品/剧情”的能力，不关闭或替代其他模块。

`transformation-spectacle` 按“变化过程是否值得被观看”触发，不按行业触发：当任务存在明确 A→B，且“如何从 A 变成 B”有机会比直接展示 B 更有新鲜度、审美价值或产品表达价值时命中。命中后负责设计现实动作、触发点、传播路径、中间形态与完成态；若发生在真人/实景/真实产品中继续叠加 `grounded-surreal`，若承担首屏留存继续叠加 `golden-3s-hook`。UGC、纪录感、自然口播和现实对话不因“更高级”自动命中。

`observational-camera` 按摄影者行为触发，不按广告/剧情/纪实片型触发：当真实感依赖摄影者身处现场、注意力有限、由事件触发反应并经历短暂设备恢复时命中。它可以与广告、剧情、UGC、群像、年代美术、写实超现实、产品事实和画质叠加；不得因广告身份关闭观察者行为，也不得因纪实身份关闭事实、物理和连续性。

## 2. 四层规则结构

| 层级 | 放什么 | 调用方式 |
| --- | --- | --- |
| A 全局硬规则 | 任何任务都不能丢失的方向、事实、物理、证据、声音、画质、输出与硬约束 | 写在 `SKILL.md`，始终生效 |
| B 公共运行层 | 用户稳定习惯、双轴路由、跨模块治理、冲突优先级与最低失败保护 | 每次完整读取 |
| C 能力模块 | 商品、UGC、食品、美妆、群像、运镜、连续性、长时、声音等详细方法 | 按所有命中标签叠加读取 |
| D 执行模块 | Seedance、编辑、延长、白模、PPM、Excel等模型或交付流程 | 仅在对应任务读取 |

专项 reference 不能改写或关闭 A/B 层；只能增加细节、严格度或适用示例。不同专项模块冲突时，按“当前用户硬约束 → 已确认事实/素材 → 更具体且有证据的规则 → 公共最低基线 → 最小合理假设”解决。

## 3. 跨域最低基线

即使没有加载专项文件，也始终保留：

- **事实与身份**：人物、产品、空间、文字、素材职责和已确认项目状态不得被风格化改写；没有参考素材时不虚构素材编号，没有尺寸证据时不用伪精确数字替代相对比例。
- **物理与连续性**：数量、尺度、站位、轴线、手别、道具归属、动作起点/接触/完成态、重力、支撑、反作用与主光世界方向连续。
- **证据边界**：产品功效、认证、成分、性能、兼容性和精确参数无依据不编造；剧情事件必须改变认知、决定或关系。
- **摄影职责**：镜头和运镜必须新增信息、关系、感知或产品证据，并以可承接的落幅结束。
- **声音真源**：精确语言只能有一个原文和一个声音源；同步声由可见动作触发。
- **画质与交付**：画质词落到边缘、材质、高光、暗部、运动、焦点、曝光和本色；分辨率、码率、编码和平台压缩归到交付层。
- **局部返修**：保留成功层，只修改唯一主问题和必要承接。
- **写实超现实**：先建立可信现实；一个镜头或生成段只允许一个高权重幻想规则，其余身份、尺度、受力、光影、人物反应和连续性保持现实，奇观后必须回收至实际使用、稳定空间、人物反应、产品记忆或剧情落点。
- **视觉蜕变**：当 A→B 的变化过程被选为核心看点时，必须先有可理解动作或力源，再从明确触发点沿可读路径传播，保留连续中间态并形成完成态；结果可以超现实，但不得破坏观众理解动作、接触、遮挡、受力和空间的过程。
- **感知与成像**：当目标是纪实、真人秀、幕后、家庭录像或档案电视真实感时，把摄影者视为现场中的有限身体：事件可以先发生，摄影机再发现、反应、追随并恢复构图。只允许与设备、身体和现场因果一致的受控摄影缺陷；人物身份、商品事实、空间、接触拓扑和动作连续性仍必须正确。

这些基线不得只存在于商品、短剧、UGC或画质等单一模块中。

## 4. 内部模块覆盖单

每次调用在后台完成，不默认外显：

```text
对话阶段：分析 / 生成 / 返修 / 技能维护
第一轴：产品品牌 / 人物剧情
第二轴：表演关系 / 氛围体验证据
能力标签：[可多选]
必须读取：[文件列表]
跨域最低基线：[本任务最相关的3–6项]
可省略模块及理由：[仅记录容易误触发的相邻模块]
```

检查 `SKILL.md` 的“强制读取条件”每一行后才开始写提示词。不能凭关键词机械匹配；只要任务语义需要该能力，即使命名不同也算命中。

## 5. 新知识写入规则

用户以后要求优化本技能时，逐条处理新增知识：

1. 写成一句可验证规则，区分方法、偏好、项目事实和模型临时限制。
2. 判断覆盖面：所有任务、两个及以上片型、单一片型、单一模型/交付。
3. 所有任务适用的规则进入 A/B 层；跨两个及以上片型，或遗漏会造成身份、事实、物理、声音、画质、合规或交付根本失败的规则，至少在本文件保留最低基线，并把详细方法放入最合适的专项 reference。
4. 单一行业或片型知识只进入专项 reference，但必须从 `SKILL.md` 直接列出语义触发条件；不得靠另一个 reference 间接发现。
5. 若一条规则与多个模块相关，指定一个“详细规则唯一归属文件”，其他模块只写短交叉引用，避免多份内容漂移。
6. 为新规则增加至少一个正向案例；跨域规则必须增加一个混合任务案例和一个不应误触发的反例。
7. 删除被新规则完全取代的重复表述；不得删除仍承担独立失败保护的公共基线。
8. 模型实测只有在因果清楚、完整成片验证且跨项目可复用时才可永久写回；单次随机成功或失败只作为测试记录，不直接升级为规则。

## 6. 防漏与防膨胀验收

- 是否把“主方向”误当成“唯一可读分支”？
- 是否逐项检查所有能力标签，而不是只匹配第一个关键词？
- 跨片型的高风险规则是否在公共层有最低基线？
- 每个专用模块是否能从 `SKILL.md` 一跳直达，并写明语义触发条件？
- 同一详细规则是否只有一个权威归属，其他位置只做短引用？
- 新知识是否真正改变判断或执行，而不是增加同义词和文件体积？
- 当前任务未命中的专项模块是否被合理省略，以免提示词带宽被无关知识占满？
