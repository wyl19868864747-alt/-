# 实体接管式转场

把转场写成一个真实物体或光学表面接管画面的连续动作，不依赖“无缝转场”“高级转场”或作者自定义术语。用于地点、时间、造型、人物状态、产品使用阶段或现实／想象之间的换景。

## 母公式

先确定七个可见变量：

1. **前镜完成态**：主体在遮挡前完成什么动作，观众需要读到什么结果。
2. **接管物**：帽子、肩背、衣料、产品、车辆、门板、墙柱、车窗、玻璃或镜面。
3. **入画路径**：从哪一侧进入，向镜头靠近还是横向扫过，速度如何变化。
4. **满屏阈值**：接管物何时覆盖整个画面，或反射何时成为画面主层。
5. **换景位置**：只在满屏遮挡或光学接管成立的短暂区间内，把场景A替换为场景B。
6. **继承关系**：下一镜继承运动方向、速度、主体位置、动作相位、构图重心、轮廓、亮度或声音中的至少两项。
7. **揭示完成态**：接管物的尾缘或同一动作离开画面，完整揭示新场景并停留到可读。

最终提示词按观众看到的顺序写：

`前镜动作完成 → 接管物进入 → 面积持续扩大／横向扫过／反射增强 → 画面被完整接管 → 在接管内部换景 → 接管物保持同方向和速度离开 → 新场景主体继承动作并完成结果`

## 三种可执行变体

### 1. 近镜不透明覆盖

让帽檐、肩背、手掌、衣料、包装、产品或门板靠近镜头，面积由局部扩大到满屏。在表面纹理完全占满画面的瞬间切换场景；下一镜由同一颜色、轮廓或动作沿原方向离开镜头。

可复制句式：

```text
[主体]把[接管物]从[方位]送向镜头，[接管物]由局部近景迅速扩大，直至其[颜色／材质纹理]完整覆盖画面；满屏遮挡持续一个短促节拍，场景在遮挡内部切换为[新场景]。同一[接管物／匹配轮廓]保持原运动方向和速度从镜头前移开，揭示[新主体]已在[对应位置]继续[承接动作]。
```

适合：人物换装、地点跳转、使用前后、产品开箱、剧情时间跃迁、短视频节奏点。

### 2. 横向运动物扫屏

让车辆、行人、门、柱体或大型前景物从画面一侧移动到另一侧。前缘逐步遮挡旧场景；物体覆盖画面中心并形成最大遮挡时换景；尾缘继续同速离开，像移动幕布一样揭示新场景。

可复制句式：

```text
[车辆／行人／门板]从画面[左／右]前景高速进入，前缘依次遮住[旧场景主体和背景]，摄影机保持[固定／同向平移]；当[接管物]的实体表面横跨并覆盖整个画面时，遮挡内部已经切换为[新场景]。其尾缘继续沿同一方向、近似同一速度退出，逐行揭示[新主体与环境]，新场景的地平线、主体高度和运动轴与前镜对齐。
```

适合：城市旅行、汽车广告、空间巡游、人物跨地点行动、节奏型TVC。它能保留运动能量，让硬切看起来由现实物体自然触发。

### 3. 透明表面与反射接管

让车窗、玻璃门、橱窗、镜面或水面同时承载透射层和反射层。随着玻璃升起、摄影机角度改变或主体靠近，旧场景透射层减弱，下一场景反射层增强；反射占满画面后转为实体新空间，保持玻璃边框、人物轮廓、视线或横向运动继续。

可复制句式：

```text
[玻璃表面]沿[方向]进入并逐渐占据画面，开始时仍能透过玻璃看见[旧场景]；随着[玻璃升起／摄影机侧移／入射角改变]，透射影像自然减弱，[新场景]的反射从玻璃暗部出现并逐渐增强。反射覆盖整个画面时，它无断点地成为真实的新空间；[人物轮廓／窗框／摄影机横移]保持原位置、方向和速度，随后完整显露[新时空的主体动作]。
```

适合：昼夜变化、现实与回忆、室内到室外、旅程跨时空、奢华汽车／时尚／香水／酒店TVC。它比不透明覆盖更柔和、更梦幻，但必须存在合理反射面和可解释的角度变化。

## 效果选择

| 目标效果 | 优先变体 | 关键继承 |
| --- | --- | --- |
| 干净、利落、节奏强 | 近镜不透明覆盖 | 方向、速度、颜色或轮廓 |
| 动感、城市感、旅程推进 | 横向运动物扫屏 | 地平线、运动轴、尾缘速度 |
| 梦幻、回忆、昼夜或时空交叠 | 透明反射接管 | 窗框、人物轮廓、亮度、摄影机路径 |
| 换装或身份变化 | 帽子／衣料／身体近镜覆盖 | 姿态、手势相位、画面重心 |
| 产品阶段切换 | 产品或包装靠近镜头 | 产品几何、持握手、标签朝向 |

## 激活方式

不要只写转场名称。至少同时写出以下五项，模型才有足够条件执行：

`接管物 + 入画方向 + 完整覆盖／反射占满 + 遮挡内部换景 + 新镜运动继承`

最短激活句：

```text
让[接管物]从[方向]进入并完整接管画面；只在满屏遮挡／反射占满的瞬间把[场景A]替换为[场景B]，随后让同一运动沿原方向和速度继续，揭示新场景中的主体已承接[动作／位置／视线]。
```

若没有写“完整覆盖”或“反射占满”，模型容易提前换景、双重曝光或把接管物变形。若没有写继承项，新镜容易改变轴线、人物位置或运动方向。

## 摄影与声音

- 不透明覆盖优先使用固定机位、短距离推近或单一方向平移；覆盖期间不叠加旋转、变焦和甩镜。
- 横向扫屏让接管物贴近镜头形成大面积视差；前后镜保持近似机位高度、地平线和主体占比。
- 反射接管明确玻璃边框、反射来源、透射层、入射角变化和曝光过渡；反射符合环境方向，不让玻璃凭空成为发光屏幕。
- 在满屏阈值加入一次短促掠过声、衣料摩擦、车身风切、车窗电机声或环境声桥；新场景环境声可提前少量进入，再在揭示后稳定。
- 日夜跨度较大时，让遮挡区吸收曝光变化；新镜揭示后完成曝光稳定，不用无来源白闪掩盖切换。

## 使用边界

以下情况默认不用：

- 前镜核心动作或产品 Proof 尚未形成可读完成态；
- 长对白、口型或情绪反应需要连续观察；
- 没有合理接管物，只能凭空出现一块遮挡；
- 产品英雄镜、标签或CTA正在建立，遮挡会抢走焦点；
- 同一短片已经连续多次使用，开始形成模板化炫技；
- 两个场景的主体位置、地平线和运动轴差异过大，且没有关键帧控制。

一条15秒视频通常使用1次主转场，最多2次不同变体。每次转场承担地点、时间、造型、状态或情绪中的一个明确变化，不把它当作无目的装饰。

## 生成控制升级

- 简单帽子、肩背或车辆遮挡可用文字直出。
- 人物身份、服装、产品几何需要严格保持时，为转场前后分别提供关键帧。
- 反射接管、昼夜跨越或两个空间差异大时，优先使用首尾帧、故事板或两段生成后在满屏遮挡处剪接。
- 连续失败两次时，不增加“无缝、丝滑、自然”等同义词；改为拆出“覆盖前—满屏遮挡—揭示后”三张关键帧，或把切点交给后期。

## 后台 QA

- 接管物是否有真实来源、材质、运动路径和离开方式；
- 是否在切换前达到完整覆盖，或让反射成为清楚主层；
- 换景是否只发生在接管区内部，没有提前漏出新场景；
- 接管物有没有变形、融化、穿过镜头或突然消失；
- 新镜是否至少继承两项：方向、速度、位置、动作相位、构图、轮廓、曝光或声音；
- 透明表面的反射、透射、边框和环境光是否符合物理关系；
- 转场前后的主体动作是否各自完整可读；
- 新场景是否在揭示后保持足够时间，让观众理解变化；
- 转场是否服务叙事、产品或节奏，而不是单纯炫技。
