# 摄影机与视觉成像基线｜Always-on Capture + Visual Surface Pass

## 0. 权限与调用

本模块拆成两层：

1. **Capture Baseline / Visual Surface Pass｜常驻层**：任何新写 / 重写视频 Prompt 都必须读取并在后台执行。它不只检查摄影机和清晰度，还固定完成一次“材质差异 → 光×材质响应 → 颜色层级 → 景深信息层级 → 构图/前中后景”的联合判断；不能因为用户没有主动说“画质、摄影、灯光”而跳过。
2. **Lighting / Advanced Cinematography｜条件层**：只有复杂布光、设备、光学或特殊材质展示本身决定结果，或用户明确要求 / 当前成片正在返修这些问题时才展开。

“常驻”不等于把五项视觉判断写成五个栏目，也不等于每镜重复术语套餐。后台每次都过，前台只保留会改变当前画面的最短可见词组，并融合进总控或对应动作—摄影句。

用户明确要求低清监控、DV、旧手机、故意失焦、强噪点、过曝实验影像等媒介时，以用户媒介为准，不强行修成干净数字电影画面。

默认篇幅权重仍低于：
`主体/产品 > 事件 > 动作/状态 > 连续性 > 每镜简短摄影机`

---

## 1. Capture Baseline｜每次必过

后台每次检查以下六项，但最终 Prompt 不机械逐项列出。

### 1.1 摄影机是现实中的观察者
- 景别、机位和运镜必须能由真实摄影机完成；
- 摄影机运动与人物动作、视线、遮挡、形变或空间揭示耦合；
- 横移 / 前后移动存在真实前中后景视差，不像平面贴图；
- 快速主体或快速镜头运动保留与速度相符的自然运动模糊，不做冻结锐边；
- 镜头停止或主体急停后允许轻微自然收稳，不做无惯性的“游戏自由摄像机”；
- 焦点和景深服务当前信息层级，不把“电影感”机械等同于全片大光圈浅景深。

### 1.2 成像与表面响应底盘
默认追求：
- 主体关键细节清楚、解析度充足，但边缘不过锐、不出现数码锐化白边；
- 人物皮肤、头发、布料、皮革、木材、金属、玻璃、塑料、水体等先按真实表面属性区分；不同表面保持不同粗糙度、反射、折射、透光或吸光结果，不统一成一层塑料亮面；
- 光与材质联合判断：高光只出现在合理的曲率、边缘、湿润面或油脂面，并随光源方向连续变化；皮肤可保留轻微油脂高光，发丝边缘、玻璃杯沿、金属棱边、潮湿地面等只在真实受光处出现局部亮点，不做全身/全场平均发亮；
- 人物、产品与环境处于同一受光世界，主光在世界中的方向稳定；亮部柔和滚降并保留细节，阴影保留少量环境反射与纹理，不无因死白、死黑或脏灰；
- 颜色先分工再调色：环境建立基底色，真实光源形成局部冷暖，肤色/产品固有色尽量保持可辨，强调色只给关键信息；需要空间纵深时，远景可自然降饱和、降对比或偏冷，近景保留更完整的材质与颜色密度，不默认全局高饱和；
- 景深跟信息走：脸、手、产品细节、关键表情可适度浅景深；人物关系、空间关系、尺度揭示与产品全貌恢复中深/深景深，不把“电影感”机械等同于全片大光圈；
- 运动区域允许真实运动模糊，静止关键主体保持可读，不用“全画面刀锐”冒充高清。

### 1.3 默认全局编译句
普通写实视频可压成一条：

`真实摄影透视与自然运动模糊；皮肤与关键材质保留真实纹理和局部受光差异，亮暗有层次，色彩与景深随当前信息层级自然变化。`

这句话只提供底盘；当某个镜头真正依赖玻璃折射、皮肤油脂高光、远景空气透视、前景遮挡等信息时，再把对应结果用一个短词组嵌进该镜。不要把材质、光、颜色、景深、构图拆成五句。

这是一条**可改写的功能句，不是固定咒语**。如果用户媒介是手机 UGC、家庭录像、胶片、监控等，要按媒介改写，而不是原样复制。

例如手机 UGC：
`手机主摄真实曝光与轻微手持，快速动作保留自然运动模糊；人物和产品细节清楚但不过锐，背景景深不过度虚化。`

如果这些结果已经由用户参考图 / 参考视频或明确媒介完整锁定，可进一步压短，但后台检查不能省略。

## 2. Shot Camera｜每镜仍然必须执行

常驻成像基线不替代每镜摄影机描述。

每个明确镜头仍按主 Skill 写：
`景别 + 观察方位/机位 + 一条短运镜`

并满足：
- 运动有事件触发；
- 镜头结束后新增可见信息，或让关键过程持续可读；
- 固定机位用于需要连续观察的过程，不为了“丰富”强行移动；
- 相机速度与主体动作匹配，不在普通动作中突然无因高速甩动。

复杂动作摄影、一镜到底、强注意力调度继续读取 `director-camera-attention.md`；具体焦段 / 光学方案继续读取 `cinematography-toolkit.md`。

## 3. 局部可见结果｜按风险选，不做套餐

只有当前镜头确实有风险时，补最短的一条或两条。

### 快速移动容易“AI锐边”
`转身和横移边缘保留自然运动模糊，停下后主体重新稳定清楚。`

### 横移像贴图
`前景掠过速度明显快于远景，形成真实空间视差。`

### 焦点层级混乱
`当前说话者和手中产品保持清楚，远背景自然退焦。`

### 皮肤蜡感
`皮肤保留轻微毛孔、油脂与局部色差，不磨成均匀蜡面。`

### 玻璃 / 金属容易假
`玻璃边缘保持透明折射，高光不过曝；金属反射沿表面曲率连续变化。`

### 产品 / 人物漂浮
`承载面保留自然接触关系与轻微接触阴影，主体不悬浮。`

### 暗部死黑 / 脏灰
`阴影面保留少量环境反射和结构，不抬成均匀灰雾。`

## 4. Lighting Design｜条件层

**基础受光与材质响应已经属于常驻 Visual Surface Pass。** 本节只处理复杂灯光设计；不因为常驻层存在就强制展开灯具、布光或高级摄影术语。

命中以下任一情况时才重点写光：
- 光线直接决定主体是否可读；
- 产品材质、颜色或卖点依赖受光；
- 光线本身触发剧情或状态变化；
- 当前成片问题就是过曝、死黑、脏灰、塑料感、环境脱节；
- 多场景存在明确不同的光源逻辑；
- 用户明确要求摄影、灯光或画质方案。

需要写光时，先回答“光从哪里来”。

光源可以来自窗户、顶灯、屏幕、火焰、霓虹、车灯、发光产品等；环境色只影响合理受光面。相机换侧时，光源在世界中的位置不跟着摄影机一起换边。

普通片不独立建立长篇【光影】块；能并入相关镜头就并入。只有多场景灯光明显不同、产品材质展示依赖精确布光、光线驱动剧情或用户明确要求摄影方案时，才展开独立灯光段。

## 5. 设备与光学名词

设备名不是质量咒语。

只有用户明确指定，或设备身份会直接改变可见结果时才保留，例如：
- 手机主摄：自然曝光变化、轻微手持、有限暗光表现；
- 数字电影摄影：柔和亮部、自然肤色、受控景深；
- 大画幅胶片：更明显的空间尺度、细微颗粒和柔和亮部。

不把 IMAX、ARRI、UE5、Octane、ILM、8K、HDR 叠成通用“高级套餐”。

焦段、光圈、色温只有在数值本身会改变结果或用户明确要求时写；优先转换成可见效果：
- `近机位广角，前景明显放大，背景快速退远。`
- `远机位长焦，主体尺寸保持稳定，远景在身后显得更近。`

不输出无测量依据的假精确值。

## 6. Prompt Pollution Audit

写入摄影 / 成像 / 光影句前检查：

1. 这是常驻成像底盘，还是专项灯光设计？
2. 全局一句已经覆盖的结果，是否又在每镜重复？
3. 局部句是否解决一个明确风险或承担一个视觉职责？
4. 是否只是设备名、摄影术语或“高级感”包装？
5. 是否开始比主体、动作或产品描述更长？
6. 是否与用户明确媒介冲突，例如把手机 UGC 强行修成无噪电影摄影？
7. 是否为了“清晰”错误删除了真实运动模糊、景深层级或材质细节？
8. 本次是否真的完成了材质差异、光×材质局部反馈、颜色分工、景深信息层级、构图/前中后景五项后台判断？
9. 最终是否把五项判断融合成少量可见结果，而不是输出“材质层／光层／色层／景深层／构图层”或固定套餐？

最终原则：

> **每次调用都完成完整 Visual Surface Pass；最终只保留最少、最有效的可见结果。复杂灯光和高级摄影按需展开，让 Skill 懂更多，让模型看到更少、更准。**
