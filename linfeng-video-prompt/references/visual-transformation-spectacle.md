# 视觉蜕变奇观｜Visual Transformation Spectacle

能力标签：`transformation-spectacle`。

用于高概念广告、模型能力展示、产品变形、世界重构、超现实品牌片、唯美视觉Hook，以及任何“从 A 变成 B，而 A→B 的过程本身有机会成为主要看点”的任务。

本模块不负责替代 `grounded-surreal-product-spectacle.md` 的写实超现实世界合同，也不替代连续性、商业证据、黄金3秒或转场规则。它只解决一个问题：**如何让“变化发生的过程”本身成为值得观看的视觉事件。**

## 1. 自动激发条件

出现以下任一语义时，主动评估本模块，不要求用户明确说出“视觉蜕变奇观”：

- 有创意、新奇、唯美、惊艳、视觉奇观、视觉冲击、电影级、高概念、模型能力展示；
- 原素材/绿幕/草图/普通产品/普通空间需要重构成另一种完成态；
- 用户要求变形、生成、生长、绽放、包裹、凝结、结晶、重组、世界变化或产品形成；
- 存在明确 A→B，但常规“切一下就变成 B”会浪费创意空间；
- 产品属性、材质、功能或品牌情绪可以通过连续变化被看见。

触发后先做适配判断，不自动强行使用。

## 2. 四项适配判断

只有以下大部分成立时才启用：

1. **存在简单现实动作**：踩、触碰、按下、拉动、打开、倒入、穿过、拿起、拍摄等，观众一眼能读懂。
2. **存在清楚的完成目标**：产品、服装、空间、场景、材质、角色状态或模型输出有明确 B 状态。
3. **“怎么变”比“变成什么”更有观看价值**：变化过程有机会成为这一镜最值得看的内容。
4. **片型允许视觉介入**：高概念TVC、品牌片、模型Demo、时尚、美妆、汽车、科技与视觉实验优先；UGC、纪录感、自然口播、现实对话默认降低优先级，除非用户明确需要超现实介入。

若只是为了“高级感”添加变化、删除变化后产品理解与视觉兴趣不受损，则跳过本模块。

## 3. 核心创意公式

内部按以下顺序设计：

`熟悉现实动作 → 微悬念 → 明确触发点 → 连续可观察传播 → 超预期形态重构 → 产品/信息收束`

核心不是让 B 突然出现，而是让观众亲眼看到 B 如何诞生。

内部第一问：

`这一镜里，有没有什么东西可以不是“出现”，而是“诞生”？`

若答案成立，再继续设计传播过程。

## 4. 变化必须有因果与传播路径

变化不能全画面无原因同时发生。先锁定：

- **触发动作**：谁做了什么；
- **变化起点**：接触点、受力点、按钮、液体落点、屏幕边缘、物体表面等；
- **传播方向**：沿身体、地面、产品表面、空间边缘、镜头深度或已有运动方向推进；
- **中间状态**：观众能看见变化逐步完成，而不是 A 与 B 之间被闪白、粒子或模糊遮掉；
- **完成态**：最终形成、揭示、包裹、强化或解释产品/信息。

先动作，再变化。门、车门、抽屉、包装等具有机械结构的对象，必须先由人物或真实力源完成开启/触发动作，再允许变化发生；不得让门自己开启、人物穿过实体、产品无接触瞬移。

## 5. 变化路径候选

启用后，后台至少快速探索两到三种不同机制，再选一版最优，不把候选全部外显。

### 主体蜕变
主体自身连续重构，如轮廓、材质、结构、服装或产品状态逐步变化。

### 材质蜕变
一种真实或超现实材质沿可读路径流动、编织、凝结、结晶、塑形并形成目标。

### 环境蜕变
变化从局部触发点向空间扩散，让普通环境逐步成为另一个完整世界。

### 空间蜕变
利用屏幕、镜面、门框、摄影机取景框、容器或空间边界，让变化跨越一个明确边界并接管现实。

选择标准：

`产品关联度 × 创意新鲜度 × 唯美程度 × 动作合理性 × 模型可生成性`

不要因为“绽放、结晶、粒子”曾经成功就机械复用同一种机制。

## 6. 唯美动态优先级

当目标是唯美、高级、梦幻而非破坏性刺激时，优先考虑具有连续生命感的运动逻辑：

- 生长、绽放、蔓延；
- 流动、缠绕、编织；
- 折叠、展开、覆盖；
- 凝结、结晶、塑形；
- 结构重组、表面生成、空间逐层重构。

这些是运动家族，不是固定画面模板。具体材质与运动必须由产品属性、场景和品牌情绪推导。

## 7. 构图锚点与世界变量

连续多次蜕变时，优先保留至少一个稳定锚点：主体位置、动作方向、构图骨架、摄影机路径或接触点。再大幅改变材质、尺度、环境、世界规则或完成方式。

目标是“观众不需要重新理解画面，但每次都得到新的视觉奖励”。

若每次同时更换主体、机位、动作、空间、材质和光线，优先减少变量。

## 8. 连续奇观必须升级

同一片中多次使用时，不允许只是“换一种材质再重复一次”。按需使用：

`建立规则 → 强化规则 → 改变传播方式/尺度/空间关系 → 打破已建立预期 → Hero/信息回收`

升级维度可来自传播方向、空间尺度、主体与环境关系、摄影机关系、最终结果或物理规则，而不是单纯增加粒子、爆炸和快切。

## 9. 与黄金3秒的组合

当任务同时命中 `golden-3s-hook` 时，可把现实动作本身作为未完成状态：

`观众看懂动作 → 预测普通结果 → 动作触发异常 → 唯美变化开始兑现 → 延迟完整完成态`

第一Hook是“接下来会发生什么”，第二Hook是“居然这样发生，那下一次会怎样”。不要为了前三秒把完整变化一次性泄露。

## 10. 与写实超现实的组合

当蜕变发生在真人、真实产品或实景世界中，同时加载 `grounded-surreal-product-spectacle.md`：

- 默认让一个主幻想机制引导当前变化；用户明确的多机制按先后和局部作用边界组织，容量判断见 `prompt-compilation-and-consistency.md`；
- 接触、重力、遮挡、反射、主光、人物反应和尺度仍服从现实；
- 变化结束后形成明确完成态，并回收到产品、实际使用、人物反应或稳定空间。

视觉结果可以超现实，但观众理解动作的过程不能被破坏。

## 11. 提示词编译

最终提示词按时间顺序写可见过程，不写幕后创意解释：

`正常首帧 → 人物/物体动作 → 接触或触发 → 局部首次变化 → 变化沿明确路径传播 → 中间形态连续可见 → 完成重构 → 产品/信息落幅`

优先具体描述材质如何移动、形态如何变化、从哪里开始、沿哪里传播、何时完成。删除“视觉蜕变奇观、很有创意、超级震撼、唯美转场”等不能直接成像的标签。

复杂蜕变时，摄影机优先固定、缓慢推进、短跟随或单轴运动，让观众看清变化；变化本身已经足够高能时，不再叠加无因360°、频繁变焦、甩镜和多次切镜。

## 12. 后台验收

交付前检查：

1. 动作是否先于变化发生？
2. 变化是否有明确起点、传播方向和完成态？
3. A→B 的中间过程是否真的比瞬间替换更值得看？
4. 变化是否服务产品、功能、模型能力、情绪或品牌，而不是纯装饰？
5. 是否存在一个稳定构图/动作锚点帮助观众读懂变化？
6. 多次变化是否升级，而非换皮重复？
7. 是否避免无因闪白、随机粒子、突然传送和全画面同时变化？
8. 是否保持人物、产品、空间、受力、门体/车门等机械动作的连续合理？
9. 若为UGC、纪录或自然对话，是否有充分理由使用本模块？
10. 最终提示词是否只留下可见过程，没有把内部规则原样写给生成模型？
