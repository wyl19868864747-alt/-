## 1. 使用边界

只在主技能判定为“完整创意”时读取本文件。快速重写、分镜转提示词、视频编辑、延长、转场、已有方案的局部优化，不读取本文件。

本文件只补充广告策略、创意方向、品牌世界、视觉定调和前期资产规划。摄影参数、可视化语言、站位连续性、Seedance任务模式与生成调试继续使用主技能已有专项参考，不在这里重复。

## 2. 最小输入与需求校准

完整TVC至少需要产品、目标时长和产品视觉基准。真实产品优先使用官方多角度图、实拍图或可靠渲染；没有产品参考时说明身份一致性风险，但可以继续概念产品路径。缺少产品或时长时只问一个会改变核心方案的问题，同时给出带标记的可修改草案。

先提取并区分：

- **用户已确认**：产品、卖点、受众、时长、画幅、平台、模型、声音、引用语法、禁用元素与已有资产。
- **导演推导**：主传播命题、观众欲望、品牌世界、视觉母题、叙事模型、节奏和产品植入强度。
- **待确认**：只有不同答案会明显改变故事、视觉或交付方式的缺口。

不得虚构功能、认证、数据、竞品比较或材料结构。Logo、包装文字、字幕和法务小字默认规划安全区并交给后期，不要求生成模型准确绘制。

## 3. 创意判断顺序

在写故事前完成八个判断：

1. **传播命题**：观众看完只记住哪一个事实或感受。
2. **主决策**：观众购买前最需要确认什么。
3. **首要犹豫**：哪项具体不确定性最可能阻止行动。
4. **视觉证据**：什么过程、即时结果、生活后果或可靠验证能够证明卖点，而不是口头宣布。
5. **观众欲望**：产品让观众进入什么状态、成为谁或摆脱什么阻力。
6. **品牌世界**：只有该品牌合理存在的空间、色彩、材质、动作和声音气质。
7. **视觉母题**：贯穿全片的一个形状、运动、材质、构图或光线逻辑。
8. **收束记忆**：Hero Shot、End Frame和最后一个声音如何共同落点。

只保留一个主传播命题、一个主决策和一个首要犹豫。其他卖点作为证明层，不能与主命题竞争。优先选择可以被画面直接证明的利益点；抽象利益必须转成可见后果。需要从卖点反推Hook、产品介入和证明事件时读取 `decision-driven-ad-creative.md`。

## 4. 叙事模型选择

| 主模型 | 适合 | 必须补足 |
|---|---|---|
| 觉醒揭示 | 奢侈品、电子、汽车、精密产品 | 不能只做漂亮转台，至少有一次功能或结构证明 |
| 问题—转化—结果 | 家电、清洁、护肤、效率产品 | 将问题压缩成一个强视觉瞬间 |
| 性能升级 | 运动、户外、汽车、性能装备 | 每次升级都回扣产品证据 |
| 双世界交叉 | 耳机、跑鞋、手表、汽车、运动相机 | 每个切点有运动、形状、色彩、声音、意义或因果桥梁 |
| 使用仪式 | 咖啡、美妆、香水、厨房、穿戴产品 | 动作从克制到释放，避免重复 |
| 材质诗 | 珠宝、腕表、护肤、音响、奢侈品 | 中后段完成尺度揭示和完整产品Hero Shot |
| 人物微叙事 | 家庭、食品、礼赠、生活方式、服务 | 产品必须触发或完成情绪转折 |
| 视觉隐喻 | 抽象利益和高概念品牌片 | 隐喻、产品特征和利益点一一对应 |

15秒通常只选一个主模型；30秒可以加入一个辅助模型；60秒才适合更完整的混合。方向之间必须在叙事机制或产品植入机制上真正不同，不能只换颜色、场景或摄影风格。

## 5. 创意方向提案

默认给2–3个方向，每个方向简洁包含：

- 概念名与一句话概念
- 单一传播命题、主决策、首要犹豫和视觉证据
- 目标受众、观众欲望与目标感受
- 主叙事模型及选择理由
- 品牌世界、产品世界和视觉母题
- 产品以线索级、参与级、主角级如何递进
- 0秒到结束的内容流程
- Hook、升级、高潮、Hero Shot与End Frame
- 交叉剪辑或转场桥梁
- 构图、色彩、材质、光线与活力曲线
- 人物出镜策略
- 必要资产、AI可行性、主要风险与替代方案

用户选择后再展开导演阐述。用户明确要求直接执行时，选择能最清楚证明卖点、品牌辨识度最高且AI风险可控的方向；只说明会影响结果的关键假设，然后继续。

## 6. 视觉定调

进入批量资产和提示词前锁定：

- 摄影级写实、电影写实、精密产品CG、高能品牌CG或特定美学。
- 构图母题、焦段倾向、机位能量与主要运动方式。
- 主色、辅助色、唯一饱和强调色和色彩弧线。
- 主材质对比、高光形状、粗糙度、反射边界与微纹理。
- 世界空间中的主光方向、软硬、色温和品牌色来源。
- 活力波形：压缩、停顿、爆发、悬停、收束。
- 禁用美学和最可能破坏产品识别的AI瑕疵。

每个关键镜头只选一项主张力和一项辅助张力，例如大/小、明/暗、静/动、粗/细、冷/暖或满/空。视觉张力不得遮挡产品轮廓、功能区或标签面。

## 7. 前期资产规划

从选定分镜反推必要资产，不按“可能有用”无限扩张：

1. **产品标准**：官方多角度参考优先；锁定比例、轮廓、材质、配色、接口、按钮、Logo区域和不可改变项。
2. **产品状态**：为关闭、开启、功能灯、拆解、组装、使用/佩戴等状态编号；每镜只使用一个主状态。
3. **人物标准**：身份、体态、发型、服装、鞋、配饰、惯用手、表演气质和与产品的尺度关系。
4. **场景标准**：平面关系、入口、关键物体、时间天气、主光方向、品牌色来源和可用于转场/环境反馈的元素。
5. **声音规则**：对白、环境声、指定音效和BGM有无；用户要求无BGM时，后续每段视频提示词前置该限制。
6. **资产映射**：编号、内容、唯一职责、来源、锁定状态、使用镜头和风险。引用语法全片统一，不超过平台或用户上限。

生成顺序默认是：产品多视图 → 产品细节/状态 → 人物设定 → 场景基准 → 特效/UI状态 → 关键帧/多宫格 → 视频段落。真实产品不得被文字提示词重新设计。

进入分镜前建立最小一致性圣经：产品、人物、场景、影像各自的固定项、可变项和禁止项。

## 8. 导演结构与交叉剪辑

先写整片脉络：观众先看到什么、何时识别产品、卖点如何被证明、哪里升级、最后怎样记住产品。再拆镜头；每镜只有一个主要功能：Hook、建立、证明、转折、欲望、揭示、记忆或收束。

拆分两个及以上镜头时完整读取 `director-information-control.md`：先建立核心问题、知情曲线、揭示计划、视点策略、空间秩序和注意力接力，再逐镜回答“为什么必须有这一镜 → 应该怎样拍”。产品TVC把逐镜问题转译为“产品是什么、怎样进入、怎样使用、材质/功能如何被证明、为什么相信、最终记住什么”。复杂运镜再读取 `director-camera-attention.md`，删除无因移动并让英雄镜前减速停稳。

常用时长骨架：

- **6–10秒**：0–2秒Hook；中段一个产品证据；最后Hero Shot与End Frame。
- **15秒**：0–3秒Hook；3–9秒卖点证明与一次升级；9–12秒欲望/结果；12–15秒Hero Shot与End Frame。
- **30秒**：0–4秒开场；4–11秒世界建立与第一次证明；11–21秒交叉升级或第二证据；21–26秒高潮；26–30秒收束。

交叉剪辑的每个切点至少有一个可见桥梁：运动方向、形状、构图、颜色、光线、声音、意义或因果。复杂世界切换优先放在不同生成段或Phase边界，精确切点交给后期。

默认让产品在约70%的关键帧中清晰可读，每5–8秒至少出现一次明确识别或功能证据。该比例是策略参考，不是机械硬限制；悬念或情绪需要隐藏产品时，必须用后续完整揭示、因果证明和End Frame补偿。

## 9. 向林枫执行层交接

选定方向后，只向后续模块传递一份精简“创意生成合约”：

```text
产品事实与禁改项：
单一传播命题：
主决策与首要犹豫：
目标受众／欲望／目标感受：
Hook、产品因果介入与视觉证据：
品牌世界与视觉母题：
产品揭示方式：
节拍／升级／高潮／Hero Shot／End Frame：
视觉基准、主色、材质与主光：
资产映射与唯一职责：
声音与后期文字规则：
主要AI风险：
```

后续由林枫主框架完成模型任务选择、观看顺序、动作因果、摄影机反应、站位轴线、物理连续性、Seedance时码、负面提示和可复制成品。不要在交接后重新生成另一套创意，也不要重复加载本文件已经完成的方向比较。

## 10. 商业质量检查与迭代

交付前检查：

- **策略**：只有一个主传播命题、主决策和首要犹豫；Hook 暴露真实犹豫、结果或欲望；卖点被画面证明；产品触发故事或结果；广告结论不超过证据与事实边界。
- **品牌与美学**：品牌世界、视觉母题、色彩、材质和光线统一；张力服务产品；活力包含停顿、爆发和释放。
- **产品**：身份、比例、材质与关键结构稳定；关键节奏点清晰可读；Hero Shot与End Frame完整。
- **资产**：每个参考只有一个主要职责；编号与正文一致；文字、Logo和法务留给后期。
- **可执行性**：高风险交互、液体、机械、多人、复杂反射和复合运动已拆分或升级控制方式。

审片先观察证据，再按单变量修改。连续三次微调无效时回到上游：产品错误回产品资产，人物错误回角色设定，空间错误回场景和轴线，运动错误拆段，美学错误重做视觉母题和主对比；不要继续堆叠同义负面词。

## 11. 输出裁剪

- 用户只要创意方向：输出2–3个方向，不提前展开全部提示词。
- 用户只要分镜或提示词：完整创意判断在内部完成，只输出一段最佳方向摘要和当前所需成品。
- 用户要求端到端且允许直接执行：选择最佳方向，按“创意合约 → 资产 → 分镜 → 提示词”继续，但不展示冗长内部自检。
- 用户只改单一镜头：保留已确认的品牌、创意和资产，只修改受影响镜头及必要承接。
- 没有新证据时不输出学习摘要；只有用户明确要求永久固化时才更新技能规则。
