# 情绪表情动作链：FACS研究底座与AI视频编译

## 1. 定位与边界

本专区用于已经形成故事大纲、剧情节拍或人物目的后，细写人物分镜与视频提示词。它只补充人物反应，不替代镜头的主体、事件、空间、产品证据和动作因果。

FACS编码的是可观察面部动作，不直接证明人物内心情绪；同一动作可以出现在多种情绪中，复杂情绪还依赖刺激、语境、视线、头部、呼吸、声音和身体。下方分为两层：

- **研究锚点**：基础情绪与复合情绪的常见FACS原型；用于保证眉、眼、鼻、嘴的组合不互相打架。
- **导演扩展**：把自然表演研究与常见剧情状态转成可拍动作链；用于尴尬、怀疑、释然、骄傲等没有唯一FACS公式的状态，不得宣称是读心或唯一表情。

禁止把“说谎、善恶、人格、动机、疾病”写成可由一张脸准确识别的固定表情。

## 3. 写入分镜的表情DNA

### 3.1 后台选择链

`人物此刻想要什么 → 哪个可见刺激改变判断 → 从下方选一个最接近状态 → 选2–4个相容动作 → 安排出现顺序 → 让表情导向台词、决定或下一动作`

### 3.2 前台压缩式

默认只写：

`刺激到达 → 视线/手/呼吸先停一下 → 眉眼或鼻嘴出现一个主变化 → 头部/重心或语言随之改变`

例如，不写“她非常震惊”，写：

`数字落下，她正要翻页的手停住，双眉抬高、眼睛短暂睁大，嘴唇微张；半拍后把账单拿近重新核对。`

### 3.3 强制编译规则

1. **画面优先**：具体表情动作只进入发生反应的时间段，放在刺激与主体动作之后；不进入【开场总述】、技术基线或资产锁定前部。
2. **一拍一主状态**：一个反应节拍只选一个主情绪，可带一个低权重残留状态；不要同时堆“震惊、恐惧、兴奋、怀疑、感动”。
3. **动态而非定格**：写出 `出现前 → 主变化 → 释放/转向下一动作`；同一张静态表情持续数秒会变成面具感。
4. **动作预算**：普通对白每次保留2–3个面部信号；近景核心反应最多4个。能用手停、视线落点或一次呼吸说明的，不再补满整套脸部动作。
5. **强度匹配**：生活对白用轻至中等强度；Hook或反转可明显，但必须由事件强度支持。不得把低价、普通问候或小失误一律演成尖叫、瞪眼、捂嘴。
6. **口型让位**：说长台词时少写复杂嘴部动作，把鼻、嘴、下颌的表情变化放在开口前、关键词停顿或说完后；准确口型优先于同时执行多个AU。
7. **人物错峰**：双人/多人不复制同一表情。先看见者先变，后理解者稍后变；说话者保持自己的目的，听者承担核对与决定。
8. **跨镜继承**：切镜只改变观察距离，不重置眼湿、嘴唇紧张、呼吸、视线和表情阶段。下一镜从上一镜完成态继续。
9. **复杂状态带语境**：怀疑、羞耻、爱、嫉妒、心虚等必须同时写清看向谁/什么、头部或身体怎样变化以及随后做什么；只写脸不能唯一辨认。
10. **不做读心结论**：表情只说明当前画面如何被观众读取，不据此判断人物是否说谎、危险或患病。

## 4. 研究锚点：基础与复合情绪

下列动作是适合视频生成的精炼版本；括号中的AU用于后台校验，不必进入成片提示词。

### 4.1 基础状态

- **中性** = 眉眼放松 + 双唇自然合拢 + 下颌不绷紧 + 视线自然停留或扫动。
- **喜悦/开心（AU6+12，可伴25）** = 双颊抬起 + 眼裂略窄、眼尾出现细纹 + 双侧嘴角上扬 + 双唇自然分开。
- **悲伤（AU1+4+15，可伴17）** = 眉内侧抬起且眉心收拢 + 上眼睑略垂 + 嘴角下压 + 下巴中央轻抬。
- **恐惧（AU1+2+4+5+20+25/26）** = 双眉抬起又向眉心收紧 + 上眼睑明显打开 + 嘴角横向拉开、双唇分开 + 下颌松开并短促吸气。
- **愤怒（AU4+7+23/24）** = 双眉下压收紧 + 眼睑收紧直视刺激源 + 双唇收紧或压紧 + 下颌绷住。
- **惊讶（AU1+2+5+25/26）** = 双眉迅速抬高 + 上眼睑打开 + 双唇分开 + 下颌自然下落。
- **厌恶（AU9+10，可伴17/24）** = 鼻梁皱起 + 上唇抬高 + 眼睑略收紧 + 下唇或下巴向上顶。
- **轻蔑（常见单侧AU14/12）** = 单侧嘴角收紧并微抬 + 同侧面颊形成浅凹 + 眼睑略压低 + 下巴保持稳定。

### 4.2 复合状态

- **惊喜/喜悦地惊讶** = 双眉抬高 + 眼睛先睁大 + 双颊随即抬起 + 嘴角上扬、双唇分开。
- **笑着嫌弃/喜悦地厌恶** = 鼻梁轻皱、上唇抬起 + 双颊抬起 + 嘴角仍向上 + 头轻轻后撤。
- **悲伤又害怕** = 眉内侧抬起、眉心收紧 + 眼睛紧盯刺激源 + 嘴角横向拉开又略下坠 + 呼吸变浅。
- **悲伤又愤怒** = 双眉下压但眉内侧仍上提 + 眼睑收紧 + 嘴角下压 + 下巴顶起、双唇压住话。
- **悲伤地惊讶** = 眉内侧先抬高 + 眼睛打开 + 嘴唇微张、下颌下落 + 嘴角随后下坠。
- **悲伤地厌恶** = 眉内侧抬起、眉心收拢 + 鼻梁皱起、上唇抬高 + 嘴角下压 + 下巴轻抬。
- **害怕又愤怒** = 双眉下压收拢 + 上眼睑打开、下眼睑收紧 + 嘴角横向拉开 + 下颌绷紧准备行动。
- **惊恐/害怕地惊讶** = 双眉高抬又在眉心收紧 + 双眼明显睁大 + 双唇横向拉开并分开 + 下颌下落、吸气停住。
- **害怕又厌恶** = 眉心收紧、眼睛先睁大 + 鼻梁皱起 + 上唇抬高、嘴角横向拉开 + 头部后撤。
- **愤怒地惊讶** = 双眉下压 + 眼睛突然打开 + 双唇分开、下颌下落 + 视线立即锁住对方。
- **愤怒又厌恶** = 双眉下压、眼睑收紧 + 鼻梁皱起 + 上唇抬高 + 双唇压紧、下巴绷住。
- **厌恶地惊讶** = 双眉抬起后眉心微收 + 眼睛打开 + 鼻梁皱起、上唇抬高 + 嘴唇微张。
- **骇然/强烈反感（appalled，厌恶主导）** = 鼻梁明显皱起、上唇抬高 + 双眉压低 + 眼睛短暂睁大 + 头和上身迅速后撤。
- **憎恶（hatred，愤怒主导）** = 双眉压低、眼睑收紧并持续盯视 + 鼻梁轻皱、上唇抬起 + 双唇压紧 + 下巴略向前。
- **敬畏/震撼（awed）** = 双眉柔和抬高 + 双眼睁大并稳定凝视 + 双唇轻分、下颌微落 + 头稍抬起后安静停住。

## 5. 导演扩展：自然、社会与认知状态

这些是可拍模板，不是“某情绪唯一科学公式”。必须根据故事刺激、人物关系和表演强度取舍。

### 5.1 正向与接近

- **觉得好笑/被逗乐** = 双颊先抬起 + 嘴角向上失守 + 双唇分开短笑 + 头轻低后再看向对方。
- **满足** = 眼睑放松 + 双颊轻抬 + 闭口小笑 + 缓慢呼气、身体安定下来。
- **释然** = 眉心与下颌先松开 + 双唇分开长呼气 + 肩部落下 + 嘴角轻轻回升。
- **欣喜** = 眼睛亮起 + 双颊快速抬高 + 嘴角明显上扬、双唇分开 + 身体自然前倾。
- **狂喜** = 双眼短暂闭合 + 双颊高抬 + 张口大笑 + 头与胸口向上打开。
- **骄傲** = 克制微笑 + 下巴微抬、头略向后 + 胸口打开 + 视线稳定接受注目。
- **胜利感** = 眼睛睁亮 + 嘴角高扬、双唇分开 + 下巴上抬 + 拳头或双臂短促展开。
- **兴趣** = 眉内侧轻抬 + 视线锁定新信息 + 双唇微分 + 头与上身稍向前。
- **好奇** = 双眉轻微不对称 + 眼神先扫动再聚焦 + 头微侧 + 嘴唇轻分。
- **期待** = 双眉轻抬 + 视线固定在即将发生处 + 双唇先压住再分开 + 重心前移。
- **渴望** = 眼睑略低、目光停留更久 + 双唇轻分 + 缓慢吸气 + 头部不自觉靠近目标。
- **爱意/温柔** = 眉内侧轻抬 + 眼神柔和持续 + 闭口小笑 + 头轻侧向对方。
- **同情/心疼** = 眉内侧抬起并靠拢 + 眼神变软 + 双唇轻压、嘴角略下 + 头和上身靠近对方。
- **平静** = 眉眼无紧张 + 眼睑自然开合 + 双唇松弛合拢 + 呼吸均匀、头部稳定。

### 5.2 思考、判断与社交防御

- **专注** = 眉心轻收 + 眼睑略紧 + 双唇轻压 + 视线固定在任务点。
- **沉思** = 视线移向侧上方或空处 + 眉心轻收 + 双唇抿住或微噘 + 头部安静停留。
- **困惑** = 双眉一高一低或眉内侧收紧 + 眼睛轻眯后眨一下 + 嘴唇微张 + 头向一侧倾。
- **怀疑** = 单侧眉峰抬起 + 眼睑收窄 + 单侧嘴角收紧 + 头部轻轻后撤。
- **警惕/猜疑** = 双眉低压且略不对称 + 眼睛从侧面观察 + 双唇压紧 + 下巴后收、身体不靠近。
- **突然听懂** = 视线停住 + 双眉和上眼睑轻抬 + 嘴唇形成很小的“哦”形 + 随即点头或开始行动。
- **勉强相信** = 眉心张力先减弱 + 目光再次核对证据 + 双唇松开 + 身体前倾或给出一次小点头。
- **冷漠/无所谓** = 眉眼变化极少 + 双唇保持中性 + 视线从刺激源移开 + 身体状态不随信息改变。
- **尴尬** = 短促紧张微笑 + 视线向下或侧开 + 头低下并偏向一侧 + 手短暂触碰脸或颈部。
- **局促** = 单侧僵硬微笑 + 眼神移开后快速回来 + 双唇重新压住 + 头部小幅侧倾。
- **羞耻** = 视线下垂 + 头部向下 + 双唇压紧或失去表情 + 肩部与胸口内收。
- **内疚** = 眉内侧轻抬 + 尝试对视后再次移开 + 嘴角略下、双唇压住 + 下巴降低。
- **客套假笑** = 嘴角上拉但双颊几乎不抬 + 眼周仍紧张 + 笑容固定半拍 + 视线很快离开。
- **憋笑** = 嘴角先被压住又微微上窜 + 双颊开始抬起 + 眼尾轻收 + 视线躲开后再回来。
- **得意** = 单侧嘴角微抬 + 眼睑放松略窄 + 下巴稍高 + 视线不回避对方。
- **嫉妒/眼红** = 眉心轻收 + 视线在对方与目标之间来回核对 + 双唇压紧 + 身体略撤开；必须用剧情对象说明，不能只靠脸。

### 5.3 压力、受挫与防御

- **担心** = 眉内侧抬起、眉心收紧 + 眼神反复核对关键对象 + 双唇轻压 + 呼吸略浅。
- **焦虑/紧张** = 眉眼持续带张力 + 视线短促移动、眨眼增加一次 + 双唇压住后又松开 + 吸气不完整。
- **失望** = 眉内侧轻抬 + 上眼睑下落 + 嘴角下压 + 缓慢呼气、头部降低。
- **苦恼/痛苦情绪** = 眉心收紧 + 眼睛湿润或用力忍住 + 嘴角向两侧又向下拉 + 呼吸断开。
- **无助** = 眉内侧抬起 + 眼神寻找他人回应 + 双唇轻分却说不出话 + 肩部先抬后落。
- **认命/无奈** = 眼睑下落 + 双唇压住后呼气松开 + 下巴降低 + 视线离开问题。
- **无聊** = 上眼睑半垂 + 视线游离 + 嘴部完全松弛 + 头部歪向支撑物。
- **不耐烦** = 双眉轻压 + 侧目时间或出口 + 双唇收紧 + 鼻腔短促呼气。
- **烦躁** = 眉心轻收 + 眼睑变窄 + 双唇压紧 + 头或手中动作突然停一下。
- **挫败** = 双眉下压收拢 + 双眼短暂闭合 + 双唇压紧、下颌绷住 + 用力呼气后重新看向任务。
- **压住怒气** = 双眉低压 + 眼睑收紧 + 鼻翼轻张 + 双唇压紧但不爆发。
- **坚定** = 双眉轻压 + 视线锁定目标 + 双唇压稳 + 下颌稳定、重心向前。
- **挑衅/不服** = 双眉压低 + 直视不退 + 单侧嘴角略紧 + 下巴抬起。
- **震惊/难以置信** = 双眉迅速抬高后僵住 + 双眼睁大 + 双唇分开 + 呼吸暂停、身体后靠。
- **忍泪** = 眉内侧抬起 + 眼睛湿润并多眨一次 + 双唇压紧或轻颤 + 吞咽后继续说话。
- **将哭未哭** = 眉内侧抬起并收拢 + 泪水聚在下眼睑 + 下巴中央抬起轻颤 + 嘴角下坠、呼吸开始破碎。
- **疼痛** = 双眉下压 + 眼睛用力眯紧或闭合 + 鼻梁与上唇收缩 + 嘴唇分开短促呼气。
- **疲惫** = 上眼睑下垂 + 眉毛轻抬以维持睁眼 + 嘴部松弛 + 头部与肩膀下沉。

## 6. 从大纲到提示词的使用示例

### 正向：剧情反转

大纲状态：她准备反驳，听到准确价格后发现自己判断错了。

前台写法：`价格落下，她已经抬起的食指停在半空；双眉迅速抬高、眼睛短暂睁大，嘴唇微张。半拍后她把纸拿近重新核对，重心从后靠变为前倾。`

### 混合：产品证明主导

大纲状态：人物看到清楚Proof后从担心转为释然。

前台写法：`结果稳定出现后，她的视线在结果与产品之间核对一次；眉心和下颌松开，长呼气时肩膀落下，随后点头继续操作。` 产品结果仍是本镜主体，表情只占一句。

### 不应触发：纯产品材质镜

若镜头只拍玻璃、液体、金属结构或包装Hero，没有人物脸部与认知变化，不加载本专区，也不擅自增加反应脸。

## 7. 研究依据与使用限度

- Ekman、Friesen与Hager的FACS把所有可见面部运动拆成Action Units；EMFACS是对可能具有情绪意义的组合进行选择性编码，仍需再解释为情绪。
- Du、Tao与Martinez（2014）研究了6种基础与15种复合面部情绪类别，说明复合状态可由基础动作特征组合，但不代表每个人每次都完整复制同一原型。
- Höfling等（2022）发现普通参与者比训练演员的原型表情更弱，且AU强度和组合存在差异；因此自然视频默认不用满强度原型。
- Cowen与Keltner（2020）在自然面部—身体表达中发现至少28类可被区分的情绪类别，同时类别之间存在连续梯度；复杂状态应结合身体与语境。
- Cowen等（2021）在144个国家的约600万段视频中发现16类表情与社会情境的联系约有70%跨地区保留，但情境仍是解释表情的重要组成。
- 疼痛、骄傲、羞耻与尴尬使用各自研究中的眼部、头部与身体线索，只作为导演型可见动作模板，不作为医学判断。
