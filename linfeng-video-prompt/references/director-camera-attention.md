## 1. 启用边界

复杂运镜、动作戏、一镜到底、空间揭示、镜头语言设计、运镜失败返修，或用户只说“旋转、推拉摇移、电影感运镜”时完整读取本文件。普通固定口播、简单产品演示和无空间变化的单镜也要写一条简短摄影机状态，但不强加复杂运动。

先运行 `director-information-control.md` 确定镜头唯一职责，再在本文件选择最少且最有效的摄影机动作。

## 2. 先确定观众注意力任务

摄影机运动只能承担以下一种主要任务：

- 等待信息进入；
- 搜索或发现；
- 跟随动作并保持关系；
- 领先主体揭示目标；
- 落后追赶制造压力；
- 与主体反向运动制造对抗；
- 通过视差建立尺度或空间；
- 从人物/局部把注意力交给产品/线索；
- 在结果上减速停稳，形成记忆或切点。

先按 `prompt-compilation-and-consistency.md` 继承人物、目标、接触与相机末位，确定事件如何发生及从哪里能看清，再把一条简短运镜融入动作句。没有明显位移需求时可写固定机位、稳定跟随或轻微手持，不额外解释原因。

## 2A. Camera–Event Coupling｜镜头和画面事件必须互相驱动

视觉冲击优先来自“画面事件 + 镜头响应”的配合，不来自独立堆运镜。

每个明显运镜先回答两件事：
1. 哪个可见动作、视线、遮挡、触发、形变或声源让摄影机开始动？
2. 运镜结束后，观众比起点多看见了什么具体信息？

高频匹配：
- 主体沿路径移动：跟拍／后退保持真实距离变化；
- 视线转向目标：短摇或焦点接力把注意力交给目标；
- 前景遮挡藏着新信息：横移／短弧移让遮挡边缘完成揭示；
- 变化从局部沿身体／物体传播：摄影机保持可读构图，必要时轻微跟随传播前沿；
- 威胁突然靠近：摄影机短后退或在反应镜中把完整身体反射保留下来；
- 大结果出现：运镜在结果可读的位置减速／停稳，不在最重要的中间态上甩走。

同一镜里画面越复杂，摄影机越克制；画面动作简单时才允许摄影机承担更多揭示。

**删除测试升级：** 删除这条运镜后，如果动作关系、遮挡变化、信息揭示和节奏落点都不变，则它只是装饰，应收敛。反过来，如果镜头移动能把“看不见→看见、远→近、遮挡→揭示、局部变化→完整变化”变成可读过程，则保留。

声音也可作为触发：先有可定位的碰撞／机械声／一句话，摄影机才转向声源；不要镜头先甩过去、声音随后补解释。

## 2B. Motivated Bold Move｜有职责的大胆镜头不因风险自动降级

当一个非常规镜头已经满足“有明确触发 + 新增信息 + 可读落幅”，空间或模型风险只说明它需要更好的实现，不自动说明它应该被替换。

优先修复顺序：
1. 缩短或重定摄影机世界路径；
2. 保留同一揭示关系，改变起点/终点或观察侧；
3. 用前景遮挡、动作匹配或中性机位重建方向；
4. 把一条过载长镜拆成相邻两镜，并保留原来的信息接力；
5. 必要时增加关键帧/动作参考/多角度资产；
6. 只有仍超出模型、素材、时长或物理边界时，才收敛镜头幅度。

例如原设计是“人物猛转头 → 甩镜 → 柜门遮满 → 产品在另一侧突然揭示”，若高速甩镜风险过高，可改为“更短的快速横摇/横移 + 柜门完整遮挡 + 同一产品落点”，而不是直接改成“人物看向产品，镜头缓慢推近”。

同时保持反向约束：**大胆不是目标本身。** 如果固定机位、长停顿或极简构图最能让事件被看清，就保持克制；不为避免“平淡”机械加入甩镜、环绕或极端透视。

## 3. 镜头运动术语校准

| 术语 | 摄影机真正发生什么 | 可见结果与使用边界 |
| --- | --- | --- |
| 固定等待 | 摄影机位置、朝向与焦距保持稳定 | 让主体入画、动作完成、反应可读或产品英雄镜停稳 |
| Pan / Yaw 左右摇镜 | 摄影机原地绕垂直轴左右转向 | 从A寻找/接力到B，不产生摄影机位移视差 |
| Tilt / Pitch 上下俯仰 | 摄影机原地绕水平轴上下转向 | 从脚到脸、从地面结果到高处目标；不等于升降 |
| Roll 光轴滚转 | 摄影机绕镜头光轴旋转 | 地平线倾斜或翻转；只用于明确失衡、冲击或绑定视点 |
| Orbit / Arc 环绕或弧线 | 摄影机沿世界空间中的曲线路径绕主体移动 | 产生前景/背景视差，揭示结构或关系；主体不是静态借口 |
| Tracking 跟拍 | 摄影机随主体沿直线或曲线移动 | 保持相对距离/侧别，展示行动、关系与环境变化 |
| Dolly 推进/后退 | 摄影机在世界空间向前或向后移动 | 透视与视差改变，可接近证据或拉开空间关系 |
| Handheld 手持 | 持机手、呼吸、步伐和重心造成小幅真实运动 | 运动有身体来源；不是随机抖动滤镜 |
| Whip Pan 甩镜 | 快速Pan造成方向性运动模糊 | 由突然事件、视线或匹配切点触发；落点必须清楚 |
| Zoom 光学变焦 | 摄影机位置不变，改变焦距和视角 | 主体与背景压缩关系变化，几乎无位移视差 |
| Dolly Zoom 希区柯克变焦 | 摄影机移动同时反向改变焦距，主体尺寸近似稳定 | 背景透视急剧变化；只用于明确认知、恐惧或空间错位 |
| Rack Focus 拉焦 | 摄影机位置和焦距可不变，只改变清晰平面 | 把注意力从A交给B；不改变主体尺寸或透视 |

不要把升降机位写成Tilt，把变焦写成推进，把拉焦写成变焦。每次只保留真正改变观众信息的动作。

## 4. “长镜头”与“旋转镜头”消歧

“长镜头”必须明确指：

- **长时间连续拍摄/一镜到底**：强调没有切镜、摄影机路径与状态连续；
- **中长焦/长焦镜头**：强调焦距、视角压缩与景深。

“旋转镜头”不是可执行指令。必须明确：

- 摄影机原地左右摇动或上下俯仰；
- 摄影机沿世界空间环绕主体；
- 摄影机绕光轴滚转；
- 摄影机位置不变而改变焦距；
- 焦距不变而改变清晰平面。

无法说清轴、世界路径或清晰/焦距变化时，先删除“旋转”。

## 5. 复杂运镜内部执行合约

使用：

`触发事件 → 叙事任务 → 摄影机轴或世界路径 → 与主体的关系 → 速度曲线 → 可见反馈 → 最终落幅 → 下一镜承接`

逐项回答：

1. 哪个动作、声音、视线、入画或产品状态触发摄影机；
2. 摄影机要让观众发现、理解、感受或相信什么；
3. 原地转轴还是沿世界空间移动，起点与终点在哪里；
4. 摄影机位于主体前、后、侧前、侧后、上方或低位，距离是否变化；
5. 运动怎样起步、加速、匀速、减速和停稳；
6. 前景视差、地平线、对焦、曝光、运动模糊和声音产生什么真实反馈；
7. 最后停在谁/什么上，以何种景别和焦点结束；
8. 下一镜继承方向、速度、焦点、遮挡、声音或形状中的哪一项。

最终提示词只呈现合约后的可见结论，不输出“叙事任务、观众注意力”等后台标签。

## 6. 摄影机与人物的时间关系

从以下方式中只选一种主要关系：

- **提前等待**：摄影机先锁定动作将到达的位置，主体进入、穿过或完成结果；适合英雄时刻、惊喜入画和可读动作。
- **领先引导**：摄影机在主体前方移动，提前揭示目的地或阻碍；适合行动目标清楚的推进。
- **同步陪伴**：与主体速度、方向近似一致，保持关系和表演可读；适合行走对话、生活方式和产品使用。
- **落后追赶**：主体先动，摄影机慢半拍追随；适合突发事件、紧张、真实手持和喜剧反应差。
- **反向对抗**：摄影机与主体相反运动或顶着主体后退；适合冲突、压力、速度与力量。
- **主体掠过后停留**：主体穿过摄影机，镜头不立即跟随，留在结果、空位或新信息上；适合失去、决定、空间揭示和转场。

关系改变必须由事件触发；同镜反复在领先、落后、环绕之间切换会增加空间崩坏。

## 7. 运镜简化测试

在后台检查运镜是否写得过重：

1. 镜头信息是否仍完全相同；
2. 人物/产品关系是否仍完全相同；
3. 观众感受和下一镜理解是否仍完全相同。

三项均不变时，把复杂运镜收敛为固定机位、稳定跟随或极轻微移动；仍保留一条简短摄影机状态。**若删除/收敛后会损失主揭示方式、空间反转、遮挡关系或节奏落点，则不得仅以“更稳”为由简化。**

固定等待并不低级。它能让进入、接触、反应、材质变化和完成态获得最高可读性。

## 8. TVC与产品广告运镜

TVC运镜只服务：

- 产品自然进入；
- 产品与手、人物或环境的尺度理解；
- 结构、接口、材质、使用方式或效果证明；
- 从体验结果交回产品；
- 品牌/产品轮廓记忆。

优先使用短距离滑移、可读弧线、焦点接力、遮挡揭示与受控推进。产品关键结构、标签和接触过程保持在可读平面。英雄镜前摄影机必须减速停稳，焦点和产品朝向稳定，不能以持续环绕或高速甩镜结束。

## 9. UGC微动与自拍逻辑

UGC微动只能来自：

- 持机手腕的轻微调整；
- 呼吸和身体重心变化；
- 行走步伐；
- 另一只手拿取、展示或使用商品；
- 手机自动对焦、曝光和白平衡的轻微真实反应。

不用无因棚拍轨道、光轴滚转、随机甩镜或匀速环绕冒充真实。固定自拍时手机位置不变，人物需要“靠近镜头”就身体前倾；手持自拍必须明确哪只手持机、哪只手拿商品。需要双手操作时，把手机固定或提前开盖，让一次清楚操作在画面中成立。

## 10. 高速动作、打斗、一镜到底与控制升级

高速动作的核心不是“镜头一直快”，而是让摄影机对**动作方向、攻击方向、受力方向和威胁变化**产生可读响应。先确定动作矢量，再决定摄影机矢量。

### 10.1 动作矢量 → 摄影机响应

后台按以下关系选择，不机械套模板：

| 动作事件 | 优先摄影机响应 | 目的 |
| --- | --- | --- |
| 冲刺/扑击/快速接近 | 低位或平视跟拍、向运动方向推进；必要时反向后退 | 建立距离收缩与速度 |
| 横向拳腿/挥砍/扫击 | 沿攻击弧线短距离横跟或甩向落点 | 看清攻击路线 |
| 贴地扫腿/滑铲 | 降低机位，沿贴地轨迹横向跟随 | 保留腿部/身体路径 |
| 起跳/飞膝/腾空 | 从起跳点向上跟随或上摇 | 建立离地与高度变化 |
| 下砸/俯冲/落地攻击 | 随下降方向压低或下摇，并在落点完成 | 建立垂直压迫 |
| 两人高速交错/擦身闪避 | 围绕交错点做短弧线或转向接力 | 保持谁从哪来、往哪去 |
| 命中/格挡/碰撞 | 在接触点极短锁住或减速，随后恢复运动 | 让“打中了”可读 |
| 击退/击飞/摔出 | 沿受力方向后撤、侧移或重新展开空间 | 看清距离和方向 |
| 追击连招 | 与主攻者同步侧跟/追随，保持攻防双方关系 | 保持连招密度而不丢空间 |
| 威胁来源突然改变 | 摄影机重新指向新威胁，再跟随其动作 | 完成注意力转移 |
| 下一击蓄力/战斗未结束 | 摄影机减速、略微拉开或停稳 | 为下一动作留下启动空间 |

原则：**镜头跟动作轨迹，不只跟人物身体。攻击方向改变时，摄影机响应方向才改变。**

### 10.2 打击节奏：追 → 锁 → 爆 → 放

需要强化命中时，优先使用四段节奏：

`追随攻击轨迹 → 接触前锁定落点 → 接触瞬间短促节奏变化 → 沿结果/受力方向释放`

“锁”是极短的可读停顿或减速，不写精确 `0.15秒 / 0.3秒` 等亚秒数值；“爆”通过接触、碎屑、衣料/环境响应、短促震动或声音体现；“放”负责把击退距离、失衡或下一动作交代清楚。

不得用持续Shake、全程高速甩镜或每次攻击都前弹替代打击设计。

### 10.3 一镜一个主要动作—镜头任务

默认每镜：
- 只保留一个主要摄影机运动；
- 最多允许一个从属于主运动的修正，如短促Pan跟上落点；
- 优先保证主体动作和接触结果可读，再增加速度感；
- 当人物动作本身已经复杂时，减少摄影机自由度。

如果一句提示同时要求“人物多轴旋转 + 摄影机完整环绕 + 光轴滚转 + 变焦 + 大幅升降 + 爆炸特效”，视为镜头负载过高，主动删减。

### 10.4 复杂动作优先拆镜，不默认一镜到底

不得把“一镜到底”设为高速打斗默认规则。

满足以下大部分条件时才保留连续长镜：
- 主要角色少；
- 攻防关系清楚；
- 动作方向连续；
- 摄影机世界路径可解释；
- 不需要频繁越轴或多次重新建立空间；
- 每个动作都能从上一完成态自然进入下一起始态。

出现多人交错、高空三维运动、连续攻防换位、武器/触手多方向攻击、多个关键命中点或空间关系频繁重置时，优先拆镜。切镜通过**动作方向、速度、视线、遮挡、声音或形状**承接，保持“动接动”。

一镜到底不是“没有剪辑就更高级”；无法解释摄影机如何从A到B时，取消一镜到底。

### 10.5 高速画面的清晰度与模糊

速度感优先来自：
- 前景快速掠过；
- 背景方向性运动模糊；
- 真实空间视差；
- 摄影机与主体速度差；
- 动作前后距离变化。

主体脸部、躯干轮廓和关键接触点尽量保持可读。谨慎使用“人物长拖影、残影、连续多重曝光”，避免生成模型把速度误解为肢体融化、重复手脚或五官拖烂。

### 10.6 一镜到底与控制升级

动作和一镜到底仍需满足：

- 一种主要摄影机运动；
- 一条可解释的世界路径；
- 单一轴线或可读的连续越轴；
- 稳定地平线；
- 明确起点、接触、反作用和完成态；
- 摄影机、人物、道具和主光的连续状态。

不要用文字同时控制人物多轴旋转、墙面方向变化、摄影机环绕/滚转/变焦和复杂特效。复杂三维路径、高空动作、多人调度或两轮文字修复仍失败时，升级为动作参考、关键帧或白模。

一镜到底的节拍不是切镜。每个节拍必须从上一状态通过可见动作、入画、遮挡、焦点或摄影机路径到达；无法解释就取消一镜到底或重做路径。

### 10.7 最终Prompt压缩

后台可以使用完整动作—摄影机推理，最终Prompt只保留能改变画面的最少信息：

`起始关系 + 主动作/方向 + 必要摄影机响应 + 接触/结果 + 下一状态`

例如：
`低机位侧向跟拍她向右高速冲刺；对手横扫腿逼近时，镜头沿腿弧短促甩向落点。她贴地闪过，双方擦身后镜头继续向右跟随，保持两人的前后关系。`

不要把 `Swift / Shock / FOV / 0.15秒 / 0.3秒` 等标签当成效果本身；只有模型确实需要且会改变画面时才保留术语。

## 11. 落幅、切点与承接

运镜没有落幅就没有信息完成。每镜明确：

- 最后主体与画面重心；
- 机位、景别、焦点与地平线；
- 主动作已经达到的完成态；
- 是否需要短暂停稳供观众读取；
- 下一镜承接的视线、动作方向、速度、焦点、遮挡、声音、形状或颜色。

高速运镜在落点前减速；英雄镜稳定；人物反应留足理解时间；产品接触或材质变化在切镜前可读，或由下一镜首帧直接继承。

高速动作若需要继续下一轮，不必停成Pose；优先停在**下一动作前摇**：重心已经压低、视线锁定目标、手脚进入准备位置，但下一击尚未真正发出。

## 12. 验收

- 每个明确分镜是否都有一条简短运镜或摄影机状态；
- Pan、Tilt、Roll、Orbit、Tracking、Dolly、Zoom、Dolly Zoom、Rack Focus是否区分准确；
- “长镜头”和“旋转镜头”是否已消歧；
- 摄影机与主体的时间关系是否唯一清楚；
- 运镜简化测试是否通过；
- TVC英雄镜前是否减速停稳；
- UGC微动是否有身体/持机来源，自拍手部资源是否物理自洽；
- 高速动作是否先确定动作/攻击/受力方向，再选择摄影机响应；
- 命中是否遵守接触先于反作用，并有可读的“追→锁→爆→放”节奏；
- 是否避免主体长拖影、持续Shake、无原因连续甩镜；
- 复杂动作是否在镜头负载过高时主动拆镜，而不是默认一镜到底；
- 一镜到底是否保持同一物理镜头、连续路径、稳定地平线与世界主光；
- 复杂三维控制是否在必要时升级为参考或白模；
- 镜尾是否有清楚落幅、切点与下一镜承接。
