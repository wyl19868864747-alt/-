# 成品输出合同与稳定性验证｜Minimal Output Contract

本文件是视频提示词最终格式的唯一归属。创意编译读 `prompt-compilation-and-consistency.md`；只有光影/质感明确影响结果时才读 `camera-light-quality-baseline.md`。

## 1. 默认输出格式

普通视频优先使用下面的**四层最小结构**；没有内容的块直接省略。

```text
[总时长]，[画幅]，[必要的平台/模型信息]。

【开场总控】
[1句：片型/调性/节奏/媒介观感。只定大概念，不写具体事件，不堆设备。]

【主体/锁定】
[只写会漂移的人物、产品、空间或参考事实；没有就省略。]

【时间轴】
【0–X秒】[事件 → 动作/变化 → 结果 → 必要镜头响应。]
【X–Y秒】[从上一完成态继续，只写新发生的事。]

【声音/限制】
[只写准确对白、关键环境声/SFX/BGM节点，以及2–4个当前高风险限制；没有就省略。]
```

真实性、光影、材质、景深等不设固定独立块；只有当前镜头确实需要时，直接并入对应句子。

## 2. 开场总控

只写**一条概念句**：
`片型 + 整体调性 + 节奏 + 媒介观感`

例如：
`一支明亮、利落、带轻荒诞感的美式原生剧情广告，真实商业短片质感，节奏紧凑但自然。`

不要在开场写：
- 谁具体做什么
- 产品卖点时间轴
- 每个镜头怎么运
- 精确灯位/焦段
- IMAX/ARRI/UE5/Octane/VFX技术词包

## 3. 主体/锁定

只锁**容易漂移且当前必须准确**的内容：
- 人物身份/服装/关键外观
- 商品外观/比例/标签
- 参考图职责
- 必要空间起点
- 准确文字/CTA真源

每项只定义一次。后续分镜默认继承，没有变化就不重复。

如果普通单主体片段没有明显漂移风险，整个【主体/锁定】块可以省略。

## 4. 时间轴｜核心

分镜像描述眼前正在发生的事。每一段优先：

`当前状态 → 核心事件/动作 → 可见结果 → 必要镜头响应`

示例：

```text
【0–3秒】她扫到账单上的价格，动作突然停住，低头重新核对；镜头快速推近，在她确认数字的一刻停住。

【3–6秒】她抬头看向朋友，仍不相信；朋友把包装推到她面前，价格信息进入前景，镜头固定等待她看清。
```

规则：
- 每镜只保留一个主要任务。
- 先写主体、事件和动作，再写镜头。
- 镜头默认只写一个必要动作；没有叙事价值就不写。
- 不重复全局人物、产品、风格、光影。
- 表情通常用短动作链，不默认拆眉眼鼻嘴。
- 构图、焦段、景深、灯位只在决定当前结果时写。

## 5. 真实性补丁｜按需，不独立成块

主体、事件、动作和镜头都写清后，再判断当前镜头最容易出现的**一个AI错误**。

有明确风险时，补一条最短修正；没有就不加。

例如：
- `鞋底紧贴地面，保留轻微接触阴影。`
- `产品尺寸和包装结构在推进中保持稳定。`
- `玻璃边缘保持透明折射，高光不过曝成死白。`
- `近景移动快于远景，形成自然空间视差。`
- `眼睛清晰，背景自然退焦。`

不要把多种物理规则机械叠加。

## 6. 光影与成像怎么放

普通片**不设默认【光影】块**。

只有以下情况才增加一句或独立块：
- 光线直接决定主体是否可读；
- 产品材质/卖点依赖精确受光；
- 光线本身触发剧情；
- 当前返修目标就是曝光/质感；
- 用户明确要求摄影方案。

需要时先写可见结果：
`窗外日光从人物右侧进入，脸颊保持柔和明暗过渡。`

不要自动补：HDR、ARRI、IMAX、高动态范围、电影级高光、反弹光等词包。

## 7. 声音

声音紧贴事件，准确文本只出现一次。

写：
- 谁说什么
- 必要语气
- 关键环境声/SFX
- 明确需要的BGM进入/停止点

不写：
- 重复一遍已经在镜头中出现的全部声音表
- 无关的声音设计术语
- 用户没要求的默认BGM

## 8. 限制

先用正向关系说清楚，最后只留当前最可能且后果严重的 2–4 项。

例如：
`避免产品比例漂移、手部接触穿模、屏幕文字乱码。`

不要列几十条历史禁词。没有明显风险可省略。

## 9. 复杂视频扩展格式

只有多人复杂换位、严格产品连续、多场景、复杂一镜到底、长片生产、独立声音管理，或灯光本身是主任务时，才扩展为：

```text
【开场总控】
【资产/身份锁定】
【必要表演状态】
【必要空间关系】
【必要光影基线】
【时间轴】
【必要声音】
【必要限制】
```

注意：**“必要”不是固定必填。** 没有实际控制价值就省略。

## 10. 简单片段与局部返修

单主体、单场景、单主动作时可以压成一个短段：

`规格；主体/状态；事件 → 动作/变化 → 结果；必要镜头/声音/补丁。`

局部返修只写：
`修改范围 + 保留项 + 新变化`

不要为了套完整格式重写整条视频。

## 11. Global Once, Shot Specific

全局定义一次，分镜只写变化：
- 风格一次
- 人物一次
- 产品一次
- 持续声音一次
- 光影只有真的需要时定义一次

发生变化才重新定义。

这条规则优先于“格式完整”。

## 12. 精简与容量

复杂度决定长度，不是时长决定长度。

优先保留：
1. 主体/产品
2. 核心事件
3. 动作和状态变化
4. 最终结果
5. 连续性
6. 必要镜头响应
7. 必要真实性/光影/声音

优先删除：
- 同义风格词
- 重复身份描述
- 每镜重复画质词
- 无必要的焦段/景深/构图参数
- 设备名堆叠
- 解释为什么这样拍的导演话
- 不解决具体问题的光影形容词

## 13. 最终检查

交付前只检查最可能导致失败的项：
1. 核心事实与参考职责是否正确；
2. 主体是否比光影、设备、风格词更清楚；
3. 一读是否能看懂“发生什么、怎么变、最后怎样”；
4. 每镜是否只有一个主要任务；
5. 人物/产品/空间/道具是否从上一完成态承接；
6. 镜头是否服务事件而不是抢事件；
7. 全局信息是否重复；
8. 真实性/光影/声音/限制是否只保留当前必要项；
9. 是否存在看似专业但删除后结果不变的句子。

发现问题直接修，不额外增加解释。

最终标准：**主体最清楚，事件最清楚，用最少词解决最关键的生成问题。**
