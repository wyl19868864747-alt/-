## 1. 输出原则

后台可以建立双轴判断、商业合约、导演问答、素材质量分级、技术方案、风险表、状态机和验收表。用户只要成品提示词时，不把这些表原样外显，只呈现已经设计好的可见、可听结果。

沿用用户的模型、语言、格式与硬约束。字符数、字数、时长、镜头数、素材引用数、比例、时间码和输出文件类型在交付前主动校验。

开场总控最多三句，只建立成片任务与核心体验、风格/摄影/质感、节奏曲线与视觉母机制；不写生成界面可选的时长、画幅、投放平台、发布渠道、设备清单、风险表和逐镜细节。总控中的抽象风格必须在时间轴中被具体画面兑现。详细编译与矛盾检查唯一归属 `prompt-compilation-and-consistency.md`。

## 2. 直接视频提示词结构

先通过 `prompt-compilation-and-consistency.md` 的编译复杂度门。

### 简单直写模式

典型4–10秒、单人、单场景、单动作链且没有高风险空间继承时，直接输出一个可复制提示词块，不强制展开固定前三部分：

```text
【视频提示词】
[总时长，且独立生成>=4秒]。[主体与场景]；[起始位置/状态 → 单一动作路径 → 接触或完成态]；[必要的景别、摄影机反应、光线/质感和同步声]。
```

默认1–2个高密度句。已有参考素材时只补一句唯一职责；没有影响结果的全片母规则时不为凑格式单列技术基线。不得因使用简单模式删除动作起点、接触路径或完成态。

### 结构化模式

多人相对关系、正反打、长时间连续调度、复杂一镜到底、交接、跨区域移动或跨镜状态继承任务，使用以下固定前三部分：

```text
【开场总控】
生成一个[核心画面/结果]的[片型]，让观众最终[理解/感受/记住什么]。[摄影媒介、风格与画面质感]。[节奏从何处开始、怎样停顿/升级/释放，并以什么视觉母机制贯穿和收束]。

【主体、空间与参考锁定】
每份实际参考素材只用一句绑定唯一职责：`[素材编号]：只锚定[身份/产品结构/空间/动作/摄影/风格中的一项]；仅在容易误用时说明不参考什么。` 无参考素材时不虚构编号，只用一句锁定核心主体、空间和有依据的相对比例；无尺寸证据时不编造厘米数。保证下一部分固定为第三部分。

【全片视觉与技术基线】
[只用一句，写最影响成片的成像方式、透视、运动质感、色彩语法、光源几何、材质解析力及必要的渲染/合成职责；不列设备清单。]

【主声音清单】（仅有精确对白/旁白时）
声音ID｜说话者｜准确文本｜开始时间｜硬停止时间｜表演方式｜repeat_count=1

【时间轴/镜头】
每镜通常使用2–4个高密度画面句，按观看顺序写：
首帧构图 → 可见事件/接触/变化 → 摄影机反应 → 完成态/落幅/下一镜承接 → 同步声音。

【结尾画面与声音】（时间轴末段未覆盖时）
最终人物关系/产品英雄镜、焦点、光线收束、最后同步声/口播停止与品牌/剧情记忆。
```

技术基线在内部可以非常详细，成品第三部分只能是一句。镜头段不重复摄影机、灯具、帧率、色彩管理和渲染器清单；只写当前镜头实际改变的机位、焦点、速度、遮挡、曝光触发或特殊材质事件。

每一个结构化的新写、重写、降级版、安全版或备选提示词都独立保留上述固定前三部分。不能让主版本结构完整，却把用户最可能复制的结构化备用版本压成单段，或把技术基线移出第三部分。

## 3. 分镜/导演分析/参考反推结构

用户要求分镜表、导演分析或参考视频反推时，每镜至少包含：

| 字段 | 内容 |
| --- | --- |
| 镜号/时码 | 连续且与总时长一致 |
| 镜头核心表达 | 本镜新增的信息、关系、感知或产品证据 |
| 承接 | 回答上一镜什么；用视线、动作、速度、焦点、遮挡、声音、形状或颜色中的哪一项接向下一镜 |
| 首帧与主体动作 | 起始状态、单一主动作、接触/变化和完成态 |
| 视点/景别/机位 | 由镜头职责反推的最小有效设置 |
| 注意力与必要运镜 | 观众先看什么、如何接力、为何固定或移动、最后落在哪里 |
| 反应/决定 | 人物、产品材质或环境怎样回应；产生何种下一行动 |
| 声音 | 对白ID、同步声、环境声、音乐节点与声音桥 |

参考视频反推额外区分：

- 可复用的导演信息逻辑、注意力机制、节奏和转场原则；
- 原片专属人物、场景、美术、品牌、台词和镜头组合，不直接复制。

## 4. 声音与精确文字

- 精确对白或旁白只在主声音清单完整出现一次；时间轴只引用声音ID，不重复粘贴全文。
- 每句设置开始时间、硬停止时间和表演方式；停止后不重启、不回声、不改写复述。
- 同步声由动作触发：开盖、包装摩擦、倒水、加热、蒸汽、搅拌、咀嚼、脚步、衣料、金属接触和环境变化必须贴近画面事件。
- 精准对嘴只有在真实音频，或精确台词、时间和节奏存在时承诺；否则写节奏性口型。
- 准确Logo、片名、CTA、法务文字和正式配音默认由可靠资产或后期完成；生成阶段设计文字载体、负空间、光影和停留时间。

## 5. 正向成片与独立负面提示

主提示词使用肯定式成片语言：主体从哪里开始、怎样移动、接触什么、产生什么结果、摄影机如何响应并停在哪里。

`不要、禁止、避免、为了、必须、所有运镜都应`等后台语言不进入主提示词。把风险改写为可见状态。例如：

- 后台：产品不应变大；前台：产品保持掌心尺寸，递近镜头只产生透视放大，实体尺寸连续。
- 后台：不要无意义旋转；前台：固定机位等待产品进入焦平面，动作完成后停稳。
- 后台：高光不能泄漏；前台：高光只沿面颊实际涂抹路径出现，嘴唇保持原有唇釉光泽。

只有用户或平台明确需要独立负面提示栏时，另列1–5条可验证风险，不把负面词混入时间轴。

## 6. 局部修改与成片复盘

局部修改：

1. 找出受影响的镜头、状态和承接；
2. 列出必须保留的方向、事实、母规则、成功动作和声音；
3. 只改唯一主问题层及必要的前镜镜尾/后镜镜首；
4. 重新运行时长、连续性、物理和画质验证。

成片复盘：

1. 按时间码抽帧/转写，标记实际切点、动作开始偏离点和声音停止点；
2. 区分成功层、失败层、必须保留和唯一主修层；
3. 主修层只选创意/信息、资产身份、动作物理、摄影连续、光影材质、声音或交付中的一个；
4. 用同一验收条件局部重试；同层两次失败，减少变量、拆镜或升级控制方式。

## 7. 八重验证

### 模块覆盖测试

- 是否建立了对话阶段、双轴结论和并行能力标签；
- 是否逐行检查强制读取条件，而非进入一个主分支后停止；
- 是否加载了所有语义命中的商品、食品、美妆、群像、写实超现实、声音、长时、连续性、运镜、画质与模型模块；
- 是否保留跨域最低基线，同时省略真正无关的专项细节；
- 是否把内部模块清单隐藏在最终可复制提示词之外。

### 方向与带宽测试

- 成片服务产品/品牌，还是人物关系/剧情；
- 提示词由表演关系，还是氛围/体验/证据主导；
- 混合任务是否只选择一个主导层；
- 氛围、色彩、主光、保护逻辑、成像和声音母规则是否先建立。

### 导演信息测试

- 整片核心问题、知情曲线、揭示计划、视点、空间秩序和注意力接力是否清楚；
- 每镜是否有唯一职责，回答上一镜并留下下一问题；
- 删除镜头或运镜后信息/关系/感受是否改变；
- 镜尾是否有完成态、落幅和承接。

### 人脑成像测试

- 只读一次能否连续看见首帧、动作路径、接触、变化、反应和结束；
- 主体、对象、方位、手别、代词和空间是否唯一；
- 抽象情绪是否已转译为行为、光线、材质和声音。
- 简单任务是否被压成1–2句而未滥用人物编号、空间图和多级结构；复杂任务是否每条事实只定义一次，后续只写变化。

### 全文一致性测试

- 开场总控承诺的成片任务、摄影媒介、画面质感、节奏曲线与视觉母机制，是否在分镜中得到可见兑现；
- 同一时段是否存在固定/移动、推进/后拉、完整/拆解、开口/说话、左右位置或手部职责等互斥描述；
- 跨时段是否继承人物位置/认知、手别、道具、产品状态、摄影机、主光、声音与异常规则，改变时是否有触发和完成态；
- 台词、反应、产品效果和剧情决定是否发生在相应信息、操作或接触之后；
- 有动机的节奏停顿、风格转折或现实→超现实变化是否写明触发、持续区间和恢复/新规则，而没有被机械判成矛盾。

任何未解决项必须按 `prompt-compilation-and-consistency.md` 自动裁决并重写，不能把互斥要求折中成模糊句。

### 模型容量测试

- 每镜是否只有一个主任务、一种主要摄影机运动和可控的高成本变化；
- 时长是否足以完成动作、反应和可读结果；
- 复杂三维路径、多人物、变形、反射和液体是否需要拆镜、关键帧、动作参考或白模。

### 物理连续性测试

- 产品数量、几何、比例、标签、颜色、液位、朝向、持握手和接触面是否稳定；
- 人物站位、视线、轴线、行进方向、道具、入口出口和主光世界方向是否连续；
- 重力、支撑、惯性、碰撞、受力、反作用、遮挡、接触阴影、反射和景深是否相容；
- 产品效果是否只出现在真实作用区域；自拍手部资源是否足够。

### 画质与交付测试

- 输入素材是否完成A/B/C分级，并按角度/解析力限制控制镜头；
- 技术基线是否落到稳定边缘、真实皮肤/材质、高光/暗部、运动模糊、焦点、曝光、白平衡和产品本色；
- 720p、低码率、编码和平台压缩是否被正确归到交付层；
- 最终第三部分是否只有一句基线，镜头段是否没有重复器材清单。

## 8. 最终检查

- 用户硬约束是否全部满足并主动校验；
- 是否只引用用户实际提供的素材与编号，并避免把未知尺寸写成伪精确数字；
- TVC是否只有一个主传播命题、主决策/首要犹豫和充分证据；
- UGC是否有真实地点/动机、手机成像、产品自然进入、一次清楚证据、同步声、即时反应与结尾记忆；
- 食品风味是否由真实商品、质地/制作、声音和食后余韵共同建立，且没有编造成分或功效；
- 三人以上或多手交互是否锁定人数、座次、角色ID、手别、袖口、物件归属、释放与承重；
- 美妆/时尚人物是否由年龄能量、妆发服装、表演、美术和光线共同建立当代感；
- 写实超现实任务是否先建立可信现实、每镜只保留一个高权重幻想规则，并通过受力、接触、遮挡、互动光、摄影机反应和现实回收服务产品事实或剧情意义；
- 20秒以上是否持续增加新信息并回收前文元素，而不是重复钩子和近似镜头；
- 短剧是否有清楚人物诉求、知情差、冲突、反应、决定、关系变化和情绪落点；
- 复杂运镜是否术语准确、路径清楚、有触发、有落幅；
- 一镜到底是否保持同一物理镜头、摄影机路径、空间、光线、焦点与道具状态；
- 旁白/对白是否只有一个真源；
- 用户只要提示词时，内部问答、风险表和设备清单是否隐藏；
- 用户要导演分析时，是否为每镜给出核心表达与承接；
- 多镜、多时段或状态变化任务是否通过 `Consistency Gate`，没有总控与分镜、同一时段、跨时段、叙事、声音或资产职责矛盾；
- 是否按控制难度选择简单直写或结构化模式，而不是只看时长；复杂空间是否避免混用世界、俯视图、参考图与屏幕坐标；
- 成品是否精炼、一读成像、可直接复制。
