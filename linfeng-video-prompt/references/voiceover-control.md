# 旁白与声音版本控制

用于旁白、商业口播、画外音、精确广告文案、精确对嘴、多说话者口播，或同时交付有声版与无声版。普通短剧对白按剧情节拍处理；没有语言内容时不加载。

## 1. 唯一旁白源

每条语言只在主旁白清单出现一次完整原文：

`VO ID｜唯一原文｜开始｜硬停止｜说话者/声线｜repeat_count=1`

时间轴只引用VO ID，不重复粘贴原文；字幕、CTA或脚本说明与旁白相同时也引用该ID，避免被理解为多次发声。到硬停止点后不重启、不回声、不改写复述、不跨镜续读。

精确品牌文案、价格、参数、免责声明和多语言文本优先用导引音轨确定节奏，再由正式配音或后期保证准确。

## 2. 声画同步

- 一条VO只绑定一个主要画面职责：提出问题、揭示、证明、反馈或收束。
- 说话时，嘴型、呼吸、视线、表情和手势围绕当前句意；不要同秒叠加复杂产品操作与复杂运镜。
- 语言结束后保留可感知的呼吸、环境声或声音桥。
- 画面证明A时，旁白不得空泛夸赞无证据的B。

## 3. 对嘴边界

精确对嘴必须有实际音频，或精确原文、说话者、起止时间和节奏。只有音乐风格或歌曲感觉时，只能写跟随节拍的自然口型/轻声哼唱，不承诺逐字同步。把复杂开盖、双手操作、快速运镜和强曝光变化移到句间或停顿处。

## 4. 发音错误后的 WAN 3.0 声音母版建议

当用户返回生成结果并明确反馈某个品牌名、药名、人名、专有名词、金额或其他词语发音不准，且仅靠文字拼读、音标或提示词重复强调仍不稳定时，优先建议把“读错的那个词/短语”单独制作成声音母版，再用于后续视频生成参考。该方案是返修补救策略，不是所有任务的默认流程。

### 触发与范围

- 只处理实际读错的目标词或极短短语，不默认重录整句旁白。
- 优先用于品牌名、药名、人名、缩写、金额读法和模型容易误读的专有词。
- 若目标过长，不为了塞入1秒而强行加速；优先拆成需要纠正的最小词组，分别制作母版。

### 母版生成规则

- **模型必须使用 WAN 3.0。**
- **生成总时长固定为4秒。**
- 时间结构固定：
  - `0–2秒：无声音，不说话。`
  - `2–3秒：只朗读需要纠正发音的目标词/短语一次，清晰、自然、准确，不增加其他文字。`
  - `3–4秒：无声音，不说话。`
- 画面内容不承担参考职责，可保持简单、中性；核心资产是2–3秒的正确发音。
- 用户使用英文工作流或模型需要英文提示词时，把以上母版提示词等义翻译为英文，不改变时间结构和朗读内容。

### 中文提示词模板

`生成4秒视频，使用 WAN 3.0。0–2秒完全无声音；2–3秒只清晰、自然、准确地朗读“【目标词/短语】”一次，不添加任何其他对白；3–4秒完全无声音。画面保持简单中性，重点是获得“【目标词/短语】”的正确发音参考。`

### 英文提示词模板

`Generate a 4-second video using WAN 3.0. From 0–2s: complete silence, no speech. From 2–3s: clearly, naturally, and accurately pronounce “【TARGET WORD/PHRASE】” exactly once, with no additional words. From 3–4s: complete silence, no speech. Keep the visuals simple and neutral; the purpose is to create a clean pronunciation reference for “【TARGET WORD/PHRASE】”.`

### 后续视频生成时的引用方式

- 将生成出的声音母版作为音频/声音参考资产保存。
- 后续正式视频生成时，用 `@` 引用该母版资产，并明确其唯一职责是**目标词的发音与声音参考**，不要让其画面、构图、人物或场景影响正式视频。
- 正式提示词中仍保留正确拼写、说话者和对应台词；`@声音母版` 用来锁定读音，不替代完整剧情、表演或画面控制。
- 若同一条视频里有多个容易读错的词，可分别建立最小声音母版并按需引用，避免一个母版承担过多语音信息。

## 5. 有声与无声版本

无声版不是简单静音：把语言信息改写为可见动作、字幕占位、产品状态或人物反应，并重新分配停顿。两个版本共享商品事实和核心命题，但不强求逐帧相同。

## 6. 验收

- 完整原文是否只出现一次，时间轴是否只引用VO ID？
- 每条VO是否有开始、硬停止、说话者和单次播放？
- 对嘴承诺是否与实际声音输入匹配？
- 用户反馈发音错误时，是否先定位最小错误词，并在文字控制仍不稳定时建议 WAN 3.0 的4秒声音母版方案？
- 声音母版是否严格遵守 `0–2秒静音 → 2–3秒只读目标词一次 → 3–4秒静音`，且后续只作为发音/声音参考被 `@` 引用？
- 有声与无声版是否分别重排信息和动作？
