# 旁白与声音版本控制

用于旁白、商业口播、画外音、精确广告文案、精确对嘴、多说话者口播，或同时交付有声版与无声版。普通短剧对白按剧情节拍处理；没有语言内容时不加载。

## 1. 唯一旁白源

每条语言只在主旁白清单出现一次完整原文：

`VO ID｜唯一原文｜开始｜硬停止｜说话者/声线｜repeat_count=1`

时间轴只引用VO ID，不重复粘贴原文；字幕、CTA或脚本说明与旁白相同时也引用该ID，避免被理解为多次发声。到硬停止点后不重启、不回声、不改写复述、不跨镜续读。

精确品牌文案、价格、参数、免责声明和多语言文本优先用导引音轨确定节奏，再由正式配音或后期保证准确。

## 2. 声画同步

- 一条VO只绑定一个主要画面职责：提出问题、揭示、证明、反馈或收束。
- 说话时，嘴型、呼吸、视线、表情和手势围绕当前句意；不要同秒叠加复杂产品操作与复杂运镜。
- 语言结束后保留可感知的呼吸、环境声或声音桥。
- 画面证明A时，旁白不得空泛夸赞无证据的B。

## 3. 对嘴边界

精确对嘴必须有实际音频，或精确原文、说话者、起止时间和节奏。只有音乐风格或歌曲感觉时，只能写跟随节拍的自然口型/轻声哼唱，不承诺逐字同步。把复杂开盖、双手操作、快速运镜和强曝光变化移到句间或停顿处。

## 4. 有声与无声版本

无声版不是简单静音：把语言信息改写为可见动作、字幕占位、产品状态或人物反应，并重新分配停顿。两个版本共享商品事实和核心命题，但不强求逐帧相同。

## 5. 验收

- 完整原文是否只出现一次，时间轴是否只引用VO ID？
- 每条VO是否有开始、硬停止、说话者和单次播放？
- 对嘴承诺是否与实际声音输入匹配？
- 有声与无声版是否分别重排信息和动作？
