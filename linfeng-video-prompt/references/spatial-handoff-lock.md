# 世界空间接力锁｜Spatial Handoff Lock

本模块解决多镜视频里的严重穿帮：上一镜角色已经走到新地点，下一镜因重新构图又回旧位置；一个角色移动，另一个本应原地的角色却被带走；摄影机反打后真实运动方向也被误翻转。

它不是在 Prompt 末尾追加“禁止瞬移、保持位置一致”，而是在写每一镜之前，把空间连续性作为摄影决策的前置条件。

## 1｜根源：每个新镜头都可能被重新求解

多镜生成容易把切镜当作新的画面问题重新组织：为了拍正脸而换角色朝向，为了双人同框把远处配角拉近，角色刚到门口却在近景回到客厅起点，或因为反打让运动方向看起来翻转。

因此空间锁的核心不是重复坐标，而是同时控制：

世界拓扑 + 运动所有权 + 高风险段观察方向 + 到达后的地标证据 + 光影方向。

## 2｜五个核心锁

### A. World Anchor｜固定世界锚点

先定义不会移动的实体：门、窗、楼梯、桌、沙发、道路、主入口、灯具、车辆、关键装置。

例如：主门在北，石板路南北贯通，大南瓜在南端西侧。

世界方位与画面左右分开。相机换侧可以改变屏幕左／右，不改变门、道路、人物真实世界位置。

### B. Motion Ownership｜运动所有权

每个运动段先决定“谁移动，谁原地”。

如果这一段只写 A 向门口走，则 B 默认保留上一镜位置，即使 B 已出画。只有看到 B 自己的起步、路径与停点，B 的位置才更新。

禁止把“主角在跑”自动理解成“所有角色一起跑”。

后台最小记录：A 的位置／朝向／运动状态；B 的位置／朝向／运动状态；关键道具位置与归属；摄影机世界位置与观察方向。

### C. Observation Corridor｜高风险移动段固定观察走廊

当角色从场景一端走到另一端、出门进门、跨客厅到门口、走廊到楼梯、去目标后又沿原路返回，或两个角色一动一静且距离明显拉开时，优先锁一个连续观察方向，直到移动完成。

在这段高风险路程里，不急着正反打。

示例：摄影机保持在道路南侧朝北观察。A 向北走时在画面中逐渐变小；A 返回南侧时沿同一路径朝摄影机跑来并逐渐变大；B 始终留在南端右前景。直到 A 真实回到 B 身边，才恢复自由反打。

方法的价值不是固定机位本身，而是让距离变化成为可见证据。摄影机可以轻微跟、推、后移，但观察轴和世界方向不要在高风险路程中翻转。

### D. Arrival Anchor｜到达后近景保留同地证据

角色走到新地点后，下一镜即使切近景，也至少留一个能证明“仍在这里”的同地证据：门柱边缘、目标物一部分、同一段楼梯、同方向窗口、同一侧主光或前景遮挡。

不要刚拍完“角色走到门口”，下一镜只剩无背景头像；这会给模型重新回到旧位置的机会。

### E. Light as Coordinate｜光影作为辅助坐标

固定场景里，主光源属于世界地图的一部分。

例如北侧门廊暖光、西南南瓜橙光、东侧冷补光。角色靠近北侧时暖光更近；返回南侧时门廊灯退到远景，南瓜橙光重新靠近。

不用每镜重复灯光段。只在高风险切镜里保留一个能帮助识别位置的光向或局部受光。

## 3｜四层逐镜预演

每个新镜头写之前，在后台快速检查：

| 层 | 要回答的问题 |
|---|---|
| 画面层 | 上一镜最后看见什么？本镜第一帧是否是同一事件的继续？ |
| 位置层 | 每个角色、道具现在在哪？谁在动？谁必须留原地？ |
| 构图层 | 当前机位只是观看真实空间，还是偷偷重新摆了角色？ |
| 光影层 | 固定光源方向／环境地标是否还能证明同一个地点？ |

四层通过后才写镜头正文。位置层优先级最高；如果构图想要的同框与真实站位冲突，改构图，不改人物位置。

## 4｜逐镜编译顺序

统一顺序：

上一镜全员末态 → 指定本镜运动者／静止者 → 必要路径／转身／接触 → 本镜终点 → 选择真实观察位置 → 景别／构图／短运镜 → 必要地标／光向 → 下一镜。

禁止先想漂亮特写／反打，再把演员摆进画面，最后补“保持连续”。

## 5｜最终 Prompt 仍然保持最少词

本模块是后台编译器，不是额外输出模板。最终 Prompt 不增加独立“空间锁”大段，也不输出状态表。

普通低风险镜头按原方式写。只有高风险位置关系增加一句最短必要信号，例如：

- A 沿左侧通道独自向门口走；B 仍留沙发旁，不入镜。
- 门口近景，A 仍站在刚到达的门柱旁，右后方保留同一扇门。
- 摄影机仍在客厅南侧朝北；A 从门口沿原路返回，B 保持右前景原位。

如果一句“保持位置不变”不能让人画出具体空间关系，就改写为实体锚点、路径或静止者状态。

## 6｜何时强制启用固定观察方向

每次写／改视频 Prompt 都先经过本模块判断。

强制启用 Observation Corridor：
- 两镜以上出现跨区域移动；
- 同一路径往返；
- 多角色一动一静；
- 上一次成片已出现方向翻转／复位；
- 门口、走廊、楼梯、车辆、房间之间有明显距离变化。

不强制：
- 单镜单人单动作；
- 两镜都在同一点，仅景别变化且地标稳定；
- 用户明确需要可读的跨轴设计，并已经建立新轴。

简单任务只做快速检查，不增加 Prompt 字数。

## 7｜跨区域零容忍

以下任一情况在 Prompt 层直接判失败：

- 上一镜在客厅，下一镜无移动过程在门口；
- 上一镜已到楼梯，下一镜近景回到红毯起点；
- A 独自离开，B 无动作突然出现在 A 身边；
- 角色往北走，下一镜无转身突然变成从北往南；
- 摄影机反打被误当成人物换位；
- 新近景删掉所有地点证据，导致无法判断仍在刚到达区域。

发现最早断裂镜头后，从该镜开始重传完成态，后面全部重新检查。

## 8｜经实测有效的往返模板

适用于“角色 A 从近处去远处目标，再沿原路返回；角色 B 留在近处”的结构：

1. 建立镜：近端同时看见 A、B、远端目标；固定路径方向。
2. 去程镜：同一观察轴，A 逐渐远离；B 留近端。
3. 到达镜：切目标附近近景，但保留远端地标／固定光源，证明 A 没有复位。
4. 返回镜：回到原观察轴，A 沿同一路径逐渐接近；B 仍留近端前景。
5. 汇合镜：A 真实抵达 B 的位置后，才允许新的双人近景／反打。
6. 下一动作：只有角色自己的可见移动才能更新其坐标。

方法本质：

用连续可见的距离变化证明位置；用运动所有权阻止配角被带跑；用到达锚点阻止近景复位；用固定世界光与地标帮助模型识别同一空间。
