# 节奏功能控制｜Rhythm Function Control

商业广告无论单镜还是多镜，都先建立全片【视频节奏特征】；多镜、连续节拍、参考视频节奏反推、视觉奇观、剧情推进与产品展示，再使用本文件的逐Beat功能控制。默认镜头密度与组接按 `director-information-control.md`：平均约1–3秒一切，同时控制新信息、等待与可读停留。明确单镜或慢片按用户约定，不强切。

核心原则：

`RHYTHM = FUNCTION CHANGE, NOT SHOT SPEED`

先满足当前镜头密度约定，再让每个切点带来动作或信息变化；不能用短镜头掩盖内容重复，也不能用节奏理论取消已约定的切镜密度。

## 0. 视频节奏特征｜Whole-video Rhythm Profile

这是整支视频的导演级节奏总述，先于分镜建立。它回答“整片如何呼吸、情绪在哪里转向、观众何时被推快/按住/释放”，不是逐镜动作摘要，也不是镜头时长列表。

每条商业视频从以下维度中选取真正影响成片的3–5项，不必全部写满：

1. **能量曲线**：低能量克制、平稳蓄力、逐渐加速、突然爆发、短暂悬停、释放或骤停。
2. **情绪弧线**：好奇→欲望、冷静→压迫、轻松→叛逆、亲密→自信、神秘→揭示、紧张→释放等；只选符合创意的一条主线。
3. **剪辑密度**：稳定、逐渐加密、短促跳切、不规则断裂、长镜头停留，或快慢交替。说明变化规律，不只说“快节奏”。
4. **速度反差**：快速动作与慢动作、密集切换与静止、强声压与突然抽空、运动与稳定之间如何形成对比。
5. **关键转折**：哪类事件/信息让整片从蓄力转向爆发、从混乱转向清晰、从人物转向产品，或从声音高潮转向寂静。
6. **声音弧线**：BGM何时进入、加重、与切点同步、抽空、留下余音或终止；关键SFX是否承担节奏触发。
7. **结尾落点**：以产品Hero、人物凝视、动作完成、品牌Logo、静默、骤停或无缝循环中的哪种方式结束。

### 输出句式

【视频节奏特征】全片从[起始情绪/能量]出发，以[推进和加密方式]逐步累积，在[关键事件/信息]处发生[节奏与情绪转折]，随后通过[峰值/停留/释放]把注意力落到[最终记忆点]；音乐/声音在[进入、命中、抽空或收束节点]与画面形成关系。

只写一条紧凑总述，通常1–2句即可。可以使用“克制悬置→细节加密→声画爆发→结果停留→静默收束”这样的功能关系，但必须按当前创意重新选择，不把它变成所有广告的固定模板。

### 与分镜的边界

- **视频节奏特征**：描述整片情绪和能量如何变化、哪里转折、如何释放。
- **Rhythm Function Map**：为关键Beat分配建立、加速、延迟、揭示、停留、证明、释放和收束等功能。
- **分镜时间轴**：只写每个镜头实际发生的动作、景别、机位、运镜、切点和声音。

三者上下游关系为：

全片节奏特征 → Beat功能分配 → 逐镜动作与切点执行

禁止把“视频节奏特征”写成“0–2秒拍瓶子、2–4秒拍人物、4–6秒拍液体”；禁止只写“全程快切、情绪拉满”；也禁止在逐镜时间轴后再重复一遍情绪曲线。

## 1. Rhythm Function Map

两个及以上镜头时，在后台给关键 Beat 标一个主功能；不必全部使用，也不固定顺序：

- `ESTABLISH`：建立人物、空间、常态或产品状态。
- `ACCELERATE`：连续动作/新信息加密，让预测快速前进。
- `ANTICIPATE / DELAY`：在答案前短暂减速、停住或减少信息，制造等待。
- `REVEAL`：答案、异常、产品、结果或关系被清楚看见。
- `SPECTACLE HOLD`：重大视觉结果已经出现，主动减少竞争动作，让观众真正看清。
- `PROOF / VERIFY`：用新的可见证据确认刚才的信息，不重复同一画面。
- `RELEASE`：压力下降、空间打开、人物状态放松或摄影机恢复稳定。
- `CLOSE`：把注意力收束到产品、人物决定、品牌记忆或CTA。

每个 Beat 只保留一个主节奏功能。相邻 Beat 若长期承担同一种功能，优先合并或改变信息状态。

## 2. 节奏呼吸

真正的“呼吸”不是空镜拖时间，而是：

`加速积累 → 减少信息 → Reveal → 给结果阅读时间 → 再推进`

有意减速必须至少完成一件事：
- 消化刚发生的信息；
- 等待人物决定；
- 让产品结构/材质/结果可读；
- 建立尺度、空间或奇观；
- 为下一次节奏升级蓄力。

如果删掉这段停留后，观众仍能同样清楚地理解前后信息，它不是有效呼吸。

## 3. Spectacle Hold｜视觉奇观必须有观看时间

巨物、超现实事件、完整产品 Reveal、复杂变形完成态、关键情绪反应或重要 Proof 一旦到达最可读状态：

- 主体先进入完整可读构图；
- 摄影机减速或稳定，不继续抢戏；
- 减少同时发生的次要动作；
- 焦点与主体关系保持稳定；
- 等观众完成“看见/理解”后再进入下一动作。

不要用固定秒数机械执行。判断标准是：**观众是否来得及识别主体、尺度、结果和意义。**

## 4. 快 ≠ 乱切；慢 ≠ 拖

快速段优先来自：
`连续新信息 + 动作完成态 + Reaction + 注意力接力`

而不是：
`同一信息换5个机位`

慢段优先来自：
`重要结果停留 + 人物理解过程 + 空间/材质读取 + 决策等待`

而不是：
`动作已经结束但镜头继续漂移`

同一影片允许明显快慢差。连续快 Beat 后出现一个职责明确的稳定 Hold，通常比全片同速更有节奏。

## 5. 镜头运动随节奏功能变化

- `ESTABLISH`：稳定观察、轻跟随或清楚建立空间。
- `ACCELERATE`：跟随、快速推近、动作匹配切、甩镜等只服务当前事件。
- `DELAY`：摄影机减少运动，必要时固定等待或极轻微推进。
- `REVEAL`：通过硬切、打开空间、遮挡解除、拉焦/摇镜完成信息揭示。
- `SPECTACLE HOLD`：减速落稳，让主体占据注意力。
- `RELEASE / CLOSE`：构图逐渐干净，运动趋于稳定。

普通叙事允许大部分镜头极慢前推，通过机位、景别、动作与切点变化推进；需要跟随、揭示或落稳时再变速变向，不为运镜种类配额添动作。

## 6. 给生成模型的转译

内部可以使用“节奏呼吸、Delay、Reveal、Hold”等导演标签；最终Prompt必须转成可执行变化，不直接把抽象标签扔给模型。

错误：
`前半节奏很快，后面有呼吸感，奇观要震撼。`

正确：
`她连续完成两个短促动作后突然停住；镜头也随之稳定。门打开，巨大的主体完整进入画面，人物停止额外动作，镜头在完整构图上短暂保持，随后才跟随她向前。`

只写真正会改变成片的节奏节点；不要把每个 Beat 都解释成导演理论。

## 7. 参考视频反推

分析参考视频时，不只统计镜头长度。优先提取：

`常态建立 → 信息加密 → 等待/悬置 → 揭示 → 可读停留 → 再升级/证明 → 收束`

同时判断：
- 哪个动作触发变速；
- 哪个镜头是 Reaction 标点；
- 哪个画面被刻意留时间；
- 产品/主角何时接管注意力；
- 声音何时抽空、命中、抬升或收束。

复刻的是**节奏功能关系**，不是机械复制原片时长和切镜点。

## 8. Silent QA

- [ ] 节奏是否来自信息/动作状态变化，而非单纯镜头更短？
- [ ] 默认切镜平均约1–3秒是否落实，关键完成态和最后约1秒收束是否有时间？单镜/慢片按用户约定。
- [ ] Reveal之前是否有必要的等待/蓄力，或至少避免提前泄露？
- [ ] 重大视觉结果是否得到足够可读停留？
- [ ] Reaction之后是否继续产生新信息/决定，而非停在表情上？
- [ ] 快段是否每次切换都带来新信息？
- [ ] 最终Prompt是否把抽象节奏词翻成动作、停顿、镜头速度与信息变化？
- [ ] 商业任务是否有独立的全片视频节奏特征，且它不是逐镜摘要？
- [ ] 全片节奏总述、Beat功能与分镜时间轴是否各司其职、没有互相重复？

最终原则：

`CONTROL WHEN THE VIEWER KNOWS`

`CONTROL WHEN THE VIEWER WAITS`

`CONTROL WHEN THE VIEWER SEES`

`THEN LET THE IMAGE LAND`
