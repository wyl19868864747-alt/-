# 节奏功能控制｜Rhythm Function Control

用于多镜、连续节拍、参考视频节奏反推、视觉奇观、剧情推进与产品展示。目标不是规定镜头必须多短，而是控制观众什么时候接收信息、什么时候等待、什么时候被揭示、什么时候有时间看清。

核心原则：

`RHYTHM = FUNCTION CHANGE, NOT SHOT SPEED`

不要把“节奏快”直接翻译成短镜头、疯狂切镜、持续推拉；也不要把“高级克制”翻译成长镜头和慢动作。节奏由信息、动作、情绪和镜头状态的变化构成。

## 1. Rhythm Function Map

两个及以上镜头时，在后台给关键 Beat 标一个主功能；不必全部使用，也不固定顺序：

- `ESTABLISH`：建立人物、空间、常态或产品状态。
- `ACCELERATE`：连续动作/新信息加密，让预测快速前进。
- `ANTICIPATE / DELAY`：在答案前短暂减速、停住或减少信息，制造等待。
- `REVEAL`：答案、异常、产品、结果或关系被清楚看见。
- `SPECTACLE HOLD`：重大视觉结果已经出现，主动减少竞争动作，让观众真正看清。
- `PROOF / VERIFY`：用新的可见证据确认刚才的信息，不重复同一画面。
- `RELEASE`：压力下降、空间打开、人物状态放松或摄影机恢复稳定。
- `CLOSE`：把注意力收束到产品、人物决定、品牌记忆或CTA。

每个 Beat 只保留一个主节奏功能。相邻 Beat 若长期承担同一种功能，优先合并或改变信息状态。

## 2. 节奏呼吸

真正的“呼吸”不是空镜拖时间，而是：

`加速积累 → 减少信息 → Reveal → 给结果阅读时间 → 再推进`

有意减速必须至少完成一件事：
- 消化刚发生的信息；
- 等待人物决定；
- 让产品结构/材质/结果可读；
- 建立尺度、空间或奇观；
- 为下一次节奏升级蓄力。

如果删掉这段停留后，观众仍能同样清楚地理解前后信息，它不是有效呼吸。

## 3. Spectacle Hold｜视觉奇观必须有观看时间

巨物、超现实事件、完整产品 Reveal、复杂变形完成态、关键情绪反应或重要 Proof 一旦到达最可读状态：

- 主体先进入完整可读构图；
- 摄影机减速或稳定，不继续抢戏；
- 减少同时发生的次要动作；
- 焦点与主体关系保持稳定；
- 等观众完成“看见/理解”后再进入下一动作。

不要用固定秒数机械执行。判断标准是：**观众是否来得及识别主体、尺度、结果和意义。**

## 4. 快 ≠ 乱切；慢 ≠ 拖

快速段优先来自：
`连续新信息 + 动作完成态 + Reaction + 注意力接力`

而不是：
`同一信息换5个机位`

慢段优先来自：
`重要结果停留 + 人物理解过程 + 空间/材质读取 + 决策等待`

而不是：
`动作已经结束但镜头继续漂移`

同一影片允许明显快慢差。连续快 Beat 后出现一个职责明确的稳定 Hold，通常比全片同速更有节奏。

## 5. 镜头运动随节奏功能变化

- `ESTABLISH`：稳定观察、轻跟随或清楚建立空间。
- `ACCELERATE`：跟随、快速推近、动作匹配切、甩镜等只服务当前事件。
- `DELAY`：摄影机减少运动，必要时固定等待或极轻微推进。
- `REVEAL`：通过硬切、打开空间、遮挡解除、拉焦/摇镜完成信息揭示。
- `SPECTACLE HOLD`：减速落稳，让主体占据注意力。
- `RELEASE / CLOSE`：构图逐渐干净，运动趋于稳定。

不要让整片摄影机始终处于同一种推、拉、环绕或手持强度。

## 6. 给生成模型的转译

内部可以使用“节奏呼吸、Delay、Reveal、Hold”等导演标签；最终Prompt必须转成可执行变化，不直接把抽象标签扔给模型。

错误：
`前半节奏很快，后面有呼吸感，奇观要震撼。`

正确：
`她连续完成两个短促动作后突然停住；镜头也随之稳定。门打开，巨大的主体完整进入画面，人物停止额外动作，镜头在完整构图上短暂保持，随后才跟随她向前。`

只写真正会改变成片的节奏节点；不要把每个 Beat 都解释成导演理论。

## 7. 参考视频反推

分析参考视频时，不只统计镜头长度。优先提取：

`常态建立 → 信息加密 → 等待/悬置 → 揭示 → 可读停留 → 再升级/证明 → 收束`

同时判断：
- 哪个动作触发变速；
- 哪个镜头是 Reaction 标点；
- 哪个画面被刻意留时间；
- 产品/主角何时接管注意力；
- 声音何时抽空、命中、抬升或收束。

复刻的是**节奏功能关系**，不是机械复制原片时长和切镜点。

## 8. Silent QA

- [ ] 节奏是否来自信息/动作状态变化，而非单纯镜头更短？
- [ ] 是否存在至少一次有职责的减速或停留，而不是全片同速？
- [ ] Reveal之前是否有必要的等待/蓄力，或至少避免提前泄露？
- [ ] 重大视觉结果是否得到足够可读停留？
- [ ] Reaction之后是否继续产生新信息/决定，而非停在表情上？
- [ ] 快段是否每次切换都带来新信息？
- [ ] 最终Prompt是否把抽象节奏词翻成动作、停顿、镜头速度与信息变化？

最终原则：

`CONTROL WHEN THE VIEWER KNOWS`

`CONTROL WHEN THE VIEWER WAITS`

`CONTROL WHEN THE VIEWER SEES`

`THEN LET THE IMAGE LAND`
