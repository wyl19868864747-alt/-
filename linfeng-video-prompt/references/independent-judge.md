# 交付前验收

只找实际失败，不替创作自我辩护。以下检查对最终写/改Prompt静默执行；各领域细则回到拥有该规则的模块修，不叠加新长段。

1. **事实**：参考职责、人物、产品、数量、尺寸、标签、已获准文案是否准确；不能凭空补商业功效。
2. **可拍可听**：全文含标题/总控/声音是否还要求“抓眼、高级、治愈、有感染力、信息推进快”等效果？替换成事件与声音后删除评价；保留可见物理完成态，不误删逐字锁定的对白。
3. **主次**：主体、动作、关系是否最清楚？每位音色是否一句？是否有全片景别表、镜头流、产品重点、情绪曲线等重复时间轴？删次要信息，不加长主体配平。
4. **每镜**：实际切镜含组内子镜是否有时间边界、景别、机位和一条短运镜？默认平均1–3秒是否落实？明确单镜/慢片按用户指示，不能强切。
5. **逐对组接**：相邻非特写是否相隔景别；每次切镜观察角是否大于30°且同轴同侧；是否拿同机位裁切或改景别名冒充换位；动接动/静接静是否有阶段、方向、落点承接？
6. **状态与物理**：执行下方Spatial Continuity Judge；泡沫/湿度/开合等是否继承，反应是否晚于触发、高速动作是否先接触再反馈，是否已冲净又起泡？
7. **容量**：逐时段计动作和台词，轮流对话词数合并，扣停顿/换人/反应；跨镜旁白是否明确？超时不能用“加速、流利”遮掩。最后约1秒能否在台词结束、动作完成后收束？
8. **声音与成像**：BGM是否有可听的进入/抽空/收束并压在对白下；是否有无需求声音？主体、标签和必要证据是否读得清，光源/材质是否无因变化？
9. **负载与节奏**：每镜是否一个主要变化，复杂动作/运镜/对白是否竞争；关键揭示是否有可读停留；新增信息是否代替重复角度，普通慢推是否被无理由换成花哨运镜？

## Spatial Continuity Judge｜逐对强制检查

对每一对相邻镜头（含快切子镜、最后一切和分段生成边界），从实际文本还原前镜末态与后镜首态，不因全局写了“连续”就判通过：

| 项 | 检查 |
|---|---|
| A | 人物位置能否通过已写动作连续解释？ |
| B | 身体朝向、头部/视线改变是否有转头或转身？ |
| C | 运动方向是否无故反转？ |
| D | 道具位置、持有者、连接/接触状态是否连续？ |
| E | 前景/背景关键物体是否无因换边；投影变化是否由实际相机位置解释？ |
| F | 前镜末位至后镜首位是否真实换位且观察角差大于30°，而非裁切、改标签或转向另一对象？ |
| G | 是否仍在已建立轴线同侧；新轴是否通过动作/换场建立？ |
| H | 相机视线、遮挡与景别是否确实能看到所声称的动作及关键连接？ |
| I | 前镜完成态是否完整成为后镜起始态，包括暂未入画但后续相关的对象？ |
| J | 位置、距离、高度、朝向、持物、房间的变化是否有动作过程或明确成立的时间转场？ |
| K | 本镜是否明确谁在移动、谁原地；画外配角是否被无因带到主角身边或跟跑？ |
| L | 高风险跨区域／往返段是否保持可读的世界观察方向；角色抵达后近景是否保留同地地标、前景或受光证据？ |

F按原组接约定适用实际切镜；用户明确固定单镜/一镜到底时记不适用，仍检路径和状态连续。没有切镜不伪造角差；用户明确跨轴设计仍需原规则的可读重建。

任一项失败或必要关系无法判定：返回最早出错分镜重写动作/机位；必要时补前镜动作并重新核算时长，从被改镜起向后传递完成态直至接续一致。**禁止在Prompt末尾加空间锁、禁令或检查说明作为修复。**

回归入口：`evaluation-cases/per-shot-spatial-state-regression.md`；运动所有权、固定观察走廊和到达锚点另测 `evaluation-cases/spatial-handoff-lock-regression.md`。

失败就修最早相关层，再检查前后接续；全部通过才交付。审阅文本、估算语速、独立试写均不能冒充已生成成片或已试听。
