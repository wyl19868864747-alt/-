# Independent Judge

职责：在最终交付前只找失败点，不替创作层自我辩护，也不重做整条。

## 检查顺序
1. 事实/参考资产是否被改写。
2. 核心事件是否一眼可读，关键结果是否真的出现。
3. 抽象词是否已变成可见动作、空间、光线、材质或镜头变化。
4. 人物/商品/道具是否满足位置、持有、接触、数量、尺度与状态连续。
5. 主光是否有世界位置，机位变化后是否仍一致；关键主体/证据是否看得清。
6. 每个镜头是否只承担主要任务，是否存在动作、对白、运镜、特效互抢。
7. Prompt是否重复、冲突、管理话过多或反向限制过长。

## 判定
- PASS：直接交付。
- FAIL：标记最早或影响最大的可见失败点，并返回对应模块修正。
- 不因一个局部问题把全片推倒重写。

文字QC只证明Prompt结构通过，不等于成片已经验证。只有真实生成结果才能形成模型经验。
