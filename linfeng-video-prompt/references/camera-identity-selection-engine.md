# 摄影机身份选择器

## 目的

把“用什么摄影机拍”作为导演与摄影决策，而不是器材炫耀。生成模型不会真实调用摄影机，因此机型只负责提供成像身份，最终必须转译为可见结果：画幅感、动态范围倾向、肤色、高光滚降、低照度、运动扫描、自动曝光/自动对焦、颗粒/噪点、稳定方式与操作者行为。

## 1. 先选摄影身份，再选型号

先回答四件事：

1. **创作目标**：观众应把它感知为广告大片、自然剧情、纪录观察、UGC自拍、新闻采集、家庭影像、复古DV，还是混合形态？
2. **拍摄现实**：是大型剧组可控布光，还是单人/小团队、低照度、快速移动、不可重复事件？
3. **最重要的成像需求**：高光与肤色、低照度、超高速运动、轻量机动、自动对焦，还是年代/媒介真实性？
4. **摄影者身份**：专业摄影组、纪录片摄影师、博主本人、新闻摄像、家人/朋友。摄影者身份必须与机位、稳定度、对焦和曝光行为一致。

只有机型会明显改变画面身份时才在最终提示词点名；否则后台选型后只输出成像结果。

## 3. 选择规则

### A. 广告大片 / 高端剧情
优先 `ALEXA 35`；若更需要全画幅、夜景、大空间与高端大制作感，优先 `VENICE 2`。

### B. 高速动作 / 汽车 / 机械 / VFX
优先 `V-RAPTOR X`。核心不是“8K”，而是高速运动几何、全局快门、快速横移和高帧率的干净表现。

### C. 自然光、纪录剧情、小团队商业
优先 `C400 / FX6类 / PYXIS`，根据自动对焦、低照度、机动性和后期空间取舍。

### D. 创作者Vlog / 健身 / 旅行 / UGC
先判断是：
- **原生用户自拍** → 手机；
- **高级创作者自己拍** → FX3类轻量Cinema Line；
- **年代Vlog/旧家庭影像** → MiniDV；
不要只因为“想高级”就升级成ALEXA。

### E. 纪实 / 真人秀 / 新闻
先选摄影者身份。新闻采集与不可重复事件优先ENG/轻量纪录机逻辑；电影机只在明确“纪录片电影摄影”时使用。

## 4. 摄影机不是滤镜

选择型号后至少转译出3项真正影响画面的结果：

`画幅/透视 + 亮暗/肤色 + 运动/对焦/曝光行为`

例如：
- ALEXA 35：`Super 35自然透视；窗外高光与室内肤色同时保留；高光柔和滚降，暗部开放，不数字过锐。`
- FX3夜间Vlog：`全画幅轻量手持；高感下保留自然肤色与背景实用灯；轻微手持呼吸、快速但非完美的自动对焦。`
- MiniDV：`小传感器深景深；自动曝光偶发抽动、短暂寻找焦点、生硬伺服变焦、轻微磁带/数码噪点。`

如果型号被删掉后这些可见结果仍完整，成品提示词可以不写型号。

## 5. 与成品提示词分层结合

摄影机身份、必要机型和可见成像行为不进入 `【开场总述】`。后台完成选择后，把跨全片持续成立的摄影结果压缩进 `【光影与成像基线】`，把单镜变化留在时间轴；开场总控只保留虚化的片型、风格调性、观看感受与平台原生气质。

## 6. 防止Skill膨胀

- 不保存市场上所有机型，只维护少量代表性“摄影机家族”。
- 新机型只有在带来新的可见成像能力或新的拍摄身份时才加入。
- 参数不是知识本体；参数只用于证明为什么该机型适合某类画面。
- 同类机型优先并入已有家族，不因品牌更新而无限追加表格。
