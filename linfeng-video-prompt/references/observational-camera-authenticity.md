# 观察者摄影与时代成像真实性

用于纪实、真人秀、幕后花絮、派对/街头抓拍、新闻采集、家庭录像、档案电视、早期DV、广播ENG、手机现场记录，以及任何需要摄影者真实身处现场的内容。能力标签为 `observational-camera`，可与广告、剧情、UGC、群像、年代美术、写实超现实、产品事实、连续性和画质并行叠加。

精密产品Hero、严格几何/材质证明、标签或UI读取、稳定对白覆盖、明确高端机械运动默认跳过或只在前段局部使用；手持不等于混乱失控。

## 1. 摄影者有限身体合同

真实感来自有限注意力、身体惯性、反应延迟与恢复，而不只来自颗粒、抖动、低清或复古滤镜：

`现场事件先发生 → 摄影者发现 → 身体或相机反应 → 追随/重构图 → 焦点与曝光短暂恢复 → 落在新增信息、动作结果、人物反应或产品证据。`

根据摄影者当时知道什么决定时间关系：可提前守住已知落点、同步陪伴可预期动作，也可对突发事件迟半拍追赶；禁止全片机械地永远慢半拍。摄影机移动必须由人物、声音、水花、物体进入、遮挡解除或现场变化触发。

## 2. 观察者镜头六步设计

1. **母视点与操作者位置**：明确在人群、池边、门口、车内或人物身后；锁定站立/行走、视线高度与可达路径。
2. **触发事件**：笑声、转身、跳水、物体进入、水花、欢呼等先改变现场。
3. **注意力发现**：通过声音、视线、动作或遮挡解除发现，不提前全知锁定所有高潮。
4. **身体反应**：迟半拍摇镜、短促推进、快速光学变焦、后退躲避、步伐起伏或仓促重构图；每次只保留一种主要反应。
5. **设备恢复**：自动对焦、曝光、白平衡或高光短暂变化后重新稳定；持续太久即为失败。
6. **落幅与切点**：落在动作结果、朋友反应、产品证据或新现场问题；镜头尚未恢复可读时不承担精确信息。

## 3. 允许摄影机犯错，不允许世界犯错

允许短暂偏框、前景遮挡、主体轻微出画后重构图、对焦寻找、小幅曝光呼吸、偶发高光溢出、快速摇镜的短促运动模糊、由步伐/呼吸/转身/躲避产生的非周期微动，以及晚半拍捕捉反应。

不允许人物身份/五官变化、商品变形换色/标签漂移、空间跳变、肢体异常、接触拓扑错误、道具无因增删换位、人数随机变化，或摄影缺陷长期遮挡唯一叙事结果与产品证据。核心边界：摄影机可以不完美，世界必须正确。

## 4. 受控不完美

按设备身份和事件强度只选少量缺陷：

- 手持微动来自步伐、呼吸、转身、避让或动作反应；
- 偏框/裁切短暂且有重构图；漂焦/曝光变化由距离、反光或天空进入触发；
- 快速运动的模糊、滚动或果冻感在镜头停止后恢复；
- 重要面部、动作完成态和产品证据重新清楚；
- 操作者可慢半拍但不能错过唯一结果；现场可凌乱但道具有支撑、使用痕迹和归属。

禁止随机抖动、等幅机械震动、无目标甩镜/变焦、全程漂焦、持续过曝、长期游荡或用缺陷掩盖模型错误。

## 5. 年代成像证据

先确定 `设备—年代—节目语境`，再选择成像行为。年代感至少由以下四层中的三层共同建立：

1. **设备身份**：符合时代的DV、广播ENG、消费摄像机、早期数码相机或手机，以及其取景、光学变焦、自动曝光/对焦行为；
2. **成像响应**：统一解析力、机内锐化、动态范围、高光溢出、视频噪点、隔行/DV/磁带纹理、帧率和运动表现；
3. **摄影习惯**：肩扛/掌机高度、快速光学变焦、报道覆盖、真人秀抓拍、幕后或家庭追拍；
4. **世界证据**：服装、发妆、道具、饮具、家具、车辆、场地、节目语境与社交行为。

现代高清纪录片可保留有限注意力和现场反应，但关闭旧DV隔行、低动态范围和频繁光学变焦。禁止把早期DV低动态范围、现代4K HDR商业光泽、旧广播质感、现代稳定器/无人机完美运动并列进同一基线。

## 6. 群像现场与真实蒙太奇

群像建立三层状态：主动作人物；不同时间产生反应的人；继续聊天、整理、观察、经过或做自己事情的背景人物。背景轻量自治但不得复制、闪现、换位或抢夺注意力。毛巾、包、杯、泳圈、冷藏箱和工具等可散落，但必须有支撑、归属与使用痕迹。

快速蒙太奇按 `空间建立 → 人群覆盖 → 局部动作 → 意外瞬间 → 朋友反应 → 环境插镜 → 回到整体` 组织。每个短镜只承担一个职责，用声音、动作方向、视线、水花、颜色、形状或遮挡接力；重复同一信息的碰杯、笑脸、跳水、欢呼或变焦应删除/合并。大量素材拆成可独立生成和剪辑的短镜，不能把几十个动作塞进一个连续镜头。

## 7. 提示词编译

优先写可见因果：

`[现场事件]先发生；位于[操作者位置]的摄影者被[声音/动作/视线]吸引，按其已知信息[提前守点/同步陪伴/迟半拍]向[方向]摇镜、跟上或短促变焦，[主体]短暂偏框或焦点寻找，随后在[动作结果/人物反应/产品证据]上恢复清楚并落稳。`

【光影与成像基线】按 `camera-light-quality-baseline.md` 写设备/年代的可见成像、真实光源与色彩关系；曝光迟疑、焦点寻找和追拍惯性在实际触发的镜头里写，不在每镜重复设备清单。

## 8. 审片标准

- 每次移动、变焦、漂焦或曝光变化是否有现场触发，摄影者是否有明确位置与可达路径？
- 是否体现有限注意力与合理时间关系，而非全知预判或机械延迟？
- 缺陷是否短暂可控，并在关键信息前恢复？
- 群像是否分为主动作、反应和背景自治三层？
- 年代是否由设备、响应、习惯和世界证据中至少三层共同成立？
- 是否误用现代稳定器、商业布光、超清锐利或与时代矛盾的成像语言？
- 人物、商品、空间、物理、接触和连续性是否始终正确？
- 删除颗粒与复古滤镜后，摄影者行为本身是否仍真实？若否，说明只有表面风格，必须重做行为因果。
