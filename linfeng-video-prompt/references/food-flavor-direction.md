# 食品饮料风味证据

用于食品、饮料、调味品、餐饮，以及需要表达香气、味道、清爽、浓郁或余韵的商业视频。只拍包装或器皿材质时不必加载。

## 1. 分开质地与风味

- **质地**可直接看见或听见：断面、黏度、气泡、酥脆、湿润、蒸汽、流动、融化、碰杯声。
- **风味**无法直接被摄影机拍到，必须由真实商品事实、制作/饮用联想、光色运动、声音和食用后余韵共同建立。

不要用一个拉丝、液滴或慢动作同时宣称全部口感与风味。

## 2. 三层证据

表达具体风味时至少组合三层，并且必须包含真实商品证据：

1. 包装、可见内容物、真实食材或已确认配方；
2. 与事实相符的烹饪、冲泡、冷藏、烘焙或饮用过程；
3. 光线、颜色、温度感和运动节奏；
4. 咬合、折断、气泡、倒液、吞咽或环境声音；
5. 接触和咀嚼/吞咽后的克制余韵反应。

没有证据时只写感官联想，不把视觉隐喻升级成真实成分、产地、零添加、营养、功效或工艺。

## 3. 镜头职责与因果

包装Hero负责识别，食物微距负责质地，取食动作负责使用，人物反应负责余韵；相邻镜头不重复同一证明。蒸汽、气泡、油脂和冷凝必须有温度、动作或环境原因。人物先接触、咀嚼或吞咽，再出现呼吸、眼神和姿态变化，不在入口前预演“好吃”。

## 4. 验收

- 是否区分质地证明与风味联想？
- 是否至少有三层证据并包含真实商品证据？
- 是否编造了食材、产地、配方、营养或功效？
- 包装、质地、取食和余韵是否各有职责且顺序正确？
