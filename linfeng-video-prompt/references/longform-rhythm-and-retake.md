# 长时视频节奏、元素回收与局部返修

用于20秒及以上商业片、剧情或群像短片、多场景任务、用户反馈“重复、拖、像拼镜头”，以及基于成片进行复盘、局部重试或返修。它跨商业与剧情生效。

## 1. 长时不是重复短片

- 长片仍只有一个核心传播命题或剧情核心问题；新增第二层证据、关系变化、体验发展、信任或有职责的呼吸。
- 每4–6秒至少引入一种新信息：关系、证据、状态、有效动作、声音事件或真正的场景变化。
- 真换场至少改变地点、时间、人物关系、动作目标或世界规则；只换角度、景别、背景色不是换场。
- 不重复同一Hook、近似产品展示、相同人物反应或无职责物流动作。

## 2. 节奏谷与动作预算

任意约2.5秒窗口若没有新增信息、状态变化、有效运动、切镜或新声音，即为节奏谷；只有高张力感官停留或最终Hero可有意保留。递物、移杯、推盘等物流动作通常快速完成，除非它承担因果、仪式或冲突。

产品揭示负责“如何进入注意力”，Hero/Packshot负责“观众最终记住什么”。相邻且职责重复时合并为“动态进入 → 稳定识别”。

## 3. 视觉元素铺垫与回收

记录少量关键元素：`归属角色/段落 + 首次形态 + 颜色/材质/运动 + 结尾回收方式`。结尾优先回收前文建立的2–4个元素，并保持原有归属与运动规律；不得突然加入未经铺垫的大型奇观。

## 4. 证据驱动返修

先建立镜头/时间地图并加密检查失败区间；有语言时对齐时码转写。记录 `成功层｜失败层｜必须保留｜唯一主修层`，每次只选动作、商品、人物、镜头、光色、声音、节奏或交付中的一个主要层。

局部返修按：`保留什么 → 修改时段 → 当前错误 → 目标状态 → 最小替换指令 → 验收点`。同层连续两次失败时减少变量、拆镜或升级控制方式，不继续堆同义禁令。

## 5. 验收

- 长片是否靠新证据/新关系扩展，而不是复制镜头？
- 结尾是否回收前文建立的角色、道具、产品、声音或视觉元素？
- 是否存在无新增信息的节奏谷或拖长物流动作？
- 返修是否有时间码证据、保护成功层并只修一个主要层？
