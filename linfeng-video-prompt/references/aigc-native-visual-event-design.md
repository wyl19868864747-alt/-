# AIGC 原生视觉事件设计｜Reality + One Impossible Rule

用于真人实景／宠物实景／产品实拍底盘中加入连续、可读、难以用传统实拍直接完成的视觉变化。目标不是把 Prompt 写成“魔法、超现实、视觉奇观”，而是把这些结果词编译成一个在真实世界里发生的、可连续观看的异常机制。

## 1｜参考视频提炼出的核心 DNA

AIGC 的优势不是“特效更多”，而是：

**大部分现实保持正常，只让一个明确规则暂时失效，而且变化过程本身能被镜头连续看见。**

参考结构：

现实底盘 → 明确触发 → 局部异常开始 → 沿可读路径传播 → 中间态持续可见 → 完成态稳定 → 现实人物／环境作出反应 → 下一次变化升级。

### A. Reality Chassis｜现实底盘

先保住真实感：
- 熟悉地点与真实材质；
- 人物身份、姿态、空间位置不重置；
- 背景、旁观者、家具、光源继续遵守现实；
- 阴影、遮挡、反射、接触与景深仍成立。

越多现实保持正常，唯一的“不可能事件”越显眼。

### B. Visible Trigger｜明确触发

异常不能无因出现。给观众一个一眼能懂的触发源，例如：
- 手机／屏幕中的目标图；
- 手指点按；
- 触碰衣料／产品；
- 镜面、门框、光带、影子；
- 一个物体靠近或穿过边界。

触发源负责回答“为什么现在开始”。

### C. Single Impossible Rule｜一次只破坏一个现实规则

例如：
- 衣服在人体原位自动生长并替换；
- 材质沿产品表面结晶；
- 影子先变形，再带动实体；
- 门框另一侧的现实空间逐步改写；
- 产品表面展开成可进入的小世界。

不要同时让人物漂浮、空间坍缩、衣服变形、天气突变。真实底盘越稳，异常越强。

### D. Continuous Propagation｜连续传播，不靠闪白遮住变化

变化必须有：
起点 → 传播方向 → 中间态 → 完成边界。

优先写真实可见的变化机制：
- 从鞋尖向小腿上卷；
- 沿衣摆向腰部编织；
- 从接触点沿表面结晶；
- 一道窄边界扫过身体，被扫过区域已经变成新材质；
- 布料从局部长出、包覆、收紧、形成褶皱。

避免用大面积闪白、烟雾、粒子爆炸、镜头模糊直接把 A 遮掉再出现 B。除非“遮挡本身”就是创意机制。

### E. Identity & Space Inheritance｜身份和位置继承

变的是服装／材质／物体状态，不是人突然换了一个人，也不是换了空间。

同一人物保持：
- 同一身体比例、脸、发型；
- 同一座位／落脚点／运动轨迹；
- 同一世界光源；
- 同一背景透视。

新形态必须在原来的身体／物体上生成，并与真实遮挡、褶皱、投影和接触关系对齐。

### F. Reality Witness｜现实见证者

如果画面允许，保留一个现实参照：
- 旁边的人回头；
- 主体低头检查变化；
- 手摸到新材质；
- 原本普通的环境完全不变。

见证者不是解释特效，而是证明“不可能事件发生在这个真实世界里”。

## 2｜镜头必须和事件耦合

摄影机不是独立炫技。每个明显运镜都回答：

**哪一个可见事件触发镜头？镜头移动后，新信息具体多了什么？**

常用匹配：

- 变化沿身体向上：镜头轻微上移／俯仰跟随变化前沿，而不是先拍脸再让变化在画外完成；
- 前景遮挡后出现新形态：摄影机横移，让遮挡边缘真正完成 reveal；
- 主体快速接近／逃离：摄影机跟随距离变化，画面尺度同步变化；
- 异常触发：先让触发可读，再切反应，不要先切惊讶脸；
- 形态完成：短暂停稳，让完成态被读清，再进入下一动作。

运镜若删除后画面信息完全不变，收敛它。

## 3｜声画同一因果节点

声音与镜头共享同一个事件触发：

- 触发瞬间：一个短、明确的同步声；
- 传播过程：声音纹理沿变化逐渐展开，不用每帧都加新音效；
- 完成边界：短收束音或音乐落点；
- 角色认出：音乐可短暂抽空，让呼吸、衣料、脚步或环境声承担真实感；
- 第二次变化：同一声音母题升级音高／密度／材质，不简单重复第一次。

不要让“音乐高潮、复杂运镜、形变完成、角色尖叫”全部无因堆在同一瞬间。

## 4｜连续奇观必须升级，不能平级重复

同一机制第二次出现时，至少改变一项：
- 传播方向；
- 材质；
- 目标对象；
- 空间尺度；
- 角色后果；
- 触发方式。

第一次从鞋向上生成服装，第二次可以从腰部向上下同时替换；第一次主体自己没注意，第二次让旁观者先发现。不能只是换一个颜色再完整复制第一次节拍。

## 5｜写 Prompt 的最短链

后台先回答：
现实是什么 → 哪条现实规则被打破 → 什么触发 → 从哪里开始 → 沿哪里传播 → 中间态是什么 → 怎样完成 → 谁看见／触摸／回应 → 镜头怎样跟事件 → 声音在哪个物理节点发生。

最终 Prompt 只写可拍内容：

“手机前景显示目标服装；女人仍坐在原位。粉色鞋从脚尖开始替换黑色高跟，白袜沿小腿向上织出；裙摆随后从腰侧展开并形成真实褶皱，最后兔耳在头顶立起。摄影机保持正面中景，只轻微上移跟随变化前沿；车厢、旁人和窗光始终不变。服装完成后她才低头检查，旁边乘客转头看她。”

不要写：
“AIGC优势、魔法感、视觉奇观、超现实冲击、高能变装”。

这些是设计目标，不是模型执行语言。

## 6｜适用边界

优先用于：
- 创意短片；
- AI模型能力展示；
- 高概念广告；
- 时尚／美妆／产品视觉化；
- 宠物荒诞剧情中的少量不可能事件；
- 用户明确要求虚实结合、反差、不可思议画面。

现实UGC、纪录片式口播、证据型产品演示若没有创意需求，不强行加入异常机制。

空间连续、接触、身份锁、产品事实仍由对应模块负责。本模块不能用“幻想”绕过真实位移与物理接力。
