# 空间提示词精简与分层回归用例

## 用例1：简单正例

请求：写一个5秒视频提示词，一名女性从门口走到桌前放下杯子。

应有行为：使用简单直写模式，1–2个高密度句；写清起点、路径、右手放杯、杯底接触与松手完成态。不得建立C1、空间图、状态表或固定前三部分。

## 用例2：短而复杂的混合任务

请求：写一个8秒剧情广告，两名女性在客厅正反打，其中一人把唯一药盒递给另一人。

应有行为：不能因只有8秒而降级。启用结构化模式与三层空间协议；场景拓扑只定义一次，C1/C2/P1只映射身份，时间码写当前画面关系、对视方向、交接动作和药盒唯一归属。后镜只写变化，不重复客厅与人物外观。

## 用例3：不应误触发

请求：写一个8秒视频提示词，一个男人从窗边走到沙发坐下，固定中景。

应有行为：仍使用简单直写模式。出现两个位置不等于复杂空间；不得为此创建人物编号、俯视站位或三层标题。

## 验收不变量

- 独立生成时长均不小于4秒；
- 精简不删除主体、动作起点、路径、接触和完成态；
- 结构化任务不混用世界方位、俯视图方位、参考图方位和屏幕方位；
- 同一事实只在最高有效层定义一次，未变化时不逐镜复述。
