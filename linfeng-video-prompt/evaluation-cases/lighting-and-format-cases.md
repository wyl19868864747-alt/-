# 摄影机、成像基线与格式行为用例

这些是维护时的提示词行为检查，不是已完成的视频对照实验。生成成功率、画质改善与穿模改善仍需实际输出证据。

## A. 常驻 Capture Baseline 回归

| 用例输入 | 应有行为 | 失败信号 |
|---|---|---|
| 8秒普通室内双人对话，白天自然光；用户只给剧情和台词，没有提“摄影/画质/灯光” | **仍执行常驻成像基线**：总控用一条最短句交代真实摄影透视、自然运动模糊/不过锐细节、真实材质受光、亮暗结构与合适景深；每镜仍有景别＋机位＋短运镜。不开长篇灯光块 | 因用户没说“画质”而完全没有成像基线；或每镜都重复“高清、真实材质、景深、运动模糊”套餐 |
| 10秒人物快速起身横穿客厅，镜头侧面跟移后停住 | 横移有真实前后景视差；速度变化处有自然运动模糊；人物停住后镜头轻微收稳并重新清楚；不需要额外堆设备名 | 人物和背景像一张平面贴图；高速移动仍全边缘冻结刀锐；镜头瞬停无惯性 |
| 10秒手机自拍UGC，女生边走边介绍产品 | 常驻基线按**手机媒介**改写：轻微手持/真实曝光、快速动作自然模糊、人物与产品清楚但不过锐、背景不过度虚化；不强行转成无噪电影摄影 | 套用电影摄影、极浅景深、稳定器滑轨感；把手机自动曝光/轻微手持当缺陷全部抹掉 |
| 6秒固定机位，一个人把玻璃杯放到桌上 | 虽然镜头固定，仍保留成像底盘：玻璃透明折射、亮部不过曝、杯底落稳与接触关系清楚；不为了“常驻摄影机”硬加推拉摇移 | 为了调用摄影规则强行移动镜头；玻璃像塑料或死白；只写“8K电影感” |
| 用户明确要求“低清便利店监控录像，固定高位广角，压缩噪点明显” | 用户媒介优先：常驻层仍检查空间/运动/可读性，但不把噪点、低清、固定监控视角修成干净数字电影 | 自动加入“超高清低噪点、柔和高光、电影级景深”，破坏媒介事实 |

## B. 条件 Lighting / Advanced Layer 回归

| 用例输入 | 应有行为 | 失败信号 |
|---|---|---|
| 15秒夜间客厅双人关系戏，有人从门口走到沙发；先不写具体品牌 | 常驻成像基线先执行；因空间光向影响连续性，再补必要光源方向。人物先到达再发生接触，主光在世界中固定 | 灯随反打换边；远处角色的手直接进入近景；用长篇灯具清单淹没人物关系 |
| 暗光手机POV追拍发光手绘光标，荒诞治愈，15秒 | 保留手机迟疑与手绘粗糙性；一个共享变形规则/身份标记，现实接触和遮挡成立；局部互动光较弱，结果可读 | 一律磨成稳定电影CG；三秒堆完多次变形却没有完成态；末两秒塞满走位/变形/关灯 |
| 加入IMAX、UE5、Octane、工业光魔和东方奇幻质感 | 只选择真正有可见职责的媒介/合成方式，写具体材质、光源或空间结果；设备不是质量咒语 | 全套名词堆叠；称Octane为物理引擎；只有设备名和色温参数，没有可见目标 |
| 同房间先只开台灯，人物拉开窗帘后受光改变 | 基线锁台灯/窗位置，分镜先写开帘和入光，再写眯眼反应；局部光线变化按因果发生 | 人物先眯眼再出现强光；一边说台灯是唯一光源一边始终有强日光 |
| 香水瓶产品特写，用户明确要求突出玻璃和液体 | 在常驻成像基础上启用专项材质受光：玻璃边缘折射、液体层次和标签可读；只写承担材质职责的光 | 只写“高级棚拍、电影光”；玻璃死白、标签丢失；把主辅轮廓光术语整套列出 |

## C. 格式与编辑回归

| 用例输入 | 应有行为 | 失败信号 |
|---|---|---|
| 只把已有视频外套改为灰色，保留其他内容 | 局部编辑，继承原摄影机、光源、动作、声音与已有成像媒介；衣料受光随原环境适配 | 为颜色修改重写剧情、换灯、换摄影媒介或加配乐 |
| 6秒一个人把杯子放到桌上，固定机位，自然窗光 | 简单短段只保留必要规格、短总控、动作和完成态；常驻成像基线不等于强制七个标题 | 强制全房地图、人物编号、长摄影参数表或多段重复画质描述 |

维护检查同时确认：
- 写／重写 Prompt 即使没有“摄影/画质/灯光”关键词，也不会跳过 Capture Baseline；
- 常驻基线默认全局只写一次，逐镜只补明确风险，不形成摄影词套餐；
- 每个明确镜头仍有景别＋机位/观察方位＋短运镜；
- 用户明确媒介优先于默认干净成像；
- 声音原文只出现一次，时间安排连续但不承诺逐帧执行。
