# 光影与新格式行为用例

这些是维护时的提示词行为检查，不是已完成的视频对照实验。生成成功率与穿模改善需实际输出证据。

| 用例输入 | 应有行为 | 失败信号 |
|---|---|---|
| 15秒夜间客厅双人关系戏，有人从门口走到沙发；先不写具体品牌 | 概念开场；资产、人物情绪、固定空间、显式光影、自然句分镜；主光在世界中固定，人物先到达再发生接触 | 开场复述走位/剧情；灯随反打换边；远处角色的手直接进入近景 |
| 暗光手机POV追拍发光手绘光标，荒诞治愈，15秒 | 保留手机迟疑与手绘粗糙性；一个共享变形规则/身份标记，现实接触和遮挡成立；局部互动光较弱，结果可读 | 一律磨成稳定电影CG；三秒堆完多次变形却没有完成态；末两秒塞满走位/变形/关灯 |
| 加入IMAX、UE5、Octane、工业光魔和东方奇幻质感 | 选择真正需要的主媒介与合成职责，写具体美术/光源/材质；设备不是实际运行参数 | 全套名词堆叠；称Octane为物理引擎；只写色温/饱和百分比没有可见目标 |
| 6秒一个人把杯子放到桌上，固定机位，自然窗光 | 简单短段包含起点、路径、杯底落稳/松手、光线与必要声音 | 强制七个空标题、人物编号、全房地图 |
| 只把已有视频外套改为灰色，保留其他内容 | 局部编辑，继承原光源/动作/声音；衣料受光适配 | 为新格式重写剧情、换灯或加配乐 |
| 同房间先只开台灯，人物拉开窗帘后受光改变 | 基线锁台灯/窗位置，分镜先写开帘和入光，再写眯眼反应；局部变化不重复全片设备 | 人物先眯眼再出现强光；一边说灯是唯一光源一边始终有强日光 |

维护检查同时确认：声音原文只出现一次，整数时间安排连续但不承诺逐帧执行，用户媒介与事实优先。
