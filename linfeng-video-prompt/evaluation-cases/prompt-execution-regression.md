# 执行编译回归案例

维护依据：用户提供30秒宠物洗澡草稿，含结果评价、长音色、多处两三秒长对白、湿毛泡沫重置。以下是验收标准，不是已完成生成的记录。

## Original Failure：30秒宠物洗澡

输入：金毛幼犬，主人不露脸，英语吐槽转产品介绍；首帧已湿毛起泡；3秒抓眼、后段更快，音色明确、音乐配合；参考产品仅确认包装，未提供功效证明。末2秒包含三句15词对白并要求停住1秒。

验收：
- 不把抓眼/感染力/热门等放进最终标题和指令；开场直接出现具体事件。
- 两个说话者各一句声线且按要求实际发声，不能把主人的声线挪给幼犬；画面与动作占主体；不附镜头流和流程复述。
- 从已有湿泡状态继续，不重新打湿/首次上洗液；冲净后不重新起泡；浴巾后仍可微湿。
- 每镜与快切子镜都有短摄影信息；平均约1–3秒且不等分；相邻非特写跨景别、切镜换大于30°同侧方位；不是仅写全局口号，不把斜前/侧前当作不同方位，包含最后一切。
- 逐窗压缩台词，允许旁白跨镜；后半保留多个具体信息而非空泛一句好评；不编造皮肤功效；结尾台词说完留约1秒。

## Neighbor Case：18秒双人产品交接

输入：两位年轻女性在厨房把唯一一只耳机仓从A交给B；画面先于口播；流利英语；不要求固定镜头。

验收：身份区分、产品只一只、交接有接触和归属；每镜有景别/机位/短运镜，同侧角度与视线清楚；两人对白合计可读，不能各算满同一窗口；普通叙事允许多镜极慢前推，不强制每镜新运镜种类。

## Counterexample：8秒固定镜头

输入：固定中景一镜到底，女性窗边走到桌前放下杯子；无对白、无音乐。

验收：保持单镜/固定，完整动作接触与约1秒收束；不强加1–3秒切镜、机位变化、音色或BGM；简短输出。

## Boundary：可见完成态与固定文案

输入：杯底落桌、水冲掉泡沫等动作完成态，及用户要求逐字保留的台词“That feels amazing.”。

验收：不得误删可见状态或锁定对白；结果评价禁令作用于导演指令。引用的事实仍按真源检查。

## Boundary：密度不等于组内漏镜

输入：17–20秒内安排瓶身、泡沫、宠物、冲水四镜与35词旁白。

验收：组内逐镜有切点/景别/机位/运镜；语音判超载后精简或跨窗重排，不能只在每镜补“短推”便宣布修好。

## Boundary：明确慢片与声音专项

输入A：用户明确15秒长镜头产品观察，最后读标签。
验收A：遵守长镜，阅读停留不被切镜密度覆盖。
输入B：用户仅要求详细设计三个角色的声音母版。
验收B：声音成为主任务，可展开；不以“每人一句”阻止所求，不加无关画面分镜。


## Neighbor Case：大场景变化中的自然空间揭示

输入：人物从狭窄室内走向开阔户外，或从一个区域进入更大的新空间；场景本身存在门框、柱体、人物肩背、家具、植物等真实近景元素。

验收：逐镜先保证人物路径、观察方向与新空间连续；若真实近景能帮助揭示，摄影机运动应自然利用近远不同速度的视差或短暂遮挡，让遮挡边缘移开后出现新空间，并在人物与环境可读处收稳。最终只在对应分镜正文中用一小段动作—摄影语言表达，不另列“前景”“构图”“电影感”栏目；近景不得遮住关键表情、产品证据或文字。

## Counterexample：没有合理前景时不强加

输入：干净白底产品英雄镜、固定自拍口播、必须连续观察的关键操作，场景中没有自然近景层。

验收：仍执行空间层次判断，但允许结果为“不使用前景”；不得凭空加入树枝、黑色虚化块、路人肩膀等遮挡，也不得为了构图变化破坏产品可读性、口型或关键操作。强制的是判断与镜头—事件耦合，不是每镜必须出现前景。
