# 摄影机前置语序与景别/构图/运镜回归

本组测试确保时间轴先建立观众如何看见画面，再描述人物/产品动作；同时不牺牲空间连续性、动作因果和构图判断。

## 核心规则

- 每个实际镜头先写紧凑摄影短语，再写主体动作。
- 推荐语序：景别 → 构图关系（确实有效时）→ 机位/观察方位 → 运镜/固定机位 → 主体动作与变化。
- 构图可用黄金分割、三分法、中心对称等准确术语，也可写人物偏左、右侧留白、前景框景等可见空间关系；不得机械要求每镜都出现构图术语。
- 运镜与事件有因果。人物抬头时镜头上摇、人物移动时镜头跟拍；不能让镜头无因运动，也不能因把镜头短语前置而让镜头动作看起来先于触发事件。
- 后台推演顺序不变：先锁人物/道具完成态、运动路径、空间轴侧和真实摄影机观察位置，再把摄影短语前置到最终文字。
- 一个时间段含多个子镜时，每个子镜分别具备时间、摄影机短语和动作，不可只在段首写一组通用运镜。

## Case 01｜人物反应镜头

**输入**：男主听见门外异响，突然露出惊讶表情。

**合格写法**：

```text
【0–2秒】中景，黄金分割构图，平视机位，镜头缓慢前推。男主角露出惊讶的表情，嘴角快速抽动，视线从画面左侧转向门口。
```

**失败写法**：

```text
【0–2秒】男主角露出惊讶的表情，嘴角快速抽动。镜头采用中景和黄金分割构图，缓慢向前推进。
```

失败原因：摄影机信息滞后，主体动作与取景方式被拆成两次指令。

## Case 02｜构图不应机械套用

**输入**：人物站在空旷走廊中央，右侧门口是叙事重点。

**合格写法**：

```text
【2–4秒】中远景，人物位于画面左侧，右侧门口保留负空间，平视机位，镜头轻微横移。人物停下脚步，转头看向门口。
```

**失败信号**：无论人物、产品或场景都强行标注“黄金分割构图”，但画面主体关系并不符合或没有因此受益。

## Case 03｜运镜由动作触发

**输入**：人物从低头状态抬头看向高处。

**合格写法**：

```text
【4–6秒】近景，略低机位，人物抬头时镜头同步缓慢上摇。人物视线从地面移向高处，眉头逐渐收紧。
```

**失败信号**：镜头先无因上摇，人物随后才抬头；或只写“镜头运动自然”，没有具体方向和触发关系。

## Case 04｜多子镜快切

**输入**：同一时间组包含产品瓶身、液体滴落、人物使用三个子镜。

**通过标准**：三个子镜分别写明景别、必要构图/机位、运镜或固定机位，再写各自的动作；不得只在时间组开头给一条通用摄影指令。

## Case 05｜空间连续性优先于漂亮构图

**输入**：人物从门口向室内桌边走，镜头需要从中景切到桌边近景。

**通过标准**：后台先锁人物路径、门口/桌边相对位置、相机轴侧和到达状态；确认真实观察位置后，最终文字才将景别/构图/机位/运镜短语放在动作之前。不能为了黄金分割或前景遮挡让人物瞬移或改变运动方向。

## 总体验收

- 摄影机短语是否在主体动作之前？
- 景别是否明确？
- 构图是否确实服务主体层级/空间/动线，而非机械标签？
- 机位/观察方位与运镜是否明确且可执行？
- 运镜是否与事件因果一致？
- 后台空间接力与动作路径是否先于摄影机选择？
- 多子镜是否逐一写出自己的摄影短语？
