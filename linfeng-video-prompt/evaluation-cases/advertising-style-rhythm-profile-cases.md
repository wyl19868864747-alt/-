# 广告类型、整体调性、色彩、光影、BGM与全片节奏回归

本组用例检查商业视频是否建立清晰的广告定位，并把整体调性、色彩风格、光影氛围、BGM/音频氛围和全片视频节奏特征分工输出，而不是把视听规则含糊塞进一条形容词句。它们是提示词行为测试，不代表视频生成成功率或成片质量已实测。

## 通用通过标准

- 广告任务明确写出具体 Ad Type；不能只写“TVC / Commercial”。
- Script Type（若有）说明表达机制，不与广告类型重复。
- 【整体调性】有明确审美身份、情绪姿态或核心张力，并由具体空间、表演和媒介观感支撑；不能只堆形容词。
- 【色彩风格】明确主辅色、冷暖和饱和度/对比度层级，保护真实肤色与产品固有色。
- 【光影氛围】明确可信光源、方向、软硬和阴影层次；不因单独成栏而堆砌灯具术语。
- 【BGM/音频氛围】明确音乐有无、音乐类型、节拍/音色、口播与环境声关系；指定静音/无配乐时不得臆造音乐。
- 视频节奏特征用1–2句描述全片情绪/能量曲线、主要转折、峰值/停留/释放/收束；不得写成逐镜时间表或分镜摘要。
- 全片节奏特征先于分镜，随后由Beat功能和逐镜动作兑现；不得把“快节奏”误解为全程快切，也不得把“慢奢华”误解为全程慢推。
- 既有空间连续性、摄影机/景别/运镜、材质真实感、事实边界与模型容量规则仍然生效。
- 用户提供品牌/设计师风格参考时，提取可见视觉DNA，不擅自复制未提供的Logo、包装、商标或具体创意资产。

## Case 01｜深邃元素奢华香氛

**输入**：15秒男士香氛广告，深蓝玻璃瓶、黑色石材、海浪、午夜烟雾、男性模特直视镜头；音乐由低频鼓点与失真电吉他组成，最后突然抽空。

**必须识别**
- Ad Type：高端男士香氛品牌TVC / 香氛产品美学广告。
- Script Type：电影感产品美学 / 感官男性气质。
- 风格DNA：冷峻、神秘、原始元素与精密奢华的张力；空间/材质/灯光/声音要共同支撑。
- 全片节奏：低频悬置 → 香雾与元素逐步加压 → 人物凝视形成情绪峰值 → 音乐抽空 → 产品英雄镜静止收束。

**失败信号**：只写“Dior风、高级、神秘、电影感”；把“节奏强”写成每镜都快速移动；节奏特征重复Scene 01–05的逐镜内容。

## Case 02｜高能美妆产品广告

**输入**：15秒珠光腮红广告，金色包装、玫瑰粉粉体、化妆刷扫粉、模特上妆、四色试色，Deep House与小提琴节拍。

**必须识别**
- Ad Type：高端彩妆产品美学TVC。
- Script Type：产品质地展示 / 快节奏美妆广告。
- 风格DNA：明亮现代的奢华感，以金属金、玫瑰粉、珠光反射和快速微距运动建立感官识别。
- 全片节奏：清脆动作开场 → 粉体与珠光细节加密 → 刷扫/上妆形成声画爆发 → 模特妆效短暂停留 → 色号与品牌收束。

**失败信号**：只说“快、酷、闪”；没有节奏转折；把每个切镜都设成相同速度；在节奏总述中复述七个镜头的动作。

## Case 03｜复古俏皮时尚美妆广告

**输入**：15秒复古酒店房间中的唇釉广告，奶油色真丝、古董蕾丝、琥珀玻璃、模特短促眨眼和随性动作；法式独立流行乐与相机快门声。

**必须识别**
- Ad Type：复古时尚美妆社媒广告。
- Script Type：产品美学 / 生活方式片段。
- 风格DNA：复古奢华、俏皮叛逆、柔和却锋利；以真丝、蕾丝、琥珀玻璃、暖窗光和低保真胶片质感落地。
- 全片节奏：朦胧慢速细节建立 → 俏皮跳切打断 → 人物目光与唇部质地形成停顿 → 相机快门带动短促加速 → 产品落版。

**失败信号**：机械套用高能爆发；把每个镜头写成慢动作；只写“法式、Miu Miu风、时尚”。

## Case 04｜极简无重感底妆广告

**输入**：15秒单色裸肤底妆广告，暖沙色建筑摄影棚、磨砂粉底瓶、真实肌肤纹理、柔和顶光与低频电子音乐。

**必须识别**
- Ad Type：高端底妆产品美学 / 肤质证明TVC。
- Script Type：产品质感展示 / 极简生活方式。
- 风格DNA：纯净、单色、现代奢华、原始但精致；通过暖沙色、燕麦奶油色、磨砂瓶身、肌肤微纹理与柔和均匀光线建立。
- 全片节奏：安静的身体/肌肤细节开场 → 产品几何与膏体质感交替 → 模特稳定目光成为情绪落点 → 产品雕塑式静止收束。
- 不把“柔焦”解释为抹除真实毛孔；保留用户指定的真实肌肤纹理。

**失败信号**：套用强烈故障快切；把真实毛孔磨掉；整体只剩“干净高级”。

## Case 05｜赛博复古睫毛膏广告

**输入**：30秒Y2K赛博银色睫毛膏广告，液态银、婴儿蓝皮革、低保真摄像机扫描线、15fps/120fps切换、Breakbeat与Glitch Techno。

**必须识别**
- Ad Type：高端赛博美妆产品广告 / 彩妆视觉Campaign。
- Script Type：产品美学 / 视觉故障叙事。
- 风格DNA：复古未来主义、叛逆、高时装感；液态铬银、粉蓝软材质、黑色阴影、扫描线、闪光灯与不规则帧率切换构成统一视觉语法。
- 全片节奏：低保真闪烁开场 → 产品机械细节逐步加密 → 刷头/睫毛效果形成高能峰值 → 画面短暂静止确认效果 → 故障式品牌收束。
- 帧率切换必须服务信息与质感变化，不随机闪烁。

**失败信号**：所有镜头变成普通稳定器慢推；只写“赛博、未来、高级”；故障效果无节奏和信息职责。

## Case 06｜自然草本护肤广告

**输入**：15秒草本精华广告，明亮极简居家空间、清晨窗光、草本叶片、透明精华液、真实肤质、柔和钢琴与自然环境声。

**必须识别**
- Ad Type：高端天然护肤品产品美学TVC。
- Script Type：自然成分与产品质地展示 / 日常护肤仪式。
- 风格DNA：植物系、清新、真实、舒缓；以浅绿色玻璃、草本叶片、水滴、亚麻布、自然窗光与真实肌肤纹理支撑。
- 全片节奏：清晨空间安静建立 → 液体/滴管微距加深触感 → 上脸与吸收过程带来轻微推进 → 人物自然放松 → 产品安静收束。

**失败信号**：强行加入爆炸式转场或高频快切；皮肤变成塑料质感；节奏总述只是把12镜头重新念一遍。

## Case 07｜快节奏与慢奢华的区分

**输入**：同样是15秒高端产品广告，A为金属彩妆，B为极简香氛，要求分别给出风格与节奏总控。

**必须识别**
- A可采用高密度微距、鼓点命中、快速跳切与短暂停留；B可采用克制镜头、较长观看时间、低频蓄力与静止英雄镜。
- 两者都必须有清晰的节奏转折，但转折形式不必相同。
- 镜头平均时长和切点仍按 director-information-control.md 的默认约定及用户明确要求执行。

**失败信号**：所有15秒广告统一“0–3秒Hook、3–9秒快切、9–12秒情绪、12–15秒Packshot”；把所有高端广告都处理成慢镜头。

## Case 08｜15秒西装生活方式UGC：四项视听总控独立可执行

**输入**：15秒、9:16、男性西装出门Vlog；卧室镜前整理→城市街道步行→咖啡馆门前收尾；自然口语旁白，低调indie / lo-fi音乐，衣料声、脚步声与城市环境声。

**必须识别**
- Ad Type：男士西装生活方式UGC广告；Script Type：生活方式融合/人物微叙事。
- 整体调性：松弛自信、轻微电影质感，但保持原生生活记录和不刻意表演的气质。
- 色彩风格：低饱和中性色为底，深黑/海军蓝西装、自然肤色和少量暖色城市高光。
- 光影氛围：室内柔和晨光与户外方向明确的暖色日光，面料随动作有真实受光起伏；若是连续叙事，应避免晨光直接跳成日落造成时间逻辑错误。
- BGM/音频氛围：低调indie/lo-fi稳定律动，口播时自动压低，衣料、脚步与街道声音保持可辨；只在镜头里追加确实触发的声音变化。
- 视频节奏特征：镜前轻松建立→街头步行推动自信→短暂停下确认状态→西装细节与轻微微笑收束，不强塞突兀高潮。

**失败信号**：只写“生活方式电影感”，不单列色彩/光/音乐；把四项重复进每个镜头；晨光与黄金时刻同日连续空间无解释；UGC被过度电影棚拍化。

## Case 09｜指定无配乐/无声时的栏位语义

**输入**：A为安静的产品演示，仅现场触碰与机械声，明确不要BGM；B为完全无声的品牌视觉短片。

**必须识别**
- A的【BGM/音频氛围】写“无BGM，以动作声和环境声组成节拍”，镜头只写关键Foley；不擅加lo-fi或鼓点。
- B的【BGM/音频氛围】写“无配乐、无环境声、无音效和人声”，不以“完整度”为由添加音频。
- A、B仍要保留独立的整体调性、色彩风格、光影氛围和视频节奏特征，且不互相重复。

**失败信号**：机械填充音乐流派，或将“无配乐”误读为“完全静音”。

**通过标准**：广告类型、调性、色彩、光影、BGM/音频身份和视频节奏特征彼此匹配，并且保留原有导演信息控制、空间连续性、镜头运动和模型执行约束。
