# 逐镜空间状态编译回归

本文件是测试输入与验收标准，不是已生成视频记录。维护时用同一原始任务分别试写旧版/新版，保存实际输出与失败镜对；不把验收答案附进试写请求。文字与结构通过不代表Seedance成片已验证。

## Original Failure：幼犬夜间救黄鸭

原问题：先写“幼犬跑向机器人，侧面跟拍”，在Prompt末尾另写机器人/幼犬/玩具的位置。后续镜头虽有运镜和连续性口号，实际位置、朝向、持物与观察方向没有一起参与决策。

原始任务：30秒、无对白，幼犬夜间从卧室发现客厅机器人拖着黄鸭，折返带起红毯，再追机器人救回黄鸭，最终被机器人从身后轻碰。按以下十个事件检查；这是事件序列，不是必须压成十个镜头，多步骤可拆镜：

| 事件 | 输入/动作 | 必须传出的状态及后镜要求 |
|---|---|---|
| 1 | 幼犬从卧室门后探头；客厅远处机器人拖着黄鸭 | 幼犬仍在门口、朝客厅看；卧室—走廊—客厅路径成立，黄鸭卡在机器人前缘 |
| 2 | 幼犬从门口进入走廊 | 从门口开始移动，停点在走廊；不能直接在客厅 |
| 3 | 幼犬折返床边，后腿带起红毯 | 有回头/转身和返回卧室的路径；毯边被带起、滑搭到背部的过程成立 |
| 4 | 从卧室方向穿过走廊进入客厅 | 继承歪挂的同一块红毯；不是完整披风，不重建另一套房间 |
| 5 | 机器人位于沙发右侧，黄鸭卡在前缘 | 继承机器人既定方向/路径；时间推进不能无因让机器人重置到旧起点 |
| 6 | 幼犬从机器人左后方接近 | 左后方的参照系明确；若前缘不在可咬距离，必须沿侧面追近或绕到前方 |
| 7 | 幼犬咬住黄鸭 | 狗嘴—黄鸭—机器人前缘连接同时成立，不能先松脱再拔河；证明镜能看到三者 |
| 8 | 幼犬后退，把黄鸭拉脱 | 从咬住状态继续，方向/受力可解释；脱离后黄鸭仍在狗嘴，机器人不再牵引它 |
| 9 | 黄鸭来到幼犬脚边，机器人沿原方向经过 | 有低头落地与松嘴；未见放下不能判持有权通过，狗和鸭不能与机器人互换位置 |
| 10 | 机器人从幼犬身后重新靠近并轻碰 | 从已经经过的位置通过可见转弯/绕行到身后，再接近/接触；不能反向瞬移，仍继承黄鸭脚边与红毯歪挂 |

后台为每镜记录人物/目标、朝向、道具归属/接触、相机首末位/轴侧和完成态，逐对运行 `references/independent-judge.md` 的A–J。摄影机角差以同一世界锚点计算，不能把“侧前/斜前”当两个不同机位。角色相对左右与房间左右分别明确，不强迫狗在机器人后方隔着机身咬到前缘。

验收：
- 最终动作、关键关系、观察方向写在同一分镜内；不输出独立空间锁/End-State标签/房间图。
- 全部相关状态延续；插入特写、空镜、反应镜时，画外对象只沿已有过程推进，不能无故重置、变装、掉落或回到身后。
- 保留默认约1–3秒平均切镜、非特写相隔景别、同侧真实换位大于30°、每镜短运镜、动静组接与结尾收束；不因空间描述挤爆动作容量。
- 可见路径超出当前景别就改机位/景别或拆镜，不让近景凭空证明整个房间绕行。

## Mutation Tests：失败必须回写镜头

从任一可用正例一次只注入一个错误；要求指出失败镜对与A–J项目，重写最早相关镜头并传递新完成态。尾部添加禁令即判修复失败。

1. 把进走廊改成“已站客厅”：A/I/J失败。
2. 保持人物位置却反转面向且不转身：B/J失败。
3. 把原方向追逐改为反向追逐，无转弯：C/J失败。
4. 把嘴里黄鸭直接改成脚边黄鸭，无放下：D/I/J失败。
5. 同一机位让沙发/门无因换边：E失败；真实机位改变引起的投影变化不误判。
6. 把新机位改成原位置裁切、或只写“斜前→侧前”：F失败/无法判定；改拍另一目标也不算换位。
7. 把同侧观察改到轴线另一侧，无可读重建：G失败。
8. 用仅见狗脸的紧特写声称证明三者连接，或用遮挡机位声称看见咬合：H失败。
9. 反应镜后将歪挂红毯改成整齐披风：D/I/J失败。
10. 删除机器人经过后到身后的绕行：A/C/I/J失败。

## Neighbor Case：唯一耳机仓的双人交接

输入：18秒厨房对话，A把唯一耳机仓交给B，B接过后转身放桌面；正常多镜，英语对白。

验收：逐镜继承双方位置/视线、同一只手与唯一耳机仓；接稳再松手，转身后再走/放，台面接触后释放；不把相机换位当演员换位。每位声线一句、两人对白合并核容量、BGM简短；普通极慢前推可复用，不需要每镜新花样。前台不重复人物小传/空间管理块。

## Counterexample：固定单镜

输入：8秒固定正面中景，一名女性从门口走到桌前，右手放杯；无对白、无音乐。

验收：保留起点、路径、接触、松手与收束；不引入第二镜、角差强制、C1编号或空间图。F不适用，位置/接触因果仍成立。

## Minimum Signal：没有位移的短镜

输入：幼犬仍坐在浴缸中央，主人双手停在它肩侧，正面偏右中近景极慢前推。

验收：一句即可；不扩写门窗/机器人/卧室，不输出六问或状态标签。若用作前片后镜，仍须从真实上一完成态继承，不能借例句覆盖既有事实。
