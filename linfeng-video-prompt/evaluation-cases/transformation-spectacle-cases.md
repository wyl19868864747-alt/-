# 视觉蜕变奇观｜回归案例

用于验证 `transformation-spectacle` 是否在需要时被主动激发、在不合适片型中被克制跳过，并与 `grounded-surreal`、`golden-3s-hook`、连续性和商业证据正确叠加。

## Case 1｜正向：产品形成过程本身成为看点

**输入**：高概念鞋类广告。开场只看到脚即将踩上一种陌生但漂亮的材质，希望有新奇、唯美、令人好奇的视觉体验，最后自然展示鞋。

**应命中**：`transformation-spectacle`；若保持真人/实景底盘，同时命中 `grounded-surreal`；若首秒承担留存，同时命中 `golden-3s-hook`。

**预期行为**：
- 不把鞋直接弹出或硬切出来；
- 先用脚踩下的现实动作建立未完成状态；
- 从脚与材质的接触点开始变化，沿脚部可见传播；
- 中间形态连续可观察，最终收束成鞋；
- 变化本身承担视觉奖励，摄影机不过度炫技；
- 产品结构与人体接触保持合理。

## Case 2｜混合：AI 模型能力展示

**输入**：15秒模型能力广告。普通绿幕摄影棚中，演员被真实摄影机拍摄；镜头持续前推到摄影机屏幕，随后从屏幕里的电影级画面过渡到真实世界，展示模型把普通素材重构为电影广告的能力。

**应命中**：`transformation-spectacle` + `grounded-surreal` + `golden-3s-hook` + 摄影/连续性模块。

**预期行为**：
- 先建立摄影、演员动作与屏幕内容的真实因果；
- 变化优先从摄影机屏幕或明确边界开始，而不是全画面无因换景；
- 屏幕内部的光影/材质/环境变化沿边界向现实传播，或通过镜头穿越完成空间接管；
- A→B 的过程展示“模型如何把普通素材变成电影世界”，不是普通前后对比；
- 变化过程中不让人物、门体、摄影机或实体发生穿模与无因位移；
- 最终回收模型能力与完成画面。

## Case 3｜反例：真实 UGC 口播

**输入**：一位美国女性在厨房用手机前置镜头自然讲述一款日常护肤品，要求像真实用户分享，不像广告。

**不应命中**：默认不启用 `transformation-spectacle`。

**预期行为**：
- 保持手机自拍视频、真实产品尺度、自然使用动作与同步环境声；
- 不因为用户说“画面好看一点”就加入花瓣生长、产品结晶、空间重构或超现实变形；
- 只有用户明确将创意方向改为超现实/高概念视觉广告时才重新评估。

## Case 4｜反重复：多次蜕变必须升级

**输入**：一条30秒品牌视觉片需要连续展示三次不同的产品/环境变化。

**应命中**：`transformation-spectacle`。

**预期行为**：
- 第一次建立变化规则；
- 第二次改变传播机制、尺度或主体/环境关系，不只是换材质；
- 第三次允许打破已建立预期，并向Hero或品牌记忆收束；
- 保留至少一个构图、动作、运动方向或接触点作为稳定锚点；
- 禁止三段都使用“接触→粒子包裹→产品出现”的换皮重复。
