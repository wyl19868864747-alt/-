# 跨模块并行路由评测

仅在维护本技能时使用。每个案例先检查模块覆盖单，再判断是否把主方向误当成唯一分支。

## Case 01：剧情式香水TVC

**输入**：15秒香水广告，一对恋人因气味想起初次见面，有两句精确对白，结尾产品英雄镜。

**必须加载**：商业合同、商品预检、消费者决策、导演信息、连续性、人物选角/香氛、美妆、声音、摄影画质与输出合同。

**失败信号**：因判为商业而删除人物知情差、反应和关系变化；或因剧情很强而忘记香水事实、产品证据与Hero。

## Case 02：产品只是短剧道具

**输入**：两人争执时桌上有一台咖啡机，它只用于触发一次误会，不承担品牌传播。

**必须保留**：咖啡机数量、尺度、站位、使用和连续性事实。

**不得误触发**：消费者转化、卖点堆叠、CTA和强制Hero。

## Case 03：食品UGC＋多手＋旁白

**输入**：三位朋友露营分享自热意面，多双手递接包装，有一条精确画外音。

**必须加载**：商业、商品预检、UGC、食品风味、群像、连续性、声音、摄影画质与输出合同。

**失败信号**：只加载UGC；手部归属错乱；用夸张表情代替口味证据；VO重复。

## Case 04：四人美妆社媒广告

**输入**：四位不同造型人物逐一使用同一高光产品后集结，要求年轻当代、彩色夜间氛围。

**必须加载**：商业、商品预检、美妆选角、高风格化社媒、群像、连续性、声音/摄影画质和输出合同。

**失败信号**：人物复制或无因闪现；产品在不同手中变形；彩光污染肤色和包装本色；效果泄漏。

## Case 05：25秒品牌短剧

**输入**：25秒三场景品牌短剧，产品只在结尾作为关系变化的结果出现。

**必须加载**：商业或剧情主轴依最终验收判断，同时加载导演信息、长时节奏、连续性、商品事实、声音和画质；结尾元素必须有前文铺垫。

**失败信号**：以“短剧”排除商品事实，或以“品牌”压扁人物关系；用重复镜头填满25秒。

## Case 06：画质返修不重做创意

**输入**：剧情TVC内容、表演和产品都正确，只有下载后720p低码率暗部压缩块。

**必须加载**：公共治理、画质诊断、输出合同；保留商业和剧情成功层。

**失败信号**：只因为主轴是商业/剧情而跳过交付层诊断；重写创意或堆叠8K词。

## Case 07：新规则归位

**输入**：用户要求新增“所有近景递接都必须看见释放与承重”。

**必须判断**：该规则跨商业、剧情、食品、群像，且遗漏会造成物理失败；在公共层保留最低基线，详细规则归入连续性/群像模块，并增加混合任务与反例。

**失败信号**：只写进UGC或群像文件，使双人剧情和产品TVC无法调用。

## Case 08：无参考素材与未知尺寸

**输入**：为一条香水剧情TVC写提示词；用户没有上传商品图，也没有提供香水瓶尺寸。

**必须处理**：只用“掌心可稳定持握”等有依据的相对比例描述临时产品身份，或在品牌外观必须精确时提示补充商品图；不得写“图片1/参考图1”，不得自行发明厘米数、标签版式、液位或品牌结构。

**失败信号**：引用不存在的素材编号；把常见商品尺寸写成当前产品事实；声称严格继承并不存在的参考图。

## 总通过标准

- 所有触发条件逐项并行检查；
- 主轴只改变验收和带宽，不屏蔽适用能力；
- 专项知识不过度误触发；
- 跨域高风险规则在公共层有最低基线；
- 输出仍精炼，不把内部模块清单外显。
