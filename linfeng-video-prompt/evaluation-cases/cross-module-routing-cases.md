# 跨模块并行路由评测

仅在维护本技能时使用。每个案例先检查模块覆盖单，再判断是否把主方向误当成唯一分支。

## Case 01：剧情式香水TVC

**输入**：15秒香水广告，一对恋人因气味想起初次见面，有两句精确对白，结尾产品英雄镜。

**必须加载**：商业合同、商品预检、消费者决策、导演信息、连续性、人物选角/香氛、美妆、声音、摄影画质与输出合同。

**失败信号**：因判为商业而删除人物知情差、反应和关系变化；或因剧情很强而忘记香水事实、产品证据与Hero。

## Case 02：产品只是短剧道具

**输入**：两人争执时桌上有一台咖啡机，它只用于触发一次误会，不承担品牌传播。

**必须保留**：咖啡机数量、尺度、站位、使用和连续性事实。

**不得误触发**：消费者转化、卖点堆叠、CTA和强制Hero。

## Case 03：食品UGC＋多手＋旁白

**输入**：三位朋友露营分享自热意面，多双手递接包装，有一条精确画外音。

**必须加载**：商业、商品预检、UGC、食品风味、群像、连续性、声音、摄影画质与输出合同。

**失败信号**：只加载UGC；手部归属错乱；用夸张表情代替口味证据；VO重复。

## Case 04：四人美妆社媒广告

**输入**：四位不同造型人物逐一使用同一高光产品后集结，要求年轻当代、彩色夜间氛围。

**必须加载**：商业、商品预检、美妆选角、高风格化社媒、群像、连续性、声音/摄影画质和输出合同。

**失败信号**：人物复制或无因闪现；产品在不同手中变形；彩光污染肤色和包装本色；效果泄漏。

## Case 05：25秒品牌短剧

**输入**：25秒三场景品牌短剧，产品只在结尾作为关系变化的结果出现。

**必须加载**：商业或剧情主轴依最终验收判断，同时加载导演信息、长时节奏、连续性、商品事实、声音和画质；结尾元素必须有前文铺垫。

**失败信号**：以“短剧”排除商品事实，或以“品牌”压扁人物关系；用重复镜头填满25秒。

## Case 06：画质返修不重做创意

**输入**：剧情TVC内容、表演和产品都正确，只有下载后720p低码率暗部压缩块。

**必须加载**：公共治理、画质诊断、输出合同；保留商业和剧情成功层。

**失败信号**：只因为主轴是商业/剧情而跳过交付层诊断；重写创意或堆叠8K词。

## Case 07：新规则归位

**输入**：用户要求新增“所有近景递接都必须看见释放与承重”。

**必须判断**：该规则跨商业、剧情、食品、群像，且遗漏会造成物理失败；在公共层保留最低基线，详细规则归入连续性/群像模块，并增加混合任务与反例。

**失败信号**：只写进UGC或群像文件，使双人剧情和产品TVC无法调用。

## Case 08：无参考素材与未知尺寸

**输入**：为一条香水剧情TVC写提示词；用户没有上传商品图，也没有提供香水瓶尺寸。

**必须处理**：只用“掌心可稳定持握”等有依据的相对比例描述临时产品身份，或在品牌外观必须精确时提示补充商品图；不得写“图片1/参考图1”，不得自行发明厘米数、标签版式、液位或品牌结构。

**失败信号**：引用不存在的素材编号；把常见商品尺寸写成当前产品事实；声称严格继承并不存在的参考图。

## Case 09：汽车TVC中的连续上车

**输入**：15秒汽车广告，年轻模特走向驾驶位、开门上车、关门后驶离；要求在开门全景、手部特写、脚步特写和关门中景之间切换。

**必须加载**：商业合同、商品预检、导演信息、复杂运镜、连续性、摄影画质与输出合同；把车门视为大型接触道具，按动作完成态切换景别。

**通过标准**：先看见人物接近和操作把手，再看见门体受力打开；脚、腿、骨盆和身体重心依次跨过门槛并落座，另一只脚收进后才从车内施力关门；相邻镜头继承同一手、同一脚、门体角度和身体朝向。

**失败信号**：车门无外力自行打开；人物穿过车门或车身；遮挡转场直接把站在车外的人变成已坐在车内；不同景别重复开门或改变门体开合状态。

## Case 10：没有上下车动作时不误触发

**输入**：汽车在高速公路行驶，驾驶员从开场到结尾始终坐在车内，车门保持关闭。

**不得误触发**：不为展示完整性擅自增加开门、关门、上车、下车或脚步特写；只锁定驾驶员、车门关闭状态、车辆方向与行驶连续性。

## Case 11：AI视觉平台的纯停留型悬念 Hook

**输入**：为AI商业视觉生成平台制作短视频广告，传播目标优先获取首屏停留。开场先展示一段人物陷入未完成危险事件的高冲击成片，随后揭示它是平台生成结果。

**必须加载**：黄金3秒、`attention-first-hook`、写实超现实、商业合同、摄影画质、导演信息与输出合同；为首屏建立主环境色、轮廓锚点、唯一强调色和肤色/产品色保护。

**通过标准**：危险事件从中途进入并逐拍升级；反转后的1–2个有效节拍内沿同一结果画面、颜色、品牌物件或声音后拉到生成界面；开场承担成片能力证明，不虚构平台功能。

**失败信号**：因产品未在首帧出现而自动删除强 Hook；或只有尖叫、追逐和快切，没有具体问题、升级或结果回收。

## Case 12：消费品广告中的弱关联 Hook 与产品接力

**输入**：时尚消费品广告要求先用身份误判或未完成追逐抓停留，随后进入商品展示与品牌世界。

**必须处理**：商业轴仍以产品记忆验收；允许开场弱显性关联，但必须由人物动作、商品入手、服装强调色、形状或同步声音完成 Bridge，商品事实、比例、材质和Hero保持正确。

**失败信号**：把注意力型 Hook 当成免除产品证据的理由；反转后硬切白底商品；色彩与声音全部重置造成审美断层。

## Case 13：高风险品类不误用纯停留危险 Hook

**输入**：医药价格广告要求开场用与服务无关的鲨鱼袭击吸引观看，随后直接切到价格和资格问答。

**不得启用**：不使用 `attention-first-hook` 为医疗服务制造无关危险联想，不把视觉奇观当成功效、价格或安全证明。

**正确处理**：从真实价格摩擦、账单误会、资格未知或人物关系中的未完成事件建立合规 Hook；保留强停留结构，但让事实、情绪和产品因果同源。

## 总通过标准

- 所有触发条件逐项并行检查；
- 主轴只改变验收和带宽，不屏蔽适用能力；
- 专项知识不过度误触发；
- 跨域高风险规则在公共层有最低基线；
- 输出仍精炼，不把内部模块清单外显。
# 黄金3秒与构图叙事回归案例

## 正向：短视频广告首屏

输入：为一款真实商品设计15秒UGC广告，要求首3秒强Hook并能自然进入产品证明。

验收：同时加载黄金3秒、UGC、商业合同、商品预检与构图叙事；Hook形成具体观众问题并由产品证据回收，构图保持原生拍摄可信度。

## 混合：剧情式商业片

输入：两位朋友在客厅对话，通过一张异常长账单引出服务价格，要求轻喜剧、分镜和英文台词。

验收：黄金3秒以“账单为何这么长”建立问题，构图用引导线和双人关系形成弧线；商业事实、人物反应、连续性和英文后中文括注同时保留。

## 反例：用户指定慢开场的诗性品牌片

输入：30秒诗性品牌片，用户明确要求前8秒缓慢建立环境，不做悬念或强Hook。

验收：不强制黄金3秒预测偏差；构图叙事仍可按环境、主体和情绪服务画面，但不得添加无关异常或快速剪辑。
