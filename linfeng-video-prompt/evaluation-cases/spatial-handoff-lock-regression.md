# Spatial Handoff Lock 回归测试

目的：验证林枫视频提示词 Skill 在多镜、跨区域、往返和多人一动一静时，不会因为切近景／反打而重置世界位置。文字通过不代表模型成片必然通过；成片仍需实际复核。

## Case A｜A 去远端再沿原路返回，B 留近端

输入：
- 一条南北走向的通道，目标在北端，A 与 B 初始都在南端；
- A 独自去北端目标，B 原地等待；
- A 触发事件后沿原路返回；
- A 返回 B 身边后，两人才进入新的双人近景。

必须出现的后台决策：
1. 固定世界锚点：南端／北端目标／路径。
2. 运动所有权：去程与返回段只有 A 移动；B 原地。
3. Observation Corridor：摄影机主要位于南端朝北。A 去程逐渐变小，返回逐渐变大。
4. Arrival Anchor：A 到北端后的近景仍保留北端目标、门柱、台阶或同向光源中的至少一个。
5. A 真正回到南端后才允许与 B 重新同框。

失败：
- A 到北端后切近景又出现南端背景；
- A 移动时 B 被无因带到目标旁；
- 返回段通过反打把南北方向翻转；
- 只写“保持连续／位置不变”而没有实体锚点或路线。

## Case B｜房间跨区

输入：人物从客厅沙发旁走到玄关门口，另一人留沙发边。

验收：
- 客厅、通道、玄关为固定世界拓扑；
- 只有移动人物走过通道；
- 到门口后的中近景保留门框／门锁／玄关侧主光中的一个；
- 沙发边角色未被无动作召唤到门口；
- 若人物返回，优先从同一观察轴拍实际靠近，而不是直接切回沙发旁特写。

## Case C｜楼梯／红毯

输入：主角从红毯走到楼梯并上两级，配角留在红毯另一侧。

验收：
- 红毯→台阶前→第一级→第二级为真实动作链；
- 上台阶后近景保留台阶边缘／扶手／门柱作为 Arrival Anchor；
- 配角继续留原地，除非有自己的移动镜；
- 新机位只改变屏幕投影，不改变双方世界位置。

## Counterexample｜简单单镜

输入：8秒固定中景，一人从门口走到桌前放杯。

验收：Spatial Handoff Lock 快速通过即可；写清起点、路径、杯底落桌、松手，不建立固定观察走廊表格，不增加空间管理段。

## Prompt 最小信号验收

最终模型 Prompt 不输出后台账本。只在高风险处保留一句最小信号，例如：

“A 独自沿左侧走廊向门口走；B 仍留沙发旁，不入镜。”
“门口中近景，A 仍站刚到达的门框旁，暖光从同一门内侧照来。”
“摄影机仍在客厅一端朝玄关；A 沿原路返回，B 保持右前景原位。”

如果需要在 Prompt 尾部附“不要瞬移、保持站位、保持空间一致”才能理解，则判为前面逐镜编译失败。

## 通过标准

逐对运行 independent-judge.md 的 A–L：
- A–J 原空间／物理状态通过；
- K 运动所有权通过；
- L 观察走廊与到达锚点通过；
- 不牺牲镜头节奏、动作容量和最终约1秒收束；
- 没有实际视频生成时只记录“文本回归通过，成片未验证”。
