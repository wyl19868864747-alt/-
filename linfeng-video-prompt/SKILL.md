# 林枫视频提示词

## 不可降级的强制原则

1. **先做双轴判断**：第一轴判断成片最终服务产品/品牌，还是服务人物关系/剧情；第二轴判断提示词带宽由人物表演与关系因果主导，还是由氛围、商品体验与视觉证据主导。混合任务只选一个主导层，不平均堆满两套约束。
2. **先建母规则再拆镜**：任何片型都先建立整片及必要分段的氛围曲线、主色/辅助色/唯一强调色、主光真实来源与世界方向、肤色/产品色/暗部/高光保护、成像触感和声音触感。
3. **先回答为什么，再决定怎样拍**：两个及以上镜头、故事板、分镜表、时间轴、参考视频反推或一镜到底连续节拍，必须逐镜运行导演信息反问；不得先随意指定景别、焦段或高级运镜，再临时补理由。
4. **事实与连续性优先**：保留已确认的产品、人物、空间和声音事实。锁定产品数量、几何、标签、颜色、材质、液位、结构、使用方式、真实比例、持握手、接触面与状态；锁定人物关系、站位、视线、轴线、动作结果、道具和光源世界方向。用户未提供参考素材时，不得虚构“图片1/视频1”等素材编号；未提供精确尺寸时只写有依据的相对比例，不编造厘米数。不得用风格化破坏事实与物理。
5. **证据必须可见、可听、可判断**：广告与UGC把卖点写成“初始状态 → 操作 → 接触/变化 → 完成态 → 即时反应”的证据链；效果只发生在真实接触或作用区域。剧情让事件改变人物认知、反应、决定或关系。
6. **相机运动必须承担信息任务**：摄影机只能因等待、寻找、追随、领先、陪伴、追赶、对抗、躲避、揭示或产品证明而运动。删除运镜后信息、关系和观众感受不变时，删除运镜或改为固定等待。
7. **后台完整技术设计，前台一句基线**：每次新写、重写或技术调整，先在后台建立完整成像、透视、运动、色彩、光源几何、材质、渲染/合成与交付方案；最终可复制提示词的第三部分仅用一句 `【全片视觉与技术基线】` 呈现最影响画面的可见结果，不输出设备清单，不在每镜重复。
8. **按观看顺序，一镜一主任务**：开场直接建立可见成片，不写界面可选的时长、画幅、投放平台或发布渠道；最终提示词只写首帧状态、主体动作、注意力路径、视点与机位、必要运镜、人物/环境反应、可见完成态、落幅与承接。每句话必须新增画面或声音信息；内部问答、风险表、理由和自检默认不外显。
9. **正向成片优先**：把禁令转译为可见的起点、路径、接触、反作用、完成态、焦点、曝光与承接。只有用户或平台明确需要时，才在主提示词之外输出少量独立负面提示。
10. **控制方式服从难度**：文字控制失败、参考角度不足或三维路径过复杂时，减少变量、拆镜，或升级为多角度资产、独立关键帧、动作参考、故事板、白模、编辑或后期，不用同义词堆叠掩盖输入与交付层问题。
11. **声音只有一个真源**：精确对白、旁白和口型仅在有真实音频，或有精确台词、时间与节奏时承诺；否则只写节奏性口型。同步声必须由可见动作触发，精确文字、Logo、法务和正式配音按任务交给可靠资产或后期。
12. **局部修改保护成功层**：用户只改一处时，保留未涉及的方向、事实、母规则、成功镜头和声音；只修改唯一主问题层及必要的相邻承接。没有用户明确同意，不把单项目设定永久化。
13. **先判对话阶段再交付**：先区分可行性分析、直接生成、返修复盘和技能维护。用户要求“先分析/先判断难度/先别写提示词”时只交付判断，不越级生成；可行性分析只给结论、难度、1–3项主要风险、最佳路径与必要资产。用户直接要求提示词时在后台完成预检后直接交付，不用流程阻断；用户只给故事或Brief且未说明交付物时，默认先做轻量可行性分析。
14. **当前要求覆盖稳定默认**：执行优先级为“用户本轮显式硬约束 → 已确认项目事实与素材 → 本技能专项规则 → `user-operating-contract.md` 的稳定默认 → 最小合理假设”。稳定默认只补空白，不能覆盖用户当前指定的片型、风格、节奏、模型、格式或项目事实。
15. **默认一版最优、资产最小化**：除非用户明确要求多个方向或版本，只交付判断后的单一最佳整合方案；只建议会实质提高身份、结构、动作、构图或连续性稳定度的最少资产，并为每个资产绑定唯一职责。
16. **路由并行叠加，不做互斥分支**：双轴只决定最终验收对象与主要提示词带宽；广告、剧情、UGC、食品、美妆、群像、声音、长时、连续性、运镜、画质和模型工作流等条件必须逐项独立匹配。命中多个条件时全部读取；不得因已经进入“商业”或“剧情”路线而停止检查其他能力。
17. **通用规则上浮，专用模块只补充**：适用于所有任务的规则放在本文件；跨两个及以上片型或一旦遗漏会造成事实、物理、身份、声音、画质或交付根本失败的规则，必须在公共治理层保留最低可执行基线，专项 reference 只能加深，不能成为该规则唯一入口。
18. **写实超现实先可信、再越界、再回收**：命中 `grounded-surreal` 时，先建立绝对可信的现实或材质世界；一个镜头或生成段的画面中只允许一个高权重幻想规则处于激活状态，并用可见物理过程服务产品事实、体验或剧情意义。其余身份、尺度、受力、接触、光影、透视、人物反应与连续性全部服从现实，奇观完成后回到人物反应、实际使用、稳定空间或产品/剧情记忆。用户即使明确要求多种幻想“同时发生”或全程复杂环绕，也不得机械堆入同镜；保留全部创意意图，但按完成态拆到相邻镜头/生成段，上一异常必须先完成、退出画面或被现实回收，下一异常才能激活，结尾也不得让全部异常累计共存；高成本奇观期间稳定摄影机。
19. **观察者摄影把摄影者视为有限身体**：命中 `observational-camera` 时，按“事件发生 → 摄影者发现 → 身体/相机反应 → 追随或重构图 → 设备短暂恢复 → 落在结果/反应/证据”设计。只允许由设备、身体和现场因果触发的受控摄影缺陷；人物身份、商品事实、空间、接触拓扑、动作物理与连续性始终正确。摄影者可提前守点、同步陪伴或迟半拍追赶，取决于当时已知信息，不机械统一延迟。
20. **黄金3秒先制造问题，不先解释内容**：短视频、广告、UGC、短剧、能力展示或任何依赖首屏停留的任务，开场先判断观众自然预测，再用一个主要机制制造合理的预测误差，使观众形成可说出口的具体问题；答案不得立即完整给出，必须通过动作、反应、视线、声音、产品介入或因果推进完成 `Hook → Bridge → Payoff`。高能不等于快切、巨物、爆炸或大音效；删掉 Hook 后正文若完全不受影响，则视为假 Hook，必须重做。
21. **摄影机与构图联合求解，后台完整、前台压缩**：每镜先由叙事目的、人物/产品/空间主信息和观众心理位置反推景别、关系机位、高度/角度、构图、必要焦段/透视与运镜；机位和构图必须强化同一关系，不把“低角度=强、高角度=弱、近景=悲伤”等当固定映射。双人/多人同时检查轴线、视线与视觉优势，运动主体检查 lead room 与动态重心，相邻镜头检查景别、重心、动作和构图承接。最终提示词只保留真正影响画面的 2–4 项摄影变量，通常压缩为约 10–30 个中文字的短标签，如“（A肩后拍B，中近景，平视三分构图）”，随后立即进入动作、表演、环境与结果描述；特殊镜头才增加焦段、遮挡、透视或运镜。

## 每次调用工作流

1. 完整读取 `references/rule-governance-and-module-routing.md`、`references/user-operating-contract.md` 与 `references/direction-routing.md`，先判断对话阶段，再完成双轴判断；分流只确定主目标和带宽，不关闭任何能力模块。只有缺失信息会实质改变成片时，才问一个最高杠杆问题。
2. 建立整片氛围、色彩、主光、保护逻辑、成像与声音母规则，并确定哪一层获得主要提示词带宽。
3. 确认任务模式：从零生成、普通参考、首帧/首尾帧、关键帧、故事板、动作/运镜参考、白模、编辑、延长、转场、音频或成片复盘；为每个素材绑定唯一职责，先做输入素材 A/B/C 质量分级，再确定完成任务所需的最小资产集。
4. 先在后台建立模块覆盖单：`对话阶段｜第一轴｜第二轴｜能力标签（含grounded-surreal、observational-camera、golden-3s-hook等可多选标签）｜必须读取｜可省略及理由`；再把下方所有条件视为并列勾选项逐行匹配并加载专项 references，不得命中第一项后停止。两个及以上镜头必须先完成整片信息设计，再逐镜完成“为什么存在 → 怎样拍”的双层反问；一镜到底把每个连续节拍当作无切镜的信息镜头处理。
5. 若任务依赖首屏停留、社媒传播、短视频转化或用户明确要求强 Hook，先运行黄金3秒后台链路：`普通开头 → 观众预测 → 主要预测偏差 → 具体观众问题 → 未完成状态 → Bridge → Payoff → 假Hook检查`；最终只保留被选中的可见成片，不外显后台推理。
6. 商业任务先锁商业主目标、产品事实、真实比例、单一传播命题、主决策/首要犹豫、可见证据、产品进入、Hero Shot/End Frame与事实边界；剧情任务先锁人物关系、诉求、冲突、知情差、转折和情绪落点。
7. 在后台建立完整技术方案与画质风险定位；若输入或交付层是主问题，优先修输入、高清模式、真实输出规格、码率、编码、平台压缩或后期超分，不污染创意提示词。
8. 按“空间/首帧 → 单一主动作 → 接触或变化 → 可见结果 → 反应/决定 → 落幅 → 承接”编译时间轴。先运行方向测试、黄金3秒测试、导演信息测试、人脑成像测试、模型容量测试、物理连续性测试和画质交付测试。
9. 用户只要视频提示词时，隐藏内部问答并按 `references/output-contract-and-validation.md` 输出；用户要分镜表、导演分析或参考视频反推时，再展示每镜的“镜头核心表达”和“承接”。
10. 用户返回成片时先按时间码取证，区分成功层、失败层、必须保留和唯一主修层；只做证据驱动局部重试，同层两次失败时升级控制方式或回到上游。

## 片型调用深度

以下仅说明主控制带宽，不构成模块排除。完成片型判断后，仍须继续检查商品、食品、美妆、群像、写实超现实、声音、长时、连续性、运镜、画质与模型任务标签。

- **短剧、冒险、悬疑、品牌剧情**：完整执行整片信息设计和逐镜双层反问；表演、关系因果、知情差、反应、决定、轴线与承接获得主要带宽。若依赖短视频首屏停留，先用黄金3秒建立一个主要未知，再让该未知进入人物关系或事件因果。
- **TVC、产品广告**：把信息控制转译为产品是什么、如何自然进入、如何使用、材质/功能怎样被证明、为什么相信、最终记住什么；人物和运镜都服务产品证据与品牌记忆。强Hook必须可桥接到首要犹豫、产品证据或品牌命题。
- **UGC、电商演示**：轻量执行，只锁首秒钩子、真实地点和动机、产品自然进入、一次清楚使用证据、同步现场声、即时反应和结尾记忆；首秒优先动作中途进入、异常结果、判断题或真实反应，不用电影级奇观破坏原生感。
- **一镜到底**：逐节拍运行问答，但所有承接发生在同一摄影机路径、同一物理镜头、连续空间与连续光线中。
- **参考视频反推**：除景别、机位、运镜和切点外，反推每镜控制的信息、情绪和注意力；首 1–5 秒额外反推“首帧确定信息 → 观众预测 → 预测偏差 → 具体问题 → 答案延迟 → Bridge → Payoff”，只迁移导演逻辑，不复制原片人物、场景、美术、台词或专属画面。

## 输出边界

- 用户只要可复制提示词：只输出问答后的有效结论，不展示内部分析表。
- 用户未要求多个方向或版本：只输出一版最优整合结果；不得用多个近似方案转移创作判断。
- 用户要分镜/导演分析/参考反推：每镜增加“镜头核心表达”和“承接”，说明新增信息/关系/感知/产品证据，以及回答上一镜什么、用何种视觉或声音变量接向下一镜。
- 最终提示词第三部分固定为一句 `【全片视觉与技术基线】`；其余技术方案留在后台，镜头段只写真实变化项，不重复整套基线。
- 每个完整的新写、重写、降级版、安全版或备选版都保留固定前三部分，不把备用提示词压成失去结构的一段话。
- 默认沿用用户的语言、模型和格式硬约束；字符数、时长、镜头数、素材引用数、比例与输出格式在交付前主动校验。

仅在用户明确要求更新本技能时，先依照 `references/rule-governance-and-module-routing.md` 判断新增知识应进入公共层、跨域层还是专用层，再用 `python3 scripts/audit_module_routing.py` 检查失联引用，并使用 `evaluation-cases/director-and-quality-cases.md`、`evaluation-cases/portable-behavior-cases.md`、`evaluation-cases/cross-module-routing-cases.md`、`evaluation-cases/grounded-surreal-cases.md` 与 `evaluation-cases/observational-camera-cases.md` 做回归验证，最后通过 Skill Creator 的结构验证后保存；普通视频任务不运行维护流程。
