# 林枫生图提示词｜High-Signal Image Compiler

目标：**主体最清楚，画面关系最清楚，用最少词解决最关键的生成问题。**

默认原则：
- 主体信息永远先于光影、设备和摄影术语；
- 不追求字段完整，只追求结果清楚；
- 抽象目标先由大语言模型完成设计，再翻译成模型能直接执行的可见内容；
- 光影、材质、景深、反射等是按需加分项，不是固定必填项；
- 最终Prompt可以很短，Skill内部判断可以很深。

## 1. 固定链路

`Contract Lock → Subject Lock → Scene/Composition → Signal Budget → Optional Reality Patch → Pollution Audit`

## 2. 默认优先级

`用户明确要求 > 主体/产品 > 动作/状态 > 场景关系 > 构图/机位 > 关键风格与色彩 > 必要真实性补丁 > 光影/设备术语`

如果用户本轮明确要求灯光、材质或摄影方案，对应层级可以上调。

## 3. Contract Lock

先锁真正不能错的信息：
- 是真人、产品、动漫、海报还是其他媒介；
- 人物年龄感、体型、发型、服装、身份等关键识别点；
- 产品结构、颜色、包装、文字、尺寸比例、参考图职责；
- 场景、画幅、必须出现/禁止出现的元素；
- 用户明确指定的风格、用途和平台。

用户已给的信息不重复询问。缺少非关键细节时，按常见视觉逻辑补全。

## 4. Subject Lock｜主体优先

主体描述必须比光影、设备和装饰词更具体。

### 人物主体
优先写：
`身份/年龄感 + 体态/脸型/发型/服装 + 当前动作/神态`

只保留能影响识别和画面结果的特征，不把毛孔、睫毛、皮肤纹理等全部展开。

示例：
`25岁高颜值欧美女性，黑色长发，自然妆容，身材修长有轻度训练痕迹；手持透明香水瓶贴近脸侧，闭眼轻笑。`

### 产品主体
优先写：
`品类 + 结构/形状 + 主色/材质 + 当前状态/摆放`

示例：
`方形透明玻璃香水瓶，浅金色液体，银色金属瓶盖，标签朝向镜头；女性单手握住瓶身。`

### 多主体
每个主体都只写自己的识别点和动作；公共场景、构图、光色只写一次。

## 5. 场景与构图

只写会影响主体关系的空间信息：
- 在哪里；
- 主体位于哪里；
- 景别/视角；
- 必要的前中后景或留白；
- 关键对象之间的距离与朝向。

不要为了“专业”默认写焦段、相机高度、透视参数。

示例：
`胸像特写，人物在画面左侧，香水瓶靠近镜头，右侧大面积留白；纯白背景，画面干净。`

## 6. 风格与色彩

风格必须翻译成可见结果。

不要把这些抽象词原样当成主要生成信息：
`高级感、电影感、视觉冲击、氛围感、张力、超现实感、大片感`

先完成设计，再写成可见内容，例如：
- `高级美妆感` → `纯白高键背景、黑发与蓝色排版形成清晰色块关系、画面留白多、装饰元素极少。`
- `视觉冲击` → `巨大的红色产品占据前景，人物被压到画面边缘，尺寸反差明显。`
- `超现实` → 明确写出唯一违反现实的视觉规则及其与真实空间的关系。

默认只保留一套主色关系，不堆多种风格词。

## 7. 真实性补丁｜按需最多1条

主体、动作、场景和构图已经清楚后，再问：

`这张图最可能出现的一个AI错误是什么？`

只有答案明确时，加入一条最短修正；没有明显风险就不加。

常见补丁：
- 漂浮：`瓶底紧贴桌面，底缘保留轻微接触阴影。`
- 玻璃塑料感：`玻璃边缘保持透明折射，高光不过曝成死白。`
- 金属廉价：`金属反射连续，不出现大片白色塑料高光。`
- 人景分离：`环境主色只轻微影响朝向光源的一侧。`
- 景深混乱：`双眼清晰，背景自然退焦。`
- 空间扁平：`前景遮挡明显，中景主体清楚，远景细节降低。`

真实性补丁是修错层，不是固定装饰层。

## 8. 光影｜非固定字段

普通生图不单独设置【主光】【辅光】【特效光】【高光】【阴影】等多个固定字段。

只有以下情况才写光：
- 光线决定脸或产品是否读得清；
- 产品材质/透明度/反光是当前卖点；
- 用户明确要求特定时间、灯光或摄影效果；
- 当前问题就是过曝、死黑、脏灰或环境脱节。

需要时优先一句可见结果：
`窗外柔光从右侧照到脸颊，暗侧仍保留轮廓。`

不要自动加入 HDR、ARRI、IMAX、高动态范围、电影级高光等词包。

## 9. 默认输出格式

普通图片优先使用下面的最小结构；没有内容的块直接省略。

```text
【主体】
[人物/产品是谁 + 最重要识别点 + 当前动作/状态]

【场景/构图】
[在哪里 + 主体位置 + 景别/视角 + 必要空间关系]

【视觉】
[已经翻译成可见结果的风格 + 主色关系 + 必要媒介特征]

[按需：把1条真实性/光影补丁直接并入最相关句子，不单独堆模块]

【限制】
[2–4个当前最容易出错且后果严重的问题；没有则省略]
```

### 简单图片

如果单主体、单场景、单构图就能说清，可以压成一个短段，不强制加标题。

### 复杂图片

只有多人、多产品、严格版式、复杂空间、精确文字或灯光本身是主任务时，才展开更多字段。

## 10. Prompt Pollution Audit

输出前逐句检查：
1. 这句话是否直接改变主体、动作、空间、构图、色彩、材质或文字？
2. 是否已经表达过？
3. 是否只是解释一个抽象概念？
4. 是否只是为了显得专业加入摄影术语？
5. 是否把次要的光影细节写得比主体还多？
6. 是否存在没有具体画面结果的“高级、电影级、超清、极致”等形容词？

命中重复、解释性、低价值信息就删。

## 11. 修改已有Prompt

用户反馈某一层失败时，只修对应层，不自动重写全部：
- 主体不像 → 修主体识别点；
- 产品变形 → 修结构/比例；
- 构图乱 → 修位置、景别、留白；
- 太暗/过曝 → 只补必要受光结果；
- 塑料感 → 只修当前关键材质；
- 背景抢戏 → 降低背景细节；
- 颜色脏 → 收敛主色和杂色；
- AI味重 → 先找最明显物理错误，只补1条真实性修正。

## 12. 最终标准

- 第一眼知道主体是谁/是什么；
- 第一眼知道主体在做什么；
- 场景和构图服务主体；
- 风格已被翻译成可见设计，而不是抽象词；
- 光影没有抢主体的信息权重；
- 不为字段完整增加无效词；
- 最终Prompt尽量短，但关键控制不丢。
