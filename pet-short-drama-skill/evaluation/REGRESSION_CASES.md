# 回归案例｜真实失败类型

Case 1～12 主要来自此前成片观察；Case 13 为跨风格架构回归；Case 14 是此前万圣节稀疏对白的Prompt层回归；Case 15～16 来自上一轮《THE BRAVEST GHOST》成片与Prompt；Case 17～19 来自最新上传《草稿(1).mp4》约30秒成片与原Prompt逐镜对照。观察到的画面事实与提示词根因分析分别记录，不把规则修订当成重新生成后的验收。

## Case 1｜主角无因换边

失败：12秒主角在门外左侧，20秒没有移动过程却跑到右侧。

根因：下一镜重新构图时重新摆放角色，没有继承上一镜End State。

修复：先写主角从原位置经过谁、向哪个方向走、到哪里停，再选新机位。

判定：如果删除摄影机描述，角色仍能解释自己怎样到达新位置，才通过。

## Case 2｜主角瞬移到楼梯

失败：上一镜仍在红毯，下一镜直接出现在第二级台阶。

修复：明确“走到台阶前 → 迈第一级 → 迈第二级 → 停住”。

## Case 3｜管家迎错对象

失败：台词写“Welcome home, sir.”，但构图里管家实际蹲在白贵宾旁边，观众会误以为贵宾才是主人。

修复：管家路径、停点、朝向和视线必须明确指向主角；反派放在另一侧前景/背景。

## Case 4｜大门Reveal破坏空间

失败：Reveal镜里主角突然已经在豪宅深处，下一镜又回到门外。

修复：主角保持门外原位，让大门在它面前打开；用后拉、低机位和背景肖像完成Reveal，而不是移动主角。

## Case 5｜人手和狗嘴穿模

失败：人直接把球递到狗嘴边，生成时手指、球、嘴容易融合。

修复：人把球放下 → 松手 → 手退出 → 狗再叼。

## Case 6｜贵宾拨球穿过主角

失败：为了拨球，贵宾爪子从金毛前腿区域穿过。

修复：提前把球位置放在两只狗之间偏喷泉侧，贵宾从球外侧接近并横拨。

## Case 7｜宠物说话像成年人类VO

失败：幼犬画面配成年声线，嘴不动，像旁白。

修复：幼年宠物声线；说话镜头脸部清楚；身体停稳；自然下颌口型。

## Case 8｜BGM从头到尾一个强度

失败：镜头在变化但音乐没有事件节点。

修复：用同一条配乐，在冲突、Reveal、回击、Reaction、结尾改变密度/音色/抽空。

## Case 9｜最后一句后直接结束

失败：主角说完回旋镖台词立即切掉。

修复：Reaction → Consequence → Final State → 稳定停留。

## Case 10｜Reaction有了，但后果没完成

失败：反派尴尬了，工作人员也指了方向，但反派还没真正执行结果，视频结束。

修复：继续到反派真实转身/离场/被迫执行，并留环境完成态。

## Case 11｜构图驱动人物瞬移

失败：为了下一镜黄金分割或中心构图，把角色放到与上一镜不一致的位置。

修复：构图只能组织当前真实位置；需要新位置时，先写位移动作。

## Case 12｜布料魔法变装

失败：毯子上一镜只勾到后腿，下一镜变成整齐披风。

修复：写清拖拽路径和最终歪斜落点，后镜继续继承同一歪斜状态。


## Case 13｜只在一个风格修订公共原则

失败：豪门风格已新增上台阶位移规则，但UGC、剧情带货或荒诞IP仍允许换场时瞬移。

根因：公共原则被写成风格独享副本，缺少唯一拥有者和跨风格回归。

修复：在 `references/CORE_RULES.md` 确认 G-02，修改 `references/01-spatial-state-chain.md`，并按 `evaluation/CROSS_STYLE_REGRESSION.md` 在所有风格测试该位移规则。

判定：所有风格生成的逐镜文本都可解释真实位移；只通过结构校验不能冒充视频测试通过。

## Case 14｜30秒多对白被压缩回4句（提示词层回归，非成片实测）

失败：万圣节30秒脚本仅有金毛两声“Boo”、贵宾一句质疑和金毛一句“Told you.”左右，总计约4句；对白没有形成完整的交锋→升级→反转→补刀，不能满足本轮至少3倍台词的要求。

根因：此前 G-05 仅写“台词短、时长装得下”，编译时为了给镜头腾时间，把可承载情绪关系的对话删成零散金句；音效或碎句也可能被误算为对白。

修复：按公共 G-05 在大纲阶段建立不少于12条有不同剧情功能的发声轮次，编排在真实时间窗内；与动作预演和镜头对嘴联动，最后保留Reaction／Consequence／Final State。当前万圣节片中机械骷髅的录音“BOO!”是事件音效，不算宠物对白。

判定：默认30秒带对白故事可逐句点名≥12个独立、自然、因果递进的英文口语轮次；逐句有角色、镜头／时间窗和口型条件；能按真实时长演完，且结尾没有被对话挤掉。用户明确无对白等例外要标记，不误判。

## Case 15｜惊吓角色背对真正刺激源（本轮成片可观察）

成片证据：约8–9秒，贵宾沿门廊方向接近右侧机械骷髅；约10.5秒的贵宾正面特写里，骷髅位于贵宾背后，贵宾直视南侧摄影机。原Prompt写了“贵宾脸占画面右侧，骷髅留在后方”，实质上让角色面向观众、背对应该吓到它的骷髅。

根因：把“摄影机能够同时拍到贵宾正脸和骷髅”误当成“贵宾自己也能看见骷髅”；没有把世界朝向、角色视线、刺激源位置和摄影机观察位一起推演。

修复：贵宾触发骷髅时仍面向北／东北；在骷髅附近反拍贵宾三分之二正脸（骷髅可置前景边缘），或从侧面同时拍到贵宾朝向骷髅。先见／听刺激，拍到头耳／肩背／前爪真实后缩，之后贵宾才转身沿原路逃跑。

判定：删除机位描述仍能说明贵宾如何看见／听见骷髅；第一反应镜头中贵宾面部和前肢可见，且视线目标明确。不允许摄影机换位代替贵宾转身。

## Case 16｜尾部再次“Boo”但没有惊吓反射（本轮成片可观察）

成片证据：约26.8～27.5秒贵宾在南瓜后已朝左侧／金毛方向带笑观察；约28秒切至金毛特写，28.6秒回到双犬全景时贵宾仍没有清晰的缩肩、蹬退或突然转头。原Prompt把27秒金毛“Boo”、贵宾被吓、认出金毛、说“Seriously?!”、后拉和结尾停留压在接近2秒的尾部，其中贵宾第一反射没有独立可读的镜头和时窗。

根因有三层：①贵宾已经注意金毛，没有建立“未知近侧声源”的惊吓条件；②“身体猛缩→马上认出→吐槽”的语义在不足1秒的反应镜头里过密；③近景／极近脸部与快速后拉不能验证应由肩背和前爪完成的第一身体反射。写“惊讶”“BGM停半拍”不能保证反应发生。

修复：先让贵宾真正转回北侧骷髅、金毛位于被南瓜遮挡的左侧；突然近侧短“Boo”后，以包含头胸前爪的中近景拍完贵宾耳朵后弹、前爪后蹬、重心后撤；接着才认出金毛、瞪它／可选短句，最后留完整双犬状态和约1秒稳定画面。时长不足时删掉“Seriously?!”而不删除反应／停留。

判定：反应前状态、触发、第一身体反射、认出后的变化在不同时间点可见；不靠旁白或字幕解释，也不把“微笑／正常转头”当作“被吓一跳”。

## Case 17｜主角到达新地点，切近景复位到旧位置（最新成片观察）

观察：约18.5～20.5秒金毛沿小路已经来到北侧骷髅附近，画面可见骷髅、主门和贵宾。约21秒变成没有门廊／骷髅地标的草坪近景，缺少从北侧返回的真实路程，视觉上像重置到初始南端。

脚本根因：19.1～20.1秒用双主体构图强行重排人／骷髅关系；20.1秒近景只写金毛说话，没有以门廊地标、身体朝向、受光方向继续证明它仍在骷髅面前。镜头单独看成立，上下镜空间接力却未通过。

修复：金毛抵达北侧后，所有近景都应有同处骷髅旁的门柱／骷髅局部或一致北侧受光；金毛只能从该位置完成转身并沿小路向南跑，回到南端前不得使用起点背景。验收按 G-02＋G-10 四层联审，删除摄影描述后也能追溯位置。

## Case 18｜配角被无因带到门廊与跟跑（最新成片和Prompt两层失败）

观察：约19.5～20.5秒贵宾与金毛、骷髅同时出现在门廊关系镜，虽按剧情贵宾应留南端；约23.5～24秒贵宾又跟着金毛跑向南瓜。

脚本根因：金毛独自向北行动后未明确保留出画贵宾在南端的持续位置，随后镜头为了双犬构图召唤贵宾入景。原Prompt还直接写了“贵宾立即跟上”，与用户要求“23秒贵宾仍在原地”相矛盾，属于编排错误，不能只归因于模型。

修复：每镜后台明确运动者与静止者；17～23秒只有金毛走到门廊并跑回，贵宾在南端原位等待／看向北侧，23秒在原位被拍见；24秒金毛实际回来后，贵宾若需靠近南瓜，只拍从自身原位的一两步移动。不能因为另一个角色移动，就默认全员同行。

## Case 19｜结尾空间与反应缺少构图转折（最新成片）

观察：约27～28秒南瓜中央遮挡两犬，贵宾对金毛一直保持可见的关注；金毛“Boo”前后没有形成从隐藏到突然出现的强烈画面变化，贵宾缺少第一身体反射；随后只是普通双犬对视。

根因：静态近景承载了隐藏、出现、声源、惊吓、认出全部信息，缺少角色认知盲区和摄影机能看见全身反射的独立镜头。加大音乐或“更惊讶”的抽象词并不能修好画面。

修复：金毛实际躲在南瓜西侧遮挡之后，贵宾仍在东侧面朝北观察已经停下的骷髅；突然露出白披风与脸并从其左侧发出短“Boo”，切至贵宾头胸与前爪同框，完整拍到向东缩退／帽子歪斜，之后才认出和瞪金毛；最后双犬同框约1秒。南瓜橙光始终从西南，骷髅／门廊始终在北侧背景。

## Case 20｜空间锁住了，但表演与镜头被一起锁死

失败：为了避免角色换位，长时间保持同一观察方向、同一中景和站桩对白；空间连续通过，但视觉变化、突然入画、前景遮挡、动作反差与角色关系反应明显变弱，结尾用双方友好站稳代替原本的互怼回合。

根因：把 G-10 的高风险位移保护错误扩展成全片保守摄影；把“Final State”误解成“所有角色停止动作”，而不是关系冲突已经完成。

修复：跨区域／往返时保持 Observation Corridor；位移完成并建立 Arrival Anchor 后立即恢复自由摄影与表演密度。结尾按最后刺激 → Reaction → 认出／判断 → 短促回击／承认 → 主角回应小动作 → 关系终态 → 约1秒停稳。空间位置不变，但景别、机位、前景和动作可以明显变化。

判定：空间层仍全部通过；安全段至少有可见的表演变化和摄影变化；结尾不是无铺垫的突然和解或并排站立，而是完成前文关系回合后停稳。

## Case 21｜对白句数够，但像“蹦豆”

失败：30秒里虽然达到多轮对话，但连续出现“Really?”“Sure.”“Fine.”“Plastic.”“Prove it.”等孤立单词／两词短句；镜头一切就换一句，角色像机械轮流发声。

根因：把 G-05 的“至少12个有效轮次”误执行成“尽可能把每句话缩到最短”，为了塞镜头牺牲了自然口语的语义承接。

修复：保留轮次，但让大多数台词成为自然口语意群；下一句承接上一句或上一动作的具体意思。允许一句跨反应镜收尾，不要求每次切镜都截断一句。时长不够先删重复意思／重复视觉事件，不把所有台词削成单词。

判定：读出对白时能听出真实争辩／试探／反击关系；孤立1–2词只作少量节拍，不连续主导整段。

## Case 22｜画面写实，但没有发挥生成视频的原生优势

失败：整条视频的构图、剪辑、角色动作都像传统实拍；所谓“AI感”只靠文案写“魔法、超现实、视觉奇观”或后期式闪白／粒子，现实与异常之间没有连续可见的机制。

参考观察：一个有效范式是在普通公共交通实景中保留人物、座位、旁观者和窗光，只让服装在原位从鞋／腿部开始逐段生成，保留中间态；手机前景提供明确目标与触发，第二次换装改变传播方式，旁观者／主体反应继续证明异常发生在现实里。

根因：创意阶段只设计“拍什么剧情”，没有设计“哪一条现实规则可以被AIGC连续打破”；摄影机、声音与异常过程各自独立。

修复：执行 G-11：现实底盘＋单一不可能机制＋明确触发＋可见传播＋中间态＋现实见证者；运镜跟随动作／遮挡／传播前沿，声音落在同一触发和完成节点。第二次使用相同机制必须升级，不平级重复。

判定：静音看画面也能理解异常如何开始、如何传播、何时完成；删除“视觉奇观／魔法感”等词后，Prompt仍能生成明确的新视觉事件。

## 最终回归问句

- 每一镜的第一帧能否从上一镜最后一帧直接继续？
- 如果不能，中间的动作/转场是否明确？
- 摄影机换位有没有被误当成人物换位？
- 所有接触是否先接近再接触？
- 道具是否有连续位置和持有者？
- 最后一个爽点之后是否真的发生了后果？
- 触发源是否处于被影响角色可见／可听方向？角色是否真的收到了刺激，而不是仅摄影机看见？
- 关键惊吓／认出有没有独立可读的第一身体反射，还是被快切、台词和特写吞掉？
- 上一镜已到新地点，本镜近景是否保留同地地标／受光方向？原地配角是否被无因带跑？镜头的画面／位置／构图／光影四层是否同时成立？
- 空间锁是否只用于高风险位移，而没有把安全段的景别、机位、前景、突然入画和动作表演一起锁死？结尾是否完成角色关系最后一回合后才停稳？
- 台词是否形成连续口语意群，而不是为了凑轮次连续吐单词？
- 如果创意允许虚实结合，是否真正设计了一个现实底盘中的不可能事件及其可见传播，而不是只写“魔法／视觉奇观”？镜头和声音是否与这个事件同一因果节点？
