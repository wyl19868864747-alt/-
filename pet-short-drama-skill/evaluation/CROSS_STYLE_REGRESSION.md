## 3. 其他公共规则跨风格试题

- G-01：更换风格后幼犬仍保持同一脸型／年龄与已声明参考职责；产品图不能被人物图改写。
- G-03：四种风格各设一个接触交接（机器人／沐浴露／开箱玩具／递网球），必须可见接近、接触、响应、分离；无人手／狗嘴交叠。
- G-04：每种风格给一处构图变更，确保只换镜头观察位、不无因重摆角色；高风险位移结束并建立到达锚点后，恢复明显的景别、机位与前景变化。
- G-05：四种风格默认30秒有对白故事均编排至少12句有效英文短对白；检查句子具有交锋→升级→反转→回击的原因与情绪变化，逐句能看清发声角色、容得下自然发音和换人，不侵占最后Reaction／Consequence／Final State。机械装置音效、把一句拆段及旁白标题不得计数。明确无对白任务单独标记用户例外。
- G-06：每种风格至少一个由实际事件触发的音乐抽空／重拍／音色变化；对白被听清。
- G-07：荒诞英雄有反拍、带货有使用结果、开箱有实际玩耍、豪门有反派被迫执行后果；全部停稳结束。
- G-08：各风格随机选一镜检查“抽象目标词→可见动作／声音”；参考职责与世界站位逐镜写清。
- G-09：跨风格逐条核验刺激源方位、角色当前视线／是否知道、可达视觉／声源、第一身体反射、识别／台词以及能看见动作的景别；快切不能跳过反应。

## 3A. G-05 30秒多对白跨风格试题

| 风格 | 原本容易失败的对白编排 | 修正后的最低条件 |
|---|---|---|
| IP荒诞英雄／万圣节 | 30秒只有“Boo!”等约4句，其余全是说明动作；骷髅音效被错当对白 | 两只狗至少12句有效短对白，沿挑衅→嘲笑→机关启动→惊慌→补刀推进；不把骷髅录音算句数 |
| 剧情带货 | 为达到12句重复价格、凭空编造产品功效或连续独白挤掉使用动作 | 至少12句有明确角色与真实需求的短对白；实际产品事实经过核实，并留使用和后果画面 |
| UGC开箱 | 为凑台词让狗在叼玩具或撕包装时反复说话 | 用发现／求助／尝试／反馈的可见对话或符合任务的主人互动，身体停稳时说短句；若用户指定无对白，记录明确例外 |
| 豪门翻盘 | 只保留反派长段嘲讽和主角两句狠话，身份揭示后马上切断 | ≥12句有对话反击轮次，反派发言和主角回应随地位变化而变化；台词之后仍有真实后果和完整反应镜头 |

测试标注：文本静态通过、逐镜对白容量通过、实际生成口型／声音通过为三种**不同状态**，未生成视频不能声明第三项通过。

## 3B. G-09 感知—反应跨风格试题（v1.3.0）

| 风格 | 故意制造的错误 | 必须通过的修正 |
|---|---|---|
| IP／万圣节 | 贵宾朝北侧骷髅行走；下一镜为拍正脸突然面朝南侧镜头，骷髅落在身后，却仍被写成“正面看见骷髅吓到” | 继承朝向，让骷髅位于贵宾前方可视方向；机位从骷髅侧反拍贵宾三分之二正脸或侧面双主体，拍到耳朵／肩背／前爪后撤，先反射后转身逃跑 |
| IP／万圣节结尾 | 贵宾已经看向左侧金毛，金毛轻声“Boo”，贵宾在不足1秒内既后跳又认出又说完整句还要切全景；成片直接微笑 | 贵宾先转而盯北侧已复位的骷髅、金毛被南瓜遮住；近侧短促声触发后，独立拍到完整第一反射，再认出和瞪眼，最后留约1秒稳定画面 |
| 剧情带货 | 宠物未接触产品就赞美效果；摄影机看见产品但角色背对产品 | 先拍到角色观察／使用时视觉或触觉可达，再出现有物理根据的反应与反馈 |
| UGC开箱 | 玩具在箱内背后露出，狗始终望向镜头却无因惊喜；极近特写掩掉后退动作 | 箱口／包装声先把狗的头或视线引向玩具；若惊吓则用能看到胸与前爪的镜头呈现蹬退 |
| 豪门身份翻盘 | 工作人员朝主角鞠躬在反派背后；反派一直对镜头正面、未听未看就开始震惊 | 先建立工作人员语音从哪侧传来或反派转头看清；反派脸与身体发生可读反应，再进行后续回击和后果 |

按 G-02 同样把注意力视线／认知状态传入下一镜。成片通过只能从实际生成视频观察获得；不能将“Prompt中写了后跳”当成视频已发生。

## 3C. G-10 四层预演跨风格试题（v1.4.0）

| 风格 | 高风险状态断裂 | 必须通过的四层修正 |
|---|---|---|
| IP／万圣节 | 金毛已走到北门廊骷髅旁，下一近景突然恢复南端草坪；贵宾在南端原地却被编进门廊同框 | 北侧近景保留骷髅／门柱与北侧暖光；每镜指定金毛独自运动、贵宾南端持续原位，23秒贵宾仍在原地观察金毛跑回；完整案例见 HALLOWEEN_STATE_FIXTURE.md |
| 剧情带货 | 主角从浴室到客厅展示产品，中间没有走出浴室；独立产品近景更换桌面和窗口光源 | 可见经过门口／走廊，产品随实际持有者进入客厅；展示镜保留客厅锚点及固定窗光方向 |
| UGC开箱 | 镜头外的主人在客厅打开包装，下一镜狗／玩具无因换到卧室，阳光方向也重置 | 玩具在原开箱位置可追踪，主人出画仍保留原位；只有拍到搬运／成立转场后才换房间、重算窗光 |
| 豪门翻盘 | 金毛从红毯走上台阶后，特写回到红毯初始背景；站在侧门的贵宾被无因拉到主门同框 | 真实迈台阶动作、近景台阶／门柱锚点、贵宾持续停在侧门；摄影机可移动但不能搬角色 |

审核每镜画面／位置／构图／光影四层，特别核对谁移动、谁静止、谁出画。跨大距离没有真实动作／成立转场时，该Prompt不得交付。同时验证 G-10 只约束高风险位移；到达锚点建立后，恢复原风格的摄影变化与表演密度。静态矩阵通过不等于生成视频必然通过。
