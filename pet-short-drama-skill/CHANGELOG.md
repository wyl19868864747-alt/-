# Changelog

## 1.2.0｜2026-09-23

- 公共 G-05 从“对白时长／自然对嘴”升级为默认30秒有对白宠物短剧至少12句有效英语短对白，约为本轮万圣节4句版本的三倍；推荐12–14句，并明确角色、镜头、剧情功能、情绪递进及真实时间窗。
- 把交锋→升级→反转→回击的对白设计前置到大纲与项目对白账本，最终Prompt逐句核算，不能编译时删回4句，也不能靠拆句／机械音效凑数。
- 保持逐镜空间状态接力、物理预演、Reveal停留和 Reaction → Consequence → Final State → 停稳的结尾闸门；对白不能挤占这些动作。
- 同步总控、核心登记、项目事实模板、Prompt编译器、四风格回归矩阵、结构校验和Case14提示词层失败测试。
- 仅完成规则与静态／文本级检查；本版不宣称实际生成视频对嘴已通过。

- 风格模块显式继承核心，仅存本风格的叙事差异。
- 新增跨风格回归矩阵及静态结构校验；原12个真实失败案例保留，并补充规则扩散失败案例。
