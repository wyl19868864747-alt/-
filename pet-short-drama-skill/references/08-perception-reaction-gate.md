# G-09｜感知—反应因果闸门（Perception → Reaction Gate）

**全风格公共规则唯一维护文件。** 补足 G-02（真实位置）、G-04（摄影观察位置）、G-05（表演与口型）、G-07（完整结尾）之间的因果约束：事件发生，不等于角色已经看见／听见；写了“惊讶”，不等于画面里有可读反应。

## 1｜每个转折必须经过一条可预演的链

`已建立的注意力／基线 → 触发源开始变化 → 刺激物进入角色可见／可听范围 → 角色真正感知 → 第一身体反射／微表情 → 识别与判断 → 后续动作或台词 → 可读完成态`

普通对话可压缩阶段；**惊吓、发现、认出身份、揭示、道具突然出现、角色误判**不能省掉“角色如何收到信息”或“画面怎样证明反应发生”。若用户明确要求角色尚未注意某物，先锁定其看向别处、被遮挡或相应声源尚未触发；不能一面写“没注意”，一面把它放进角色已经正对的视野。

## 2｜视线、声源与机位三者必须成立

逐镜在后台记录：触发源世界位置；角色身体朝向、头部角度、视线落点；视野／遮挡；声音来自哪侧、是否已被听见；摄影机站在哪里、从何方向看见脸和动作。

- 角色面朝门廊北侧骷髅时，第一惊吓反应应仍朝北／东北的骷髅。若从南侧拍到贵宾正脸而骷髅又在贵宾背后，贵宾其实背对触发源；不能用“它睁大眼”掩盖视线断裂。
- 可以从骷髅附近反拍贵宾的三分之二正脸，让贵宾视线明确落向镜头旁的骷髅；或使用侧面双主体镜头，让骷髅位于狗身体和视线前方。**摄影机能看见狗的脸，不代表狗能看见摄影机后方／自己背后的物体。**
- 触发源不必和角色总在同框，但要由前后镜的动作轴、视线匹配、方位与声源明确建立两者关系。不能为了漂亮正脸而无因调转角色身体。
- 听觉触发也需明确：声音到达角色的相对方位、是否被其他声覆盖、角色此前是否预期该声音；不要在角色明确看到同伴开口时仍要求“毫无防备地被轻声吓到”。

## 3｜惊讶与惊吓必须是可见状态跃迁

“被吓一跳”“震惊”“惊讶”只是目标，不是终版动作指令。先写反应前的稳定状态，再写触发点和**第一身体反射**，最后写识别后的自主反应：

- 反应前：例如贵宾目光仍看北侧已经复位的骷髅，耳朵放松，未看见南瓜左侧金毛把头凑近。
- 声音触发：金毛在贵宾左侧、被南瓜遮住的下方突然近距离短促“Boo”；贵宾听见时才启动反应，金毛不能提前与贵宾对视。
- 第一反射：肩背突然收紧、耳朵弹向后、前爪向后蹬半步，身体重心后移，头猛地朝左侧声源转去，眼睛短暂睁大；四足接地，不要求宠物做人类夸张站姿。
- 识别／第二反应：看清是金毛后才停止后退、眯眼或瞪它；这一步不是惊吓本身，不能和第一反射合成一句“吓到后立刻发现并说话”。

角色已经注视同伴、预期同伴恶作剧、声源距离不合理或刺激力度太弱时，**惊吓缺少动机**。先重排注意力、遮挡、声源与动作，或改成怀疑／嫌弃的笑点；禁止在结尾追加“反应更夸张”来碰运气。

## 4｜摄影必须把目标反应拍得到

如果反应依赖耳朵、肩背、胸口和前爪后撤，**第一反应镜头使用能看到头部＋肩背＋至少前爪的中近景／近景**；极近面部特写只适合眼睛、嘴角等微反应，不能承担全身后跳的验证。

反应镜头应先从已继承位置开始，第一反射发生时暂不切到刺激源或其他角色；让观众实际看到“刺激发生→身体状态发生变化”。随后再切面部识别、反派眼神或主角回击。机位与运动服从可读反应，不为快切删掉关键动作。

## 5｜时间预算与先后顺序

惊吓／突然发现的参考节拍（按实际动作可微调）：

`注意力已被建立 → 触发与声音0.2–0.4秒 → 第一反射约0.4–0.7秒 → 认出／回看约0.3–0.6秒 → 允许台词或转入后果`。

这是**事件所需的可读先后**，不是给所有风格强制固定秒数。不能在不足1秒的镜头内同时要求全身后缩、抬头认人、完整英文台词、镜头大幅后拉和切全景。时长不足时提前触发，缩短重复对话、删除无关特写或延长总时长；优先保留真正的反射动作及最终 G-07 完成态。

对白规则 G-05 不能挤掉本闸门：先惊吓并可读，再恢复姿态、张嘴说“Seriously?!”；音效／BGM抽空只能辅助触发，不能替代画面反应。

## 6｜逐镜反应账本（后台）

对每个重大转折，内部填写：

| 字段 | 必须写明 |
|---|---|
| Trigger | 触发源是什么、世界位置、触发秒点、声音方向 |
| Attention / Awareness | 角色当前看／听什么；是否已经知道触发源存在 |
| Access | 角色通过哪个画面方向或声音渠道收到刺激；有无遮挡 |
| Start State | 上镜末态与当前身体／头部／视线一致 |
| Reflex | 第一帧可见的具体身体／表情变化 |
| Recognition | 何时看清／确认，是否需要第二次转头 |
| Camera Proof | 哪个镜头完整容纳这次关键变化，能看见哪些身体部位 |
| Time / End State | 反射、识别和后续台词各占多少时间；完成态交给下一镜 |

任一字段无法回答，不能靠“角色惊讶”“镜头快速切换”“保持空间一致”等抽象补丁通过验收。先重写最早不成立的感知／反应镜头，再从新的结束状态继续后续分镜。

## 7｜跨风格示例

- 荒诞／万圣节：骷髅在贵宾前方，贵宾先看见／听见，再缩身和后退；结尾金毛恶作剧必须先让贵宾注意别处、近声触发、完整反射后再认出。
- 剧情带货：角色必须先看见／体验到产品变化，再有惊喜、疑问或使用反馈；不能先说体验结论、后镜才出现接触动作。
- UGC开箱：宠物先看向箱口并听到包装声，玩具露出后才靠近、后退或摇尾巴；产品在背后时不得无因作出“看到玩具”的表情。
- 身份翻盘：权威人物朝主角致意后，反派先通过声音／视线真正注意到，再发生表情及地位反应；不能从反派背后传来身份信息，却拍反派一直正对观众而没有听觉／转头证据。
