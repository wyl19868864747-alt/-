# 逐镜空间状态接力｜Spatial State Chain

这是本 Skill 的最高优先级执行规则之一。

## 1. 核心公式

`下一镜起始状态 = 上一镜结束状态`

每个镜头结束后，后台必须冻结一个 End State，下一镜只能从它继续。

至少记录：

- 每个角色的世界空间位置
- 身体朝向、头部/视线方向
- 角色间前后左右和距离
- 道具世界位置、归属、接触关系
- 正在发生的运动方向
- 摄影机轴侧与观察方向
- 高度状态：地面、台阶、第几级、家具上/下
- 房间/区域状态：门外、门口、走廊、客厅、台阶、室内

## 2. 世界空间 ≠ 画面左右

“主角在世界空间的红毯左侧”与“主角在画面左边”不是同一概念。

摄影机换位可以改变屏幕构图，但不能凭空改变角色的真实位置。默认保持同一动作轴侧，避免仅靠反打让观众误以为角色换边。

## 3. 可见位移门槛

只要以下任一状态变化，必须有可见动作或明确成立的转场：

- 左侧 → 右侧
- 门外 → 门内
- 红毯 → 楼梯
- 地面 → 台阶
- 面向A → 面向B
- A持有道具 → B持有道具
- 两只动物相隔一米 → 紧贴接触
- 背景道具从左侧 → 右侧

写法示例：

错误：`上一镜金毛在红毯左侧。下一镜金毛站在台阶第二级。`

正确：`金毛从红毯左侧沿主门方向走过贵宾，来到台阶前；下一镜它先迈上第一级，再迈上第二级停下。`

## 4. 写镜顺序

禁止先想“下一镜要一个漂亮低机位”再重新摆人物。

正确顺序：

`上一镜完成态 → 下一事件需要什么位移 → 写角色动作 → 确认新完成态 → 从同轴可见位置选择机位 → 选择景别/运镜/构图`

## 5. 摄影机不能替人物移动

如果人物位置变了，必须是人物移动、载具移动、物体推动、时间跳转或明确场景切换造成。

“切到另一个角度”“推镜”“拉镜”“绕拍”都不能解释角色从门外到楼梯、从左侧到右侧。

## 6. 暂时出画也继续保存状态

某角色进入特写之外，不代表它重置位置。

例如：

- 贵宾在右侧出画后，下一镜重新出现时仍在右侧，除非之前写过移动
- 管家走向喷泉后，即使中间两镜不拍他，他的位置仍沿这条路径合理推进
- 球落进喷泉后，不能在没有捡取过程的情况下重新出现在门口

## 7. 切镜检查

对每一对相邻镜头问：

1. 上一镜最后一帧每个角色在哪？
2. 下一镜第一帧是否从同一状态开始？
3. 如果变化，变化动作在哪里？
4. 摄影机是否仍能看清当前关系？
5. 构图是否迫使角色无因换位？

任何一项答不上来，先重写空间动作，再继续后续镜头。
