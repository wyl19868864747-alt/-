# BGM与声音推进｜Music as Narrative Motion

## 1. BGM不是背景填充

整段优先使用一条连续配乐，通过层次变化推动事件。

最终Prompt不能只写“BGM带动情绪、音乐突出爽感”。必须写可听变化。

## 2. 常用可听变量

- 节拍：稀疏 → 稳定 → 密集 → 抽空
- 音色：低弦、轻鼓、拨弦、低铜管、木质敲击等
- 动态：对白下压、Reveal前抽空、回击落重拍、结尾收窄
- 节点：进入、加层、停拍、胜利和弦、喜剧尾音

## 3. 爽剧节奏模板

- 开场冲突：低弦脉冲＋少量鼓点
- 羞辱升级：鼓点稳定前进
- 权威人物出现：低铜管进入
- Reveal前：短暂抽空
- Reveal画面：和弦展开
- 主角狠话：单个干净重拍
- 反派失势：鼓点减少
- 回旋镖台词：短铜管尾音
- 尴尬Reaction：配乐变轻，留环境声
- 最后宠物可爱反差：轻拨弦/木质短音结束

## 4. 小事件大音乐

荒诞宠物故事可以故意让音乐规模大于事件本身：例如扫地机器人拖走玩具，却使用英雄行动节奏。反差来自声音和现实事件的比例差。

## 5. 动作声

只保留能帮助读懂剧情的声音：

- 爪子踩地
- 球滚动/落水
- 布料拖动
- 门开启
- 扫地机器人电机
- 玩具摩擦/吱声
- 轻碰撞

对白出现时BGM降低，关键动作声不要被盖住。
