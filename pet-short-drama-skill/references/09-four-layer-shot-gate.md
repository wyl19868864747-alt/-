# G-10｜逐镜四层预演与状态交接闸门

**所有风格公共规则。** 本文件是跨层编译闸门，不另造位置规则。G-02 的 01-spatial-state-chain.md 仍是位置／可见位移唯一规范；G-10 把画面、位置、构图、光影四层一起预演。所有判断在幕后完成，最终Prompt只保留必要的具体画面锚点，不增加四段附录。

## 1｜四层同一镜头联审

| 层 | 每镜后台核对 | 失败 |
|---|---|---|
| 画面层 | 上镜最后可见主体、道具、事件完成度；本镜首帧的延续；可辨场景地标 | 金毛到过骷髅前，下一镜突然恢复走之前的草坪头像 |
| **位置层／主闸门** | 全角色及道具世界区域、相对地标、身体与视线朝向、高低、运动路径、停稳或运动；镜头外角色也有持续状态 | 金毛在北门廊，下一镜无路程回南端；贵宾在南端原地，却进入骷髅旁 |
| 构图层 | 摄影机世界观察位、动作轴、景别、前中后景及可见地标；构图从真实位置派生 | 为了同框而把远处静止贵宾召唤到骷髅旁 |
| 光影层 | 灯的位置／方向、阴影朝向、材质反光和背景发光状态；地点不变则保持同一套受光关系 | 门廊暖光无因变成草坪近处完全不同的正面棚灯 |

验收单位是上一镜末帧到下一镜首帧的**全员状态差分**，不是漂亮的单张构图。摄影机换位不能替角色走路；角色出画不是离场。

## 2｜全角色持久状态＋运动所有权

内部账本每镜保存：角色A／角色B的世界地点、相对地标距离、身体／头部朝向、当前注意力、运动或停稳、是否出画；道具地点和归属；摄影机位置／观察方向；灯源世界方向和工作状态。

每镜先指派谁实际移动，其他角色默认保留上一镜末态。**没有拍到位移、也没有成立的时间／空间转场，配角不能因主角跑动自动跟随。** 特写之外的配角也不能复位或重置认知。

例如17–20秒只有金毛从南端向北走向骷髅；贵宾继续留在南端。切金毛特写或骷髅镜头时，贵宾依旧留南端，不得为双犬同框进入门廊。

## 3｜跨空间与近景高风险接续

走廊到客厅、红毯到台阶、门外到门内、南端到北门廊，必须先有真实位移、明确成立的时间跳转或可辨的连续动作。近景切镜不能重置位置。

从远景行走到近景反应时，保留一个关键方向／同场地标：门廊灯柱、骷髅局部、同一段台阶或前景遮挡。这样画面与光影仍说明人物在刚才走到的地点；不要忽然用无锚点草坪背景把人物送回原点。

分镜编译时依次执行：冻结全员末态 → 选择当前移动者和静止者 → 预演位移／接触／感知 → 核对首尾地点／朝向 → 选择真实可拍机位和构图 → 核对光源与地标 → 压缩为最终Prompt。

若出现上一镜A在客厅、下一镜A在门口且没有路径或成立转场，**Prompt层直接判失败，不进入交付**。不靠结尾补一句“位置锁定”修复。

## 4｜光影协助定位，而非新增负担

先记录持续场景的光源世界方位。万圣节例：北侧主门暖光、西南侧南瓜橙光、东侧夜间冷补光；骷髅红眼只在装置启动时亮。

人物向北靠近门廊，受北侧暖光与门廊背景影响逐渐加强；向南返回，远处门廊灯缩小、南瓜橙光逐渐靠近。摄影机绕拍时灯源依然固定在世界原位。只有新光源、位置风险、时段或场景转换才在最终镜头里补一句具体光向；平常沿用场景总设定。

## 5｜最终Prompt必须轻量

**不要**另附“画面层／位置层／构图层／光影层”四块重复说明，也不要每镜罗列全体角色的完整账本。

保持每镜标题＋紧跟的【构图】＋自然的动作／对白正文。只对**容易出错的关系**增加一句最短地标或静止者状态，例如：“金毛仍在北门廊骷髅旁，贵宾留南端不入镜。”其他状态在后台继承。角色移动的镜头直接写清原点、经过路径和终点；不把“禁止穿模”作为最终模型执行动作。

画面变化来自景别、观察角度、运镜、前景遮挡与事件推进，绝不靠重新摆放演员制造新构图。

## 6｜双角色异步运动专项

分别记录每位角色的路线和起止时间。金毛去北侧骷髅时贵宾不自动跟去；金毛回南端时贵宾继续在原位等待；两只狗只有在同一地点通过已拍过的动作建立之后，才能出现同地双犬近景。

万圣节用例：17–20秒金毛独自走向北侧；20–21秒近景仍在骷髅旁；21–23秒金毛沿原路向南跑，贵宾仍留南端；24秒金毛实际到达南端；如果随后贵宾也站到西南南瓜右侧，需拍到它从原地迈过去的短距离。27–30秒用角色各自的南瓜左右侧位置建立声源、遮挡和惊吓反射。

## 7｜验收

任一相邻镜头若角色／道具的世界区域、相对地标、朝向或高度无因改变，或关键静止配角被带跑，判为状态接力失败。回到最早错误镜头重写，传播其新的末态直至结尾。静态验证只能保证Prompt逻辑通过；模型仍可能生成失误，需通过实际成片复盘持续补回归。
