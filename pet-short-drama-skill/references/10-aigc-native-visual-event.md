# G-11｜AIGC 原生视觉事件与声画耦合

**所有风格公共创意闸门。** 本规则不要求每条宠物视频都加魔法；它要求在创意允许时，主动利用生成视频相对传统实拍的优势：在可信现实中连续呈现一个“不可能但一眼能懂”的事件。最终 Prompt 禁止直接写“视觉奇观、魔法感、超现实冲击、AIGC感”，必须转译成具体触发、传播、材质、镜头和反应。

## 1｜现实底盘 + 一条不可能规则

先保持绝大多数现实正常：
- 宠物身份、四足身体、毛发和当前站位不变；
- 家具、道路、门廊、草地、光源、重力和遮挡保持真实；
- 未参与异常的角色继续做普通反应。

然后只破坏一条规则，例如：
- 白色幽灵披风像有生命一样沿南瓜边缘滑动并包住主角；
- 影子先变成另一形状，实体随后被牵引；
- 普通玩具在地面自己折叠成小型装置；
- 水迹沿地面长出一条短暂发光路径；
- 产品包装在桌面原位展开成可进入的微缩空间。

现实越稳定，异常越显眼。不要同一镜同时让角色漂浮、房屋扭曲、天气突变和道具爆炸。

## 2｜Visible Trigger｜异常必须有明确触发

给观众一个可读原因：
触碰、踩下、咬住、打开、手机／屏幕目标图、镜面、门框、声源、影子、产品接触点。

触发前先建立正常状态；触发后才开始异常。

## 3｜Continuous Propagation｜让“正在变化”成为画面

必须写：
起点 → 传播方向 → 中间态 → 完成边界。

优先：
- 从爪边向披风上卷；
- 从南瓜表面一小块开始蔓延；
- 沿毛发／地面／道具表面逐步编织、结晶、折叠、变形；
- 一道窄边界扫过，被扫过的区域已经变成新状态。

不优先：
闪白 → 烟雾盖住主体 → 粒子爆满屏 → 直接换成完成态。

至少保留一个中间态，观众应能在静音状态下看懂“变化从哪里到哪里”。

## 4｜Identity / Space Inheritance｜异常不能重置身份与空间

异常过程仍执行 G-01、G-02、G-10：
- 同一只狗保持同一脸、体型、服装锚点和世界位置；
- 变的是指定物体／材质，不是重新生成另一只狗；
- 摄影机换位不能让角色无因移到新地点；
- 异常跨空间传播时仍要有实际路径；
- 光影、投影、遮挡和接触跟随当前真实场景。

“幻想”不构成瞬移豁免。

## 5｜Reality Witness｜让现实见证异常

变化完成后至少给一个现实响应：
- 宠物低头／回头检查；
- 另一只狗先愣住再靠近；
- 人类旁观者转头；
- 爪子触碰新材质；
- 环境保持原样，只有异常主体改变。

先发生异常，再有反应。不要让角色提前“知道”效果要来。

## 6｜Camera–Event Coupling｜镜头和画面内容必须配合

视觉冲击来自事件和摄影机的配合，不来自独立堆运镜。

每个明显运镜回答：
1. 什么可见事件触发摄影机？
2. 运镜结束时新增了什么信息？

推荐关系：
- 宠物沿路径冲刺：低机位跟拍，距离变化真实可见；
- 角色视线突然锁到目标：短摇把注意力交给目标；
- 南瓜／门框形成遮挡：横移或短弧移让遮挡边缘完成 Reveal；
- 异常沿主体传播：稳定中景或轻微跟随传播前沿，别切掉中间态；
- 突然惊吓：先看清触发，再切能看到头胸前爪的反应镜；
- 结果完成：镜头减速／停稳，让完成态被读清。

如果删掉某条复杂运镜后，画面信息完全不变，就删掉这条运镜。

## 7｜Sound–Event Coupling｜声音落在同一个因果节点

一条连续 BGM 仍由 G-06 管理；G-11 只规定异常事件的声画绑定：
- 触发瞬间：短同步声；
- 传播过程：一条连续的材质／机械／空气纹理随变化展开；
- 完成：短收束音或音乐落点；
- 角色认出：可以短抽音乐，让脚步、呼吸、衣料、爪地声回到前景；
- 第二次异常：沿用声音母题但改变音高、密度或材质。

不要让镜头大推、BGM高潮、形变完成、角色尖叫四件事无因同时堆满。

## 8｜Escalation｜第二次不能平级重复

同一异常机制再次出现时，至少改变一项：
传播方向／材质／触发／对象／尺度／角色后果。

第一次只改变一个小物件，第二次可以扩展到角色周围；第一次角色自己先发现，第二次让另一个角色先看到。不能只换颜色后完整复制第一次。

## 9｜大纲阶段的精彩度检查

创意允许时，大纲至少检查一次：

“这一段有没有一个传统实拍很难直接完成、但生成视频可以在同一真实镜头里连续展示的可见事件？”

如果答案只有“加一点魔法光、视觉奇观、超现实感”，视为未设计。

如果答案能写成：
“金毛踩到南瓜旁的影子，影子先从地面立起变成另一只小幽灵轮廓，金毛仍在原位，贵宾先看见影子后退，金毛回头才发现。”
则通过创意候选门。

现实UGC、纪录感、用户明确要求纯写实时可以跳过异常机制，但 G-11 的 Camera–Event Coupling 仍适用于镜头设计。
