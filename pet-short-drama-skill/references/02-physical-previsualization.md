# 真实预演与物理 Gate｜Physical Previsualization

在导演分镜完成后、最终Prompt输出前，必须把整段按真实拍摄逻辑预演一遍。

## 1. 预演方法

像在真实场地里摆演员和摄影机：

- 角色从哪里进入
- 走几步到哪里
- 谁挡谁的路
- 两者之间是否有空间
- 道具在谁脚边
- 谁先触碰
- 触碰后物体朝哪个方向运动
- 摄影机从哪里能看到接触关系

不是问“画面好不好看”，而是问“现实里能不能这样发生”。

## 2. 高风险接触链

宠物与宠物、宠物与人、宠物与道具发生接触时，优先拆成：

`接近 → 对准/停稳 → 接触 → 响应 → 完成 → 分离`

### 例：贵宾拨球

安全路径：贵宾从球右侧接近 → 停在球旁 → 前爪从右向左拨球 → 球滚向喷泉。

不要让贵宾前爪从金毛腿下穿过再碰球。

### 例：管家给球

安全路径：管家到台阶前 → 弯腰把球放在石阶 → 松手 → 手臂完全退出 → 金毛低头叼球。

不要让人手和狗嘴同时包住球长时间重叠。

## 3. 宠物动作真实性

幼犬：

- 转向通常先转头/肩，再带动身体
- 上台阶必须迈步，不瞬移到高处
- 急停时身体会有轻微惯性
- 叼取前先低头和靠近
- 从坐姿起跑需有前倾/起身过程
- 四足移动时布料可以随速度拖拽，但不能无因变成完美披风

## 4. 道具物理

- 球被拨动后沿接触面滚动，遇边缘才掉落
- 落水后先在落点附近漂浮，不瞬间去池中央
- 湿物体保留湿润状态直到擦干/时间跳转
- 被拖拽的布料、玩具、绳子保持连接方向
- 已经取下/掉落的物件不能自动复位

## 5. 人物数量控制

当身份Reveal需要“工作人员”时，宁可使用少量固定站位角色，也不要让大量人物同时走位、转身、互动。

复杂背景人群只承担背景反应，不与主角发生精密接触。

## 6. 生成风险优先级

先修：

1. 角色穿模
2. 道具归属错误
3. 瞬移/换边
4. 人宠接触错误
5. 重复肢体/多余角色
6. 复杂运镜压过主要动作

不靠大段负面词解决；修改动作路径和镜头观察位置。
