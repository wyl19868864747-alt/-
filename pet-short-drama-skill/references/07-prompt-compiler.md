# 最终视频Prompt编译器｜Pet Short Drama Prompt Compiler

## 1. 总原则

最终模型提示词只写模型能拍到、听到、执行的东西。

禁止把创作者目标直接下发，例如：

- 强钩子
- 高能
- 高级感
- 电影感
- 爽感
- 情绪感
- 张力
- 视觉冲击
- 热门短剧感
- 信息推进快
- BGM突出情绪

把这些目标转成角色、事件、运镜、构图、光线、声音和时间变化。

## 2. 默认输出结构

### 【规格】
模型 / 画幅 / 时长 / 必要场景。

### 【参考】
使用真实存在的引用：

`@参考图1：只锁定主角身份、脸型、毛色和年龄比例；不参考背景和动作。`

若有产品图：单独锁定产品外观、标签、颜色、比例，不让人物图修改产品。

### 【角色/声线】
只写决定生成结果的身份、外观和声音。

### 【持续环境】
只写固定拓扑和持续光线，例如主门、红毯、喷泉、侧门的固定世界关系。

注意：动态人物站位不放在这里，动态站位逐镜写。

### 【时间轴】
先在后台对每一镜运行 `references/09-four-layer-shot-gate.md` 的画面／位置／构图／光影联审；明确每镜实际移动者，所有未移动角色包括出画者继续留原位。高风险近景保留一个位置地标或光向；若上下镜缺位移却跨区，不得编译成品。最终Prompt不附四层长表，只在动作正文自然写必要的站位和关键地标。

惊吓、突然发现、身份揭示等情绪转折前，先按 `references/08-perception-reaction-gate.md` 完成刺激源／视线／第一反射／识别的后台账本。最终Prompt要把这些可见状态编译进各自镜头正文，不能在末尾追加抽象“要有惊讶反应”。

每镜：

`【时间｜景别｜机位/运镜】`
`【构图：主构图＋必要辅助构图】`

正文中写：

- 继承的当前位置、朝向及关键注意力（角色此前在看谁／知道什么）；高风险时用最短一句标明本镜运动者与原地配角
- 当前动作；关键转折须写出触发、可达感知、第一身体反射、识别与动作完成态
- 必要接触/位移
- 摄影机如何观察
- 对白/声音
- 镜尾完成态需要影响下一镜时要写清

### 【BGM与环境声】
一条连续音乐基线＋少量事件节点。

## 3. 不附独立空间锁

空间连续性是每镜写出来的，不在结尾附：

“人物位置固定、禁止瞬移、不要越轴、保持连续”等大段补丁。

如果需要写这些，说明前面的分镜还没有编译完整。

## 4. 构图不替代站位

`【构图】`描述摄影机如何组织现有空间，不赋予人物新位置。

如果黄金分割要求主角到另一个区域，必须先让主角真实移动过去。

## 5. 参考职责

参考素材只承担被声明的职责。

一张人物图不自动锁定背景；一段动作视频不自动锁定人物身份；一个音频参考不自动控制画面。

## 6. 台词｜编译时不可丢失 G-05

在编译时间轴之前，先在后台按 `references/04-performance-voice-lipsync.md` 建立对白账本：逐句标明说话者、情绪阶段、剧情功能、预计发音／停顿时间、可看清脸的镜头和与上一句的因果关系。默认30秒带对白宠物短剧至少12句有效英文口语短句，用户明确无对白等例外按任务处理；不能在大纲写了12句、最终Prompt又压缩回4句。

先把约12–14句短对白分配到开场交锋、升级、反转、回击的合理时间窗；对嘴时宠物身体基本停稳，复杂位移动作另留时间。超过片长先缩短句子、移除重复视觉事件并重排分镜，不挤掉真实移动、Reveal或结尾Reaction／Consequence／Final State；仍不可兼容时说明冲突。

最终英文台词直接写进对应镜头实际时间窗，各出现一次，并明确唯一说话者和对嘴动作。音效喊声、喘气、标题、把同一句拆成多段均不算有效对白；无需在Prompt末尾附重复的对白总表。需要中文翻译时放在Prompt外。

## 7. 最终检查

逐镜问：

- 这是上一镜最后状态的继续吗？
- 位置变化有动作吗？
- 构图有没有偷偷移动角色？
- 接触先后成立吗？
- 运镜看得见关键关系吗？
- 默认30秒带对白短剧是否有至少12句有效台词，且每句都有新的情绪／剧情功能？
- 每句台词时长、换人／口型及动作反应是否都装得下？
- G-09：刺激源在角色可见／可听方向吗？摄影机有没有为了拍正脸把角色翻到背对刺激源？反应前基线、触发、第一可见反射、识别与台词是否分别可读？
- G-10：本镜四层后台联审通过了吗？谁在动、谁原地？切主角近景是否仍留在刚到的地点？静止配角有没有被带跑？光源／地标是否连续？
- BGM在关键节点真的有变化吗？
- 最后一段有Reaction、Consequence、Final State和停稳吗？
