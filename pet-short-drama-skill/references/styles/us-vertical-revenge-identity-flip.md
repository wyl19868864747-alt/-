# 风格｜美国竖屏爽剧 / 豪门 / 复仇 / 身份翻盘

## 核心

把欧美微短剧的高冲突关系机制移植到宠物IP：主角外表可爱低调，但拥有更高身份；反派因误判主动把羞辱做绝；主角不急着解释；权威证据出现后，原话或规则反弹到反派身上。

## 30秒结构

`开场已被拦/被羞辱 → 对方连续升级 → 主角冷静确认 → 对方召唤权威/做绝 → 权威反而向主角致意 → 身份Reveal → 主角短句回击 → 反派认知崩塌 → 回旋镖后果落地 → Reaction → 完成态`

## 关键机制

### 1. 高定位不是主角自己说出来

优先由第三方权威、空间、资产、工作人员态度或场景控制权证明。

### 2. 反派必须先把规则说清

例如：“VIP only”“Side gate’s around back.”

后面才能形成同一句规则的回旋镖。

### 3. 主角少说

主角回击越短，越需要画面先把身份铺实。

### 4. Reaction是爽点的一部分

Reveal后不能连续只拍主角。给反派一个短反应镜头，但随后画面权力回到主角。

### 5. Consequence必须发生

如果主角说“Your reservation just expired.”，背景要能看到牌子被撤、工作人员改变安排等实际后果。

如果说“Side gate’s around back.”，最后要看到反派真的被引向侧门，而不是台词说完就结束。

## 摄影视觉

Reveal前：

- 反派更靠近镜头
- 主角受遮挡或偏三分边缘
- 可用过肩、轻俯、前景压迫

Reveal后：

- 主角逐渐进入低机位
- 豪宅门、红毯、台阶形成引导线
- 中心对称/黄金分割用于权威画面
- 反派逐渐进入负空间

## 空间连续特别规则

这种片型最容易为了“主角身份变高”而偷偷把主角从左侧切到右侧、从门外切到楼梯。

禁止用身份变化代替物理位移。

主角要从红毯去台阶：必须拍到走向主门、到台阶前、迈上台阶。

## 结尾

建议：

`回旋镖台词 → 反派尴尬Reaction → 工作人员执行结果 → 反派被迫行动 → 小型额外尴尬/宠物反差 → 环境停稳`

不要在最狠一句台词后切黑。
