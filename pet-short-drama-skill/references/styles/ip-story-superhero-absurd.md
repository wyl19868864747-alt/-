# 风格｜宠物IP剧情 / 小事件大叙事 / 荒诞英雄

> **全局继承：** `../CORE_RULES.md`（G-01～G-10）；本文件仅定义本风格独有的事件结构与具体视觉案例。空间、物理、摄影、口型、声音、结尾和Prompt验收始终引用公共模块；如有冲突，以核心规则唯一拥有者为准。

## 核心

把一个很小的宠物日常事件，用大叙事规格处理，但事件本身必须简单、可读。

示例逻辑：扫地机器人拖走最爱的玩具 → 幼犬误以为朋友被绑架 → 披着意外勾到的毯子追击 → 拉回玩具 → 刚发表英雄宣言就被机器人轻碰一下。

## 结构

`异常出现 → 主角误判/赋予大意义 → 行动升级 → 真实小目标被看清 → 主角完成救援 → 英雄式自我确认 → 小型喜剧反拍 → 收束`

## 视觉

可以加入：

- 夜间冷暖反差
- 轻微漫画半调纹理
- 短暂运动拖影
- 英雄式低机位
- 大门、走廊、窗光形成框架和引导线

但宠物毛发、家具、道具和接触保持真实。

## 荒诞规则

荒诞来自“主角把小事当大事”，不是来自物理世界崩坏。

毯子可以因为奔跑勾到背上形成歪斜披风；不能下一镜无因变成完美服装。

## 表演与镜头释放

空间锁只约束真实位置，不降低本风格的动作与镜头变化。高风险移动完成、地标重新建立后，恢复低机位、贴地、斜前反打、前景遮挡、突然入画、景别跳变和短推拉。

恶作剧／互怼类节拍优先让角色持续“在演”：藏身、探头、侧眼、压低身体、耳朵变化、前爪挪动、披风或帽子产生物理变化、受惊后退、认出后瞪回去、主角得意的小动作。不能为了空间稳定把整段压成站桩对白。

## BGM

允许比事件更大的低鼓、铜管、弦乐推进；关键笑点时突然抽空或转成轻巧短音。

## 结尾

英雄台词后必须留反拍和停稳，不在主角刚说完时结束。
