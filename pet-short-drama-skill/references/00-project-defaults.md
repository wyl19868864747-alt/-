# 项目默认值｜Pet IP Defaults

## 默认主角

当用户引用“之前的金毛”时，使用同一只幼年浅金色金毛：圆脸、深色大眼、黑色湿鼻、自然垂耳、真实幼犬身体比例。若当前任务提供新的参考图，以新参考图为身份真源。

服装、围巾、胸兜、项圈不自动继承；只有用户明确指定或参考职责明确时才保留。

## 拟人边界

宠物可以：

- 说流利美式英语
- 有明确判断和戏剧意识
- 做停顿、侧眼、回头、审视、得意、尴尬、警惕等表演
- 在真实犬类动作中承担高身份角色

宠物仍然：

- 四足移动
- 真实坐下、趴下、叼取、摇尾、耳朵反应
- 不做复杂人类手势
- 不长期两脚站立

高身份来自场面调度、他人反应、摄影角度、空间占位、对白和权威关系，不靠把狗变成人形。

## 美国社媒语言

默认对白使用自然、短促的美式英语。台词追求口语节奏和角色性格，不使用过度书面化表达。

当用户需要中文理解，可在Prompt外另给翻译；英文视频执行块内只保留实际要朗读的英文。
