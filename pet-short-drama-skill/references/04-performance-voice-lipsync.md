# 宠物表演、声线与口型

## 1. 幼年金毛表演

动作小而清楚：

- 抬眼
- 耳朵轻抬/后收
- 停步
- 侧眼确认
- 头部缓慢转回
- 尾巴轻摆或突然加快
- 身体前倾、坐下、低头叼取

避免把“震惊、霸气、尴尬、得意”直接当动作。转成可见链条。

例：

尴尬：`看周围 → 嘴角收住 → 耳朵后收 → 视线移开`

认真回击：`先停稳 → 抬眼 → 短停 → 说一句 → 保持目光`

## 2. 主角声线

默认：幼年宠物拟人声线，偏高、柔软、清亮，带轻微鼻腔共鸣和气声；语言是自然美式英语。

不能听起来像成年男性或成年女性配音。

## 3. 口型

宠物说话必须满足：

- 脸清楚可见
- 身体基本停稳
- 下颌小幅自然开合
- 嘴角和口鼻毛发随音节轻微变化
- 偶尔露一点舌尖可以，但不长成人类嘴唇
- 说完恢复闭嘴或自然轻喘

不要在高速跑动、叼着大玩具、复杂转头、人与狗接触同时安排长句。

## 4. 台词容量

先按时间容量删句，不用“说快一点”硬塞。

双角色轮流对白要把换人和反应时间一起算。

短剧台词倾向：

- 一句只完成一个功能
- Reveal前可以让反派多说，主角少说
- 主角回击尽量短
- 最狠的一句之后留反应时间

## 5. 高身份反差

主角可以说出成熟、冷静的短句，但声线仍然是幼犬。

这类反差比给幼犬成年低沉男声更有效。

例如：

`“You done?”`
`“No. I own it.”`

说完后，结尾可以通过叼球、摇尾巴等真实幼犬动作把角色拉回宠物本体。
