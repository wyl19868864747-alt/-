# Scene & Tension Library｜情侣关系场景库

## Purpose

Choose a believable physical space that supports the selected adult-couple action and relationship temperature.

This is a **runtime scene asset library**, not a location moodboard.

Runtime:

`RELATIONSHIP TEMPERATURE → ACTION FAMILY → SELECT SCENE FAMILY → CHECK SPATIAL COMPATIBILITY / RISK → COMPILE SCENE GEOMETRY → IMAGE PROMPT / VIDEO PROMPT`

A scene must provide usable space, light, environmental anchors and camera positions for the relationship action. It must not be selected merely because the location sounds romantic.

Core rule:

`PRIVATE SPACE ≠ AUTOMATIC CHEMISTRY`

Romantic tension still comes primarily from:

`ACTION + GAZE + BODY DISTANCE + WEIGHT TRANSFER + EXPRESSION`

The scene only creates believable conditions for those signals to happen.

All people are adults. Scene routing is gender-neutral and must support Woman × Man, Man × Woman, Woman × Woman and Man × Man without assigning fixed gender roles.

---

# 1. Status Labels

Use:

- `VALIDATED CORE` — direct project generation / production evidence supports default use.
- `VALIDATED CONDITIONAL` — direct project evidence exists, but use only when the requested relationship state actually needs the space.
- `EVIDENCE-INFORMED` — supported by established couple / engagement / lifestyle photography practice and compatible with current action grammar.
- `CANDIDATE` — useful commercial scene family, but not yet strong enough for default routing.
- `HIGH-RISK` — scene can be useful, but reflections, low light, occlusion, coercive geometry or complex props raise generation risk.

Do not reopen broad benchmarking merely to promote every scene. Test only when the result would change a real routing decision.

# 2. Scene Compatibility Gate

Before selecting a scene, check:

## 2.1 Movement Space

- A09 `HAND-HOLD WALK`, A10 `PLAYFUL PULL-IN`, A11 `HALF-TURN INTO EMBRACE`, A12 `WALKING WAIST HOLD`, A13 `TURN-BACK LOOK` require enough open floor / path space.
- Do not route walking actions into a cramped sofa corner, narrow bedside gap or crowded bar booth.

## 2.2 Seating Support

- A14 `SOFA / SEATED LEAN-IN` and A19 `SEATED LAP-SIDE / CLOSE PERCH` require a physically readable seat / bench / bed edge / booth.
- Do not invent unsupported seated geometry.

## 2.3 Surface Support

- A18 `WINDOW / WALL-SUPPORTED CLOSE` requires a real wall, window edge, column, doorframe or other stable surface.
- Keep an open exit side visible so the pose does not read as trapped / coercive.

## 2.4 Face Visibility

- Avoid scene geometry that hides one adult face behind another body, furniture, strong shadow or reflective overlay.
- Identity-critical scenes should allow at least one clear 3/4 or front-side view for both people.

## 2.5 Contact Readability

- Waist / upper-back / hand contact should remain visible enough to communicate relationship intent.
- Furniture / counters / tables should not block the exact contact point that makes the action romantic.

# 3. Scene Risk Levels

## LOW RISK

Usually:

- simple open interiors;
- sofa / window / terrace spaces with clear geometry;
- parks / gardens / wide paths;
- outdoor café with simple table layout;
- golden-hour walks.

Typical risk:

- formal-pose drift;
- low relationship tension if action is weak.

## MEDIUM RISK

Usually:

- night city scenes;
- rooftops;
- bars / lounges;
- hotel interiors;
- beaches / waterfronts;
- busy urban streets.

Typical risk:

- low-light face drift;
- mixed color casts;
- background crowd / signage noise;
- wind / moving clothing / hair;
- complex environmental occlusion.

## HIGHER RISK

Usually:

- mirrors / reflective glass as a major visual element;
- car-side / door-open geometry;
- very narrow hallways;
- bed / deep lounge poses with overlapping limbs;
- aggressive wall-corner blocking;
- complex bar seating with tables / glasses / stools between bodies.

Typical risk:

- duplicate / reflected people;
- extra limbs;
- trapped / coercive relationship read;
- furniture penetration;
- identity drift in low light.

# 4. VALIDATED CORE SCENES

## S01 — WINDOW-SIDE｜VALIDATED CORE

**Why this space works**

A window naturally gives two adults a reason to stand close, turn toward each other or share a view. Side / directional light can shape both faces while the window edge provides usable support for A18 when needed.

**Spatial geometry**

- standing face-to-face / diagonal;
- side-by-side view toward window;
- one partner slightly nearer glass, the other open to camera;
- enough floor space for one half-step / turn.

**Best temperatures:** Sweet / Romantic / Flirty / Protective

**Compatible actions:** A01, A02, A03, A04, A05, A06, A07, A13, A18

**Camera readability:** medium two-shot / medium-close 3/4; side angle works well for profile separation.

**Physical color sources:** daylight sky, curtains, interior textiles, plants, wood, practical lamp if present.

**Light source:** directional window daylight; use soft side light rather than blowing out the entire window.

**Identity risk:** MEDIUM if window is over-bright; strong backlight can flatten / haze faces.

**Anatomy / occlusion risk:** LOW–MEDIUM; glass edge / curtains can cut through hands if badly placed.

**Video continuation value:** HIGH — supports lean-in, turn-back, face-side touch, slight release and cut-to-close reaction.

**Guard:** avoid using the glass reflection as a major second image of the couple unless explicitly desired.

# 12. Camera / Environment Risk Guards

## Glass / Reflection Guard

Large reflective windows can show unwanted duplicate people / interior reflections.

Default:

- use the window as light / background / edge;
- do not request a strong readable reflection of the couple unless the reflection itself is the concept;
- keep bright practicals from reflecting directly over faces.

## Night Identity Guard

For S05 / S10 / S11 / S12:

- keep faces exposed enough to preserve identity;
- do not let saturated neon cross facial landmarks;
- use city / practical lights as environment, not as hard masks on the face.

## Backlight / Haze Guard

For S01 / S04 / S14 / S16 / S19:

- avoid fully blown windows / sky behind both faces;
- keep directional side / back-side light rather than full silhouette when identity is priority;
- preserve clear skin tone and facial structure.

## Furniture Guard

For S02 / S03 / S08 / S12 / S13 / S17:

- table / cushions / bedding / stools must not cut through hands, waist contact or legs;
- simplify props before adding intimacy.

## Narrow-Space / Coercion Guard

For S09 / A18-type geometry:

- keep one visible exit direction;
- require reciprocal body lean / touch;
- never use both arms / walls to cage one partner.
