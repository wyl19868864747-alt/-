# Editorial Intimacy DNA｜高级情侣视觉 DNA

## Purpose

Raise the visual ceiling of AI Virtual Partner outputs so sensual couple images do not collapse into safe lifestyle selfies, generic home portraits, beige knitwear, or stock-photo romance.

This module does **not** add the abstract word `高级` to prompts.

It translates the desired result into visible production decisions:

`VISUAL TREATMENT + BODY LINE + WARDROBE MATERIAL + CAMERA DISTANCE + ASYMMETRY + LIGHT DIRECTION + RECIPROCAL EXPRESSION + NARRATIVE RESIDUE`

Core separation:

`RELATIONSHIP TEMPERATURE = WHAT THEY FEEL`

`VISUAL_INTIMACY_LEVEL = HOW BOLDLY IT IS SHOWN`

`VISUAL_TREATMENT_PROFILE = HOW THE IMAGE IS STAGED / PHOTOGRAPHED`

All people are adults. This module stays non-explicit.

# 1. Default Product Position

For final user-facing fantasy couple images, do **not** silently default to:

- bright apartment selfie;
- cream-on-cream knitwear;
- both people smiling at camera;
- symmetrical side-by-side hug;
- even flat front lighting;
- generic plants / sofa / beige lifestyle décor;
- stock-photo couple posture.

Recommended product default when the user does not specify a visual treatment:

`VT3 FRAGRANCE-CAMPAIGN TENSION + V3 BOLD SENSUAL`

If the user explicitly asks for cozy / UGC / everyday / selfie, the lifestyle route may override this default.

# 2. Research-Distilled DNA

High-value fashion / fragrance / editorial intimacy repeatedly uses:

1. **Documented intimacy rather than fabricated romance**
   - the frame feels caught inside a relationship event;
   - subjects are reacting to each other, not presenting themselves to the viewer.

2. **Narrative residue**
   - something appears to have just happened or is about to happen;
   - shirt collar moved, hair slightly displaced, jacket slipping from shoulder, unfinished gaze, body still turning.

3. **Asymmetric composition**
   - off-center faces;
   - one body closer to lens;
   - partial shoulder / curtain / doorframe foreground;
   - intentional crop of arm / torso;
   - negative space used to create tension.

4. **Directional, imperfect light**
   - side window light;
   - practical lamp + city light;
   - sunset edge light;
   - shadow shapes the face / body line;
   - avoid flat beauty fill across both faces.

5. **Material contrast**
   - skin against silk / satin / fine knit / crisp shirt / leather accent / linen / glass / metal;
   - tactile contrast makes the image feel styled without relying on decorative luxury objects.

6. **Reciprocal emotion**
   - both adults participate;
   - one initiates, the other visibly responds;
   - no “AI partner is seductive while USER looks emotionally absent.”

7. **Controlled imperfection**
   - loose hair strand;
   - slight clothing displacement;
   - relaxed hand pressure;
   - non-perfect symmetry;
   - skin remains real.

# 3. VISUAL_TREATMENT_PROFILE

## VT1 — RAW PRIVATE INTIMACY

Use for:
- candid;
- documentary;
- private-room / travel / window / terrace moments.

Visible DNA:
- close camera distance;
- slight off-axis framing;
- natural or mixed available light;
- loose hair / imperfect garment alignment;
- private gaze rather than camera-facing smile;
- captured reaction instead of pose.

Best with:
- Sweet / Romantic / Flirty;
- V1–V3.

Avoid:
- polished studio posture;
- equal front lighting;
- both subjects looking into lens.

---

## VT2 — REFINED EDITORIAL INTIMACY｜DEFAULT

Use for:
- premium final couple stills;
- attractive social hero images;
- modern fashion-editorial romance.

Visible DNA:
- medium-close / tight 3/4 couple framing;
- one face / shoulder slightly forward;
- clean asymmetry;
- clear body line;
- 1 strong contact point;
- 1 secondary response gesture;
- directional light with protected skin highlights;
- one refined wardrobe anchor + one softer support look;
- background simplified into shape / depth rather than décor showcase.

Default combination:
- V2 Sensual;
- reciprocal gaze;
- waist / lower-waist / upper-back contact;
- material contrast;
- no stock-photo smile.

This is the default “好看 + 不保守” route.

Use for:

- collar / shoulder / waist / hair-side interaction;
- direct mutual gaze or short eye→lip→eye;

- open-collar shirt;

- silk / satin / soft leather accent;

Avoid:

# 4. High-End Composition Rules

## 4.1 Camera Inside the Relationship

Prefer:

`camera feels physically close to the couple, as if it arrived during the moment`

Not:

`camera observes two models posing for a romantic campaign`

Executable signs:
- one shoulder larger in foreground;
- one face slightly higher / lower;
- one body angled toward lens;
- intentional crop at arm / hip / shoulder;
- close two-shot instead of centered full-body.

## 4.2 One Dominant Gesture

Use:

`ONE DOMINANT RELATIONSHIP GESTURE + ONE RESPONSE SIGNAL`

Examples:
- hand at lower waist + partner hand at collar;
- arm around waist + partner hand at chest;
- hand at upper back + partner gaze break;
- fingers near hair / neck-side + receiver softens eyes.

Avoid five simultaneous contact instructions.

## 4.3 Body Line Before Décor

The frame should first read:
- face;
- neck / shoulder line;
- torso angle;
- waist contact;
- leg / hip line when relevant.

Background exists only to support depth / light / context.

# 5. Wardrobe DNA

Do not use “luxury clothes” as an instruction.

Prefer specific silhouettes / materials.

## Refined sensual options

- fitted fine-gauge knit;
- open-collar crisp shirt;
- silk / satin slip-inspired dress with covered intimate areas;
- low-back / open-back evening dress;
- high-slit skirt or dress where scene supports it;
- tailored trousers + fitted top;
- soft leather jacket over fitted base layer;
- body-skimming jersey dress;
- structured dark overshirt with open neck;
- translucent outer layer over opaque base when appropriate.

## Anti-conservative guard

For V2+ do not default both people to:
- bulky cream sweater;
- loose beige overshirt;
- fully covered high neckline;
- identical soft knit textures.

Use at least one of:
- shoulder line;
- collarbone;
- open neck;
- back line;
- fitted waist;
- leg line;
- structured torso silhouette.

# 6. Color / Material Direction

“高级” should usually come from **fewer stronger relationships**, not more colors.

Prefer:
- skin + one dark anchor + one soft support + one practical light source;
- wine / espresso / black / deep navy / dark olive / charcoal as anchors;
- ivory / stone / blush / sand / muted sage as supports;
- glass / metal / wood / textile providing material contrast.

Avoid default:
- cream person A + cream person B + cream room;
- every element warm beige;
- pastel-everything romance.

The Color Library still owns exact palette assignment.

---

# 7. Expression / Gaze DNA

High-end sensuality fails if only one adult carries the chemistry.

Hard rule:

`BOTH ADULTS MUST PARTICIPATE EMOTIONALLY`

Default:
- one initiates;
- the other receives and visibly responds;
- expressions are not identical;
- both eyes / mouth corners show relationship participation.

Useful pairings:
- focused attraction → restrained responding smile;
- direct gaze → brief look away → return;
- collar / waist pull → receiver softens eyes;
- near-contact → both reduce smile, hold gaze, then one gives a tiny mouth-corner response.

Immediate failure:
- Partner affectionate + USER blank;
- Partner sensual + USER looks at camera neutrally;
- both faces emotionally dead;
- identical pasted smile.

---

# 8. Lighting DNA

Prefer:
- side window light;
- sunset edge light;
- warm practical + cool exterior;
- lamp edge on cheek / shoulder;
- shadow gradient across one side of face;
- readable eye catchlight.

Avoid:
- flat office-like front light;
- evenly bright entire room;
- white haze;
- blown skin;
- “cinematic lighting” without physical source.

---

# 9. Scene Priority for Editorial Routes

Prefer first:
- hotel window;
- night city window;
- terrace at dusk;
- corridor / doorway with open exit;
- refined lounge corner;
- elevator / lobby edge;
- rooftop evening;
- private window seat;
- coastal balcony.

Use cozy home / sofa / kitchen only when:
- user asks for everyday / sweet / UGC;
- or the director route specifically needs documentary intimacy.

Do not let home-lifestyle become the universal default.

# 10. Anti-Stock / Anti-Low-Cost Guard

Reject / reroute when the result reads as:
- engagement-photo pose;
- real-estate lifestyle ad;
- influencer couple selfie when editorial route was requested;
- both smiling at camera;
- symmetrical embrace;
- overly clean beige home set;
- generic sofa cuddle;
- two people standing square to camera;
- wardrobe has no body line / material contrast;
- all emotion carried by one person.

Correction order:
1. expression reciprocity;
2. composition asymmetry;
3. body line / contact point;
4. wardrobe silhouette / material;
5. light direction;
6. scene only if still necessary.

`VT2 REFINED EDITORIAL + V2 SENSUAL`

---

# 13. Final Hard Rules

1. Do not use `高级 / premium / cinematic / luxury` as substitutes for visual design.
2. Do not default final fantasy couple images to cozy beige lifestyle photography.
3. Use narrative residue + asymmetry + body line + material contrast + directional light.
4. Both adults must emotionally participate.
5. More sensual does not mean more contact; unfinished distance is often stronger.
6. V2+ requires at least one visible styling / body-line cue beyond ordinary covered casualwear.
7. Keep one dominant relationship gesture.
8. Background décor never outranks faces / body geometry.
9. Avoid stock-photo smiles and centered couple posing.
10. Preserve identity, anatomy, adult mutual agency and non-explicit boundaries.

# 14. Concept-Image DNA Lock｜概念图视觉母版

The latest concept-image tests define the desired **visual ceiling** for the product.

When the user asks for:
- 高级;
- 奢华;
- 性感;
- 荷尔蒙;
- 暧昧;
- 大尺度;

do not treat those words as prompt content. Route them into the following visible DNA.

## 14.1 Desired Read

The final image should feel like:
- a fashion / fragrance campaign frame;
- a private adult relationship moment;
- visually expensive but not overloaded with luxury props;
- sensual through body line, skin, material, gaze and proximity;
- emotionally reciprocal;
- one beat before or after a more intimate action.

Reject the result if it mainly reads as:
- cozy couple portrait;
- engagement photo;
- tourist selfie;
- beige lifestyle ad;
- ordinary social-media couple snapshot.

## 14.2 Body / Skin Read

For V3 / V4 routes, require at least **two** readable body-line cues when physically compatible:
- shoulder / collarbone;
- upper-back / back line;
- fitted waist;
- side torso;
- leg line;
- open neck / chest line without explicit exposure.

Do not hide both adults inside bulky layers.

## 14.3 Wardrobe Direction

Preferred:
- silk / satin slip-inspired dress with intimate areas covered;
- low-back / open-back dress;
- fitted body-skimming dress;
- fitted bodysuit with opaque coverage;
- open-collar fitted shirt;
- fine-gauge fitted knit;
- tailored dark jacket / shirt with open neck;
- swimwear only in physically appropriate pool / coast / resort scenes.

Avoid as the default for sensual editorial routes:
- oversized cream sweaters;
- loose beige overshirts;
- high-neck fully covered knitwear on both people;
- matching casual couple outfits.

## 14.4 Contact / Geometry

Use one strong relationship gesture plus one response signal.

Preferred contact zones:
- rear waist;
- lower waist;
- side waist;
- upper hip;
- upper back;
- collar / chest-clothing edge;
- neck-side / hair-side touch when anatomy is stable.

Preferred body states:
- torso-to-torso close with slight offset;
- one body partially crossing in front of the other;
- seated side-perch;
- wall / window supported close with open exit geometry;
- half-turn pull-in;
- back-neck / near-whisper;
- breath-close unresolved hold.

Do not solve sensuality by adding many hands or complex limb overlap.

## 14.5 Expression / Hormonal Read

Both adults must carry the chemistry.

Use:
- focused partner-directed gaze;
- one brief eye→lip→eye cue;
- slightly softened eyelids;
- restrained mouth-corner response;
- lips relaxed or slightly parted only when natural;
- one adult initiates, the other visibly receives / returns the signal.

Hard fail:
`PARTNER HOT + USER COLD = FAIL`.

## 14.6 Composition

Prefer:
- medium-close / close 3/4 two-shot;
- asymmetric body placement;
- one face / shoulder slightly closer to lens;
- intentional crop at shoulder / arm / hip;
- partial foreground occlusion;
- body lines crossing diagonally through frame;
- camera positioned inside the relationship space.

Avoid:
- centered full-body pose;
- side-by-side equal-scale portrait;
- both looking at camera;
- evenly spaced couple composition.

## 14.7 Luxury / Expensive Read

Luxury comes from restraint:
- one strong material contrast;
- one physically sourced light direction;
- clean background depth;
- fewer objects;
- controlled surfaces: stone / dark wood / glass / metal / textured fabric;
- private hotel / night window / terrace / refined lounge / pool / resort / corridor / elevator edge.

Do not add logos, champagne, jewelry or designer props merely to signal luxury.

## 14.8 Color DNA

Preferred families:
- black / espresso / deep navy + warm skin + amber practical;
- wine / burgundy + charcoal / deep teal + cool city depth;
- champagne / nude / muted blush + dark anchor;
- bronze / sand / dark chocolate + sunset edge light.

Avoid:
- cream-on-cream-on-cream;
- pastel-everything;
- saturated red / purple used as a cheap sensual shortcut.

## 14.9 Default High-Desire Route

When user intent includes `高级 + 奢华 + 性感 + 荷尔蒙 + 暧昧 + 大尺度`, default to:

`VT3 FRAGRANCE-CAMPAIGN TENSION + V3 BOLD SENSUAL`

with:
- Moment = M03 / M10 / M12;
- Action = A01+T03 / A18 / stable A19 / A11;
- Expression = reciprocal E05 / E09 with G01 / G03;
- Scene = S05 / S13 / S12 / S19 / refined private interior;
- Camera = asymmetric medium-close / close 3/4;
- Wardrobe = fitted / open / low-back / silk-satin / tailored-dark support;
- Light = directional practical + exterior or sunset edge;
- Skin / identity = realistic and clearly readable.

If the user asks for the strongest non-explicit result, V4 may be used while preserving adult agency, coverage, anatomy and identity.

## 14.10 Hard Acceptance Gate

For V3 / VT3 or stronger, the final still should satisfy at least **5 of 7**:

1. visible body line beyond ordinary covered casualwear;
2. close body distance;
3. meaningful waist / hip / back / collar contact;
4. reciprocal expression on both adults;
5. asymmetric intimate framing;
6. private / refined scene with controlled material depth;
7. directional physically sourced light.

If fewer than 5 are present, treat the result as **TOO CONSERVATIVE / TOO GENERIC** and reroute before approval.
