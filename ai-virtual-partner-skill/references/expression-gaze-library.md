# Expression + Gaze Library｜情侣表情与眼神运行库

## Purpose

Translate relationship temperature into **visible, model-executable facial and eye behavior**.

This file does not own body pose or scene.

Runtime:

`RELATIONSHIP TEMPERATURE + MOMENT STATE + CURRENT ACTION GEOMETRY → SELECT GAZE PATTERN + EXPRESSION PATTERN → ASSIGN PERSON A / PERSON B RESPONSE → IMAGE PROMPT / VIDEO PROMPT`

Core principle:

`MICRO-EXPRESSION > EXAGGERATED PERFORMANCE`

All people are adults. Expression roles are gender-neutral.

---

# 1. Pattern Grammar

Use:

`GAZE TARGET + GAZE CHANGE + EYELID / EYE TENSION + BROW STATE + MOUTH CORNER / SMILE LEVEL + HEAD ANGLE + REACTION TIMING + RECIPROCAL RESPONSE`

Avoid vague labels such as:

- sexy
- seductive
- romantic face
- happy couple

Translate them into visible behavior.

---

# 2. Global Rules

## 2.1 Asymmetry Creates Believability

Default:

`PERSON A EXPRESSION ≠ PERSON B EXPRESSION`

One person initiates; the other reacts.

Useful chains:

- direct gaze + slight smile → brief look away → look back with restrained smile
- whisper → short reaction smile → eyes return to partner
- playful pull → surprise-softening → laugh settles → eye contact

Avoid two people making the same smile, same eyebrow movement and same head tilt at the same instant.

## 2.2 Keep Expressions Small

Prefer:

- 5–15% mouth-corner lift rather than broad grin;
- brief eye softening rather than exaggerated squint;
- small brow relaxation rather than dramatic eyebrow lift;
- short gaze shift rather than repeated eye darting;
- subtle head angle change rather than large neck movement.

Avoid:

- open-mouth laugh unless the moment specifically needs it;
- cartoon surprise;
- obvious “trying to look sexy” expression;
- prolonged half-closed eyes across the whole clip;
- permanent fixed smile.

## 2.3 Eye Contact Is a Relationship Signal, Not a Constant Pose

Mutual eye contact is useful because it strongly communicates interpersonal attention and attraction, but in video it should usually **change** rather than remain frozen.

Default rhythm:

`LOOK → RESPONSE → BREAK / SHIFT → RETURN`

## 2.4 Expression Must Follow Cause

Every facial change should have a visible reason:

- touch changes;
- partner approaches;
- whisper occurs;
- joke / playful pull occurs;
- partner looks back;
- distance closes;
- brief contact ends.

Do not animate random smiles with no relationship trigger.

# 6. Social Misread Guard

## Friends / Siblings

Risk:
- shoulder contact only;
- camera-facing smiles;
- no partner-directed gaze.

Correct with:
- G01 / G02;
- restrained reaction rather than social-camera smile;
- action-level waist / upper-back connection where appropriate.

## Coworkers

Risk:
- neutral eye contact + upright posture + conversational distance.

Correct with:
- shared private gaze + smaller distance + micro-reaction caused by touch / approach.

## Bodyguard / Client

Risk:
- strong person uses E08 but receiver shows no response.

Correct with:
- receiver returns gaze / touch / smile; keep both adults agentic.

## Parent / Child

Risk:
- one person over-soothes while the other appears passive / juvenile.

Correct with:
- age coherence + reciprocal adult gaze + equal agency.

## Trainer / Client

Risk:
- task-focused gaze / instructional expression.

Correct with:
- transition from task to G01 / G02 and romantic contact.

## Fashion Posing

Risk:
- both maintain E05 / direct stare with no cause / response.

Correct with:
- use a Moment timeline and reciprocal expression change.

# 7. Still Image vs Video

## Still Image

Select one immediately readable pair:

- M01 + G01 + E01 / E05
- M03 + G01 / G03 + E09
- M04 + G06 / G07 + E02
- M08 + G02 / G08 + E03
- M12 + G01 + E05 / E09

Do not describe a long expression sequence in one still.

## MiniMax H3 Video

Every explicit shot should define:

`CURRENT GAZE + CURRENT EXPRESSION + TRIGGER + CHANGE`

Example:

`direct mutual gaze + restrained smile → waist pull triggers brief look-away / reaction smile → gaze returns as distance closes`

Use one meaningful facial / gaze change per beat. Do not fill the prompt with facial micro-management.

Default useful chain:

`G01 + E01`
→ partner action
→ `G04 / G06 + E02`
→ renewed approach
→ `G01 + E05 / E09`
→ slight release
→ `G02 + E01 / E06`

# 8. Prompt Compile Rule

Bad:

`They look sexy, romantic and deeply in love.`

`Person A holds direct eye contact with a restrained closed-mouth smile. Person B briefly looks away after the waist pull, then looks back with a small reaction smile as both lean closer.`

Keep expression / gaze language shorter than the subject + relationship action description.

# 10. Dual-Response Chemistry Gate｜双向表情硬规则

Couple chemistry is invalid when only one adult carries the emotional read.

Hard rule:

`PARTNER AFFECTION + USER BLANK FACE = FAIL`

`USER AFFECTION + PARTNER BLANK FACE = FAIL`

For every couple still / video beat:

- both adults must be emotionally present;
- expressions must not be identical copies;
- one person may initiate, but the other must visibly respond;
- both people need partner-directed gaze or a clearly readable relational reaction;
- mouth corners / eyelids / head angle should show small but visible emotional participation.

Default pattern:

`INITIATOR SIGNAL → RECEIVER RESPONSE → SHARED RELATIONSHIP READ`

Useful pairings:

- focused attraction → restrained responding smile;
- direct mutual gaze → one brief gaze break → return with softened eyes;
- waist / collar pull → receiver softens eyes + slight mouth-corner lift;
- playful action → short reaction smile → reconnect;
- near-contact → both reduce smile, hold gaze, one gives a tiny response.

Immediate failure patterns:

- one partner is flirtatious while the other looks cold;
- USER looks into camera with neutral selfie face while PARTNER looks affectionate;
- intimate body distance but emotionally dead faces;
- both people wear the same pasted AI smile;
- one adult reads as passive mannequin / bystander.

Recovery order:

`GAZE TARGET → EYE SOFTNESS → MOUTH-CORNER RESPONSE → HEAD ANGLE → EXPRESSION BALANCE`

Do not first change Scene / Color / Partner when the actual failure is one-sided facial response.

For still images, one frame must already show reciprocity.

For video, each beat must preserve:

`CURRENT GAZE + CURRENT EXPRESSION + TRIGGER + RECIPROCAL RESPONSE`.
