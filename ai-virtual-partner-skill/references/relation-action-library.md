# Relation Action Library｜情侣关系动作库

## Purpose

Translate adult romantic chemistry into executable body relationships instead of generic pose labels.

This is a **runtime asset library**, not a pose encyclopedia. The Skill should select the smallest action family that best expresses the requested relationship temperature, then compile it into still-image or video geometry.

Runtime:

`RELATIONSHIP TEMPERATURE → SELECT ACTION FAMILY → COMPILE BODY GEOMETRY → IMAGE PROMPT / VIDEO PROMPT`

Core grammar:

`INITIATOR + BODY ORIENTATION + CONTACT POINT + WEIGHT TRANSFER + HEAD RELATION + GAZE + HAND PLACEMENT + INTIMACY LEVEL`

Optional runtime fields when useful:

`ENTRY STATE + EXIT / NEXT ACTION + CAMERA READABILITY + ANATOMY RISK + VIDEO CONTINUATION VALUE`

Do not prompt only with labels such as `back hug`, `romantic pose`, `sexy couple`, or `high chemistry` when body geometry matters.

All people are adults. Action roles are **gender-neutral**: Woman × Man, Man × Woman, Woman × Woman, and Man × Man routes use the same action grammar. The initiator is chosen from relationship logic / current body geometry, never from gender stereotypes.

Use:

- `VALIDATED CORE` — supported by direct project generation evidence and safe for default routing.
- `EVIDENCE-INFORMED` — strongly supported by established couple-photography / lifestyle posing practice and compatible with current project grammar; suitable for production when geometry is simple.

# 2. Global Action Rules

## 2.1 Relationship Readability

Every selected action should visibly answer at least two of these:

- who initiates;
- who reciprocates;
- where physical contact occurs;
- how personal distance changes;
- where each person looks;
- where body weight moves;
- what happens next.

A useful couple action is not two attractive people standing near each other. It creates a readable relational event.

## 2.2 Reciprocal Response

Default romantic actions should include:

`INITIATION + RECIPROCAL RESPONSE`

Examples:

- one partner pulls at the waist → the other leans in / touches shoulder;
- one partner whispers → the other reacts with a smile / gaze return;
- one partner takes a hand → the other follows with body weight.

Avoid one person acting while the other remains mannequin-still.

## 2.3 MORE TENSION ≠ MORE CONTACT｜VALIDATED

More contact does not automatically create more chemistry.

For romantic tension, preserve one or more unresolved elements:

- small face distance;
- eye contact before contact;
- hand that has just moved into place;
- body turning toward the partner;
- micro-pause before a payoff.

`BREATH-CLOSE` remains the current strongest validated tension layer.

## 2.4 Hands Carry Relationship Meaning

Hand placement changes social meaning.

General routing:

- shoulder / upper arm → safe, supportive, lower tension;
- waist / rear waist → clear romantic claim / stronger couple read;
- upper back / shoulder blade → secure, intimate support;
- face-side / jaw-side → higher intimacy, higher anatomy risk;
- interlaced hands → sweet / everyday / movement-friendly;
- neck-side → higher intimacy; use only when geometry is clear and platform/model allows.

Keep fingers relaxed. Avoid showing complex interlaced fingers directly toward camera when not necessary.

## 2.5 Avoid Formal-Portrait Drift

If bodies are upright, symmetrical, front-facing, equally spaced, and both gaze at camera, the result can become a formal portrait.

Correct by adding one or more:

- asymmetric weight transfer;
- one body turned inward;
- different head heights / angles;
- shared eyeline;
- action in progress;
- one hand changing contact point.

# 3. Core Default Action Families

## A01 — FACE-TO-FACE WAIST HOLD｜VALIDATED CORE

**Best temperatures:** Romantic / Flirty / Passionate

**Use:** Still Image ✅ | Video Start ✅ | Video Middle ✅ | Video Payoff ✅

**Grammar**

- initiator: either partner, slightly more active;
- body orientation: face-to-face, bodies close but not perfectly square;
- contact: one hand at waist / rear waist; reciprocal hand at chest / upper arm / shoulder;
- weight transfer: both shift slightly inward;
- head relation: one head slightly lowers while the other raises / angles;
- gaze: each other, not camera;
- hand placement: keep waist hand outside clothing silhouette and readable;
- intimacy: Romantic Tension → Passionate.

**Entry state:** standing close / side-facing / prior eye contact.

**Exit / next:** breath-close → face-side touch → slight pullback / smile → near-contact payoff.

**Camera readability:** strongest in medium two-shot / medium-close 3/4 angle.

**Risks:** waist penetration; face fusion if starting too close; static square stance becomes posed.

**Social misread:** low when gaze + waist contact are clear.

**Mitigation:** stagger feet / shoulders; show reciprocal touch; retain a small unresolved face gap.

**Video continuation value:** very high.

# 12. Social-Role Misread Guard

Before compiling a final prompt, check whether the geometry could read as the wrong relationship.

## FRIENDS / SIBLINGS

Common causes:

- shoulder-only contact;
- large body gap;
- both look at camera;
- no reciprocal gaze / weight transfer.

Correct with:

- waist / upper-back connection;
- partner-directed gaze;
- smaller shared personal space;
- asymmetrical lean.

## BODYGUARD / CLIENT

Common causes:

- one person stands rigid behind the other;
- protective stance without reciprocal touch;
- large strength / height contrast plus formal expression.

Correct with:

- receiving partner turns inward / touches forearm / waist;
- soften stance;
- direct eye contact / smile.

## TRAINER / CLIENT

Common causes:

- athletic scene + instructional hand placement;
- bodies face same task rather than each other.

Correct with:

- switch attention from task to partner;
- use romantic hand / gaze geometry.

## FORMAL POSED PORTRAIT

Common causes:

- symmetrical stance;
- both face camera;
- static arms;
- equal head height / spacing.

Correct with:

- action in progress;
- unequal weight;
- inward head / shoulder angle;
- shared eyeline.

## PARENT / CHILD

Common causes:

- large visual-age mismatch;
- one person fully envelops / cradles the other;
- receiving person's face / body appears juvenile.

Correct with:

- adult age coherence;
- equal agency / reciprocal touch;
- avoid cradling geometry.

# 13. Anatomy Risk Routing

## LOW RISK

- Shoulder / Side Lean
- Protective Side Embrace
- Hand-Hold Walk
- Turn-Back Look with simple hand contact

## MEDIUM RISK

- Face-to-Face Waist Hold
- Back Hug
- Forehead Close
- Walking Waist Hold
- Seated Lean-In
- Laugh Into Embrace

## HIGHER RISK

- Face-Side Touch
- Hair Tuck
- Half-Turn with linked arms
- Window / Wall-Supported Close
- Seated Lap-Side / Close Perch

If high-risk geometry is not essential to the user's requested feeling, choose a lower-risk family that preserves the same relationship temperature.

# 14. Prompt Compile Rule

Compile **physical facts**, not abstract judgment words.

Bad:

`very romantic, sexy, high chemistry, passionate couple`

Better:

`Person B keeps one hand at Person A's rear waist and draws them half a step closer; Person A shifts weight toward B and rests one hand on B's shoulder; both keep direct eye contact; their faces remain just apart; the bodies are slightly staggered rather than square.`

For video, add the action transition:

`waist hold → reciprocal shoulder touch → half-turn → reaction smile → breath-close hold`

Do not stack every available action into one prompt.

# 16. Library Expansion Rule

Add a new Action Family only when it contributes a genuinely new relationship geometry or transition function.

Do not add separate entries merely for synonyms such as:

- cuddle / snuggle / close hug;
- turn / spin / twirl when geometry is functionally identical;
- cheek-close / face-close when the actual contact / head relationship is unchanged.

Prefer a smaller set of reusable action families with clear routing metadata over a large pose list.

Future real production successes / failures should update:

- status;
- anatomy risk;
- model suitability;
- best video beat;
- social-role misread guard.
