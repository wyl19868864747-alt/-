## Commercial / Story Routing

- Audience：美国女性 28–38
- Core Decision Question：这件看起来利落的旅行夹克，隐藏口袋真的能装下常用旅行小件而不显得笨重吗？
- Top Hesitation：这么修身、口袋又不明显，容量大概只是噱头。
- Best Proof：同一件夹克中依次放入护照、手机、薄钱包、移动电源；每件都有明确入口/状态，拉链关闭后衣服轮廓仍自然。
- Primary Architecture：SA06 Discovery → Investigation → Reveal
- R-level：R2 True Reversal
- Wrong Answer：女二认为女主“没带包＝什么都没带”。
- Evidence 1：女主双手空着、身边没有包。
- Evidence 2：夹克轮廓利落，隐藏口袋几乎不可见。
- Micro Anomaly：女主手指找到侧缝里几乎看不出的拉链头。
- Reveal：从隐藏口袋直接取出护照。
- Reinterpretation：她不是忘了带东西，而是都装在夹克里。
- Commercial Payoff：继续把手机、钱包、移动电源分别装入其他隐藏口袋，证明不是“一只小口袋的巧合”。

## Exact Seedance Prompt

【开场总控】
一支高能、聪明、带轻喜剧反转爽感的美式TikTok原生30秒剧情广告，机场临登机压力推动节奏，人物表演自然利落，对白像真实美国朋友互怼，镜头快速但空间清楚。

【人物、空间与产品锁定】
Maya：30–35岁高颜值美国女性，深棕色长发，年轻利落，穿同一件炭黑色女士旅行夹克；她冷静、自信，不炫耀，知道朋友即将误判她。

Rachel：30–35岁高颜值美国女性，金棕色中长发，现代休闲旅行装；她直率、反应快，负责提出质疑并验证，不递交产品、不与Maya发生复杂肢体交叉。

两人位于现代美国机场登机口旁的候机区。同一排座椅、同一小桌/行李置物台、同一登机通道关系全片保持稳定。背景旅客有自然轻微活动，不抢主剧情。屏幕和登机牌不要出现需要准确读取的复杂文字。

夹克固定为同一件：
炭黑色、臀上长度、轻量哑光织物、前中拉链、利落修身但不紧绷；两侧接缝各有一个隐藏竖向拉链口袋，内侧左右各有一个隐藏拉链口袋。全片不改变颜色、长度、领型、拉链位置、口袋位置和面料。

本条只证明一个卖点：
隐藏拉链口袋可以分散收纳常用旅行小件，同时保持自然利落的穿着轮廓。

不表达防水、防盗、保暖、承重等其他能力。

【30秒剧情发动机】
错误判断：Rachel看到Maya两手空空、身边没有包，认定她忘了旅行必需品。

真实答案：Maya没有忘，她把常用小件分散装进了夹克隐藏口袋。

反转不是一句台词，而必须通过：
错误判断 → 两个可见证据强化 → 微小异常 → 护照Reveal → 再次质疑 → 多口袋Proof → Rachel信服。

【空间与轴线】
两人主要主轴为 Maya ↔ Rachel。
连续对话镜头固定在同一180°半区。
先建立双人中景，再在同侧完成Maya近景、Rachel反打、夹克操作近景。
禁止无理由越轴。
任何夹克口袋特写仍保持与人物身体左右关系一致。

【0–3秒｜强Hook：临登机 + 明确错误判断】
第一帧已经在事件中。

机场登机提示音响起，画外广播自然提醒即将开始登机，不显示复杂可读文字。

双人中景。

Maya已经站起，双手空着，身边没有手提包、背包或小包，只穿着那件炭黑色旅行夹克。

Rachel刚准备跟她走，突然停住，视线快速扫过Maya双手、座位和地面。

Rachel立刻问：
“Where’s your bag?”

Maya没有解释，只平静看她一眼。

【3–6秒｜冲突继续：旧判断被强化】
同侧Rachel中近景。

Rachel再次扫过Maya身边：
没有包；
Maya双手仍然空着；
夹克轮廓利落，侧面看不到鼓胀的大口袋。

Rachel半笑半急：
“You forgot everything.”

切Maya近景。

Maya很淡地说：
“No, I didn’t.”

不要提前做得意表情。

【6–9秒｜第二证据：看起来真的什么都没有】
同侧双人中景稍收紧。

Rachel朝Maya夹克上下看一遍，明显找不到包和外露口袋。

她指一下Maya空着的双手：
“You literally have nothing.”

Maya不争辩。

她只把右手移到夹克右侧缝线附近。

【9–11秒｜延迟 / Micro Anomaly】
右侧夹克中近景。

Maya的手指沿侧缝移动，停在一个几乎融入接缝的小型拉链头上。

保持约0.5秒短停顿。

Rachel的视线第一次从Maya的脸落到那个拉链头。

她没有说话。

这个短停顿必须让观众产生：
“那里居然有个口袋？”

【11–13秒｜第一次爆发 / Reveal】
硬切夹克右侧操作近景。

夹克被Maya身体真实支撑，布料自然下垂。

Maya用右手拉开隐藏侧缝拉链。

拉链沿真实轨道打开。

她从口袋中直接取出自己的护照。

动作链：
找到拉链 → 拉开 → 手进入口袋 → 护照离开口袋 → 手完全拿出。

护照不能穿过布料。

切Rachel Reaction近景。

Rachel眉毛短促抬起，嘴唇轻分，停半秒：
“Okay…”

【13–16秒｜质疑升级，不立刻信服】
Rachel很快恢复判断，轻轻点一下那只口袋：
“One pocket. Cute.”

她转头看向旁边置物台。

台面从前面镜头开始就合理存在三件物品：
一部手机；
一个薄钱包；
一个小型移动电源。

Rachel看回Maya：
“What about the rest?”

她不把物品递给Maya，只用视线和手势指向置物台。

【16–21秒｜第二次爆发 / 多口袋Proof】
进入短促、清楚的三段动作链，每段只完成一个高风险接触。

16–17.5秒：
Maya自己从置物台拿起手机。
切同侧左侧夹克近景。
她拉开左侧隐藏拉链口袋，把手机完整放入口袋，再拉上拉链。
手机从台面消失后只能存在于这个口袋。

17.5–19秒：
Maya自己拿起薄钱包。
切夹克内侧近景，她用左手轻拉开前襟，让内侧结构可见；另一只手打开一个内侧拉链口袋，把钱包放入，再拉上。
钱包不能穿过衣服。

19–21秒：
Maya自己拿起移动电源。
切另一侧内袋近景。
打开 → 放入 → 拉上。

三件物品全部有明确起点、入口和终点。
不做多人递物。
不让物品瞬移。

【21–24秒｜延迟Reaction：轮廓检查】
切Rachel中近景。

她这次不看Maya的脸，先认真扫过夹克正面和侧面轮廓。

夹克仍然自然垂落，没有夸张鼓包，也没有物品形状穿出布料。

Rachel向前微微探身，但不触碰Maya身体。

短停顿约0.5秒。

她低声：
“Wait…”

再切Maya平静近景。

Maya只是轻轻耸一下肩。

【24–27秒｜真正反转 / 旧规则被打破】
同侧双人中近景。

Maya把护照重新放回最初的右侧隐藏口袋：
打开拉链 → 护照进入 → 手离开 → 拉链关闭。

现在四件物品状态分别为：
护照 = 右侧隐藏口袋；
手机 = 左侧隐藏口袋；
钱包 = 一个内侧拉链口袋；
移动电源 = 另一个内侧拉链口袋。

Maya双手再次空下来。

她看向Rachel：
“Still think I forgot my bag?”

Rachel看着她空着的双手，再看夹克，终于笑出来：
“Okay. I need that.”

信服来自刚刚完成的Proof，不来自突然夸张震惊。

【27–30秒｜无文字高清产品Hero CTA】
剧情硬切结束。

进入独立STYLIZED COMMERCIAL MODE。

只展示同一件炭黑色旅行夹克的高清产品Hero Shot，夹克占画面主体，正面略带三分之四角度，完整看到前中拉链、利落版型和隐藏口袋所在的自然接缝结构；质感清楚、面料真实、轮廓高级。

可以使用极轻推近或稳定定格。

不要人物对白。
不要生成任何CTA文字。
不要生成按钮、价格、Logo或乱码。
只让高清产品本身收尾。
