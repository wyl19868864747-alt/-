# 1. Test Fixture｜固定不变量

## 产品
透明玻璃沙拉酱摇摇瓶：
- 直筒透明玻璃瓶身；
- 哑光黑色旋拧主盖；
- 主盖顶部只有一个小型翻盖倒液口；
- 全片只允许 1 个瓶体、1 个主盖、1 个翻盖。

## 可见初始状态
瓶内已经装有明显分层的透明油醋汁：
- 上层：清晰金黄色油层；
- 下层：深色醋汁与可见香料颗粒；
- 两层边界必须肉眼可读。

这样避免上一轮“乳白浓稠液体看不出 Before/After”的 Proof Fixture 问题。

## Core Decision
一个容器能否把已经分层的沙拉酱直接摇匀，并从同一瓶中完成上桌倒取？

## Best Proof
`清晰分层 → 盖紧摇匀 → 两层真正变成均匀液体 → 打开真实翻盖倒液口 → 连续倒到沙拉 → 回正`

## 时长
15 秒。

原因：单一产品 + 单一强 Proof，15 秒足够，不为 30 秒填剧情。

## 人物
同一位约 30–35 岁美国女性，深棕发，自然好看、真实皮肤。人物身份不变；服装可接受轻微风格化，但不能抢产品。

## 地点
**同一个现代中性住宅厨房。**

这是测试控制变量：生产环境中 Location Router 可以按 Style 调整地点，但本轮故意锁同一厨房，避免把“换场景”误判成“Style 生效”。

## 全片固定剧情主事件
1. 她看到瓶内明显分层；
2. 拿起并盖紧；
3. 真实摇匀；
4. 停下确认液体已均匀；
5. 打开小翻盖；
6. 从真实倒液口连续倒到沙拉；
7. 产品 Hero 收尾。

三条禁止改写以上事件。

# 2. ST01｜美式原生手机实拍风

## Seedance Prompt

### 【开场总控】
一支 15 秒美国社媒原生剧情带货广告，手机实拍质感，自然窗光与真实生活细节，轻手持跟随，像真实用户在家现场演示而不是传统棚拍广告。

### 【主体、空间与产品锁定】
同一位约 30–35 岁美国女性，深棕发、自然真实皮肤，日常浅色上衣；同一个现代中性住宅厨房。透明直筒玻璃沙拉酱摇摇瓶，哑光黑色旋拧主盖，主盖顶部只有一个小型翻盖倒液口；全片只有 1 个瓶体、1 个主盖、1 个翻盖。开场瓶内上层是清晰金黄色油层，下层是深色醋汁与香料颗粒，两层边界明确。

### 【分镜描述】
**0–2.5s**｜厨房台面中近景，轻手持。她看到瓶内明显分层，视线从上层油扫到下层醋汁，眉头轻收，直接伸手拿起瓶子。

**2.5–6s**｜镜头自然跟住双手。主盖和翻盖均处于关闭状态，她连续有力摇瓶；透明瓶内两层液体从清晰分界逐渐真正混合成均匀油醋汁，过程持续可见，不用切镜遮掉状态变化。真实液体晃动声。

**6–9s**｜她停下，把瓶子放回台面，看见液体已经均匀，眉毛轻抬、嘴角出现短促满意笑意；镜头轻微靠近瓶身确认结果。

**9–12.5s**｜她打开主盖顶部的小翻盖倒液口，倾斜瓶身，从真实开口向沙拉连续倒出一股均匀沙拉酱；镜头贴近真实倒液口与连续液流。

**12.5–15s**｜瓶子回正放在沙拉旁，轻手持自然稳定下来，高清产品 Hero，厨房仍保持真实生活状态，无生成文字。

### 【生成控制】
- 产品外观、数量、盖体结构全片不变。
- 摇匀前必须清晰可见两层；摇匀后旧分层状态结束，不再恢复。
- 只能从已打开的小翻盖倒液口出液。
- 不新增量杯、额外瓶盖、第二个瓶子或虚构刻度。
- 不用广告棚光，不做过度电影调色。
- 不生成 CTA 文字、乱码或虚假商品标签。

# 3. ST02｜高端静奢广告风

## Seedance Prompt

### 【开场总控】
一支 15 秒高端静奢产品剧情广告，低饱和克制色彩、精致材质光与充足留白，镜头稳定而精准，以慢推和微距细节让同一件日常产品呈现安静、昂贵的观看质感。

### 【主体、空间与产品锁定】
同一位约 30–35 岁美国女性，深棕发、真实皮肤，简洁米白服装；同一个现代中性住宅厨房，只通过画面秩序、材质和光线完成静奢视觉。透明直筒玻璃沙拉酱摇摇瓶，哑光黑色旋拧主盖，主盖顶部只有一个小型翻盖倒液口；全片只有 1 个瓶体、1 个主盖、1 个翻盖。开场瓶内上层清晰金黄色油层，下层深色醋汁与香料颗粒，两层边界明确。

### 【光影与成像】
低饱和米色、浅灰与深木中性色；柔和但有方向性的侧后方主光在玻璃边缘和黑色盖体上形成细薄高光，背景暗部干净有层次，不靠奢侈道具制造高级感。

### 【分镜描述】
**0–2.5s**｜稳定近景缓慢推进透明瓶身，两层液体界面清晰。她进入画面，目光停在分层边界，动作克制地拿起瓶子。

**2.5–6s**｜稳定中近景配合极轻微侧向滑动。主盖和翻盖均关闭，她有节奏地摇瓶；玻璃瓶内金黄油层与深色醋汁逐渐融合成均匀液体，整个混合过程保持可见，材质高光沿瓶身移动。

**6–9s**｜微距确认均匀后的液体状态，镜头再轻推到她的反应：眉眼放松、轻微呼气、很短的满意神情，不夸张。

**9–12.5s**｜她打开顶部小翻盖，镜头切到精致微距；瓶身缓慢倾斜，一股连续均匀的沙拉酱从真实倒液口落到沙拉表面，玻璃、液体与食材纹理清楚。

**12.5–15s**｜瓶子回正，稳定产品 Hero；大量留白，背景安静，最后轻微慢推，无遮挡、无生成文字。

### 【生成控制】
- 产品与 Proof 状态和 ST01 完全一致，风格不得改写功能。
- 不增加金色 Logo、水晶、珠宝、豪车等“奢侈符号”。
- 摇匀过程不可通过切镜跳过。
- 只能从真实小翻盖开口倒液。
- 不复制、变形或放大产品。
- 不生成 CTA 文字、乱码或虚假商品标签。

# 4. ST05｜超现实创意广告风

## Seedance Prompt

### 【开场总控】
一支 15 秒真实摄影底座上的超现实创意广告，现实厨房与产品保持可信，只加入一个清晰的空间奇观机制：产品和人物始终真实稳定，背景空间在关键 Proof 时发生受控异常，形成强烈视觉记忆。

### 【主体、空间与产品锁定】

### 【超现实机制锁定】
全片只允许一个超现实机制：**摇瓶过程中，瓶子后方的厨房空间以瓶身为视觉中心发生短暂、平滑的径向拉伸，橱柜线条与背景纵深向外延展；瓶子、双手和液体物理状态完全保持真实。液体完成均匀混合的瞬间，背景空间干净地恢复正常。** 不再加入第二种奇观。

### 【分镜描述】
**0–2.5s**｜真实厨房中近景，先建立正常空间。她看见瓶内明显分层，眉头轻收，伸手拿起瓶子；相机保持真实摄影透视。

**2.5–6s**｜她盖紧并连续有力摇瓶。玻璃瓶内两层液体真实逐步混合；同时仅背景橱柜、墙面和空间纵深围绕瓶身发生受控径向拉伸，像现实空间被搅动，但瓶子、手和人物完全不变形。液体变为均匀状态的瞬间，背景空间立刻恢复真实比例。低频空间拉伸 SFX 后瞬间收回。

**6–9s**｜空间已完全正常。她停下确认均匀结果，眼睛迅速锁住瓶内，眉毛明显抬起后短暂停顿，再轻轻点头；镜头快速小推近产品结果。

**9–12.5s**｜她打开顶部小翻盖倒液口，在完全正常的真实厨房中倾斜瓶身，从真实开口连续倒到沙拉，明确证明产品真实使用，不再发生任何超现实变化。

**12.5–15s**｜瓶子回正放在沙拉旁，背景稳定，镜头轻微拉远形成干净产品 Hero，无生成文字。

### 【生成控制】
- 超现实只发生在背景空间，产品、人物、沙拉和 Proof 不得变形。
- 全片只有一种奇观机制，不增加悬浮、巨物、复制、液体飞出等第二视觉事件。
- 摇匀前两层明确，摇匀后均匀，状态变化必须真实可见。
- 只能从已打开的小翻盖倒液口出液。
- 产品尺寸、结构、数量全片稳定。
- 不生成 CTA 文字、乱码或虚假商品标签。

# 6. 当前结论

**Prompt-level regression = PASS。**

这三条不是三个不同故事，也不是三个不同场景：
- 产品相同；
- 人物相同；
- 地点相同；
- Core Decision 相同；
- Best Proof 相同；
- 时间线主事件相同；

真正变化的是 Style 对光线、色彩、镜头、成像和受控视觉机制的编译。

因此从文本导演链看，4.1 已经实现：

`SAME PRODUCT + SAME STORY + SAME LOCATION + DIFFERENT STYLE → DISTINCT PROMPT`

下一 Gate 必须是真实 Seedance 生成三条视频后再判断：
1. 第一眼是否真的能看出 ST01 / ST02 / ST05；
2. ST02 是否只是“更干净”而没有真正静奢视觉距离；
3. ST05 的空间奇观是否会污染真实摇匀 Proof；
4. 三条产品结构、液体状态与倒液物理是否稳定。

在真实成片回来前，不把本测试登记为 real-generation PASS。
