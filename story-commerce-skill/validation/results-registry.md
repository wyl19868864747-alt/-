# 6. PS-711｜7-Eleven 30秒剧情买量广告

DATE: 2026-09-05
MODEL: Seedance 2.5
DURATION: 30s
ROUTE: NEED-LED → PRODUCT TAKEOVER

## Passed
- 强事件开场；
- 短对白负载明显更合理；
- 情绪、Reaction、手持冲突感基本成立；
- 7-Eleven约6秒后接管广告；
- 冷饮/零食/热食/冰淇淋形成Product Proof Montage；
- BGM/SFX与事件节点配合成立；
- CTA与商业清晰度通过。

## One Critical Staging Error
约19秒本应：
`人物买完东西，从7-Eleven拎袋走出来`

实际画面却读成：
`人物背对镜头，朝7-Eleven走进去`。

根因不是元素缺失，而是Prompt只列：
`人物 + 购物袋 + 店面 + 离开 + 品牌露出`
没有先锁：START / END / FROM→THROUGH→TO / Actor Facing / Movement Vector / Camera Position。

抽象修复：
- Scene Staging Compiler；
- EVENT MEANING > ELEMENT PRESENCE；
- BLOCKING BEFORE CAMERA；
- ACTION DIRECTION > BRAND VISIBILITY；
- 复杂镜头先做Scene State Card。

FINAL STATUS: `PARTIAL / ACCEPTED WITH STAGING HOTFIX`

## Partial

新经验：
`VISIBLE STATE DIFFERENCE > THEORETICAL PROOF`

若以后证明Shake→Mix，应优先透明油醋汁等天然有两层视觉差异的Fixture。
