# Reversal Router｜反转路由

## 0. 用途

本文件只解决一个问题：

> **Story Architecture和Proof Plan已经确定后，这条广告到底需不需要认知变化；如果需要，是普通澄清/揭示/惊喜，还是值得支付完整成本的真反转？**

它位于 `story-architecture-router.md` 与 Proof Plan 之后，位于具体Story编写、Scene DNA原生化与Seedance动作编译之前。

默认从 **R0** 开始。不要先找R2，再因为条件不够被迫降级。

核心顺序：

`Story Architecture + Proof Plan → Reversal Value Test → Information Shift → Architecture Integrity → True Reversal Gate → Cost/Risk Tests → R0/R1/R2 Final`

Reversal是可选Creative Module，不是Story Architecture，不得篡改Primary Driver、商品事实或Proof。

---

# 1. 三档Reversal Level

## R0｜NO REVERSAL

不需要认知翻转。

适合：
- Proof本身已经足够清楚/有吸引力；
- Problem、Demonstration、Challenge、Experience等结构不需要额外认知变化；
- 时长不足；
- 高风险商业信息不适合先制造错误理解；
- 加反转只会增加复杂度。

**R0是默认状态，也是完全合格的商用结果。**

---

## R1｜LIGHT INFORMATION SHIFT

有认知变化，但不调用强反转DNA。

仅包含三类：

### Clarification｜澄清
`明确错误理解 → 验证 → 正确答案`

人物原判断被纠正，但事件性质没有被180°重新解释。

典型：SA03普通Misunderstanding。

### Reveal｜揭示
`未知 → 调查/观察 → 答案出现`

前面没有明确错误答案，只是不知道答案。

典型：SA06普通Discovery。

### Surprise｜惊喜/意外
出现真实、意外但未经过完整错误认知链的结果。

例如真实套装中发现已确认包含的额外配件。

R1禁止为了“更像反转”补造第二误导证据、微小异常或180°结构。

---

## R2｜TRUE REVERSAL

只有事件性质被重新解释，并通过全部Gate时才允许。

核心DNA：

`明确错误答案`
→ `至少2个独立可见证据强化`
→ `微小异常`
→ `Reveal`
→ `前文证据被重新解释`
→ `新判断/新目标`
→ `新行动`
→ `Product Proof / Commercial Payoff继续剧情`

R2是高成本、稀缺结构，不是默认“更高级”的版本。

---

# 2. Information Shift边界｜不要把所有“后来知道了”叫反转

| 状态变化 | 路由 |
|---|---|
| 没有必要的信息变化 | R0 |
| 原判断被验证纠正 | R1 Clarification |
| 原本不知道答案，后面知道 | R1 Reveal |
| 出现真实意外结果，但无完整错误认知链 | R1 Surprise |
| 前面整个事件被重新解释，且继续推动剧情 | R2 True Reversal Candidate |

关键区别：
- `SA03 ≠ R2`：错误判断被纠正通常只是Clarification；
- `SA06 Reveal ≠ R2`：未知答案出现通常只是Reveal；
- “平静→震惊”“不知道→知道”“问→解释”都不是True Reversal。

---

# 3. Gate 1｜Reversal Value Test

在设计任何误导前先问：

1. 信息变化是否直接服务 `Core Decision Question / Top Hesitation / Best Proof / Purchase Decision` 至少一项？
2. 它是否让消费者更容易理解产品，而不是更绕？
3. 不加反转时，Proof/Architecture是否已经足够强？
4. 这个反转是不是只为了“显得有创意”？

处理：
- 与商业判断无直接增益 → R0；
- 普通澄清/揭示已足够 → R1；
- 只有明确存在额外商业与情绪价值时，才继续检查R2。

---

# 4. Compatibility ≠ Necessity

`Reversal Compatibility` 只表示某种Story Architecture是否容得下反转；不表示本条广告应该反转。

必须单独判断：

`REVERSAL COMPATIBILITY: LOW / MEDIUM / HIGH`

`REVERSAL NECESSITY: NONE / LOW / HIGH`

只有Compatibility允许且Necessity足够高，才继续评估R2。

Architecture倾向仅作先验：
- SA01 Problem → Solution：LOW
- SA02 Demonstration：VERY LOW
- SA03 Misunderstanding：MEDIUM；默认R1 Clarification
- SA04 Challenge：LOW–MEDIUM
- SA05 Choice：LOW–MEDIUM
- SA06 Discovery：MEDIUM；默认R1 Reveal
- SA07 Social Conflict：HIGH潜力，但仍需Necessity
- SA08 Value Question：MEDIUM–HIGH；特别防历史价格反转偏置
- SA09 Experience：VERY LOW；默认R0

不能按Architecture自动启用R2。

---

# 5. Architecture Integrity Test｜反转不得篡权

加入信息变化后再次检查：

> **Primary Story Driver是否仍然是Story Architecture Router选定的那个？**

如果NO，说明Reversal已经绑架Architecture。

例如：
- SA06本应由Curiosity发动；为了R2强行建立强Wrong Belief，若Wrong Belief变成主要发动机，应返回Story Architecture Router重新判断SA03，而不是继续硬写SA06。
- SA02本应由Evidence发动；若为反转添加大量人物误判，导致验证不再是主剧情，应回退。

Reversal Router不得在后台偷偷重写Primary Architecture。

---

# 6. True Reversal Gate｜R2七项缺一不可

## 6.1 Wrong Answer

必须能用一句话写出：

> **反转前，观众明确相信什么错误答案？**

写不出来 → 不得R2。

## 6.2 Evidence Chain

至少2个**独立可见证据**强化同一个错误答案。

独立意味着改变事实线索，而不是同一表情越来越大。

无效：
`皱眉 → 更皱眉`

有效示意：
`A挡住门 + B把箱子藏到身后`

## 6.3 Micro Anomaly

真相出现前有一个小异常，让错误答案第一次出现裂缝。

优先是动作、对象位置、人物路径、关系变化或短句，而不是解释性旁白。

## 6.4 Reinterpretation

Reveal之后，前面的Evidence必须得到**新的意义**。

如果Reveal只是加入前面完全不存在的新规则/人物/能力，不是真反转。

## 6.5 Aftermath

反转后必须形成：

`新判断 → 新目标 → 新行动`

“大家震惊→CTA”不够。

## 6.6 Commercial Payoff

Aftermath必须继续服务：
- Product Entry
- Best Proof
- 主购买犹豫
- Purchase Decision
- Conversion

否则只是短剧彩蛋。

## 6.7 Emotional Reward

至少有一个真实可感知的：
`爽 / 过瘾 / 解气 / 好笑 / 惊喜 / 释然`

回看必须合理。

缺任一项 → 降级R1或R0。

---

# 7. Commercial Double-Duty Test｜R2每个Beat都要尽量一鱼两吃

R2通常会消耗：
- Wrong Answer
- Evidence 1
- Evidence 2
- Micro Anomaly
- Reveal
- Aftermath

这些Beat不能只负责“骗观众”。

主要Evidence Beat应尽量同时承担至少一项：
- 建立人物关系；
- 展示商品/使用情境；
- 暴露购买犹豫；
- 建立Story/Scene规则；
- 为Proof准备条件；
- 推进Product Entry。

如果大量时长只用于误导，Product Proof最后才被硬贴上去，R2失败。

---

# 8. Duration / Complexity Cost

True Reversal不是免费的，通常需要4–6个剧情Beat。

默认：
- `≤10s`：R0；极少量R1；通常禁止R2
- `10–15s`：R0/R1优先；R2只允许高度复用Beat的简单链
- `15–30s`：R0/R1为主，R2可正常评估
- `>30s`：可完整展开R2，但仍不因时长长而强制使用

如果R2导致：
- Product Proof被压缩；
- 人物明显增加；
- 空间/交互复杂度大幅上升；
- Seedance动作负载过高；

优先降级。

---

# 9. Temporary Misbelief Risk｜高风险事实不要先故意骗再纠正

如果错误答案涉及重要：
- 医疗/健康功效
- 安全结论
- 金融/费用义务
- 资格条件
- 法规/认证
- 真实价格/服务范围

提高R2门槛。

低风险可误判：
- 礼物送给谁
- 谁是主人/使用者
- 行为目的
- 归属/身份

高风险事实即使最终纠正，也不能用不必要的临时误导制造停留。

真实商业事实必须在最终理解中清楚、准确、没有残留歧义。

---

# 10. Historical Pattern Penalty｜特别防价格/核价套路回潮

历史RxPros等案例不能把Router重新拉回：
`价格误会 → 反复核价 → 震惊 → CTA`

规则：
- Core Decision不是Value/Price时，不因历史熟悉度建立价格反转；
- SA08也默认先比较R0/R1，不自动R2；
- 已确认固定价格等事实可以用R1 Clarification清楚表达时，不为了戏剧性升级R2；
- 同批广告避免重复相同Wrong Answer、Evidence链、Reaction、道具和Reveal。

---

# 11. Reversal Value Delta Test｜R2必须证明净收益

进入R2前比较：

`简单版 R0/R1` VS `强反转版 R2`

R2必须满足：
- 停留/情绪潜力明显增强；
- 商业理解不下降；
- Best Proof完整度不下降；
- Product Causality不下降；
- 时长/人物/交互/生成复杂度成本可接受。

如果只是“更有戏”，但商业信息更弱或生成风险明显变高 → 不用R2。

---

# 12. Reversal Removal Test｜最后再问一次有没有必要

R1/R2设计完成后，完整删除该Information Shift再比较：

> **删掉以后是不是更清楚、更有说服力、更好生成？**

如果YES：
- R2 → 降级R1/R0
- R1 → 降级R0

Reversal必须证明存在价值，不能因为已经设计出来就舍不得删。

# 14. Seedance编译规则

## R0

不写反转链。
按Primary Architecture + Proof Plan直接编译。

## R1 Clarification

只写真实的：
`原判断 → 验证动作 → 正确答案 → Decision Change`

禁止补假Evidence 2、微小异常和180°。

## R1 Reveal

只写：
`未知/异常 → 调查动作 → 线索 → Reveal → Decision Change`

禁止把“未知”硬改成错误答案。

## R1 Surprise

只写真实意外结果：
`正常行动 → 意外但真实结果 → Reaction / Decision Change`

禁止伪造前置误导。

## R2 True Reversal

编译：
`错误答案首证据 → 独立强化1 → 独立强化2 → 微小异常 → 人物先动作反应 → 短停顿 → 真相动作/短句 → 前文重解释 → 新目标/新行动 → Product Proof / Commercial Payoff → 情绪余震`

禁止直接写“此处反转”“观众发现”“180°反转”“更抓马”而不给具体动作。

---

# 15. Silent QA｜Reversal专项

每条广告都检查：
- [ ] R-level是从R0保守升级，而不是默认寻找R2
- [ ] Information Shift分类正确
- [ ] Compatibility没有被误当成Necessity
- [ ] Primary Architecture / Story Driver未被Reversal篡改
- [ ] Reversal没有损失Best Proof和Product Causality
- [ ] 时长和生成复杂度付得起当前R-level
- [ ] 高风险事实没有被不必要地临时误导
- [ ] Reversal Removal Test通过

仅R2再检查：
- [ ] Wrong Answer明确
- [ ] 至少2个独立可见Evidence
- [ ] Micro Anomaly存在
- [ ] Reveal重新解释前文，而不是新规则救场
- [ ] Aftermath形成新判断/新目标/新行动
- [ ] Commercial Payoff继续推动Product/Proof/Decision
- [ ] Evidence Beat通过Commercial Double-Duty
- [ ] Value Delta相对R0/R1为正
- [ ] 情绪奖励真实且回看合理

关键项失败：优先降级R-level，不要为了保住反转重写商品事实或堆更多剧情。

---

# 16. 最终原则

- **R0是默认且完全合格。**
- **R1是常见的信息变化增强。**
- **R2是少数高价值真反转。**
- Clarification、Reveal、Surprise不冒充True Reversal。
- 强反转DNA保留完整，但只有通过Router全部Gate才调用。
- Proof优先于反转；商业理解优先于戏剧炫技；生成稳定优先于无必要复杂度。
