# PERCEIVED VALUE CONTRAST ROUTER｜产品尺度 × 价格定位的反差表达路由

> 位置：Commercial Decision决策层。
>
> 目标：在Story Architecture之前先决定“这个产品应该被观众以什么视觉尺度、什么价值感、什么生活距离来感知”。不是改产品事实，而是决定广告应该把它**往大了看、往贵了感受、还是往日常舒服了理解**。

---

# 0. 核心思想

广告不只回答“卖什么”，还要回答：

> **这个产品第一眼给人的天然感知，应该通过什么反差被重新定义？**

三个高价值先验：

1. **小产品往大了拍**：耳机、戒指、手表、小型美妆、配件等天然视觉占比小，广告要主动放大细节、材质、结构和存在感。
2. **便宜/基础产品往贵了拍**：价格低、品类普通、日常感强的商品，广告要通过环境、仪式、搭配、光线和人物身份抬高感知价值，让“普通”变成“值得拥有”。
3. **本来就贵的产品往舒服、实用、生活化拍**：高价产品已经拥有身份/稀缺/奢华预期，继续堆金碧辉煌往往信息增益低；更有反差的是让它自然进入真实生活，证明“贵但不是供起来看，而是真的好用、舒服、顺手、值得长期拥有”。

这三个方向可以叠加，但永远服从：

`PRODUCT TRUTH > PERCEPTION FRAMING`

`CONTRAST ≠ FALSE CLAIM`

---

# 1. 两个正交判断轴

## AXIS A｜PHYSICAL SCALE CLASS｜产品视觉尺度

不是只看厘米，而是看它在真实使用画面中的“视觉占比”。

### A1 SMALL / MICRO
典型：
- 耳机
- 手表
- 戒指
- 首饰
- 小型美妆
- 小型3C配件
- 小瓶香水/护肤

默认策略：`MAGNIFY`。

广告中提高：
- 超近景 / 微距；
- 局部纹理；
- 接口、表面、边缘、结构细节；
- 缓慢旋转Hero；
- 纯背景隔离；
- 受控悬浮/拆解，仅限STYLIZED COMMERCIAL MODE；
- 产品从人体真实尺度切到放大Hero尺度，制造“小东西，大存在感”的反差。

原则：
> **Reality段保持真实尺寸，Commercial Hero段允许视觉放大。**

禁止为了“往大了拍”把小产品在剧情世界中真的生成成巨型物体，除非创意明确进入超现实规则。

### A2 MEDIUM
典型：服装、鞋、包、厨房小电器、普通消费品。

默认策略：`HUMAN SCALE + DETAIL PUNCTUATION`。

以人体/真实使用关系为主，关键材质/结构再用近景放大，不必每镜都宏观Hero。

### A3 LARGE
典型：家具、大家电、汽车、健身器材。

默认策略：`ENVIRONMENTAL SCALE`。

重点通过：
- 人体参照；
- 空间关系；
- 使用路径；
- 环境整合；
- 功能区域；

建立价值，不再机械“往更大拍”。

---

# 2. AXIS B｜MARKET VALUE POSITION｜品类内价格/感知价值位置

价格定位必须是**相对同品类市场位置**，不是只看绝对美元数。

若真实价格/定位未知：
> 标记`UNKNOWN`，不得自行把产品判成便宜或奢侈。

## B1 VALUE / LOW-COST / BASIC｜低价、基础、普通品类

默认策略：`VALUE ELEVATION｜往贵了拍`。

目的不是假装它真的是奢侈品牌，而是把它从：

`便宜 / 普通 / 随处可见`

重新感知为：

`有品位 / 值得长期拥有 / 设计感强 / 搭配价值高 / 生活品质的一部分`。

可使用：
- 高级但克制的空间；
- 上流/精致生活方式语境；
- 奢华衣帽间、精品酒店、私人住宅、画廊、会员俱乐部等高价值环境；
- 高颜值人物与高级造型；
- 更讲究的光线、材质微距、穿搭；
- 仪式化使用；
- 把“简单”表现为“克制、经典、百搭”的审美价值。

例如简单白T：
不是只拍“便宜又能穿”，而可以把它放进高级衣帽间，与剪裁西装、羊绒、大衣形成搭配体系，让它成为“整个衣柜最常被拿起的基础单品”。

但必须注意：
- 不虚构品牌身份；
- 不虚构材质；
- 不暗示不存在的高售价；
- “永恒、经典、百搭”属于创意定位/审美表达时可以使用，但不能包装成可验证的客观事实。

核心：
> **用环境和审美抬价值，不用假事实抬价值。**

## B2 MID / ASPIRATIONAL｜中价、进阶消费

默认策略：`ASPIRATION × PROOF BALANCE`。

同时给：
- 一点向上的生活方式；
- 一点真实使用证明；
- 一点产品细节；

避免只拍“高级”却没人知道为什么值得买，也避免只拍“实用”把品牌感拍没。

## B3 PREMIUM / LUXURY｜高价、本就高级

默认策略：`LUXURY NORMALIZATION｜往舒服、实用、生活氛围拍`。

天然认知已经是：
`贵 / 稀缺 / 高级 / 有身份`

广告应优先制造另一种反差：

`这么贵的东西，居然可以这么自然、舒服、顺手地进入生活。`

重点展示：
- 真实使用；
- 舒服、放松的生活状态；
- 实用性；
- 人体/空间中的自然融合；
- 材质与细节，但不过度炫耀；
- 高级感来自克制、留白、触感、动作和生活秩序；
- “我真的每天会用/穿/戴它”，而不是“我把它供在玻璃柜里”。

典型场景：
- 高级住宅早晨；
- 周末旅行；
- 私人晚餐；
- 酒店套房；
- 轻松通勤；
- 真实穿着/佩戴/使用。

例如贵重手表：
不要只有黑金背景+旋转表盘；可以从早餐、卷袖、开车前看时间、晚餐等自然动作中证明它与生活融合，再用微距Hero收细节。

例如高价设计师服装：
不要只拍红毯和宫殿；可以拍人物自然走动、坐下、交谈、进入真实社交空间，让“高价”通过舒适、自信和实用场景被合理化。

核心：
> **贵已经是已知信息，广告要补的是“为什么它值得真正生活在我身边”。**

# 3. SCALE × VALUE组合路由

两个轴可以组合。

## Small + Value
`MAGNIFY + VALUE ELEVATION`

小而便宜的东西最容易被忽略。
策略：
- 微距把它拍得像值得收藏；
- 高级环境抬价值；
- Hero把细节做大；
- Reality镜头再落回真实使用。

## Small + Luxury
`MAGNIFY + LUXURY NORMALIZATION`

例如高价手表、戒指、珠宝：
- 仍然需要宏观细节和旋转Hero；
- 但剧情主体不要一直“供起来展示”；
- 更多自然佩戴、生活动作、舒适关系。

## Medium + Value
`VALUE ELEVATION + VERSATILITY`

例如基础白T、普通鞋、简单包：
- 往高级衣橱/高级搭配体系里放；
- 用多场合/穿搭适配建立“基础却不可替代”的感知。

## Medium + Luxury
`LIVED-IN LUXURY + PRACTICAL ELEGANCE`

例如设计师服装、高价包：
- 不只拍贵；
- 拍穿着、移动、社交、取物、坐下、真实使用；
- 高级感从生活秩序和实用性中长出来。

## Large + Value
`ENVIRONMENTAL SCALE + VALUE ELEVATION`

通过更好的空间整合和生活方式，让大件“看起来不廉价”，但不夸张尺寸。

## Large + Luxury
`QUIET UTILITY`

例如豪华车、高端家具、大家电：
- 少一点炫耀式奢华；
- 多一点安静、舒适、方便、真实日常；
- 用细节和生活体验说明“贵得有理由”。

# 4. PERCEPTION GAP CARD｜决策层新增字段

每条广告在Product Decision Card中静默增加：

```text
PHYSICAL SCALE CLASS:
SMALL / MEDIUM / LARGE

MARKET VALUE POSITION:
VALUE / MID / PREMIUM / UNKNOWN

NATURAL FIRST IMPRESSION:
观众第一眼天然会怎么感知它？

DESIRED REFRAMING:
广告希望把它重新定义成什么？

CONTRAST DIRECTION:
MAGNIFY / VALUE_ELEVATION / LUXURY_NORMALIZATION / BALANCED / NONE

REALITY PRESENTATION:
真实使用段如何保持尺寸、价格感和生活逻辑真实？

COMMERCIAL HERO PRESENTATION:
产品Hero如何放大、悬浮、旋转、微距或环境化？

PERCEPTION PAYOFF:
看完后观众应该产生什么新的价值判断？
```

这个Card决定**视觉价值方向**，但不决定Story Architecture或R-level。

# 5. 与后续模块的权限关系

## 对Story Architecture
只提供价值表达方向。
不得因为“便宜往贵拍”就强行选身份剧情；不得因为“贵往生活拍”就强行SA09。

## 对Scene Router
可以影响Scene Fit：
- VALUE_ELEVATION可提高高级生活方式Scene的适配度；
- LUXURY_NORMALIZATION可提高真实住宅、旅行、通勤、生活Scene的适配度；

但Scene仍必须通过商业与因果Gate，不能只因“看起来贵”获胜。

## 对Camera / Hero
- SMALL优先更多微距、Extreme CU、材质细节与产品Hero；
- STYLIZED COMMERCIAL MODE可轻度悬浮/旋转；
- Reality段不改变真实物理尺寸。

## 对Performance
高价值反差优先让人物Reaction来自“认知被改写”，而不是夸张惊讶。

# 6. 保护规则

必须避免：
- 把便宜产品伪装成不存在的奢侈品牌；
- 用豪宅/私人飞机暗示错误价格或身份事实；
- 把小产品在Reality剧情里无理由巨型化；
- 把贵产品拍得“日常”到失去品牌高级感；
- 为了反差牺牲Best Proof；
- 用视觉高级感替代真实产品优势；
- 把“贵/便宜”当成绝对数值而忽略品类相对定位。

最终原则：

`SMALL → VISUALLY BIG`

`VALUE → PERCEIVED PREMIUM`

`LUXURY → LIVED-IN USEFULNESS`

但永远：

`PRODUCT TRUTH > PERCEPTION CONTRAST`
