# ST06 — Futuristic Sci-Fi Technology

VISUAL CORE: precise, advanced, systemic, geometric, controlled.
EXPOSURE / COLOR: cool neutrals, clean darks or bright minimal surfaces; selective high-purity accent color.
LIGHT: structured edge light and controlled reflections.
CAMERA / TEXTURE: exact slides, scanning pushes, symmetry, macro structure, stable orbit.
HOOK EXPRESSION BIAS: instant system behavior, transformation, interface consequence, or engineered reveal.
STORY / CTA EXPRESSION BIAS: concise, intelligent, system-like; CTA should feel precise rather than salesy.
ENVIRONMENT TENDENCY: modern minimal space, smart living, tech architecture, abstract system space.
AVOID: fake data, unreadable UI, gratuitous holograms.
COMPRESSED STYLE LINE: Futuristic technology advertising with precise geometry, controlled reflections, structured edge light, and stable scan-like camera movement.
