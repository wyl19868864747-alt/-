# PERFORMANCE × FACS COMPILER｜剧情带货表演与微表情动作库

## 0. 定位

本文件负责把已经确定的Story Beat编译成**人物可见、克制、可生成的表演动作**。

调用位置：

`Story Architecture + Proof + R-level + Scene/Location`
→ `Performance Intent`
→ `Gaze / Face / Head / Body`
→ `Dialogue / Next Action`
→ `Seedance Prompt`

核心原则：

> **先有事件，再有Reaction；先有Reaction目的，再选面部动作。**

FACS（Facial Action Coding System）本质上是描述可见面部运动的解剖编码系统，不是“一个情绪=一个唯一表情”的真值表。本文中的情绪组合只作为商业视频表演的**动作先验**，必须结合人物、语境、Scene和前后动作判断。

最终Seedance提示词默认**不输出AU编号**，只输出人能看见的动作变化。

---

# 1. 表演优先级

每个Reaction按以下顺序编译：

`Trigger`
→ `Gaze Target`
→ `First Facial Change`
→ `Micro Pause / Release`
→ `Head / Body Response`
→ `Dialogue or New Action`

优先级：

`事件动作 > 视线 > 身体反应 > 关键微表情 > 台词语气 > 装饰性表情`

禁止为了“表演丰富”给每个Beat同时塞眉、眼、鼻、嘴、头、肩、手全部变化。

默认一个短Beat只保留：
- 1个明确视线变化；
- 1–2个主要面部变化；
- 0–1个必要身体变化。

只有特写或情绪转折镜头才增加细节。

# 2. FACS核心动作词典｜内部参考

以下AU只用于内部选择可见动作，不要求写入最终视频提示词。

| AU | 可见动作 |
|---|---|
| AU1 | 内眉抬起 |
| AU2 | 外眉抬起 |
| AU4 | 眉毛下压/眉心收紧 |
| AU5 | 上眼睑抬起，眼裂增大 |
| AU6 | 面颊抬起，眼周收紧 |
| AU7 | 眼睑收紧 |
| AU9 | 鼻部皱起 |
| AU10 | 上唇抬起 |
| AU12 | 嘴角向上拉 |
| AU14 | 嘴角单侧收紧/形成酒窝式拉紧 |
| AU15 | 嘴角向下 |
| AU17 | 下巴抬起/颏部收紧 |
| AU20 | 嘴角水平向外拉 |
| AU23 | 嘴唇收紧 |
| AU24 | 嘴唇压紧 |
| AU25 | 双唇分开 |
| AU26 | 下颌下降 |

常见基础组合只作参考：
- 快乐/真实愉悦：`AU6 + AU12`
- 惊讶：`AU1 + AU2 + AU5`，强时再加入`AU26`
- 愤怒/压怒：`AU4 + AU5/7 + AU23/24`
- 厌恶：`AU9/10`，可伴随`AU16/17`
- 悲伤：`AU1 + AU4 + AU15`
- 恐惧：`AU1 + AU2 + AU4 + AU5 + AU20`，强时再出现嘴唇分开/下颌下降
- 轻蔑：常以单侧`AU14`等不对称嘴角变化表达

**不要把这些组合当成跨人物、跨文化、跨语境必然成立的情绪指纹。**

# 3. AI视频默认强度规则

商业剧情默认使用：

`SUBTLE / LIGHT / MEDIUM`

除非故事明确要求且生成模型稳定，不使用持续MAXIMAL表情。

默认：
- 惊讶不等于长时间瞪眼张嘴；
- 愤怒不等于大喊、甩手、砸东西；
- 开心不等于全程露齿大笑；
- 尴尬不等于双手捂脸；
- 害怕不等于恐怖片表情；
- 反转不等于所有人同步震惊。

一个Reaction最好在`0.2–1.2秒`内完成主要变化，然后进入下一动作；需要喜剧停顿时可单独留`0.2–0.8秒`。

# 4. 商业剧情常用表情链｜可直接编译成画面语言

以下不是固定医学诊断，而是**可见动作模板**。根据人物、Scene和Beat删减，不要求全部出现。

## 4.1 怀疑 / 不信

`视线停在证据上 → 眉心轻压 → 眼睑微收 → 嘴唇轻压或单侧嘴角略紧 → 不马上说话`

适合：SA02验证前、SA03错误判断、SA05选择犹豫、SA08价值质疑。

## 4.2 困惑 / 没看懂

`视线在物体与人物之间切换 → 内眉轻抬同时眉心略收 → 嘴唇轻分 → 头部微偏`

重点是“寻找答案”，不是瞪眼。

## 4.3 轻惊讶

`眉毛快速抬起 → 眼睛短暂睁大 → 嘴唇轻分 → 立刻把视线锁回结果`

只持续很短，不保持张嘴。

## 4.4 难以置信

`先盯住结果 → 眉毛短促抬起 → 再轻皱眉复核 → 视线回到产品/对方 → 重新验证或问一句短句`

核心是“再确认”，不是单纯惊讶脸。

## 4.5 发现异常

`正在做原动作 → 动作突然停半拍 → 眼睛先移向异常点 → 眉心轻收或单侧眉轻抬 → 身体保持不动观察`

适合R2 Micro Anomaly；此处不要提前泄露真相。

## 4.6 恍然 / 理解

`眉心原有紧张松开 → 眼睛从证据移向人物 → 嘴唇轻分后合上 → 轻点头或开始新行动`

“理解”必须通过后续行动证明，不只靠脸。

## 4.7 压怒 / 恼火

`眉毛下压 → 眼睑收紧 → 嘴唇压紧 → 下颌轻收 → 视线保持目标`

不要自动加吼叫、摔东西、夸张翻白眼。

## 4.8 厌恶 / 排斥

`鼻翼/鼻梁短暂皱起 → 上唇轻抬 → 头稍后撤 → 视线短暂离开刺激物`

只在事件真的具有排斥/反感意义时使用。

## 4.9 担忧 / 紧张

`内眉轻抬并靠近 → 眼睑略紧 → 嘴角水平拉紧或轻抿 → 呼吸变短 → 视线快速检查关键对象`

适合Deadline、任务风险、产品是否失败前。

## 4.10 害怕

`眉毛抬起并收拢 → 眼睛明显睁大 → 嘴角向外拉/嘴唇分开 → 身体后撤或冻结`

剧情带货中默认低频使用；若轻度担心已足够，不升级为Fear。

## 4.11 失落 / 失望

`内眉轻抬并收紧 → 嘴角轻下压 → 视线落下 → 肩颈略松`

适合任务失败或选择落空，不要长时间哭丧脸。

## 4.12 尴尬

`先快速看左右/看旁人 → 视线下移或错开 → 嘴唇轻压 → 出现短促紧笑或轻收下巴 → 身体略缩`

高社交Scene可让尴尬通过“想维持体面”表达，而不是捂脸。

## 4.13 心虚 / 被戳穿

`原本直视 → 视线短暂移开 → 嘴唇压紧 → 吞咽/轻收下巴 → 再试图恢复正常表情`

不得仅凭此动作暗示违法、撒谎等未写明事实。

## 4.14 释然

`眉心和眼睑紧张先松开 → 呼气 → 肩膀下降 → 嘴角轻抬 → 重新看向产品/对方`

关键是“张力释放”，不是突然大笑。

## 4.15 满意 / 认可

`先看结果 → 眼周放松 → 面颊轻抬 → 嘴角小幅上扬 → 轻点头或继续使用`

适合Proof后的商业Decision Change。

## 4.16 开心 / 真正愉悦

`面颊抬起 → 嘴角上扬 → 眼周自然收紧 → 身体更开放`

强度服从Scene与人物，不默认露齿大笑。

## 4.17 克制好笑 / 憋笑

`嘴角先想上扬又压住 → 面颊轻抬 → 眼神短暂看向旁人 → 0.3–0.6秒停顿 → 再把注意力拉回事件`

适合deadpan喜剧；不要让笑抢掉Punchline本身。

## 4.18 轻蔑 / 不屑

`单侧嘴角略收紧/上提 → 下巴轻抬或头略偏 → 眼神停留很短 → 立即回到事件`

只适合明确关系冲突；不要把外貌、贫穷、年龄、族裔等当轻蔑对象。

## 4.19 专注 / 认真核验

`目光锁定操作点 → 眉心轻收 → 嘴唇自然闭合 → 头部减少多余移动 → 手部动作更精确`

Proof镜头中常比“情绪脸”更有用。

## 4.20 下定决心 / 坚定

`视线从证据抬回目标 → 眉眼稳定 → 嘴唇轻压后放松 → 轻点头 → 立刻执行下一动作`

Decision Change最终必须落到动作，例如拿起、选择、继续使用、下单/进入CTA逻辑。

# 5. Reaction Compiler｜从故事Beat自动选表演

每个需要Reaction的Beat先填写内部四项：

```text
TRIGGER:
人物刚刚看见/听见/确认了什么？

PERFORMANCE INTENT:
这次Reaction要让观众理解什么？

GAZE TARGET:
人物此刻具体看哪里？

NEXT ACTION:
表情之后人物要做什么？
```

再选最少必要的可见动作。

最终提示词采用：

`Trigger → gaze → facial change → micro pause/release → body/new action → line（若必要）`

例如不要写：

> 她非常震惊又难以置信，表情夸张。

应写：

> 她先低头盯住结果，眉毛短促抬起，嘴唇轻分；停半秒后重新看向产品，眉心轻皱，再做一次验证。

# 6. R0 / R1 / R2 的表演边界

## R0｜无反转

Reaction只服务：
- Problem变化
- Proof结果
- Choice
- Task Outcome
- Experience Preference
- Decision Change

禁止为了“情绪起伏”额外添加错误判断、可疑神情或提前铺反转。

## R1 Clarification

推荐：

`原判断的轻怀疑/确信 → 验证时专注 → 结果出现 → 短促理解/认可 → 新行动`

不要演成180°人格变化。

## R1 Reveal

推荐：

`未知/好奇 → 发现线索 → 注意力集中 → Reveal后短促恍然 → 新判断`

没有Wrong Answer时，不要让演员提前演“我被骗了”。

## R1 Surprise

推荐：

`正常状态 → 轻惊讶 → 快速恢复 → 立刻根据结果行动`

Surprise重点是短，不保持表情。

## R2 True Reversal

表演顺序：

`Wrong Answer阶段保持可信旧判断`
→ `Evidence阶段只强化旧判断，不提前泄露`
→ `Micro Anomaly：动作停半拍 + 视线先转`
→ `Reveal：先看真相，再看人`
→ `0.2–0.8秒认知重置`
→ `具体Aftermath行动`

R2最常见失败：演员在Micro Anomaly前就做“知道真相”的表情，导致反转提前泄底。

# 7. Scene Performance Modulation｜Scene只调表演方式，不改事件

若调用特殊Scene，FACS/Reaction动作仍由当前Beat触发，但强度与社会传播方式服从Scene DNA。

- **S01 宫廷**：克制权威；脸部小，等级Reaction逐层传递。
- **S02 高中**：反应较快；先看同伴/老师，再决定是否扩大Reaction。
- **S03 军营**：功能性压力；坏消息先停动作/收紧下颌，Proof后立刻给新命令。
- **S04 办公室**：保持职业体面；内部慌张通过扫视、压唇、停手表达。
- **S05 西部**：身体停顿和长静比脸部夸张更重要。
- **S06 Gala**：微表情权重高；用停杯、侧目、笑容轻僵、分布式Reaction。
- **S07 Mall**：先由走路/停步/重新拿起商品表现Decision Change，再补脸。
- **S08 Future**：高效冷静；系统异常后先复核，Proof后才出现轻微认可。
- **S09 Diner**：手上日常动作可继续，眼睛先偷听；Reaction横向传播，不同步转头。
- **S10 Competition**：Result先于Emotion；先看结果，再看Host/对手，再Reaction。
- **S11 Market**：可比Gala更公开，但仍通过拿、掂、靠近、重新伸手等行为证明立场变化。
- **S12 Train**：礼貌克制；笑容轻僵、整理外套、轻点头等比大表情更原生。

Scene Performance DNA不能把R0升级R2，也不能让所有人物自动使用该Scene最戏剧化表情。

# 8. 镜头与表情匹配

- 大全景：不要塞精细眉眼指令；优先姿态、停步、转身、站位。
- 中景：可写视线、头部、嘴角、肩颈等1–2个表演线索。
- 中近景/近景：可写关键眉眼与嘴部变化。
- 特写：只在Proof反应、Micro Anomaly、Reveal后认知变化等真正需要时使用。

若镜头看不清某个表情动作，就不要写。

**表情细节必须服从景别可见性。**

---

# 9. 对白与表演同步

默认顺序：

`先看到 → 先反应 → 再说话`

但人物故意抢话、隐藏Reaction等属于剧情例外。

不要写：

> 一边持续大笑一边严肃核验。

不要让长台词覆盖关键Reaction停顿。

Punchline推荐：

`动作/结果 → 0.2–0.8秒停顿 → 短句 → 对方/旁人Reaction`

# 10. Seedance最终提示词写法

AU编号只在内部使用。最终视频提示词写自然画面语言。

错误：

> 她呈现AU1+AU2+AU5+AU26的惊讶表情。

正确：

> 她先看见结果，眉毛快速抬起，眼睛短暂睁大，嘴唇轻分；不到一秒便收住表情，重新低头确认。

错误：

> 她越来越紧张，情绪升级。

正确：

> 她连续看两次门口的时钟，眉心收紧，嘴唇轻压，手上的动作明显加快；听见门把转动后，她立即把视线转向门口。

错误：

> 所有人震惊。

正确：

> 最先看到结果的人停下动作；旁边的人顺着她的视线看过去，半秒后才放下手里的杯子，最后一人才抬头确认。

# 11. Silent Performance QA

每条商用视频静默检查：

- [ ] 每个Reaction都有明确Trigger，不是凭空表演。
- [ ] 表情没有领先事件泄露后续信息。
- [ ] 表情动作与景别匹配，镜头实际看得见。
- [ ] 默认强度克制，没有连续瞪眼/张嘴/翻白眼。
- [ ] 每个短Beat只保留最少必要表情动作。
- [ ] 主动作、Proof和物理交互没有被微表情描述抢走。
- [ ] Decision Change最终落到下一行动，而不只停留在脸上。
- [ ] R0没有被表演偷偷制造成误会/反转。
- [ ] R1没有演成R2。
- [ ] R2在Micro Anomaly前没有提前泄底。
- [ ] 若调用Scene，表演方式符合Scene Performance DNA，而非统一TikTok震惊脸。
- [ ] 多人Reaction有先后顺序，不同步集体反应。
- [ ] 高风险医疗/安全/金融等内容不依靠人物表情暗示未被证明的功效、风险或结果。

关键项失败：删减表演动作或重编Reaction，不牺牲Proof和主事件。

# 12. 最终原则

`事件先发生，表情后发生。`

`Gaze before generic emotion label.`

`Reaction必须改变下一动作，才值得占时间。`

`具体可见动作 > “震惊/紧张/开心”等抽象词。`

`克制真实 > 持续夸张。`

`Scene调表演语法，不改Story事实。`

`FACS是动作词典，不是情绪真相机器。`
