# PERFORMANCE × FACS COMPILER｜剧情带货表演与微表情动作库

## 0. 定位

本文件负责把已经确定的Story Beat编译成**人物可见、克制、可生成的表演动作**。

调用位置：

`Story Architecture + Proof + R-level + Scene/Location`
→ `Performance Intent`
→ `Gaze / Face / Head / Body`
→ `Dialogue / Next Action`
→ `Seedance Prompt`

核心原则：

> **先有事件，再有Reaction；先有Reaction目的，再选面部动作。**

FACS是描述可见面部运动的动作词典，不是“一个情绪=一个唯一表情”的真值表。最终Seedance提示词默认**不输出AU编号**，只输出人能看见的动作变化。

---

# 1. 表演优先级

每个Reaction按以下顺序编译：

`Trigger`
→ `Gaze Target`
→ `First Facial Change`
→ `Micro Pause / Release`
→ `Head / Body Response`
→ `Dialogue or New Action`

优先级：

`事件动作 > 视线 > 身体反应 > 关键微表情 > 台词语气 > 装饰性表情`

默认一个短Beat只保留：
- 1个明确视线变化；
- 1–2个主要面部变化；
- 0–1个必要身体变化。

只有特写或情绪转折镜头才增加细节。

## 1.1 商业人物吸引力｜压力不等于让主角讨厌

真实Benchmark `B1-S04-P1 Attempt 2` 暴露：把“客户提前”的压力翻译成女主不耐烦，会让正常商用广告产生负面代入。

默认：

`TENSION SOURCE ≠ PROTAGONIST NEGATIVITY`

普通商用广告中，压力优先来自：
- 时间
- 环境
- 任务
- 选择
- 外部阻力
- 社会关系

主角默认应保持：
- 有能力
- 有能量
- 可喜欢/可代入
- 遇到问题后主动行动

除非用户明确要求荒诞、黑色、狗血、讽刺或强反转，不用以下方式承担Hook：
- 对同事持续不耐烦
- 丧气抱怨
- 莫名嫌弃
- 无原因翻白眼/冷笑

可以有短促压力Reaction，但应迅速转入行动。

# 2. FACS核心动作词典｜内部参考

| AU | 可见动作 |

| AU2 | 外眉抬起 |
| AU4 | 眉毛下压/眉心收紧 |
| AU5 | 上眼睑抬起，眼裂增大 |
| AU6 | 面颊抬起，眼周收紧 |
| AU7 | 眼睑收紧 |
| AU9 | 鼻部皱起 |
| AU10 | 上唇抬起 |
| AU12 | 嘴角向上拉 |
| AU14 | 嘴角单侧收紧/不对称变化 |
| AU15 | 嘴角向下 |
| AU17 | 下巴/颏部收紧 |
| AU20 | 嘴角水平向外拉 |
| AU23 | 嘴唇收紧 |
| AU24 | 嘴唇压紧 |
| AU25 | 双唇分开 |
| AU26 | 下颌下降 |

常见基础组合只作参考：
- 快乐：`AU6 + AU12`
- 惊讶：`AU1 + AU2 + AU5`，强时再加入`AU26`
- 愤怒/压怒：`AU4 + AU5/7 + AU23/24`
- 厌恶：`AU9/10`
- 悲伤：`AU1 + AU4 + AU15`
- 恐惧：`AU1 + AU2 + AU4 + AU5 + AU20`
- 轻蔑：常见单侧`AU14`

不要把组合当成跨人物、跨文化、跨语境必然成立的情绪指纹。

# 3. AI视频默认强度规则

商业剧情默认：
`SUBTLE / LIGHT / MEDIUM`

默认：
- 惊讶不等于长时间瞪眼张嘴；
- 愤怒不等于大喊砸东西；
- 开心不等于全程露齿大笑；
- 尴尬不等于双手捂脸；
- 反转不等于所有人同步震惊。

一个Reaction最好在`0.2–1.2秒`内完成主要变化，然后进入下一动作；喜剧停顿可单独留`0.2–0.8秒`。

# 4. 商业剧情常用表情链｜动作模板

## 4.1 怀疑 / 不信
`视线停在证据上 → 眉心轻压 → 眼睑微收 → 嘴唇轻压 → 不马上说话`

## 4.2 困惑
`视线在物体与人物间切换 → 内眉轻抬同时眉心略收 → 嘴唇轻分 → 头微偏`

## 4.3 轻惊讶
`眉毛快速抬起 → 眼睛短暂睁大 → 嘴唇轻分 → 立刻锁回结果`

## 4.4 难以置信
`盯结果 → 眉毛短促抬起 → 轻皱眉复核 → 回看产品/对方 → 再验证`

## 4.5 发现异常
`原动作 → 停半拍 → 眼睛先移异常点 → 眉心轻收/单眉轻抬 → 保持观察`

## 4.6 恍然 / 理解
`眉心松开 → 视线从证据移向人物 → 嘴唇轻分后合上 → 轻点头/新行动`

## 4.7 压怒 / 恼火
`眉毛下压 → 眼睑收紧 → 嘴唇压紧 → 下颌轻收 → 视线保持目标`
仅在剧情真的需要时使用，普通商用Hook不要默认调用。

## 4.8 厌恶 / 排斥
`鼻部短暂皱起 → 上唇轻抬 → 头稍后撤 → 视线短离刺激物`

## 4.9 担忧 / 紧张
`内眉轻抬靠近 → 眼睑略紧 → 嘴唇轻抿 → 呼吸略短 → 快速检查关键对象`

## 4.10 害怕
`眉毛抬起收拢 → 眼睛明显睁大 → 嘴唇分开 → 身体后撤/冻结`
剧情带货低频使用。

## 4.11 失落 / 失望
`内眉轻抬收紧 → 嘴角轻下压 → 视线落下 → 肩颈略松`

## 4.12 尴尬
`快速看左右/旁人 → 视线错开 → 嘴唇轻压 → 短促紧笑/轻收下巴 → 身体略缩`

## 4.13 心虚 / 被戳穿
`直视 → 视线短移开 → 嘴唇压紧 → 轻收下巴 → 试图恢复正常`

## 4.14 释然
`眉心/眼睑松开 → 呼气 → 肩膀下降 → 嘴角轻抬 → 回看产品/对方`

## 4.15 满意 / 认可
`看结果 → 眼周放松 → 面颊轻抬 → 嘴角小幅上扬 → 轻点头/继续使用`

## 4.16 开心 / 真正愉悦
`面颊抬起 → 嘴角上扬 → 眼周自然收紧 → 身体更开放`

## 4.17 克制好笑 / 憋笑
`嘴角想上扬又压住 → 面颊轻抬 → 短看旁人 → 0.3–0.6秒停顿 → 回到事件`

## 4.18 轻蔑 / 不屑
`单侧嘴角略收紧 → 下巴轻抬/头略偏 → 很短 → 回到事件`
只适合明确关系冲突，不能无原因给主角增加“傲慢感”。

## 4.19 专注 / 认真核验
`目光锁定操作点 → 眉心轻收 → 嘴唇自然闭合 → 头部减少移动 → 手更精确`

## 4.20 下定决心 / 坚定
`视线从证据抬回目标 → 眉眼稳定 → 嘴唇轻压后放松 → 轻点头 → 立刻行动`

# 5. Reaction Compiler

内部四项：

```text
TRIGGER:
PERFORMANCE INTENT:
GAZE TARGET:
NEXT ACTION:
```

再选最少动作。

最终：
`Trigger → gaze → facial change → micro pause/release → body/new action → line（若必要）`

Reaction若不改变观众理解或下一动作，就不要占时间。

---

# 6. R0 / R1 / R2 表演边界

## R0
Reaction只服务Problem / Proof / Choice / Task / Experience / Decision Change。
禁止为了“情绪起伏”偷偷添加反转。

## R1 Clarification
`轻怀疑/确信 → 验证专注 → 结果 → 理解/认可 → 新行动`

## R1 Reveal
`未知/好奇 → 线索 → 注意力集中 → Reveal后恍然 → 新判断`

## R1 Surprise
`正常状态 → 轻惊讶 → 快速恢复 → 按结果行动`

## R2 True Reversal
`旧判断可信 → Evidence强化旧判断 → Micro Anomaly停半拍/转视线 → Reveal → 认知重置 → Aftermath行动`

# 7. Scene Performance Modulation

若调用特殊Scene，强度与社会传播服从Scene DNA：
- S01 宫廷：克制权威、等级链
- S02 高中：同伴快速扩散
- S03 军营：结果→Commander→新命令
- S04 办公室：职业控制，压力来自任务，不用无原因嫌烦
- S05 西部：身体停顿/长静
- S06 Gala：停杯/侧目/笑容轻僵
- S07 Mall：停步/重新拿起
- S08 Future：系统异常→人工复核
- S09 Diner：手继续、眼睛先偷听
- S10 Competition：Result先于Emotion
- S11 Market：拿/掂/靠近体现改判
- S12 Train：礼貌克制、整理衣服/轻点头

Scene Performance不能改Story事实或R-level。

# 8. 镜头与表情匹配

- 大全景：姿态、停步、转身、站位
- 中景：视线、头部、嘴角、肩颈
- 中近景/近景：关键眉眼/嘴部
- 特写：Proof Reaction、Micro Anomaly、Reveal后认知变化

镜头看不清的表情不要写。

---

# 9. 对白与表演同步

默认：
`先看到/听到 → 先反应 → 再说话`

长台词不能覆盖关键Reaction停顿。

Punchline：
`动作/结果 → 0.2–0.8秒停顿 → 短句 → 对方Reaction`

## 9.1 Audio / Hearing Causality｜听见也必须有物理原因

真实Benchmark发现：人物空间距离和听觉状态若不写，模型会把任何对白当成“贴脸可听”。

每句关键对白内部锁：

```text
SPEAKER LOCATION:
ON/OFF SCREEN:
DISTANCE:
DIRECTION:
RELATIVE LOUDNESS / ROOM FEEL:
LISTENER HEARING CONDITION:
```

### 画外音
远处/门外/走廊里的声音应通过：
- 较弱直接声
- 更明显房间/走廊反射
- 方位感
- 与画面距离一致的语气

表达距离，而不是只把音量写小。

### 耳机 / 门 / 玻璃等听觉阻隔
人物佩戴耳机、隔着门/玻璃或处于高噪环境时，先问：

> **她为什么能听见这句话？**

合法原因例如：
- 已摘下一只/两只耳机
- 对方靠近到合理距离
- 使用真实Transparency等功能且已明确打开
- 通过视觉手势而非听觉获得信息

不能因为“后面需要她回答”就自动让她清楚听见。

若依赖产品功能，功能必须来自确认事实，不能编造“耳机会自动听懂任何外部对话”。

# 10. Seedance最终提示词写法

AU编号只在内部使用，最终写自然动作。

错误：
`她越来越紧张，情绪升级。`

正确：
`她连续看两次门口，眉心收紧，手上动作加快；听见门把转动后立即转头。`

错误：
`她用余光看同事，形成干幽默。`

如果这个眼神没有明确关系语义，改为动作：
`同事刚要开口，她不看他，只抬起食指示意“等一下”；同事立即停住并退回门外。`

**幽默优先通过动作关系表达，不靠含混的笑、侧眼、冷笑让模型自行猜情绪。**

# 11. Silent Performance QA

- [ ] 每个Reaction都有明确Trigger。
- [ ] 表情没有领先事件泄底。
- [ ] 表情与景别匹配。
- [ ] 默认克制，没有连续瞪眼/张嘴/翻白眼。
- [ ] 主动作/Proof没有被微表情抢走。
- [ ] Decision Change落到行动。
- [ ] 普通商用广告的张力没有被错误写成主角持续负面人格。
- [ ] 含混“侧眼/冷笑/干幽默”是否已改成可读动作关系？
- [ ] R0没有被偷偷制造反转。
- [ ] R1没有演成R2。
- [ ] R2在Micro Anomaly前没有泄底。
- [ ] Scene表演方式符合Scene DNA。
- [ ] 多人Reaction有先后。
- [ ] 每句关键画外音有位置/距离/方向/空间感。
- [ ] 人物佩戴耳机/隔门时，听见外部对白有合理原因。
- [ ] 高风险内容不靠表情暗示未证明结论。

失败：删减/重编Reaction或声音逻辑，不牺牲Proof和主事件。

# 12. 最终原则

`事件先发生，表情后发生。`

`Tension source ≠ protagonist negativity.`

`Gaze before generic emotion label.`

`Reaction必须改变下一动作，才值得占时间。`

`听见也必须有空间与物理原因。`

`动作关系 > 含混情绪表演。`

`克制真实 > 持续夸张。`

`Scene调表演语法，不改Story事实。`

`FACS是动作词典，不是情绪真相机器。`
