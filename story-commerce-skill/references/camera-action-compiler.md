# CAMERA × ACTION COMPILER｜机位、轴线、操作面、动作节拍与情绪运镜编译

> 来源：真实 Benchmark `B1-S04-P1 Attempt 1–5` + 30秒服装/7-Eleven剧情广告复盘。
>
> 目标：让人物真实可操作、Proof可见、轴线稳定、场面方向正确、道具运动有动力来源、动作节拍年轻利落，并让运镜真正跟情绪走，而不是“人物在冲突，镜头还像访谈”。

---

# 0. 核心原则

镜头不是动作写完以后再加的装饰。

涉及产品开合、插拔、取出、放回、佩戴、拆装、倒入、递交时，先建立：

`Scene Staging / Blocking`
→ `人物操作方向`
→ `产品工作面 / 开口面`
→ `人物实际能看见/接触的位置`
→ `180°主轴线`
→ `允许机位半区`
→ `机位所在侧`
→ `动作时长/速度`
→ `状态变化`
→ `动力来源`
→ `情绪强度 / Camera Handoff`
→ `镜头能否同时看清动作与Proof`

永远：

`ACTOR OPERABILITY > PRODUCT HERO ANGLE`

`BLOCKING BEFORE CAMERA`

`ACTION VISIBILITY ≠ 把产品正面硬转给镜头`

`ACTION ENERGY ≠ 把简单动作慢慢演完`

`STATE CONTINUITY > “看起来像完成了”`

`180 AXIS CONTINUITY > 随机多角度`

`NO MOTION WITHOUT MOTIVE FORCE`

`CAMERA ENERGY FOLLOWS EVENT ENERGY`

---

# 1. 180° AXIS LOCK｜先锁轴线，再选角度

## 1.1 先定义主轴线

每个连续空间先选一条主轴：
- 双人对话：两人视线连接线；
- 单人办公：人物 ↔ 电脑/主要任务目标；
- 产品操作：人物 ↔ 产品工作面；
- 行走/交通：人物主要运动方向；
- 柜台/桌面：人物 ↔ 对侧关键对象。

## 1.2 允许机位半区

建立主轴后，连续镜头默认只在轴线同一侧180°半区内变化。

例如人物左前侧为主拍摄半区，可在：
- 左前30°
- 左侧60–90°
- 左后OTS

之间变化，但不能突然切到右前/右后，除非执行合法跨轴。

## 1.3 合法跨轴只有三种

1. 镜头连续移动穿过轴线，观众清楚看到方向变化；
2. 先切轴线上中性正面/背面，再建立新半区；
3. 人物或任务方向在画面内明确改变，形成新主轴后再切。

## 1.4 Axis Ledger

```text
PRIMARY AXIS:
ALLOWED CAMERA HALF:
SCREEN DIRECTION:
CURRENT CAMERA SIDE:
NEXT CAMERA SIDE:
AXIS CROSSING METHOD: NONE / NEUTRAL / VISIBLE_MOVE / NEW_AXIS
```

如果跨半区且`AXIS CROSSING METHOD = NONE`，必须改机位。

# 2. Proof–Action Alignment Gate

任何产品操作镜头先问：
1. 人物从哪个方向使用产品？
2. 产品真正需要被操作/观察的是哪一面？
3. 当前机位是否处于人物真实可操作侧？
4. 为了让镜头看清，产品是否被不合理朝向观众？
5. 当前机位是否仍在已锁定的180°允许半区？

若第4题YES：
> **换机位，不许旋转产品作弊。**

若第5题NO：
> **在同半区重新找OTS/侧面近景，不直接越轴。**

典型错误：
- 耳机盒内部朝镜头，人物面对盒盖背面；
- 手机屏幕完全朝镜头而非人物；
- 接口背对人物却要求插入；
- 包装开口为了Hero转到人物无法操作的一侧。

# 3. 默认机位规则

## 3.1 拿起产品
可用：
- 同半区人物侧前30–45°中近景；
- 同侧桌面机位；
- 已建立空间关系后的手部近景。

必须看见：
`人物靠近/伸手 → 接触 → 产品离开原位置`

## 3.2 开盒 / 开盖 / 内部结构
优先人物肩后OTS或人物操作侧斜后方近景，且来自当前允许半区。

`产品稳定 → 同侧OTS → 单一开盖动作`

人物和观众看同一个工作面。

## 3.3 取出 / 放回小物体
默认：
- 产品有稳定支撑；
- 一镜只完成一次主要接触；
- 明确哪只手、抓哪里、朝哪个方向；
- 一次状态变化后切镜。

耳机取出：
`盒子稳定 → 手指夹住耳机柄 → 单一方向提起离开槽位 → 硬切`

放回：
`耳机到槽位上方 → 单一方向进入 → 手指松开 → 硬切`

不要同镜强塞：
`手持盒子 + 开盖 + 捏耳机 + 转方向 + 戴耳 + 保持精确结构`。

## 3.4 佩戴 / 插入人体
主要证明：
- 从手中移动到正确身体位置；
- 尺度合理；
- 最终状态稳定。

高风险时：
`靠近身体位置 → 动作匹配硬切 → 正确佩戴后的稳定状态`

---

# 4. Interaction Risk Budget｜一镜一项高风险接触

高风险交互：
- 小物体从紧槽取出/放回
- 插头插接口
- 戴耳机/耳饰
- 扣纽扣/拉链
- 多人递物
- 开门同时拿商品
- 液体倾倒
- 狭窄空间穿门/交接

默认：
> **一个镜头最多1个高风险精细接触。**

若2项以上：拆镜 / 动作匹配切 / 稳定支撑 / 删除非必要过程。

---

# 5. Action Tempo Budget｜动作时间不是按秒填满

## 5.1 简单微动作
年轻、利落、高能广告中，以下单一动作通常按约`0.5–1.2s`视觉节拍：
- 拿起
- 单次打开
- 抬手
- 单侧佩戴
- 按一下
- 轻扫/轻推
- 单次放下

原则：
> **动作越简单，越不应占满长时间段。**

## 5.2 蓄力高能感
正确：
`事件Cue / 声音Cue / 视线锁定 → 极短预备 → 快速动作 → 清楚结果 / 硬切`

错误：
`人物抬手2秒 → 慢慢靠近 → 再慢慢完成`

## 5.3 时间段写法
若3秒Beat里只有0.8秒动作，其余时间必须由新事件 / Reaction / Camera transition / Result / 新信息承担，而不是把简单动作拉长。

---

# 6. Object State Ledger｜成对/多件产品逐镜记账

```text
BEAT n
Object A: <location/state>
Object B: <location/state>
Container: <location/open-closed state>
```

下一镜若状态改变，必须有可见移动动作或明确动作匹配切。

Hero Shot也服从Ledger，不能为了经典商品图把正在使用的配件复制回包装。

---

# 7. MOTIVE FORCE GATE｜任何移动物体必须回答“谁让它动”

```text
MOVING OBJECT:
MOTIVE FORCE:
VISIBLE AGENT / MOTOR:
START STATE:
PATH:
END STATE:
```

合法动力：人推/拉/拿，明确电机，重力、弹簧、水流、风，车辆自身动力等。

禁止普通手推车、椅子、箱子、门、杯子等无原因自己运动。

---

# 8. META-CAMERA GUARD｜机位描述不能变成场景道具

最终Seedance提示词中：
- 写`人物右肩后方OTS近景`、`右侧30°近景`；
- 避免把“摄影机”写成执行动作主体；
- 除非剧情需要拍摄设备，否则不让摄影器材进入画面。

推荐：
> `人物右肩后方OTS近景，画面与人物看向同一产品工作面。`

---

# 9. Action Cut Trigger｜什么时候必须切镜

满足任一优先切：
1. 从外观进入内部结构；
2. 操作侧变化；
3. 需要看清接口/槽位/开口；
4. 开始精细抓取厘米级小物体；
5. 从产品操作进入人体佩戴；
6. 当前机位不能同时满足可操作性与Proof可见性；
7. 同镜即将出现第二项高风险接触；
8. 简单动作被拖成长时间；
9. 成对物体状态将跨位置变化。

切镜前检查下一机位仍在180°允许半区。

---

# 10. 镜头描述最小信息

关键产品操作内部至少判断：

```text
PRIMARY AXIS:
ALLOWED CAMERA HALF:
CAMERA SIDE:
ACTOR ORIENTATION:
PRODUCT WORKING SIDE:
HAND + CONTACT:
STATE BEFORE:
STATE AFTER:
ACTION TEMPO:
MOTIVE FORCE（若物体移动）:
EMOTION INTENSITY:
```

最终提示词不机械输出字段名，但必须判断完成。

# 11. Commercial Camera Rule｜稳定也要有能量

剧情广告镜头切换由事件驱动：
`事件发生 → 人物反应 → 关键操作 → Proof / Benefit → 结果/关系/情绪变化`

避免：
- 全片同一个正面中景；
- 产品一直正面对镜头；
- 无因果环绕；
- 简单动作长期占镜；
- 为了角度丰富在人物左前/右前/左后随机跳机位。

“多角度”必须在同一已锁180°半区内，或先合法重建轴线。

## 11.1 CAMERA × EMOTION COUPLING｜运镜必须跟情绪变化

Camera读取 `performance-facs.md` 的Beat强度和状态变化。

### Conflict / Pressure 3–4/5
可用：
- 轻手持呼吸感
- 快速小幅推近
- 短促甩镜反打
- 事件发生后迅速重构图
- 中景快速收紧到中近景/近景

目的：让镜头产生逼近和不稳定感。

### Delay 2–3/5
可用：
- 突然稳定
- Hold 0.3–0.8秒
- 缓慢微推

目的：用“突然不动”制造等待。

### Reveal / Burst 4–5/5
可用：
- 突然硬切
- 从局部快速打开到完整结果
- Full Result后停0.3–0.6秒让结果成立

### Strong Reaction 4–5/5
可用：
- 硬切近景/特写
- 很短的快速微推近

不要用长时间环绕替代Reaction。

### Relief / Payoff
- 摄影机逐渐稳定
- 构图稍微变宽
- 运动幅度下降

原则：
`EMOTION TIGHTENS → CAMERA TIGHTENS`

`DELAY STABILIZES`

`REVEAL HITS`

`RESOLUTION STABILIZES`

但情绪运镜不能破坏Scene Staging、180°轴线、Actor Operability与Product Proof。

# 12. SCENE STAGING HANDOFF｜先场面语义，再机位

若镜头涉及：
- 进/出门
- 上/下车
- 接近/离开商店
- 3个以上关键元素同时出现
- 人物 + 品牌 + 道具 + 空间关系

必须先执行 `scene-staging-compiler.md`。

Camera只接收已经锁定的：
- START / END
- FROM → THROUGH → TO
- Actor Facing
- Movement Vector
- Foreground / Midground / Background

例如“离开7-Eleven”：
不是先想“怎样同时看到人和Logo”，而是先锁：
`店内 → 自动门 → 店外 → 远离店门`。

然后机位放在店外人物前方，让店面留在身后背景。

`ACTION DIRECTION > BRAND VISIBILITY`

---

# 13. Silent QA｜关键交互必检

- [ ] Scene Staging是否已经先锁人物走位和动作方向？
- [ ] 当前连续空间是否已锁Primary Axis？
- [ ] 所有镜头是否处于同一180°允许半区？
- [ ] 若跨轴，是否有合法过渡？
- [ ] 人物能从当前方向真实使用产品吗？
- [ ] 工作面没有为了镜头背离人物吗？
- [ ] 操作前是否需要主动切同侧OTS/操作侧？
- [ ] 一镜是否塞了2项以上高风险接触？
- [ ] 取出/放回有明确起点、接触、路径、终点吗？
- [ ] 简单动作时间是否过长？
- [ ] 成对/多件产品逐镜状态是否有Ledger？
- [ ] 状态变化是否都有动作或合法动作匹配切？
- [ ] 所有普通移动道具有动力来源吗？
- [ ] 提示词中的镜头描述没有被生成成摄影器材实体吗？
- [ ] Proof可见性没有破坏真实操作逻辑？
- [ ] 冲突/Delay/Reveal/Payoff的运镜是否与情绪强度一致？
- [ ] 品牌露出是否为了构图反转了人物移动方向？

任何一项失败：
> 先改Blocking、轴线、机位、动力来源、动作节拍、情绪Handoff、状态设计或拆镜，不先追加负面词。
