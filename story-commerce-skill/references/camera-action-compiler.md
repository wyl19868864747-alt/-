# CAMERA × ACTION COMPILER｜机位、轴线、操作面、动作节拍与物理交互编译

> 来源：真实 Benchmark `B1-S04-P1 Attempt 1–5`。
>
> 目标：让人物真实可操作、Proof可见、轴线稳定、道具运动有动力来源、动作节拍年轻利落，并降低小物体/成对物体跨镜穿模与状态瞬移。

---

# 0. 核心原则

镜头不是动作写完以后再加的装饰。

涉及产品开合、插拔、取出、放回、佩戴、拆装、倒入、递交时，先建立：

`人物操作方向`
→ `产品工作面 / 开口面`
→ `人物实际能看见/接触的位置`
→ `180°主轴线`
→ `允许机位半区`
→ `机位所在侧`
→ `动作时长/速度`
→ `状态变化`
→ `动力来源`
→ `镜头能否同时看清动作与Proof`

永远：

`ACTOR OPERABILITY > PRODUCT HERO ANGLE`

`ACTION VISIBILITY ≠ 把产品正面硬转给镜头`

`ACTION ENERGY ≠ 把简单动作慢慢演完`

`STATE CONTINUITY > “看起来像完成了”`

`180 AXIS CONTINUITY > 随机多角度`

`NO MOTION WITHOUT MOTIVE FORCE`

---

# 1. 180° AXIS LOCK｜先锁轴线，再选角度

真实 Attempt 5 出现同一人物连续被拍成左前、右前、左后等多个跨轴角度，造成明确越轴和空间方向混乱。

## 1.1 先定义主轴线

每个连续空间先选一条主轴：
- 双人对话：两人视线连接线；
- 单人办公：人物 ↔ 电脑/主要任务目标；
- 产品操作：人物 ↔ 产品工作面；
- 行走/交通：人物主要运动方向；
- 柜台/桌面：人物 ↔ 对侧关键对象。

## 1.2 允许机位半区

建立主轴后，连续镜头默认只在轴线同一侧180°半区内变化。

例如已经选择人物左前侧为主拍摄半区，可在：
- 左前30°
- 左侧60–90°
- 左后OTS

之间变化，但不能突然切到右前/右后，除非执行合法跨轴。

## 1.3 合法跨轴只有三种

1. 镜头连续移动穿过轴线，观众清楚看到方向变化；
2. 先切到轴线上中性正面/背面镜头，再建立新半区；
3. 人物或任务方向在画面内明确改变，形成新的主轴后再切。

没有上述过渡：禁止跨轴。

## 1.4 Axis Ledger

复杂片段内部记录：

```text
PRIMARY AXIS:
ALLOWED CAMERA HALF:
SCREEN DIRECTION:
CURRENT CAMERA SIDE:
NEXT CAMERA SIDE:
AXIS CROSSING METHOD: NONE / NEUTRAL / VISIBLE_MOVE / NEW_AXIS
```

如果 `NEXT CAMERA SIDE` 跨到另一半区而 `AXIS CROSSING METHOD = NONE`：必须改机位。

# 2. Proof–Action Alignment Gate

任何产品操作镜头先问：
1. 人物从哪个方向使用产品？
2. 产品真正需要被操作/观察的是哪一面？
3. 当前机位是否处于人物真实可操作侧？
4. 为了让镜头看清，产品是否被不合理朝向观众？
5. 当前机位是否仍在已锁定的180°允许半区？

若第4题为YES：
> **必须换机位，不许旋转产品作弊。**

若第5题为NO：
> **在同半区重新找OTS/侧面近景，不为了产品Proof直接越轴。**

典型错误：
- 耳机盒内部朝镜头，人物面对盒盖背面；
- 手机屏幕完全朝镜头而非人物；
- 接口背对人物却要求直接插入；
- 包装开口为了Hero Shot转到人物无法操作的一侧。

# 3. 默认机位规则

## 3.1 拿起产品
可用：
- 已锁定半区内的人物侧前方30–45°中近景；
- 同侧桌面机位；
- 已建立空间关系后的手部近景。

必须看见：
`人物靠近/伸手 → 接触 → 产品离开原位置`

禁止人物还在远处，下一镜无来源的手直接持有产品。

## 3.2 开盒 / 开盖 / 展开内部结构
默认优先人物肩后OTS或人物操作侧斜后方近景，**但OTS必须来自当前允许半区**。

优先：
`产品稳定 → 切同侧OTS → 单一开盖动作`

人物和观众看同一个工作面，不需要把产品反向展示给镜头。

## 3.3 取出 / 放回小物体
默认：
- 产品尽量有稳定支撑；
- 一镜只完成一次主要接触；
- 明确哪只手、抓哪里、朝哪个方向；
- 完成一次状态变化后切镜。

耳机取出：
`盒子稳定 → 手指夹住耳机柄 → 单一方向提起离开槽位 → 硬切`

耳机放回：
`耳机到槽位上方 → 单一方向进入 → 手指松开 → 硬切`

不要同镜强塞：
`手持盒子 + 开盖 + 捏耳机 + 转方向 + 戴耳 + 保持精确结构`。

## 3.4 佩戴 / 插入人体
佩戴主要证明：
- 物体从手中移动到正确身体位置；
- 尺度合理；
- 最终状态稳定。

精细接触高风险时：
`靠近身体位置 → 动作匹配硬切 → 正确佩戴后的稳定状态`

不为证明每毫米接触牺牲脸和产品稳定性。

---

# 4. Interaction Risk Budget｜一镜一项高风险接触

高风险交互：
- 小物体从紧槽取出/放回
- 插头插接口
- 戴耳机/耳饰
- 扣纽扣/拉链
- 多人递物
- 开门同时拿商品
- 液体倾倒
- 狭窄空间穿门/交接

默认：
> **一个镜头最多1个高风险精细接触。**

若出现2项以上：拆镜 / 动作匹配切 / 稳定支撑 / 删除非必要中间过程。

---

# 5. Action Tempo Budget｜动作时间不是按秒填满

真实Benchmark发现：给简单佩戴动作3秒，模型容易慢慢演满，形成拖沓和老年感。

## 5.1 简单微动作
年轻、利落、高能广告中，以下单一动作通常按约`0.5–1.2s`视觉节拍设计：
- 拿起
- 单次打开
- 抬手
- 单侧佩戴
- 按一下
- 轻扫/轻推
- 单次放下

不是死数值，但原则是：
> **动作越简单，越不应占满长时间段。**

## 5.2 蓄力高能感
正确：
`事件Cue / 声音Cue / 视线锁定 → 极短预备 → 快速动作 → 清楚结果 / 硬切`

错误：
`人物抬手2秒 → 慢慢靠近 → 再慢慢完成`

## 5.3 时间段写法
如果一个3秒Beat里只有0.8秒动作，其余时间必须由新事件 / Reaction / Camera transition / Result / 新信息承担，而不是把简单动作拉长。

# 6. Object State Ledger｜成对/多件产品逐镜记账

适用于左右耳机、鞋/手套、多配件套装、拆出的零件等。

内部记录：

```text
BEAT n
Object A: <location/state>
Object B: <location/state>
Container: <location/open-closed state>
```

下一镜若状态改变，必须存在可见移动动作或明确动作匹配切，且前后状态不冲突。

禁止：上一镜两只耳机还在耳朵，下一镜一只已经自动躺在仓里。

Hero Shot同样服从Ledger，不能为了经典商品图把正在使用的配件复制回包装。

---

# 7. MOTIVE FORCE GATE｜任何移动物体必须回答“谁让它动”

真实 Attempt 5 出现普通无动力办公手推车无人推动却自己划过画面，属于物理因果错误。

任何非人物物体发生明显位移前，先锁动力来源：

```text
MOVING OBJECT:
MOTIVE FORCE:
VISIBLE AGENT / MOTOR:
START STATE:
PATH:
END STATE:
```

合法动力：
- 人推 / 人拉 / 人拿；
- 明确电机/轮机/机器人底盘；
- 重力、弹簧、水流、风等真实可见条件；
- 车辆自身动力系统。

禁止：
- 普通手推车无人自己滑过平地；
- 椅子、箱子、门、杯子无原因移动；
- 没有电机设定的货架/推车自动巡航；
- 为了“背景更忙”让普通道具自己运动。

如果希望自动移动：必须把对象定义为真实可自驱设备，例如`small autonomous delivery robot cart`，并让外观明显具有电动底盘/传感器。

---

# 8. META-CAMERA GUARD｜机位描述不能变成场景道具

真实 Attempt 5 在5–6秒把“摄影机和人物看向同一工作面”的元指令误生成成画面中的DSLR/三脚架。

因此最终Seedance提示词中：
- 可以写`从人物右肩后方过肩观察`、`右侧30°近景`、`画面从同一操作侧看到盒内`；
- 尽量避免把“摄影机/摄像机/camera”写成执行动作主体，例如“摄影机位于她面前”“摄影机和人物看向同一方向”；
- 除非剧情本身需要拍摄设备，否则明确：`no visible filming equipment in scene`。

推荐表达：
> `人物右肩后方OTS近景，画面与人物看向同一产品工作面。`

不推荐：
> `摄影机站在人物右肩后，摄影机和人物一起看向产品。`

# 9. Action Cut Trigger｜什么时候必须切镜

满足任一，优先主动切镜：
1. 从外观进入内部结构；
2. 操作侧发生变化；
3. 需要看清接口/槽位/开口；
4. 开始精细抓取厘米级小物体；
5. 从产品操作进入人体佩戴；
6. 当前机位无法同时满足人物可操作性与Proof可见性；
7. 同镜即将出现第二项高风险接触；
8. 简单动作正在被拉成长时间慢动作；
9. 成对物体状态将发生跨位置变化。

切镜前还必须检查：下一机位是否仍在180°允许半区。

# 10. 镜头描述最小信息

关键产品操作内部至少判断：

```text
PRIMARY AXIS:
ALLOWED CAMERA HALF:
CAMERA SIDE:
ACTOR ORIENTATION:
PRODUCT WORKING SIDE:
HAND + CONTACT:
STATE BEFORE:
STATE AFTER:
ACTION TEMPO:
MOTIVE FORCE（若物体移动）:
```

最终提示词不必机械输出字段名，但必须判断完成。

---

# 11. Commercial Camera Rule｜稳定也要有能量

剧情广告镜头切换由事件驱动：
`事件发生 → 人物反应 → 关键操作 → Proof / Benefit → 结果/关系/情绪变化`

避免：
- 全片同一个正面中景；
- 产品一直正面对镜头；
- 无因果环绕；
- 简单动作长期占镜；
- 为了“角度丰富”在人物左前/右前/左后随机跳机位。

“多角度”必须发生在同一个已锁定180°半区内，或先合法重建轴线。

---

# 12. Silent QA｜关键交互必检

- [ ] 当前连续空间是否已锁Primary Axis？
- [ ] 所有镜头是否处于同一180°允许半区？
- [ ] 若跨轴，是否有中性镜头/可见移动/新轴线建立？
- [ ] 人物能从当前方向真实使用产品吗？
- [ ] 工作面没有为了镜头背离人物吗？
- [ ] 操作前是否需要主动切同侧OTS/操作侧？
- [ ] 一镜是否塞了2项以上高风险接触？
- [ ] 取出/放回有明确起点、接触、路径、终点吗？
- [ ] 简单动作时间是否过长？
- [ ] 成对/多件产品逐镜状态是否有Ledger？
- [ ] 状态变化是否都有动作或合法动作匹配切？
- [ ] 所有普通移动道具都有明确动力来源吗？
- [ ] 提示词中的“镜头/机位”没有被写成可生成的摄影器材实体吗？
- [ ] Proof可见性没有破坏真实操作逻辑？

任何一项失败：
> 先改轴线、机位、动力来源、动作节拍、状态设计或拆镜，不先追加一串负面词。
