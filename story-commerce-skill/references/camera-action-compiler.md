# CAMERA × ACTION COMPILER｜机位、操作面与物理交互编译

> 来源：真实 Benchmark `B1-S04-P1 Attempt 1`。
>
> 目标：避免为了“让观众看清产品”而让人物以不可能的方向操作产品；同时降低小物体与手部精细交互的穿模概率。

---

# 0. 核心原则

镜头不是动作写完以后再加的装饰。

涉及产品开合、插拔、取出、放回、佩戴、拆装、倒入、递交时，必须先建立：

`人物操作方向`
→ `产品工作面 / 开口面`
→ `人物实际能看见/接触的位置`
→ `机位所在侧`
→ `镜头能否同时看清动作与Proof`

永远：

`ACTOR OPERABILITY > PRODUCT HERO ANGLE`

`ACTION VISIBILITY ≠ 把产品正面硬转给镜头`

`观众看清Proof，不能以人物无法正常操作为代价。`

---

# 1. Proof–Action Alignment Gate

任何产品操作镜头先问：

1. 人物从哪个方向使用这个产品？
2. 产品真正需要被操作/观察的是哪一面？
3. 当前机位是否和人物处于同一“可操作侧”？
4. 为了让镜头看清，产品是否被不合理地朝向观众？

如果第4题为YES：

> **必须换机位，不许旋转产品作弊。**

典型错误：

- 人物坐在镜头后方，耳机盒内部朝镜头打开，人物实际面对盒盖背面；
- 人物使用手机，屏幕完全正对镜头而不是人物；
- 人物倒液体时瓶口/杯口为了Hero Shot转向错误方向；
- 插头/接口明明背对人物，却要求人物直接完成插入。

---

# 2. 默认机位规则

## 2.1 拿起产品

可用：
- 人物侧前方 30–45° 中近景；
- 桌面侧机位；
- 已建立空间关系后的手部近景。

必须看见：
`人物靠近/伸手 → 接触 → 产品离开原位置`

禁止：
人物还在远处，直接切一只无来源的手拿着产品。

## 2.2 开盒 / 开盖 / 展开内部结构

**默认优先人物肩后过肩机位（OTS）或人物操作侧斜后方近景。**

原因：
- 人物和观众基本看向同一个工作面；
- 内部结构可见；
- 不需要把产品反向展示给镜头；
- 手部路径更容易保持合理。

对于桌面产品，优先：

`人物先把产品稳定放/持在真实操作位置 → 硬切到操作侧OTS近景 → 单一开盖动作`

## 2.3 取出 / 放回小物体

默认：
- 产品尽量有稳定支撑；
- 一镜只完成一次主要接触；
- 明确使用哪只手、抓取哪个部位、运动方向；
- 取出后再切下一镜，不要求同镜完成“抓取+旋转+佩戴”。

例如耳机：

`盒子稳定 → 右手拇指/食指夹住耳机柄 → 垂直提起离开槽位 → 硬切`

放回：

`盒子稳定 → 耳机先到槽位上方 → 垂直落入对应槽位 → 手指松开 → 硬切`

不要求视频模型在一个近景里同时：

`手持盒子 + 开盖 + 捏耳机 + 转方向 + 戴耳 + 保持精确产品结构`

## 2.4 佩戴 / 插入人体

佩戴镜头主要证明：
- 物体从手中移动到正确身体位置；
- 尺度合理；
- 最终状态稳定。

若“手指+小物体+耳朵/脸部”精细接触风险高：

> 可使用动作匹配切镜：靠近耳部 → 硬切到已经正确佩戴后的稳定中近景。

不要为了证明每一毫米接触过程而牺牲人物脸和产品稳定性。

---

# 3. Interaction Risk Budget｜一镜一项高风险接触

以下属于高风险交互：
- 小物体从紧槽取出/放回
- 插头插接口
- 戴耳机/耳饰
- 扣纽扣/拉链
- 多人递物
- 开门同时拿商品
- 液体倾倒
- 狭窄空间穿门/交接

默认规则：

> **一个镜头最多承担1个高风险精细接触。**

如果同一镜要求2项以上：
- 拆镜；或
- 用动作匹配切；或
- 先让产品获得稳定支撑；或
- 删除不影响商业Proof的中间过程。

---

# 4. Action Cut Trigger｜什么时候必须切镜

满足任一，优先主动切镜：

1. 产品从“看外观”进入“操作内部结构”；
2. 人物与产品的操作侧发生变化；
3. 需要看清接口/槽位/开口/内部结构；
4. 手指开始精细抓取小物体；
5. 动作从产品操作切到人体佩戴；
6. 当前机位无法同时满足人物可操作性与Proof可见性；
7. 同一镜出现第二个高风险接触。

切镜不是失败，而是降低生成歧义。

---

# 5. 镜头描述必须包含的最小信息

涉及关键产品操作时，不再只写：

> “近景拍她打开耳机盒。”

至少写清：

```text
CAMERA SIDE:
人物肩后 / 左侧 / 右侧 / 桌面侧等

ACTOR ORIENTATION:
人物面向哪里

PRODUCT WORKING SIDE:
开口/屏幕/接口/内部结构朝哪里

HAND + CONTACT:
哪只手接触哪里

STATE CHANGE:
关闭→打开 / 槽内→取出 / 手中→佩戴等
```

最终提示词不必机械输出字段名，但这5项必须在内部判断完成。

---

# 6. Commercial Camera Rule｜机位也要服务剧情能量

“稳定”不等于“全片同一个正面中景”。

剧情广告中，镜头切换应由事件驱动：

`事件发生`
→ `人物反应`
→ `关键操作`
→ `Proof`
→ `结果/关系变化`

优先使用：
- 事件中开场的中景/跟拍；
- 人物收到任务后的反打；
- 产品操作时切OTS/操作侧近景；
- Proof完成后切人物Reaction；
- 新行动再切回空间关系。

避免：
- 为省事全片固定机位；
- 为展示产品一直正面对镜头；
- 为“电影感”无因果环绕。

---

# 7. Silent QA｜关键交互必检

- [ ] 人物真的能从当前方向看见/使用产品吗？
- [ ] 产品工作面没有为了镜头而背离人物吗？
- [ ] 镜头是否应该在关键操作前主动切到OTS/操作侧？
- [ ] 一个镜头是否塞了2项以上高风险接触？
- [ ] 取出/放回是否有稳定起点、接触、运动路径、终点？
- [ ] 手指没有从产品内部穿过？
- [ ] Proof可见性没有破坏真实操作逻辑？
- [ ] 若精细接触不值得冒险，是否使用动作匹配切镜？

任何一项失败：

> 先改机位/拆动作，不先追加一串“禁止穿模”负面词。
