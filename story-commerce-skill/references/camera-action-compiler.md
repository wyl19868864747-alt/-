# CAMERA × ACTION COMPILER｜机位、操作面、动作节拍与物理交互编译

> 来源：真实 Benchmark `B1-S04-P1 Attempt 1–2`。
>
> 目标：让人物真实可操作、Proof可见、动作节拍年轻利落，并降低小物体/成对物体在跨镜中的穿模与状态瞬移。

---

# 0. 核心原则

镜头不是动作写完以后再加的装饰。

涉及产品开合、插拔、取出、放回、佩戴、拆装、倒入、递交时，先建立：

`人物操作方向`
→ `产品工作面 / 开口面`
→ `人物实际能看见/接触的位置`
→ `机位所在侧`
→ `动作时长/速度`
→ `状态变化`
→ `镜头能否同时看清动作与Proof`

永远：

`ACTOR OPERABILITY > PRODUCT HERO ANGLE`

`ACTION VISIBILITY ≠ 把产品正面硬转给镜头`

`ACTION ENERGY ≠ 把简单动作慢慢演完`

`STATE CONTINUITY > “看起来像完成了”`

---

# 1. Proof–Action Alignment Gate

任何产品操作镜头先问：

1. 人物从哪个方向使用这个产品？
2. 产品真正需要被操作/观察的是哪一面？
3. 当前机位是否和人物处于同一“可操作侧”？
4. 为了让镜头看清，产品是否被不合理地朝向观众？

如果第4题为YES：

> **必须换机位，不许旋转产品作弊。**

典型错误：
- 耳机盒内部朝镜头，人物面对盒盖背面；
- 手机屏幕完全朝镜头而非人物；
- 接口背对人物却要求直接插入；
- 包装开口为了Hero Shot转到人物无法操作的一侧。

---

# 2. 默认机位规则

## 2.1 拿起产品

可用：
- 人物侧前方30–45°中近景；
- 桌面侧机位；
- 已建立空间关系后的手部近景。

必须看见：
`人物靠近/伸手 → 接触 → 产品离开原位置`

禁止：人物还在远处，下一镜无来源的手直接持有产品。

## 2.2 开盒 / 开盖 / 展开内部结构

**默认优先人物肩后OTS或人物操作侧斜后方近景。**

优先：
`产品稳定 → 切操作侧OTS → 单一开盖动作`

人物和观众看同一个工作面，不需要把产品反向展示给镜头。

## 2.3 取出 / 放回小物体

默认：
- 产品尽量有稳定支撑；
- 一镜只完成一次主要接触；
- 明确哪只手、抓哪里、朝哪个方向；
- 完成一次状态变化后切镜。

耳机取出：
`盒子稳定 → 手指夹住耳机柄 → 单一方向提起离开槽位 → 硬切`

耳机放回：
`耳机到槽位上方 → 单一方向进入 → 手指松开 → 硬切`

不要同镜强塞：
`手持盒子 + 开盖 + 捏耳机 + 转方向 + 戴耳 + 保持精确结构`。

## 2.4 佩戴 / 插入人体

佩戴镜头主要证明：
- 物体从手中移动到正确身体位置；
- 尺度合理；
- 最终状态稳定。

精细接触高风险时：

> `靠近身体位置 → 动作匹配硬切 → 正确佩戴后的稳定状态`

不为证明每毫米接触牺牲脸和产品稳定性。

---

# 3. Interaction Risk Budget｜一镜一项高风险接触

高风险交互：
- 小物体从紧槽取出/放回
- 插头插接口
- 戴耳机/耳饰
- 扣纽扣/拉链
- 多人递物
- 开门同时拿商品
- 液体倾倒
- 狭窄空间穿门/交接

默认：

> **一个镜头最多1个高风险精细接触。**

若出现2项以上：拆镜 / 动作匹配切 / 稳定支撑 / 删除非必要中间过程。

---

# 4. Action Tempo Budget｜动作时间不是按秒填满

真实Benchmark发现：给简单佩戴动作3秒，模型很容易把动作慢慢演满，形成拖沓、老年感。

## 4.1 简单微动作

在年轻、利落、高能广告中，以下单一动作通常按约`0.5–1.2s`视觉节拍设计：
- 拿起
- 单次打开
- 抬手
- 单侧佩戴
- 按一下
- 轻扫/轻推
- 单次放下

不是死数值，但原则是：

> **动作越简单，越不应占满长时间段。**

## 4.2 蓄力高能感

不要通过“慢慢做动作”制造蓄力。

正确：
`事件Cue / 声音Cue / 视线锁定 → 极短预备 → 快速动作 → 清楚结果 / 硬切`

错误：
`人物抬手2秒 → 慢慢把产品靠近 → 再慢慢完成`

## 4.3 时间段写法

如果一个3秒Beat里只有0.8秒动作，其余时间必须由：
- 新事件
- Reaction
- Camera transition
- Result
- 新信息

承担，而不是要求演员把简单动作拉长。

# 5. Object State Ledger｜成对/多件产品逐镜记账

适用于：
- 左右耳机
- 鞋/手套
- 两只杯/瓶
- 多配件套装
- 拆出的零件

内部记录：

```text
BEAT n
Object A: <location/state>
Object B: <location/state>
Container: <location/open-closed state>
```

例如：

```text
BEAT 1
L earbud: left ear
R earbud: right ear
case: desk / open
```

下一镜若变成：

```text
L earbud: case
R earbud: hand
```

必须存在：
- 可见的摘取/移动动作；或
- 明确动作匹配切，且前后状态不冲突。

禁止：
上一镜两只耳机还在耳朵，下一镜一只已经自动躺在仓里。

如果收纳过程不是核心Proof，宁可：

> `先建立“她开始摘耳机” → 硬切到两只已正确收好`，

也不要生成矛盾的中间状态。

---

# 6. Action Cut Trigger｜什么时候必须切镜

满足任一，优先主动切镜：

1. 从外观进入内部结构；
2. 操作侧发生变化；
3. 需要看清接口/槽位/开口；
4. 开始精细抓取厘米级小物体；
5. 从产品操作进入人体佩戴；
6. 当前机位无法同时满足人物可操作性与Proof可见性；
7. 同镜即将出现第二项高风险接触；
8. 简单动作正在被拉成长时间慢动作；
9. 成对物体状态将发生跨位置变化。

切镜是降低歧义，不是失败。

---

# 7. 镜头描述最小信息

关键产品操作内部至少判断：

```text
CAMERA SIDE:
ACTOR ORIENTATION:
PRODUCT WORKING SIDE:
HAND + CONTACT:
STATE BEFORE:
STATE AFTER:
ACTION TEMPO:
```

最终提示词不必机械输出字段名，但必须判断完成。

---

# 8. Commercial Camera Rule｜稳定也要有能量

剧情广告镜头切换由事件驱动：

`事件发生`
→ `人物反应`
→ `关键操作`
→ `Proof / Benefit`
→ `结果/关系/情绪变化`

优先：
- 事件中开场
- 任务/问题Reaction
- 产品操作切OTS/操作侧
- Benefit/Proof后切Reaction
- 新行动推进

避免：
- 全片同一个正面中景
- 产品一直正面对镜头
- 无因果环绕
- 简单动作长期占镜

---

# 9. Silent QA｜关键交互必检

- [ ] 人物能从当前方向真实使用产品吗？
- [ ] 工作面没有为了镜头背离人物吗？
- [ ] 操作前是否需要主动切OTS/操作侧？
- [ ] 一镜是否塞了2项以上高风险接触？
- [ ] 取出/放回有明确起点、接触、路径、终点吗？
- [ ] 简单动作的时间是否过长，导致拖沓/老年感？
- [ ] 蓄力是否来自事件/声音/剪辑，而不是慢动作？
- [ ] 成对/多件产品逐镜状态是否有Ledger？
- [ ] 状态变化是否都有动作或合法动作匹配切？
- [ ] Proof可见性没有破坏真实操作逻辑？

任何一项失败：

> 先改机位、动作节拍、状态设计或拆镜，不先追加一串负面词。
