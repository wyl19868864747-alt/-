# SCENE STAGING COMPILER｜场面调度、元素组合与空间语义编译

> 来源：7-Eleven 30秒剧情买量广告真实生成复盘。19秒目标是“人物买完东西离开7-Eleven”，Prompt同时要求“人物 + 购物袋 + 7-Eleven店面/品牌环境”，但没有先锁出店方向、人物朝向、起终点与镜头位置，模型为了保留店面品牌视觉，把人物安排成背对镜头朝店面移动，语义读成“走进店里”。
>
> 目标：解决“元素都出现了，但组合关系错误，导致场面意思反了”的导演决策问题。

---

# 0. 核心定义

元素清单不是场面调度。

错误思路：

`人物 + 品牌店面 + 购物袋 + 离开`
→ 让模型自己决定谁在哪里、朝哪走、镜头在哪。

正确顺序：

`事件意义`
→ `起始状态`
→ `状态变化`
→ `人物/物体走位`
→ `运动方向`
→ `画面前中后景关系`
→ `机位`
→ `品牌/产品元素嵌入`
→ `下一个Beat交接`

核心原则：

`EVENT MEANING > ELEMENT PRESENCE`

`BLOCKING BEFORE FRAMING`

`ACTION DIRECTION > BRAND VISIBILITY`

`RELATIONSHIP BETWEEN ELEMENTS > ELEMENT CHECKLIST`

如果所有要求元素都出现了，但观众读出的事件意义与Story Beat相反，判定：

`FAIL｜STAGING SEMANTIC REVERSAL`

---

# 1. ELEMENT ROLE ASSIGNMENT｜元素先分角色

复杂镜头中，每个元素必须先知道自己“负责什么”，不能所有东西同时抢主画面。

常用角色：

- `PRIMARY ACTOR`：执行主要动作的人
- `ACTION TARGET`：人物正在接近/离开/拿取/交互的目标
- `PROOF OBJECT`：必须让观众看清的产品/结果
- `SPATIAL ANCHOR`：帮助理解空间的门、柜台、桌、车、入口等
- `BRAND ANCHOR`：店招、包装、品牌色、品牌环境
- `PROP`：袋子、杯子、手机等支持动作的道具
- `BACKGROUND`：只提供氛围，不改变主要动作语义

硬规则：

> **品牌元素通常只能在动作关系确定后再嵌入构图，不能为了“必须看到Logo/店面”反过来改变人物的运动方向。**

---

# 2. SCENE STATE CARD｜先写状态，不先写镜头

只要一个Beat满足任一条件，就静默建立Scene State Card：
- 人物进入/离开一个空间；
- 人物跨门、上/下车、进/出店；
- 同时需要表现人物 + 场所 + 品牌/产品 + 道具；
- 画面中3个以上关键元素必须建立明确关系；
- 上一镜与下一镜存在明显空间状态变化。

内部字段：

```text
STORY INTENT:
观众这一镜必须读懂什么？

START STATE:
人物/产品/道具开始在哪里、是什么状态？

END STATE:
这一镜结束时他们必须在哪里、是什么状态？

PRIMARY ACTION:
唯一主动作是什么？

FROM:
动作从哪里开始？

THROUGH:
通过什么真实路径/入口？

TO:
动作到哪里结束？

ACTOR FACING:
人物身体/脸主要朝向哪里？

MOVEMENT VECTOR:
朝镜头 / 远离镜头 / 左→右 / 右→左 / 室内→室外 / 室外→室内

PROP STATE:
人物手里/身上应该持有什么？

SPATIAL LAYERS:
前景 / 中景 / 背景分别是什么？

BRAND ANCHOR:
品牌元素在哪里出现才不破坏动作语义？

CAMERA POSITION:
镜头必须位于动作路径的哪一侧，才能让目标事件一眼读懂？

NEXT BEAT HANDOFF:
下一镜需要继承什么状态？
```

---

# 3. FROM → THROUGH → TO｜位移动作必须编译成路径

禁止只写：
- 走出店面
- 走进房间
- 离开餐厅
- 上车
- 下车
- 走向柜台

因为这些词对生成模型来说方向信息不足。

必须至少建立：

`FROM → THROUGH → TO`

例如“离开7-Eleven”：

`店内`
→ `自动门打开`
→ `人物穿过门槛`
→ `到店外人行区域`
→ `继续远离店门`

如果镜头在店外：

`店门在背景`
→ `人物从门内出现`
→ `穿过门`
→ `向镜头方向走来`
→ `人物与店门距离持续增加`

这比只写“离开店面”稳定得多。

---

# 4. DIRECTION SEMANTICS LOCK｜进入/离开不能只靠动词猜

## EXIT｜离开
至少满足：
- 起点在空间内部；
- 经过真实出口；
- 终点在外部；
- 运动过程中与入口/内部的距离增加。

## ENTER｜进入
至少满足：
- 起点在空间外部；
- 朝入口接近；
- 经过真实入口；
- 终点进入内部；
- 与外部参考点距离增加、与内部目标距离减少。

### 方向QA
如果目标写“离开”，最终画面却表现为人物越来越靠近店门/入口：

> 立即判定语义反转，重排Blocking或机位。

---

# 5. BLOCKING BEFORE CAMERA｜先让人站对，再选机位

镜头设计必须服从已经确定的走位。

错误：
> 想同时看到人物和7-Eleven店招 → 镜头对准店面 → 再让人物“离开”。

结果模型可能让人物背对镜头朝店面走，因为这样Logo最容易保留。

正确：
1. 先锁人物动作：`从店门出来，向外走`；
2. 再锁身体方向：`人物背对店门，面向外部/镜头方向`；
3. 再找机位：`镜头在店外、位于人物前方`；
4. 最后安排品牌：`7-Eleven店招保持在人物身后上方背景`。

核心：

`BLOCKING → CAMERA → BRAND COMPOSITION`

---

# 6. DEPTH LAYER GRAMMAR｜复杂元素用前中后景固定关系

当必须同时看到人物、品牌场所、产品/道具时，优先明确前中后景。

例如7-Eleven正确退出镜头：

```text
BACKGROUND:
7-Eleven店面与清楚店招

MIDGROUND:
自动门与店门入口

FOREGROUND:
两位女性手提已购买商品袋，刚从自动门出来，面向镜头方向快步离开
```

人物向前景运动，店面停留在背景，因此：
- “离开”语义清楚；
- 店招仍可见；
- 购物完成状态也可见。

比“人物离开店面，背景能看到品牌”更明确。

---

# 7. ELEMENT COMBINATION RULE｜元素必须有关系词，不只列名词

如果一个镜头包含3个以上核心元素，最终Prompt不能只列：

`人物、7-Eleven、购物袋、店门`

必须给关系：

`两人手提购物袋`
+
`从7-Eleven自动门内走出`
+
`店门在她们身后`
+
`她们继续向镜头方向前进`
+
`店招保持在背景上方`

每个关键元素至少承担一个：
- 动作关系；
- 位置关系；
- 因果关系；
- 视觉层级。

没有关系的元素应删除，避免提示词噪音。

---

# 8. ONE PRIMARY EVENT PER SHOT｜一镜只有一个语义主动作

复杂场面不能同时要求：
- 走出店门；
- 展示品牌；
- 两人聊天；
- 打开购物袋；
- 展示商品；
- 做强Reaction。

先决定这一镜观众必须读懂的唯一事件。

例如19秒镜头：

> **唯一主事件：她们已经买完，正从7-Eleven出来。**

所以必须优先保证：
- 出店方向；
- 购物袋状态；
- 店面在身后。

品牌展示只是辅助，不得反转动作。

---

# 9. BRAND VISIBILITY GATE｜品牌不能为了露出破坏场面逻辑

品牌露出有三种安全位置：

### A. Spatial Background Anchor
人物完成动作，品牌在背景提供地点确认。

### B. Product/Packaging Anchor
人物使用/拿着商品，包装自然提供品牌。

### C. Dedicated Hero
独立品牌/产品Hero镜头。

若在剧情动作镜头中，“为了让Logo更大”会导致：
- 人物转错方向；
- 产品朝向不合理；
- 人物走回原地点；
- 动作语义反转；

则：

> 缩小品牌露出或另切品牌Hero，不能牺牲故事动作。

---

# 10. SCENE TRANSITION HANDOFF｜场景切换必须继承结果

位置跳转前，前一Beat最好给出一个清楚的完成状态。

例如：

店内Product Montage
→ `购物篮/袋子已经装好`
→ `人物从店门走出`
→ `下一镜回到公寓，商品已经摆上桌`

这样空间转换是：

`购买完成`
→ `离店`
→ `带回家`

而不是：

`店内拿商品`
→ `人物莫名朝店门走`
→ `家里突然出现一桌商品`

场景转场必须有状态接力。

# 11. 7-ELEVEN 19秒错误的标准修正

## 错误写法

> 两人快步离开店面，背景明确还能看到7-Eleven品牌环境。

问题：
- “离开”没有起点/终点；
- 没锁人物朝向；
- 没锁镜头在店内还是店外；
- “背景看到品牌”与“离开”发生构图竞争；
- 模型选择了最容易保留品牌的构图，导致人物背对镜头朝店门走。

## 正确编译

> 店外正对入口的中景。7-Eleven店招位于背景上方，自动门在中景。自动门打开，两位女性手提装满商品的购物袋从店内走出，背对店门、面向镜头方向快步走来；她们与店门的距离持续增加，7-Eleven店面始终留在她们身后。硬切回公寓。

这句话同时锁了：
- 空间；
- 动作起点；
- 门；
- 运动方向；
- 人物朝向；
- 购物结果；
- 品牌位置；
- 下一镜交接。

# 12. 与其他模块的边界

## Physical Logic DNA
回答：
> 这个动作在现实世界能不能发生？路径、状态、支撑、动力是否合理？

## Scene Staging Compiler
回答：
> 人物、产品、品牌、空间这些元素怎样组合，观众才会读对这件事？

## Camera × Action Compiler
回答：
> 已经正确走位以后，机位怎样让操作和Proof看清，同时不越轴？

## Performance/FACS
回答：
> 已经明确发生的事件，人物怎样Reaction？

正确调用顺序：

`Story Beat`
→ `Scene State / Staging`
→ `Physical Logic`
→ `Performance/FACS`
→ `Camera × Action`
→ `Seedance Prompt`

# 13. 最终提示词压缩规则

内部可以完整建立Scene State Card，但不要把所有字段都背给模型。

最终只保留最有杠杆的：

`机位/空间起点 + 主动作 + FROM→THROUGH→TO + 人物朝向 + 前中后景关键关系 + 必要道具状态 + 终点`

例如最终只需：

> `店外正对入口中景；自动门在两人身后打开，她们手提购物袋从店内走出，面向镜头快步离开，7-Eleven店招始终位于身后背景。`

不要再额外堆十句“不要走进去、不要反向、不要转身”等负面补丁。

---

# 14. SILENT QA

- [ ] 这一镜观众必须读懂的唯一事件是什么？
- [ ] 每个核心元素都有明确角色，不是单纯“必须出现”
- [ ] 人物/物体的START与END清楚
- [ ] 位移有FROM → THROUGH → TO
- [ ] 人物身体朝向与动作目标一致
- [ ] “进入/离开”不会因机位产生相反语义
- [ ] 前景/中景/背景关系帮助而不是破坏主要事件
- [ ] 品牌露出没有改变人物动作方向
- [ ] 道具状态与Story结果一致
- [ ] 当前Beat结束状态能自然交给下一Beat
- [ ] 如果删掉品牌/装饰元素，主要事件仍然空间正确
- [ ] 最终Prompt只输出少量高杠杆关系，不堆无用态度描述

最终原则：

`MEANING FIRST`

`STATE BEFORE SHOT`

`BLOCKING BEFORE CAMERA`

`ACTION DIRECTION BEFORE BRAND`

`ELEMENT RELATION > ELEMENT PRESENCE`
