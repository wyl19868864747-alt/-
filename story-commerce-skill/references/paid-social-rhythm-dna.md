# PAID SOCIAL RHYTHM DNA｜剧情买量广告节奏、情绪与声画推进

> 来源：4条海外买量剧情游戏广告真实样本 + 后续实体商品剧情广告Benchmark。
>
> 目标：提炼可迁移到剧情带货广告的节奏、情绪、声画与产品接管规律。游戏是虚拟产品，试玩是CTA；物理商品同样适用“剧情吸引 → 产品接管 → Proof升级 → 转化”的广告骨架。

---

# 0. 核心结论

这些广告不是“完整短剧 + 结尾广告”，也不是“产品第一秒必须出现”。

更接近：

`高情绪未完成事件 → 持续升级 → 商业需求/欲望被明确 → 产品成为答案 → 产品接管画面 → Proof逐级升级 → CTA`

核心原则：

`STORY HOOK MAY LEAD`

`BUT PRODUCT MUST TAKE OVER`

`PROOF ESCALATION > POST-REVEAL DRAMA`

`AUDIO FOLLOWS EVENT, NOT THE CLOCK`

新增节奏总则：

`RHYTHM = FUNCTION CHANGE, NOT SHOT SPEED`

前段剧情不是塑造人物完整人生，而是预热一个产品能够解决/满足的强需求。节奏也不是“越快越好”，而是控制观众什么时候得到新信息、什么时候等待、什么时候看见结果、什么时候需要停下来读完画面。

---

# 1. 实测节奏特征

4条样本时长约46–67秒。

自动镜头变化检测显示：
- 全片平均镜头长度约1.5–1.8秒；
- 多数样本前10–20秒更快，约1.1–1.4秒/镜；
- 产品/游戏进入后不回到长篇对白，而快速转入UI、结果、金额、玩法、验证与CTA。

因此：
> **前段快不是乱切，而是每1–3秒给新信息、新Reaction或新情绪。**

30秒实体商品广告不机械复制1秒一镜；但若大量镜头稳定在2.5–4秒且信息不升级，很容易产生“电视短片感”。

更重要的是：镜头时长只是结果，不是设计起点。先决定当前Beat的节奏职责，再决定是否需要加速、停住或延长。

---

# 2. RHYTHM FUNCTION MAP｜先定节奏职责，再定镜头长度

每个关键Beat只标一个主功能；不固定顺序，也不要求全部出现：

- `ESTABLISH`：建立人物、空间、常态、产品或当前关系。
- `ACCELERATE`：连续加入新动作、新证据、新问题或Reaction。
- `ANTICIPATE / DELAY`：答案前短暂减速、停顿、抽空声音或减少信息。
- `REVEAL`：异常、产品、价格、结果、关系或答案被明确看见。
- `SPECTACLE HOLD`：重大视觉结果已经出现，主动减少竞争动作，让观众真正看清。
- `PROOF / VERIFY`：增加新的可见证据，确认而不是重复刚才的Reveal。
- `RELEASE`：压力下降、空间打开、人物状态放松或摄影机恢复稳定。
- `CLOSE`：产品Hero、决定、品牌记忆或CTA收束。

推荐的节奏不是固定公式，但常见有效关系是：

`建立 → 加速 → 等待 → 揭示 → 停留 → 再证明/升级 → 释放 → 收束`

连续多个Beat都承担相同功能时，容易产生“同速”“同情绪”“一直在演但没推进”的感觉。优先合并、删减或改变其中一个Beat的职责。

---

# 3. BREATHING RHYTHM｜呼吸不是空白，是信息压力变化

真正的节奏呼吸：

`信息加密 → 减少信息 → 重要结果出现 → 给结果阅读时间 → 再推进`

有意减速必须至少完成一项：
- 让观众消化刚发生的信息；
- 等待人物理解/决定；
- 让产品结构、材质或Proof被看清；
- 建立尺度、空间或视觉奇观；
- 为下一次升级蓄力。

无职责的长停留不是“高级”，只是拖。

同样，持续快切也不是“短视频感”。如果每次切镜都没有新信息，只是同一动作换机位，会产生忙而不紧的AI广告感。

---

# 4. SPECTACLE HOLD｜视觉奇观必须有观看时间

完整产品Reveal、巨大尺度变化、超现实主体、关键变形完成态、强Proof、决定性Reaction到达最可读状态时：

1. 先让主体完整进入可读构图；
2. 摄影机明显减速、落稳或维持简单运动；
3. 同时发生的次要动作减少；
4. 焦点和主体关系保持稳定；
5. 观众完成“看见 + 理解”后再进入下一Beat。

不要机械规定固定秒数。判断标准：

> **观众是否来得及识别主体、尺度、结果和它为什么重要。**

这条尤其适用于超现实、视觉奇观、产品世界化和高级Hero画面。贵的画面如果一闪而过，视觉价值等于没被使用。

---

# 5. EMOTION ESCALATION｜情绪不是平滑线，是阶梯

样本前半常用高强度情绪入口：
- 背叛/误会；
- 贫困/羞辱；
- 善意/意外回报；
- 旧关系冲击；
- 钱的焦虑与突然希望。

真正可迁移的是：

`强情绪状态 → 新信息升级 → Reaction → 更高/不同一级状态`

避免：
`质疑 → 平静回答 → 再质疑 → 平静回答`

后者逻辑完整但没有情绪斜率。

对高价/克制品类，可以降低长期表演幅度，但不能降低信息升级强度，也不能把关键Reveal Reaction压平。

默认和 `performance-facs.md` 联动：
- 冲突：3–4/5
- Delay：2–3/5
- Burst/Reveal：4–5/5
- Verify：3–4/5
- Payoff：2–4/5

不是死分数，只用于避免全片同一情绪平面。

---

# 6. STORY HOOK ROUTE｜允许产品延迟，但必须先建立商业需求

产品本体可以中段才明确出现，只要前段持续建立的就是它即将承接的核心商业需求。

例如游戏广告前段虽然没有游戏UI，但一直在建立：
`缺钱 / 钱的冲突 / 钱的机会 / 对赢钱的好奇`

允许两种开场：

## ROUTE A｜DIRECT PRODUCT HOOK
产品/产品矛盾第一秒出现。

## ROUTE B｜NEED-LED STORY HOOK
产品可暂缓出现，但前段必须持续锁定明确商业需求、欲望或犹豫；后续产品必须直接接管并解决/改写它。

禁止：
前段只是好看的情节，产品出现后才临时找卖点。

---

# 7. PRODUCT TAKEOVER POINT｜产品必须接管广告

产品一旦进入，就迅速从剧情配角变成主角。

常见后半：
`产品被提到`
→ `直接展示产品/界面`
→ `第一次结果`
→ `更强结果/验证`
→ `功能/使用连续展示`
→ `CTA`

产品出现后，不再回去演大量独立人物支线。

对30秒实体商品：
- Need-led Hook时，产品通常约8–14秒明显接管；
- 约15秒以后多数高价值镜头应属于Product Detail / Proof / Use / Reframe；
- 不是27–30秒才突然给Hero。

`PRODUCT TAKEOVER > LATE PRODUCT HERO`

---

# 8. PROOF LADDER｜证据必须逐级变强

游戏样本常见：

`听说/宣称`
→ `看到结果`
→ `金额`
→ `提现/支付账户`
→ `实际玩法`
→ `CTA`

物理商品同样要逐级增加新信息。

服装示例：
`挂着外观`
→ `材质/结构细节`
→ `完整上身`
→ `侧面/动态`
→ `真实生活使用状态`
→ `最终Hero`

不是重复拍三次“很好看”。

---

# 9. REACTION CUT DNA｜Reaction是节奏标点

常用：
`事件/台词 → Reaction近景 → 下一条信息`

Reaction短、明确、可读，负责帮观众消化刚发生的信息。

推荐：
- 强信息后快速切Reaction；
- 不让人物边完成复杂动作边念长对白；
- Reaction后必须有新行动/新问题；
- 高潮Reaction允许更强，但不拉长。

对剧情带货，Reaction对象必须是产品、Proof或商业信息变化。

Reaction本身也可承担短暂“呼吸”，但只有它展示人物真正理解了什么时才成立；纯瞪眼、纯惊讶不算有效Beat。

---

# 10. AUDIO / BGM RHYTHM｜声画不是背景装饰

样本音轨明显分段，不是一条BGM从头铺到底。

默认结构：

`HOOK HIT / STINGER`
→ `对白段BGM让位`
→ `新事件用短SFX标点`
→ `关键答案前短暂压低/抽空`
→ `Reveal / Product Pivot时能量抬升`
→ `Proof Montage进入连续节奏脉冲`
→ `Payoff稍放松`
→ `CTA干净收束`

禁止只写：
“全片高级BGM，高潮加强”。

必须写清：
`哪个事件前收 → 哪个事件爆 → 哪个Proof进入节奏段 → CTA怎么收。`

## 10.1 AUDIO EVENT MAP｜每条30秒广告静默建立

内部至少锁：

```text
HOOK AUDIO CUE:
DIALOGUE BED:
FIRST ESCALATION SFX:
DELAY DROP / SILENCE:
PRODUCT PIVOT HIT:
PROOF MONTAGE RHYTHM:
PAYOFF RELEASE:
CTA END HIT:
```

最终Prompt不必逐字段输出，只保留真正有杠杆的节点。

## 10.2 BGM不能和对白抢权重

对白镜头：
- BGM主动压低；
- 不用高频旋律盖住人声；
- Punchline / 决策句前可留0.1–0.4秒短空位。

Delay：
- 主动减少节拍/高频；
- 可以保留低频Pulse或环境声；
- “突然安静”本身就是情绪事件。

Reveal：
- Product Result先成立；
- 同一瞬间用Hit/Stinger抬升；
- 不让音乐先泄漏答案。

Spectacle Hold：
- 不需要持续加更多Hit；
- 必要时保留环境声、低频或简单持续音，让画面有阅读空间。

Proof Montage：
- 切镜与节拍/短SFX对应；
- 每个Proof不必都重击，避免噪音轰炸；
- 重点节点才用Bass Hit / Whoosh / Click / Snap / Fabric Flick等。

CTA：
- 减少复杂节奏；
- 保留品牌/产品Hero空间；
- 最后用短促干净End Hit收束。

---

# 11. CAMERA × RHYTHM HANDOFF｜镜头节奏随功能与情绪变化

与 `performance-facs.md`、`camera-action-compiler.md` 联动。

### Establish
`稳定观察 / 清楚空间 / 轻跟随，不急着炫技`

### Conflict / Accelerate
`轻手持 + 快速小推 + 短促甩镜 + 更近景别`

### Delay
`突然稳定 + Hold + 慢微推或固定等待`

### Reveal
`硬切 / 突然打开空间 / 遮挡解除 / Full Result进入完整构图`

### Spectacle Hold
`摄影机减速落稳，减少次要运动，让主体真正可读`

### Product Takeover
`Product Detail / Use / Proof之间快速动作匹配硬切`

### Payoff / CTA
`摄影机逐渐稳定，构图变干净`

不能全片用同一种推拉方式，也不能让摄影机一直比剧情更兴奋。

---

# 12. 30秒实体商品推荐节拍

不是死时间表：

```text
0–3s   HIGH-EMOTION / HIGH-CURIOSITY HOOK
3–7s   NEW EVIDENCE / ESCALATION
7–10s  COMMERCIAL NEED / QUESTION LOCK
10–13s PRODUCT PIVOT / DELAY
13–18s PRODUCT REVEAL / FIRST PROOF
18–24s PRODUCT TAKEOVER + PROOF LADDER
24–27s PRODUCT REFRAME / DECISION
27–30s PRODUCT-DOMINANT CTA / HERO
```

如果产品第一秒出现，前10秒全部改为产品相关冲突/细节/问题升级。

重点：
> **13–14秒后不要继续像短剧一样演人物，广告应明显进入产品接管阶段。**

这里的时间仅用于内部构思，不得机械覆盖用户已确定节奏，也不要因为“前3秒”就让每个开场都变成高频乱切。

---

# 13. 与电视短片感的区别

电视短片：
`人物关系 → 人物情绪 → 完整场景 → 产品只是道具`

高效剧情买量广告：
`事件抓人 → 商业需求升级 → 产品转折 → 产品证明不断升级 → 转化`

判断：
- 产品进入后，镜头密度是否向产品倾斜？
- Product Detail / Proof是否逐级增强？
- 人物Reaction是否服务产品？
- 后半是否还有无关支线？
- CTA前是否已经完成足够产品理解？
- 全片是否有节奏层次，而不是所有Beat都同样快/慢？
- 最重要的Reveal/奇观是否真正给了观众阅读时间？

若产品出现后仍主要看两个人聊天、走路、相处，高度怀疑 `TV SHORT DRIFT`。

---

# 14. 保护规则

不要机械抄游戏买量的极端贫困、婚外情、现金暴富、虚假奖金、强夸张数值。

真正迁移：
- 高信息密度；
- 情绪阶梯；
- Reaction切；
- Product Pivot；
- Product Takeover；
- Proof Ladder；
- 声画节奏变化；
- 节奏功能变化；
- Reveal后的可读停留；
- CTA前产品已经充分占据注意力。

高端服装等品类可以保持克制整体调性，但仍：
`QUIET PERFORMANCE ≠ FLAT RHYTHM`

---

# 15. Prompt Compile纪律

内部可以使用：
`ACCELERATE / DELAY / REVEAL / SPECTACLE HOLD / RELEASE`

最终Prompt不能只写：
`强节奏、有呼吸感、视觉冲击、Reveal震撼。`

必须转成具体变化，例如：

`她连续完成两个短促动作后突然停住，镜头也随之稳定；门打开，巨大主体完整进入画面，人物停止额外动作，镜头在完整构图上短暂保持，随后才切入产品近景。`

抽象目标留在Skill内部，生成模型只接收可执行的事件、动作、停顿、镜头响应和声音变化。

---

# 16. Silent QA

- [ ] 前3秒存在未完成事件、强矛盾或强视觉产品Hook
- [ ] 前10秒持续有新信息/Reaction/状态升级，而非只换机位
- [ ] 情绪强度有阶梯，不是全片同一平面
- [ ] 已建立主要Beat的Rhythm Function Map
- [ ] 全片不是从头到尾同一速度，至少存在有职责的加速/减速变化
- [ ] 若产品延迟出现，前段建立明确商业需求而非独立短剧情
- [ ] 产品出现后迅速接管广告，不回到长人物支线
- [ ] 后半至少2级不同Product Proof / Expression
- [ ] Reaction服务产品信息变化
- [ ] 重大Reveal/奇观/完整产品结果获得足够可读停留
- [ ] 已建立Audio Event Map
- [ ] BGM在对白时让位、Delay时压低、Reveal时Hit、Hold时让画面呼吸、Proof Montage时加密、CTA时收束
- [ ] 镜头节奏与功能一致：冲突更紧，Delay更稳，Reveal清楚，Hold落稳，CTA稳定
- [ ] CTA前观众已经经历完整Product Takeover
- [ ] 最终Prompt没有把“强节奏/呼吸/视觉冲击”等内部判断词直接扔给生成模型
- [ ] 片子不是最后3秒才突然像广告

最终原则：

`HOOK EARNS ATTENTION`

`RHYTHM CONTROLS EXPECTATION`

`PRODUCT TAKES OVER ATTENTION`

`PROOF ESCALATES DESIRE`

`AUDIO SHAPES EXPECTATION`

`LET THE IMPORTANT IMAGE LAND`

`CTA CONVERTS DESIRE`
