# ENGLISH PROMOTIONAL VOICEOVER｜英文宣传旁白编译器 V1.1

> 目标：在合适的广告Style与商业表达中，用英文宣传旁白补充产品身份、卖点与商业主线；但旁白不是默认必选项。若旁白会破坏风格、留白、沉浸感或高级感，则宁可不用。

---

## 0. 核心原则

`VOICEOVER IS STYLE-CONDITIONAL, NOT UNIVERSAL`

`VOICEOVER MUST COME FROM CONFIRMED PRODUCT TRUTH`

`ENGLISH BY DEFAULT WHEN VO IS USED`

`STYLE FEEL > FORCED NARRATION`

`VOICEOVER THREADS THROUGH THE FILM, IT DOES NOT EXPLAIN EVERY SHOT`

`SELLING POINT > EMPTY POETRY`

`NO NEW CLAIMS`

旁白的任务是：
- 在适合的Style下，把产品身份和卖点说清；
- 给画面一个商业主线；
- 在关键视觉/Proof之间形成连续感；
- 避免只有画面+BGM但商业表达过干。

但旁白不是为了“填满声音”。如果无旁白更符合该Style，就关闭旁白，只保留BGM / SFX / 环境声 / 人物对白。

---

## 1. VOICEOVER STYLE FIT GATE｜先判断该不该有旁白

在写任何旁白前，先静默判断：

```text
USER VO REQUIREMENT:
STYLE ID:
STYLE BENEFITS FROM SILENCE / SPACE?:
EXISTING CHARACTER DIALOGUE?:
COMMERCIAL MESSAGE ALREADY CLEAR VISUALLY?:
WOULD VO ADD CLARITY OR ONLY ADD NOISE?:
VOICEOVER MODE: OFF / AUTO / ON
```

优先级：
`用户明确旁白要求 > 用户明确无旁白 > Style自然度 > 角色对白 > 商业信息缺口`

### 强制关闭
如果用户明确要求：
- 无旁白；
- 纯音乐；
- 只要环境声 / SFX；

则 `VOICEOVER MODE = OFF`。

### 用户明确要求旁白
若用户明确要求旁白，则 `VOICEOVER MODE = ON`，但仍需根据Style控制密度、语气和字数。

### 用户未指定时
不是默认生成，而是：
> **根据Style + 画面商业清晰度自动决定是否加入英文旁白。**

只有旁白确实增加产品理解、卖点记忆或广告完整度时才加入。

## 2. STYLE × VOICEOVER POLICY｜12个Style的旁白倾向

### ST01 美式原生手机实拍风｜AUTO
- 如果有人物自然口播 / 对镜说话：优先人物口播，不额外叠旁白。
- 如果是纯动作型UGC且卖点容易显干：可加入自然、口语化英文VO。

### ST02 高端静奢广告风｜DEFAULT OFF
- 默认不加入旁白。
- 优先用留白、材质声、环境声、极简BGM和产品Hero建立高级感。
- 旁白容易破坏安静、克制、昂贵的视觉留白。
- 只有用户明确要求旁白，或产品事实必须口头解释时，才允许极少量、极短的英文VO。

### ST03 欧美高定时尚大片风｜AUTO / LOW DENSITY
- 可无旁白；优先音乐、Pose、切镜、产品视觉。
- 如加入，只用少量锋利Campaign式短句，不贯穿念满。

### ST04 好莱坞动作大片风｜AUTO
- 可用节奏强、短促、有推进力的英文VO。
- 若人物对白已承担剧情，则VO减少或关闭。

### ST05 超现实创意广告风｜AUTO
- 当视觉奇观本身已经正确表达卖点后，可用英文VO强化价值与品牌记忆。
- VO不能负责解释或修复错误奇观。

### ST06 未来科幻科技风｜AUTO
- 可用精确、干净、少词的英文VO。
- 如果视觉系统/产品Proof已经足够清楚，可保持无旁白。

### ST07 70年代复古美式胶片风｜AUTO
- 可根据广告语气使用复古Campaign式或叙述式英文VO。
- 不伪造年代事实或历史品牌信息。

### ST08 Y2K千禧流行风｜AUTO
- 可使用短、抓耳、节奏化的英文VO / tagline。
- 避免长篇解释。

### ST09 日系清透生活风｜AUTO / LOW DENSITY
- 优先安静、自然、轻柔。
- 只有商业信息偏空时，才加入极轻、极短英文VO。

### ST10 地中海阳光假日风｜AUTO
- 可加入轻松、明亮、生活方式感英文VO；也允许纯音乐与环境声。

### ST11 美式西部荒野风｜AUTO
- 可使用简短、有质感、有重量的英文VO。
- 不因为Style自动写成“牛仔旁白”或伪造地域身份。

### ST12 黑色电影暗黑风｜AUTO
- 可使用低沉、短促、叙述感英文VO；Noir本身允许旁白成为风格组成部分。
- 但不能因为Noir自动加入犯罪、危险或恐怖信息。

固定：
> **除ST02默认关闭外，其余Style均为AUTO，而不是强制ON。**

## 3. 旁白从什么信息生成

只允许使用：
- 产品名称 / 品类；
- 用户确认的产品特征；
- 用户确认的核心卖点；
- 已确认的真实功能/结果；
- 已确认品牌调性；
- 已确认CTA。

禁止自行增加：
- 最好 / 第一 / No.1；
- 医学或健康结论；
- 精确数据；
- 功效时长；
- 竞品比较；
- 保证性表达；
- 未确认成分/材料/产地。

如果产品事实不足，旁白只能使用更保守的感官/体验表达，不能补事实。

## 4. 旁白结构｜不是一整段念到底

当 `VOICEOVER MODE = ON` 时，默认形成：

`HOOK / PRODUCT IDENTITY`
→ `SELLING-POINT SETUP`
→ `PROOF / SPECTACLE PAYOFF`
→ `BRAND / CTA CLOSE`

15秒广告通常：
- 2–4个短语义段；
- 总英文词数约12–28词；
- 每段尽量3–9个词；
- 留空间给动作、Reaction、SFX和音乐。

若Style强调留白、安静或高端视觉，可进一步缩成：
- 1–2个短句；
- 甚至只在结尾出现一个Campaign Line。

30秒广告通常：
- 3–6个短语义段；
- 总英文词数约25–50词；
- 不追求旁白占满每一秒。

“贯穿”只表示前/中/后有商业连接，不表示连续念满全片。

## 5. 写法

优先：
- 短句；
- 有广告记忆点；
- 与视觉卖点同方向；
- 可自然拆成多段；
- 英语母语广告语感。

避免：
- 说明书口吻；
- 把画面逐帧描述出来；
- 长句；
- 过度文艺但不知道卖什么；
- 与屏幕文案完全重复；
- 每句都以产品名开头。

固定：
`SHOW THE EVENT, SAY THE VALUE`

## 6. ST05超现实广告旁白

当命中ST05时，先通过：
- `surreal-spectacle-decision-gate.md`
- `surreal-visual-compiler.md`

确保关掉声音后奇观本身已经能正确指向卖点。

然后再判断是否需要VO。

例如伯牙绝弦，已确认卖点：
`清爽不腻，茶底扎实`

若需要VO，可形成类似：

```text
“Tea that comes through.”
“Smooth, light, never heavy.”
“Boya Juexian — tea at the core, freshness in every sip.”
```

只是表达示意，不代表品牌官方文案；如果品牌提供官方英文文案，以官方内容优先。

---

## 7. 与角色对白的冲突处理

优先级：
`用户指定Exact Dialogue > 关键角色对白 > Voiceover > BGM装饰`

若一个2–4秒Beat已有关键人物台词：
- 默认不再叠Voiceover；
- 把VO移到无对白窗口；
- 或压成结尾短句；
- 如果人物对白已经把卖点说清，可以直接关闭VO。

禁止人物对白和旁白同时抢同一事实。

## 9. QA

- [ ] 用户是否明确禁止旁白？若是OFF。
- [ ] 当前Style是否适合旁白？
- [ ] ST02是否默认保持无旁白？
- [ ] 加旁白是否真的增加商业理解，而不是只因为“画面有点空”？
- [ ] 所有旁白是否为英文？
- [ ] 是否只使用已确认产品事实与卖点？
- [ ] 是否避开角色关键对白？
- [ ] 是否给SFX、Reaction和画面留空间？
- [ ] 结尾旁白若存在，是否和CTA/音频一起收束？
- [ ] 如果删掉VO，画面本身是否仍然成立？

最终：

> **不是每条广告都需要旁白。**
>
> **合适的Style里，英文旁白负责让卖点被记住；不合适的Style里，留白本身就是表达。**
