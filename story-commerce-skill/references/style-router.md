# Style Router

Purpose: resolve one Primary Style **before Hook and Story design** so the selected visual language can shape the expression of the ad from the start.

Read `references/styles/style-index.md`, then load exactly one Primary Style DNA file.

## Route A — User Style Lock

If the user explicitly selects a Style or clearly requests an equivalent visual language, preserve it as `HARD STYLE LOCK`.

Do not reject or replace a user-selected Style because of category, price tier, physical/digital product type, or conventional industry taste.

## Route B — Auto Style Fit

If the user gives no Style preference, select one Primary Style by judging:

1. verified product identity and physical character
2. target audience and platform
3. Best Proof readability
4. desired perception / emotional payoff
5. type of Hook the product can honestly support
6. generation stability

Do not auto-select a Style just because it is visually fashionable.

## Authority

Style is resolved early and may influence:
- Hook visual grammar and performance intensity
- story rhythm and social / cinematic behavior
- casting and environment tendency
- camera, light, texture, color, sound
- CTA tone and presentation

Style may not modify:
- product facts, price, SKU, function, claims
- Core Decision
- Best Proof
- true conversion action

`STYLE SHAPES EXPRESSION, NOT TRUTH`
`STYLE ≠ LOCATION`
`STYLE ≠ FIXED STORY TEMPLATE`
