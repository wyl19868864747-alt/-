# STYLE DNA LIBRARY｜商业上架视觉风格库 V1

> 用途：前台用户选择“成片看起来是什么风格”。
>
> 本库只锁 **视觉风格 + 大概环境特征**，不锁剧情、不锁Proof、不锁具体地点。
>
> 核心：`STYLE ≠ LOCATION`｜`STYLE ≠ STORY TEMPLATE`｜`PRODUCT TRUTH > STYLE`

每个Style必须可以迁移到实体商品、数字产品、软件、游戏、服务等不同产品形态。环境描述只作为视觉倾向，最终地点由 `location-router.md` 根据产品与剧情决定。

## ST01｜美式原生手机实拍风

**视觉核心**：真实美国社媒原生内容感，手机摄影、轻手持、自然皮肤与材质、略带生活化的不完美构图，不像传统棚拍广告。

**光影 / 色彩**：自然窗光、室内实际灯源、正常曝光、真实白平衡，避免过度电影调色。

**镜头质感**：手机广角/标准焦段、轻微手持、自然跟随、偶尔快速转向，运动来自人物行为。

**环境倾向**：住宅、厨房、街道、车内、工作空间、商店等真实日常环境；不固定具体场地。

**压缩风格句**：`美式社媒手机实拍质感，自然光与真实生活细节，轻手持跟随，构图自然不过度精修。`

## ST02｜高端静奢广告风

**视觉核心**：安静、克制、昂贵感；大量留白、秩序构图、精致材质、产品细节被认真观看，不靠堆奢侈符号制造高级。

**光影 / 色彩**：低饱和中性色、柔和但有方向性的轮廓光与材质高光，黑白灰、米色、深木等克制体系优先。

**镜头质感**：稳定、慢推、微距、短距离滑动，镜头动作少但精准。

**环境倾向**：干净、有秩序、材质高级的真实生活或商业空间；环境可以普通，但画面必须克制精致。

**压缩风格句**：`高端静奢广告质感，低饱和克制色彩与精致材质光，稳定慢推和微距细节，留白充足。`

## ST03｜欧美高定时尚大片风

**视觉核心**：强造型、强轮廓、强构图，人物与产品像Fashion Campaign / Editorial，画面更大胆、更姿态化、更具有视觉张力。

**光影 / 色彩**：可使用硬闪、雕塑式侧光、强轮廓光或高对比棚光；颜色可大胆但保持单一主视觉逻辑。

**镜头质感**：大胆裁切、低机位/高机位、快速定格式硬切、短推拉、时尚Pose与产品特写交替。

**环境倾向**：摄影棚、建筑空间、街头、后台、极简室内等均可，由产品决定，不绑定秀场。

**压缩风格句**：`欧美高定时尚大片，强造型与大胆编辑构图，雕塑式灯光，人物姿态和产品特写形成高张力画面。`

## ST04｜好莱坞动作大片风

**视觉核心**：大银幕动作电影能量，强运动、强方向、强空间纵深，画面有冲击但仍保持动作因果清楚。

**光影 / 色彩**：高反差真实光源、强逆光/边缘光、环境层次明确；烟尘、雨、水汽等只在合理时作为气氛，不强制加入。

**镜头质感**：跟拍、快速推近、短甩镜、低机位、大广角运动、关键结果瞬间稳定或硬切。

**环境倾向**：任何真实任务空间都可动作电影化；不要求爆炸、追车或危险行为。

**压缩风格句**：`好莱坞动作大片质感，强纵深与方向性光影，动态跟拍和快速推近，高能但动作因果清晰。`

## ST05｜超现实创意广告风

**视觉核心**：真实摄影底座上出现一个明确、不可能但可读的视觉机制；强调巨物、悬浮、空间变化、比例反差或视觉隐喻，但产品本体必须稳定。

**光影 / 色彩**：现实光源逻辑优先，超现实元素继承现场光影与材质关系，避免“贴上去”的VFX感。

**镜头质感**：先建立真实空间，再揭示异常；可用突然拉远、尺度揭示、空间变形、受控环绕等方式制造奇观。

**环境倾向**：优先从普通现实环境出发，再让一个核心视觉机制改变画面；不固定任何世界。

**压缩风格句**：`真实摄影底座上的超现实创意广告，只保留一个清晰视觉奇观机制，异常元素与真实光影和空间完全融合。`

## ST06｜未来科幻科技风

**视觉核心**：精密、未来、系统化、冷静，强调结构、几何、材质和先进感，不靠大量乱码UI制造科技感。

**光影 / 色彩**：冷中性色、金属反射、结构化边缘光、受控光带与干净暗部；可有少量高纯度科技色作为点缀。

**镜头质感**：精确滑动、扫描感推进、对称构图、微距结构展示、稳定环绕。

**环境倾向**：现代极简空间、智能生活空间、科技建筑、抽象系统空间均可；虚拟产品可通过设备/界面/抽象功能空间表达。

**压缩风格句**：`未来科幻科技广告，冷静精密的几何与金属质感，结构化边缘光，稳定扫描式推进和微距结构展示。`

## ST07｜70年代复古美式胶片风

**视觉核心**：明确1970s Americana视觉记忆，暖胶片、颗粒、轻晕光、复古材质与服装轮廓，具有真实年代摄影质感。

**光影 / 色彩**：暖棕、芥末黄、橄榄绿、奶油白等70s色系；自然阳光与暖钨丝灯优先。

**镜头质感**：35mm/16mm胶片观感、轻颗粒与高光晕染、缓慢手持/推拉、自然镜头呼吸感。

**环境倾向**：复古住宅、公路生活、餐饮空间、老式商业空间、郊区生活等年代线索可按产品选用；现代产品外观不得被复古化改造。

**压缩风格句**：`70年代复古美式胶片质感，暖棕与芥末色系、真实颗粒和轻晕光，Americana年代细节自然融入环境。`

**压缩风格句**：`Y2K千禧流行风，硬闪光、银色与透明材质、高饱和点色、鱼眼和早期数码相机质感，年轻张扬。`

## ST09｜日系清透生活风

**视觉核心**：清洁、通透、安静、生活化，大量空气感与自然细节，视觉刺激低但质感真实舒适。

**光影 / 色彩**：高键自然柔光、白色/浅木/浅灰/低饱和绿，阴影柔和，肤色与产品颜色真实。

**镜头质感**：稳定观察、缓慢轻推、静态构图、浅景深细节，节奏舒展但不拖沓。

**环境倾向**：干净住宅、厨房、工作台、街边生活、自然空间等简洁环境；人物地域不由风格强制决定。

**压缩风格句**：`日系清透生活风，高键自然柔光与浅木中性色，画面安静通透，稳定观察和轻微慢推强调生活细节。`

## ST10｜地中海阳光假日风

**视觉核心**：明亮、松弛、阳光充足、具有南欧假日与生活方式广告的开放感。

**光影 / 色彩**：高亮自然阳光、蓝白主色、暖肤色、石材/灰泥/水面反射等清爽材质。

**镜头质感**：宽阔构图、自然跟拍、轻微慢动作、阳光逆光、空气与风的流动感。

**环境倾向**：明亮露台、白墙空间、泳池/水边、街巷、开放住宅或旅行感空间；无须真的出现海景。

**压缩风格句**：`地中海阳光假日风，蓝白与暖阳主导，明亮开放、空气与风感明显，宽阔自然跟拍呈现松弛生活方式。`

## ST11｜美式西部荒野风

**视觉核心**：粗粝、硬朗、真实材质、土地与劳动感，强调力量、重量和户外空气，不等同于必须出现牛仔剧情。

**光影 / 色彩**：强自然阳光、沙土棕、牛仔蓝、旧木、皮革、金属，阴影硬而真实。

**镜头质感**：低机位、宽幅环境、长焦压缩、稳重跟拍、材质和动作特写；摄影有重量而不过度摇晃。

**环境倾向**：荒野、农场、院落、车库、工作间、道路、旧木建筑等粗粝空间可按产品选择；不强制马匹或西部角色。

**压缩风格句**：`美式西部荒野风，强自然阳光、沙土与旧木皮革质感，低机位和宽幅环境镜头，画面硬朗有重量。`

## ST12｜黑色电影暗黑风

**视觉核心**：Film Noir式暗黑、神秘、高反差、戏剧性，靠阴影、轮廓和构图建立张力，而非靠危险犯罪内容。

**光影 / 色彩**：低调照明、深黑暗部、硬侧光/百叶窗影、湿地反射；黑白或蓝黑/琥珀双色体系均可。

**镜头质感**：缓慢推进、静态压迫构图、侧逆光人物轮廓、局部特写、必要时突然硬切揭示。

**环境倾向**：任何室内/夜间/城市/极简空间均可通过光影转译成Noir；不要求黑帮、枪械或犯罪剧情。

**压缩风格句**：`黑色电影暗黑风，低调高反差照明与深黑阴影，轮廓光和反射构成神秘张力，缓慢推进与硬切揭示。`

# 全局边界

1. Style只决定视觉表达，不得修改产品事实、价格、功能、SKU、人物身份事实或Best Proof。
2. Style里的“环境倾向”不是场景硬锁；具体地点由Location Router选择。
3. 用户选中任一Style都必须执行，不做“产品不适合该风格”的拒绝或替换。
4. 当风格元素与Product Truth/Proof冲突时，保留Style的色彩、光线、材质、构图、镜头与成像质感，舍弃会破坏事实的装饰。
5. 同一条广告默认只锁一个Primary Style；用户明确要求混合时才允许少量混合。
6. 最终Seedance Prompt不得复制整张Style Card，只使用对应`压缩风格句`并按当前广告再压缩。
