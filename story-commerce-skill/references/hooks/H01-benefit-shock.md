# H01 — Benefit Shock

PURPOSE: open on a verified benefit that is surprising enough to create immediate attention.
BEST WHEN: the benefit itself is stronger than any invented drama.
OPENING MECHANIC: show or state the benefit immediately, then create one question about how/why it is possible.
VISUAL / PERFORMANCE DNA: benefit first; reaction supports but does not replace Proof.
STYLE ADAPTATION: express the same benefit through the resolved Style's visual grammar.
PAYOFF OBLIGATION: the body must demonstrate or honestly explain the benefit.
FAILURE MODES: vague superlatives, unsupported promise, explaining too much before curiosity exists.
