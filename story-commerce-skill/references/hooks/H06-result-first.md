# H06 — Result First

PURPOSE: show the most desirable or surprising verified result before showing the process.
BEST WHEN: the result is visually strong and the process can credibly explain it.
OPENING MECHANIC: result first, then create the question “how did we get here?”
VISUAL / PERFORMANCE DNA: result is readable instantly; do not over-explain.
STYLE ADAPTATION: result presentation follows Style while remaining truthful.
PAYOFF OBLIGATION: the body must connect the result to a valid process or Proof.
FAILURE MODES: unsupported transformation, fake before/after, result stronger than the available evidence.
