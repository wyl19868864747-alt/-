# SURREAL VISUAL COMPILER｜超现实视觉奇观编译器 V1.1

> 仅在 `ST05 超现实创意广告风` 命中时读取。
>
> 目标：把“超现实”从普通真实剧情里的光带/粒子特效，提升为真正具有产品语义、尺度反差、空间改写和连续事件逻辑的视觉奇观，同时保持Product Truth、Best Proof与Paid-Social节奏。

---

## 0. 核心原则

`PRODUCT SEMANTICS BEFORE SPECTACLE`

`SURREAL MUST COME FROM THE PRODUCT`

`REALITY HOLD → HIGH-ENERGY CHARGE → WORLD BREAK → PRODUCT PAYOFF`

`ONE EVENT, MANY ANGLES`

`SURREAL STATE MUST PERSIST UNTIL RETURN TRIGGER`

`SURREAL ≠ RANDOM VFX`

`SURREAL ≠ SLOW SPECTACLE`

真正的ST05不是在真实画面中加几条光带，而是让现实世界在一个清晰机制下发生不可能但可读的变化。

---

## 1. PRODUCT SEMANTIC MATERIAL GATE｜奇观元素必须来自产品

在设计任何奇观前，先建立：

```text
PRODUCT:
CORE SELLING POINT:
REAL INGREDIENTS / MATERIALS / COMPONENTS:
PRODUCT COLOR FAMILY:
CULTURAL / CATEGORY ASSOCIATIONS:
SENSORY ASSOCIATIONS:
SAFE SURREAL MATERIALS:
FORBIDDEN UNRELATED MATERIALS:
```

奇观中的主要元素至少命中以下一种直接关系：
1. 产品真实原材料 / 成分；
2. 产品本体颜色、纹理、材质；
3. 产品制造/使用过程中真实存在的物理元素；
4. 大众对该品类高度稳定的视觉认知；
5. 卖点本身可以直接映射的感官元素。

例如：
- 茶饮：茶叶、茶园、茶汤色、奶白色流体、清透水汽、植物脉络；
- 薯片：土豆、薯片本体、金黄脆片、土地；
- 巧克力曲奇：巧克力、曲奇、可可色流体；
- 冰饮：冰、冷凝、水、雪山等与冷感直接相关元素。

禁止：
> 仅因为“视觉好看”就加入与产品没有语义关系的红色液体、紫色能量、随机霓虹、魔法粒子、火焰、银河等。

如果删除产品后这个奇观仍可无差别套到任何广告：
> 判定 `GENERIC VFX FAIL`，重做。

---

## 2. SURREAL SCALE GATE｜必须达到“奇观”级别

ST05主视觉至少需要一个明确的不可能视觉变化：
- 巨物尺度；
- 微缩世界；
- 原材料成为建筑/地貌/天空/海洋；
- 产品或原材料与自然世界发生尺度融合；
- 真实空间整体改写成产品语义世界；
- 画框/屏幕/包装等真实边界被突破；
- 物体结构以不可能但清楚的方式重新组成空间。

仅有以下内容不算主奇观：
- 一条发光带；
- 普通粒子；
- 光晕；
- 简单颜色变化；
- 背景加烟雾；
- 物体旁边出现几条CG流体。

这些只能作为辅助手段，不能承担ST05的核心奇观。

判断：
> **缩略图静止一帧时，是否已经明显出现“现实中不可能存在”的强画面？**

如果否，奇观强度不足。

---

## 3. PRODUCT-TONE MATCH｜奇观必须符合产品调性

奇观不仅要“有关”，还要符合产品的感官与品牌调性。

例如同样是饮料：
- 清爽茶饮：优先清透绿叶、茶园、浅茶汤、奶白丝带、空气、水汽；
- 冰红茶：可用红棕茶汤、冰、烈日/冷感反差；
- 咖啡：可用深棕咖啡液、烘焙豆、crema、蒸汽；
- 果汁：可用真实水果、果肉、对应果汁色。

禁止用与产品真实感官相反的元素制造错误联想。

`PRODUCT TONE > VISUAL SHOCK`

---

## 4. HIGH-ENERGY CHARGE FRAME｜奇观前必须有蓄力

奇观正式发生前必须保留 **约0.1–0.5秒真实无奇观状态**，形成视觉落差。

推荐结构：

`真实动作已经完成关键触发`
→ `0.1–0.5s Reality Hold / 微停顿 / 声音抽空`
→ `高能视觉奇观瞬间发生`

蓄力镜头必须：
- 产品与人物仍处于真实世界；
- 不提前出现光带、粒子或奇观预告；
- 摄影机可以突然稳定、锁住动作或快速贴近；
- BGM/SFX可短暂抽空；
- 观众有极短时间形成“正常世界”的预期。

然后用硬切、尺度揭示、快速拉远、甩镜、空间翻转或强SFX击穿正常状态。

`CONTRAST CREATES IMPACT`

---

## 5. ONE EVENT, MANY ANGLES｜同一事件连续覆盖，不做独立画面拼贴

先写唯一 `ACTION SPINE`，再写镜头。

例如：
`女生坐在窗边 → 手拿同一杯奶茶 → 喝第一口 → 停顿0.2s → 世界发生原料奇观 → 她继续握杯观察 → 世界回落 → 产品收尾`

所有镜头必须是这个动作链的不同摄影覆盖。

每个镜头继承上一镜状态：
- 同一人物；
- 同一产品；
- 同一只手/持杯方式在合理范围连续；
- 杯子当前朝向；
- 人物身体朝向；
- 人物所处空间位置；
- 当前动作已经做到哪一步；
- 奇观当前发展到哪一步。

禁止：
`产品特写 → 独立人物喝水 → 独立CG产品镜头 → 独立Reaction → 独立Hero`

如果镜头之间像五张互不相关的广告图：
> 判定 `EVENT CONTINUITY FAIL`。

---

## 5.1 SURREAL STATE PERSISTENCE｜世界状态必须连续

一旦唯一主奇观由 `REAL` 进入 `SURREAL ON`，它就成为当前世界状态，而不是某一镜头的背景装饰。

默认状态链：

`REAL → REALITY HOLD → SURREAL ON → SURREAL ON (multi-angle coverage) → RETURN TRIGGER → REAL`

强制：
- `SURREAL ON` 后的Reaction、产品ECU、人物中近景、二次使用、不同机位都必须继续处于同一个超现实世界；
- 切近景不能自动切回真实背景；
- Camera Angle变化不能重置World State；
- 只有明确写出的 `RETURN TRIGGER` 才允许 `SURREAL ON → REAL`；
- 回到REAL后不得再次无因进入SURREAL ON；
- ST05默认只有一个主机制，不用 `REAL → SURREAL → REAL → SURREAL → REAL` 来制造剪辑变化。

内部必须额外记录：

```text
CURRENT WORLD STATE: REAL / HOLD / SURREAL ON / RETURNING / REAL
RETURN TRIGGER:
RETURN COMPLETION SHOT:
```

如果某个Reaction镜头、产品特写或新机位与上一镜世界状态不同，却没有因果触发：
> 判定 `WORLD-STATE CONTINUITY FAIL`。

---

## 6. CAMERA COVERAGE COMPILER｜先事件，后机位

同一事件优先通过：
- 正面中景；
- 侧面近景；
- 手/产品ECU；
- 低机位尺度揭示；
- 过肩；
- 环绕半弧；
- 前景遮挡切换；
- 动作匹配切；

来制造丰富度。

机位变化必须回答：
> **这一镜是在拍同一个动作的哪个信息？**

不要为了“多镜头”重置动作。

建议内部记录：

```text
EVENT ANCHOR:
CHARACTER POSITION:
PRODUCT POSITION:
HAND / ORIENTATION:
CURRENT ACTION STATE:
SURREAL STATE:
CAMERA SIDE / ANGLE:
NEXT SHOT HANDOFF:
```

---

## 7. SURREAL WORLD BUILD｜优先“世界化”，不是“特效化”

参考高质量超现实商业视觉时，优先思考：
- 产品成为山体/建筑/地貌核心；
- 原材料巨大化形成完整世界；
- 食材成为天空、地面、道路或空间结构；
- 人物进入由产品材料构成的超现实尺度世界；
- 原料从真实尺度瞬间扩张成巨大环境。

而不是：
> 产品旁边飞几条光带。

推荐：
`REAL PRODUCT ACTION → PRODUCT-RELATED MATERIAL EXPANDS → WORLD SCALE BREAKS → CHARACTER/PRODUCT REMAIN ANCHORED → RESULT RETURNS TO PRODUCT`

---

## 8. RHYTHM｜高能但不慢

15秒Paid-Social默认：
- 约7–10个有价值Beat；
- 普通镜头约0.7–1.8秒；
- Reality Hold约0.1–0.5秒；
- 奇观第一击约0.3–1.0秒完成；
- 奇观世界可再用1–2个短镜头从不同机位确认；
- Reaction约0.4–0.8秒；
- 静态Hero约0.8–1.3秒。

真正的高能来自：
`蓄力 → 突然尺度变化 → 新角度确认 → Reaction → 产品回收`

不是慢动作、慢漂移、长展示。

## 10. QA

- [ ] 奇观的主要元素是否与产品原料/材质/色彩/品类认知直接有关？
- [ ] 是否存在与产品无关、只是好看的随机VFX？若有删除。
- [ ] 静止一帧是否已经明显属于超现实奇观，而不仅是“真实画面+光带”？
- [ ] 奇观前是否有0.1–0.5秒真实无奇观蓄力？
- [ ] 是否只有一个主超现实机制？
- [ ] 整条片是否围绕同一人物+同一产品+同一事件连续推进？
- [ ] 每次切镜是否继承上一镜动作和状态？
- [ ] SURREAL ON后是否保持世界状态，直到明确Return Trigger？
- [ ] 是否避免无因 `REAL ↔ SURREAL` 来回切换？
- [ ] 是否通过不同机位覆盖同一事件，而不是生成独立广告画面？
- [ ] 奇观是否直接解释/放大当前卖点？
- [ ] 奇观是否高能、短促、可读，而不是缓慢TVC展示？
- [ ] 最终是否重新回到真实产品与商业理解？

最终：

> **奇观必须从产品里长出来。**
>
> **先让观众相信世界是真的，再用0.1–0.5秒蓄力把这个世界打破。**
>
> **一旦世界被打破，就保持这个世界，直到明确的返回触发。**
>
> **所有镜头都在拍同一个事件，不是在拼不同广告图。**
