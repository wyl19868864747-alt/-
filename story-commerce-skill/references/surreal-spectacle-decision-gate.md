# SURREAL SPECTACLE DECISION GATE｜超现实奇观决策层 V1

> 仅在 `ST05 超现实创意广告风` 命中时读取，并且必须先于 `surreal-visual-compiler.md`。
>
> 目标：解决“奇观视觉很好看，但为什么会发生、它到底在表达什么”这一层问题。产品相关元素只是必要条件，不代表奇观因果已经正确。

---

## 0. 核心原则

`SPECTACLE CAUSAL MEANING > SPECTACLE BEAUTY`

`PRODUCT SEMANTICS ARE NECESSARY, NOT SUFFICIENT`

`THE SPECTACLE MUST MEAN THE SELLING POINT`

`TRIGGER → SPECTACLE → VIEWER INFERENCE → SELLING-POINT PAYOFF`

`REAL + IMPOSSIBLE = SURREAL`

真正有效的视觉奇观必须同时满足：
1. 奇观元素来自产品/原料/材质/品类认知；
2. 奇观发生方式能让观众自然联想到当前卖点；
3. 不产生与卖点相反的错误联想；
4. 奇观必须发生在已建立的真实世界里，而不是换成另一张“奇幻背景图”。

---

## 1. SPECTACLE CAUSAL CARD｜先决定“为什么这样奇观”

进入任何视觉设计前，静默建立：

```text
PRODUCT:
CONFIRMED SELLING POINT:
TRIGGER ACTION:
DESIRED VIEWER INFERENCE:
PRODUCT-RELATED MATERIAL / SYMBOL:
PROPOSED IMPOSSIBLE EVENT:
WHY THIS EVENT MEANS THE SELLING POINT:
POSSIBLE WRONG INFERENCE:
SAFER / CLEARER ALTERNATIVE:
```

如果 `WHY THIS EVENT MEANS THE SELLING POINT` 说不清楚，不进入分镜。

如果 `POSSIBLE WRONG INFERENCE` 比正确卖点更强，必须换奇观机制。

---

## 2. SILENT VIEWER TEST｜关掉旁白也要能读对

设计完奇观后，先假设：
- 没有旁白；
- 没有字幕；
- 只看画面。

问：
> **普通观众会把这个现象理解成什么？**

如果观众更容易理解为：
- 产品太刺激；
- 产品有破坏力；
- 味道冲/难喝；
- 危险；
- 夸张但和卖点无关；

而广告本来想表达的是清爽、柔和、轻盈、自然等正向卖点，判定：
`SPECTACLE SEMANTIC FAIL`。

旁白只能加强正确理解，不能负责把错误奇观“解释回来”。

---

## 3. POSITIVE BENEFIT ≠ RANDOM DESTRUCTION｜正向卖点慎用破坏型奇观

桌面裂开、墙体爆裂、地面塌陷、物体炸飞、猛烈震荡等视觉语言，天然更容易传达：
- 力量；
- 冲击；
- 危险；
- 极端刺激；
- 破坏/失控。

因此只有当卖点本身与“强度、冲击、突破、耐受、强动力”等语义直接相关时才考虑。

对于：
- 清爽；
- 不腻；
- 柔和；
- 舒适；
- 纯净；
- 细腻；

默认避免把“破坏现实物体”作为核心奇观动作。

例如：
> 奶茶喝下后桌面突然裂开，即便绿色茶叶从裂缝长出，也容易先被理解为“这杯东西冲击力太强/有破坏性”，与“清爽不腻”存在语义冲突。

更合理的方向是：
- 现实桌面/窗框/空气保持完整；
- 巨型茶叶以不可能但非破坏性的方式穿越、展开、悬停、折叠或延展进真实空间；
- 清透空气、叶脉、轻薄奶白流体直接形成“清爽 + 茶”的感官映射。

---

## 4. SELLING-POINT → SPECTACLE VERB｜先选卖点动词，再选特效

视觉奇观不要先问“什么画面炸”，先问卖点对应什么视觉动词。

### 清爽 / 轻盈 / 不腻
优先：
`打开 / 透开 / 扫清 / 舒展 / 穿透 / 释放 / 变轻 / 空气化`

### 茶底扎实 / 原料浓度 / 真实材质
优先：
`展开 / 长出 / 显影 / 放大纹理 / 构成空间 / 层层延伸 / 成为结构主体`

### 速度 / 效率
优先：
`压缩 / 瞬时重排 / 快速联动 / 一次完成 / 空间折叠`

### 稳固 / 耐用 / 承托
优先：
`承受 / 保持 / 锁住 / 稳住 / 支撑`

### 柔滑 / 顺滑 / 流动
优先：
`连续流过 / 包裹 / 绕行 / 顺滑穿行 / 无阻力滑动`

### 强动力 / 爆发
只有此类卖点才优先：
`冲开 / 撞击 / 破开 / 爆发 / 推动`

---

## 5. REAL-WORLD ANCHOR｜真实世界必须保留

ST05的核心不是：
`真实前景 + 奇幻背景`

而是：
`真实前景 + 真实背景 + 不可能现象侵入/重写其中的关系`

奇观镜头至少保留2个真实空间锚点，例如：
- 原桌面；
- 原窗框；
- 原墙面；
- 原人物；
- 原椅子；
- 原街道/店面结构；

并让超现实元素与这些锚点发生真实的：
- 遮挡；
- 投影；
- 反射；
- 穿越；
- 尺度对比；
- 空间接触关系。

如果真实背景被整张替换成“茶园/山谷/银河”等另一个完整世界，优先判定：
`BACKGROUND REPLACEMENT / COLLAGE RISK`。

## 6. 伯牙绝弦案例｜正确方向示意

卖点：`清爽不腻，茶底扎实`

产品语义：`茶叶 + 奶白轻盈感`

错误高能机制示例：
`喝一口 → 桌面炸裂 → 茶叶冒出`

问题：
视觉冲击强，但“桌裂”更像刺激、破坏、强劲，和清爽不腻没有自然因果。

更合理：
`喝一口 → 0.2s真实蓄力 → 巨型鲜绿茶叶以不可能尺度从真实窗框/桌面上方/人物身后空间连续展开，但不破坏桌体 → 叶脉和轻薄奶白空气流在真实空间中穿行 → 空间更清透 → 产品回收`

这里“茶”解释茶底，“通透/轻薄”解释清爽，奇观仍然强，但语义正确。

---

## 7. 决策优先级

当视觉冲击与卖点含义冲突：

`SELLING-POINT MEANING > SPECTACLE SHOCK`

当产品元素相关但事件因果错误：

`CAUSAL MEANING > MATERIAL MATCH`

当真实场景与奇幻背景拼贴很漂亮：

`REAL-WORLD INTERACTION > BACKGROUND BEAUTY`

最终：

> **不是“产品元素出现在奇观里”就算对。**
>
> **观众必须能自然看懂：为什么是这个奇观，它如何让当前卖点变得可见。**
