# C04 — Offer / Value Action

USE WHEN: a verified price, offer, bundle, or value condition is a major conversion reason.
SEMANTIC ROLE: connect the proven value directly to the available action.
COMMON FORMS: Get the offer / Shop the bundle / See today's verified price — only when true.
STYLE ADAPTATION: value can land quietly or energetically depending on Style.
AVOID: fake countdowns, invented scarcity, unsupported savings, changing the locked price.
