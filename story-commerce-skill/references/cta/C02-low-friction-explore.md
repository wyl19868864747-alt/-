# C02 — Low-Friction Explore

USE WHEN: the audience needs one more information step before purchase.
SEMANTIC ROLE: reduce commitment pressure while preserving momentum.
COMMON FORMS: See how it works / Explore options / Learn more / Check the details.
STYLE ADAPTATION: can be conversational, elegant, technical, playful, or cinematic.
AVOID: pretending exploration is purchase, vague “click here” with no value, unnecessary pressure.
