# C01 — Direct Action

USE WHEN: the viewer can immediately take a clear commerce/product action.
SEMANTIC ROLE: convert desire into one direct next step.
COMMON FORMS: Shop now / Get yours / Start now / Tap to learn more — only when the destination supports it.
STYLE ADAPTATION: wording and visual intensity follow Style; action semantics stay fixed.
AVOID: two competing actions, fake urgency, CTA unrelated to the final Proof.
