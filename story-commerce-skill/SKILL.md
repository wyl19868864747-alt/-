# 剧情带货 Skill 2.2｜反转喜剧增强版

## 1. 核心目标

把：
`真实产品事实 → 消费者问题 → 明确错误预判 → 可见事件强化 → 180°反转 → 情绪奖励 → 产品Proof → 转化`
变成可直接交给视频模型执行的镜头动作。

大语言模型负责“想”和“导演拆解”；Seedance等视频模型只负责“拍”。
禁止把剧情推理、情绪推演、反转设计交给视频模型自行理解。

剧情不是为了机械塞入卖点，而是让观众先相信一个方向，再让真实产品信息或剧情事实改变事件性质，并把这个反转继续变成后续剧情的发动机。

## 2. 全局优先级

1. 用户本轮明确要求。
2. 产品真实事实与合规边界。
3. 单一核心卖点与主矛盾。
4. 有意义的180°反转与情绪奖励。
5. 可见Proof与剧情因果。
6. 动作可执行性与物理连续。
7. 人物/产品/空间一致性。
8. 风格、镜头、节奏与美感。

优先级原则：
`真实共鸣 > 剧情复杂度`
`有意义反转 > 随机意外`
`观众明确误判 > 单纯信息隐藏`
`反转继续发动剧情 > 反转后立即结束`
`情绪奖励 > 只有“原来如此”`
`可见Proof > 口头宣称`
`产品因果作用 > 产品露出次数`
`事件推进 > 广告式问答`
`清晰转化 > 电影炫技`

## 3. 单点聚焦

每条广告优先只锁定：
- 一个核心消费者问题；
- 一个主矛盾；
- 一个最强Proof；
- 一个主要购买阻力；
- 一个主反转；
- 一个清晰转化目标。

主反转默认必须存在。不要为了“丰富”而塞入多个互相争夺注意力的反转、卖点、人物和场景。

## 4. 默认剧情结构｜必须有主反转

默认结构：
`Hook → Wrong Expectation → Evidence Reinforcement → Escalation → Reversal Trigger → 180° Reframe → Emotional Payoff → Product Proof → Aftershock/Punchline → CTA`

如果产品、合规或用户明确要求需要调整顺序，可以让产品提前出现或让产品本身成为 Reversal Trigger，但主反转仍必须满足本节定义。

### 4.1 真反转DNA｜三个条件缺一不可

#### A. 反转必须继续发动后续剧情

反转不是结尾谜底，而是后半段剧情的新发动机。

判断方法：
- 删除反转后，后面的剧情是否还能基本照常发生？如果能，说明反转只是装饰。
- 反转发生后，人物关系、行动目标、道具意义、产品选择或购买判断是否发生改变？至少一项必须改变。

推荐：
`旧目标/旧判断 → 反转 → 新目标/新判断 → 人物立即采取新行动 → 产品/Proof顺势进入`

#### B. 观众必须先形成一个“很确定但错误”的方向，再180°改变事件性质

不是“观众不知道答案”，而是“观众以为自己已经知道答案”。

反转前必须完成：
1. 建立一个大众能快速识别的常识或情境；
2. 让观众自动得出一个错误答案；
3. 至少再给2个独立可见证据强化这个错误答案；
4. 到关键节点，用一个动作、称呼、物件、结果或人物关系，让事件性质突然180°改变。

优先利用观众脑补，不用人物提前解释答案。

可用于强化错误答案的证据：
- 社会关系位置：谁坐主位、谁站谁旁边、谁递给谁什么；
- 道具：戒指、账单、行李箱、礼物、制服、收据、钥匙、价格牌；
- 人物行为：摘戒指、收拾行李、锁门、藏东西、递辞职信、抢账单；
- 镜头构图：把两个人并置成观众熟悉的关系；
- 对白碎片：只给能支持错误理解的半句，不提前解释真相。

反转不是简单“再补一条新信息”。它必须让观众回头重新解释前面的画面。

#### C. 反转必须给观众情绪奖励，而且回头看合理

反转后的目标不是只让观众说“原来如此”，而要尽量让观众产生：
`爽 / 过瘾 / 解气 / 好笑 / 惊喜 / 释然 / 幸灾乐祸式喜剧快感`

推荐情绪轨迹：
- 紧张 → 松一口气 → 好笑
- 替人物憋屈 → 反杀 → 解气
- 以为被骗 → 原来主角才占便宜 → 爽
- 以为闯祸 → 实际解决问题 → 惊喜
- 以为关系破裂 → 实际只是误会/另一个对象被“抛弃” → 喜剧释放

新真相必须满足“意外但可接受”：
- 反转后回看前面的动作和道具仍然成立；
- 不靠突然出现从未铺垫的新人物、新规则、新能力救场；
- 不靠角色突然变蠢；
- 不靠违背产品事实、医学事实、平台合规或基本物理。

### 4.2 错误答案强化阶段｜让观众先下注

反转前不要急着揭晓。

最低要求：观众形成错误方向后，至少连续再给2个强化点，使其越来越确定。

例如不是：
`她说“I’m done” → 立刻解释“不是和你分手，是换掉旧方案”`

而是：
`她说“I’m done” → 摘戒指 → 把纸摔桌上 → 对方明显慌张 → 她停顿 → 才揭示“Not you. Them.”`

错误答案越确定，180°反转越有力量。

### 4.3 微小异常先出现，解释延迟

优先使用一个很小但无法被旧答案解释的异常作为 Reversal Trigger：
- 一个称呼不对；
- 一个数字归属不对；
- 一个物品的真正主人不对；
- 一个角色身份不对；
- 一句话中的对象不对；
- 一个动作的真正目的不对。

推荐顺序：
`旧答案持续成立 → 微小异常 → 人物明确反应 → 0.2–1秒解释延迟 → 真相揭示`

不要异常一出现就立刻长篇解释。让观众先产生“等等，怎么回事？”再给答案。

### 4.4 人物可以先反应，真相后解释

当剧情适合时，优先：
`异常出现 → 人物先做明确动作 → 观众继续追问原因 → 真相解释`

明确动作可以是：
- 把某人/某物推开；
- 夺过账单重看；
- 摘下/重新戴回戒指；
- 把旧方案扔进垃圾桶；
- 关门、退后、坐下、扶桌；
- 当众改口；
- 突然停止正在进行的仪式或动作。

禁止只写“她震惊了”“他反应巨大”。必须把反应编译成动作。

### 4.5 产品与反转的关系

最佳状态：产品、价格、功能、Proof或服务事实就是反转成立的原因。

优先：
`错误理解 → 反转揭示真实产品事实 → 人物因此改变行动 → Proof继续验证 → Punchline`

次优：产品不是反转答案，但反转后出现的新问题必须自然需要产品解决。

禁止：前面独立演一个反转短剧，反转结束后突然停下来介绍产品。

### 4.6 伪反转判定

以下情况不算合格主反转：
- 只是“人物不知道价格，后来知道价格”；
- 只是“人物惊讶，朋友解释”；
- 只是突然出现一个新人物或新事实；
- 只是把情绪从平静变震惊；
- 只是镜头突然切到产品；
- 反转前观众没有形成明确错误答案；
- 反转后剧情方向没有改变；
- 虽然意外，但观众只觉得莫名其妙，没有爽、好笑、解气、释然或惊喜中的任何一种。

发现伪反转，必须返回剧情层重写。

## 5. 抓马、荒诞、好笑｜默认氛围，但必须动作化

每条剧情带货广告默认同时追求：
- 抓马：关系、身份、利益或公开场合的风险被放大；
- 荒诞：人物为解决一个真实小问题，采取逐渐不成比例但仍能理解的行动；
- 好笑：通过误判、反差、延迟、干幽默、道具关系或反转后的余震释放。

这些是决策层目标，不得直接丢给视频模型。

### 5.1 抓马的可见DNA

优先从以下方式制造：
- 开场已经处于冲突中，不从寒暄开始；
- 公开场合出现误会、揭穿、抢夺、打断、当众改口；
- 人物关系或谁占上风在剧情中发生变化；
- 一件小事被人物当成大事认真处理；
- 第三人/旁观者反应可以放大尴尬，但只有真正承担剧情作用时才加入。

禁止用大喊大叫替代抓马。

### 5.2 荒诞的可见DNA

荒诞来自“处理方式越来越不成比例”，不是违反物理：
`正常处理 → 主动验证 → 更认真地验证 → 把普通道具当成严肃证据/对手 → 产生荒谬但逻辑连续的处理动作 → Punchline`

同一动作只做得更大不算荒诞升级。

### 5.3 好笑的可见DNA

优先组合：
- Serious setup + ridiculous object：人物极其认真，道具非常普通；
- Chaos + deadpan：一个人越忙乱，另一个人越平静；
- Misunderstanding + delayed reveal：误会持续，真相晚半拍；
- Reversal + aftershock：反转完成后，再给一句/一个动作作为喜剧余震；
- Prop as third role：让道具连续给出让人物不满意但客观正确的结果。

笑点必须有：
`铺垫 → 笑点本体 → 0.2–0.8秒停顿 → Reaction/Aftershock`

## 6. Hook｜从错误方向正在发生时进入

优先从事件中途、异常状态、尴尬、预测误差、强烈反应或视觉结果进入。
Hook必须与后续产品存在因果关系。

当使用反转结构时，Hook最好同时承担“错误答案的第一证据”。
首帧不是让观众完全看不懂，而是让观众迅速做出一个看似合理、最终会被推翻的判断。

## 7. Escalation｜升级不是形容词

Escalation 必须被设计成可见、连续、递进的事件链。

禁止只写：
- 荒诞逐渐升级
- 抓马感增强
- 人物越来越怀疑
- 气氛越来越紧张
- 喜剧感越来越强

这些只能用于内部创意判断，不能直接作为视频模型执行指令。

只要剧情出现“升级”，决策层必须先设计至少3级不同的可见变化。每一级至少改变一项：
- 人物动作
- 道具状态
- 人物关系/谁占上风
- 新证据
- 新阻力
- 空间位置
- 镜头信息

推荐阶梯：
`Level 1 正常处理 → Level 2 主动验证 → Level 3 关系/道具发生变化 → Level 4 处理方式变得荒谬 → Level 5 Reversal/Punchline/Payoff`

同一动作重复、只把表情做得更大，不算升级。

例如不是：
`她越来越怀疑 → 更震惊 → 更荒诞`

而是：
`她看朋友 → 拉过计算器重算 → 结果仍相同 → 对计算器说“Don't take her side.” → 再次重算后敲计算器说“Seriously?” → 最后把计算器推走说“You're fired.”`

## 8. Product Entry / Proof / Reaction / CTA

### Product Entry
产品必须因为剧情需要出现，而不是突然举到镜头前介绍。
反转发生后，产品应继续推动人物的新目标或新判断；产品也可以直接成为 Reversal Trigger。

### Proof
优先写成：
`初始状态 → 人物操作 → 接触/作用 → 可见变化 → 完成状态 → 人物即时反应`

### Reaction
反应必须与人物刚刚看到的结果对应，克制、可信，不用连续瞪眼代替剧情。
反转后的情绪变化必须具体，例如：僵住半秒、扶桌松气、重新戴回戒指、把旧账单扔掉、压住笑、回头看对方。

### CTA
只使用用户确认的价格、优惠、资格、链接、行动要求等事实。

## 9. 人物与对白

15–30秒广告默认1–2个主要人物。
每个人必须有剧情职责：使用者、怀疑者、知情者、观察者、问题制造者等。
没有功能的人不要加入。

对白必须绑定：
`当前动作/视线 → 说话方式 → 台词`

每句台词至少承担一个功能：推进事件、强化错误预判、制造异常、触发反转、提出疑虑、回答疑虑、传达必要事实、强化反应或CTA。
避免连续念产品说明书。

反转对白优先短句，尤其是能改变“对象、归属、身份、价格归属、关系”的词句。不要用一大段解释削弱瞬间认知坍塌。

## 10. 道具第三角色

真人数量受限时，可以让计算器、账单、收据、价格牌、电脑、包裹、咖啡机等承担第三角色功能。

道具成为“角色”必须通过连续互动建立关系：
`拿来求证 → 道具给出结果 → 结果改变人物判断 → 人物再次与道具互动 → 道具再次给出结果 → Reversal/Punchline处理道具`

禁止道具无原因自行运动或真的像生命体一样行动。

若结尾要“开除/责怪/抛弃”某道具，前面必须先让人物与该道具形成至少两次有意义互动，否则视为笑点无铺垫。

## 11. PRODUCT LOCK

产品第一次出现即锁定：
- 类型
- 主色
- 关键形状/结构
- 材质
- 包装识别
- 相对尺度

有参考图时，参考图是产品外观最高优先依据。
后续统一引用同一产品，不重新设计。
精确Logo、包装文字、屏幕文字需要准确时，优先使用真实资产，不把纯生成文字当可靠证据。

## 12. 视频提示词编译｜最高优先级

### 12.1 抽象导演词禁止直投

以下词可以存在于内部分析，但不得独立出现在最终执行提示词中：
`荒诞 / 抓马 / 狗血 / 紧张 / 压迫 / 搞笑 / 情绪升级 / 关系反转 / 180°反转 / 节奏加快 / 视觉冲击 / 夸张表演 / 高能`

每一个抽象词必须先转换成至少一种可见执行项：
`人物动作 / 道具动作 / 人物站位 / 视线 / 表情变化 / 台词 / 镜头变化 / 空间变化 / 声音变化`

无法转换的要求直接删除，不把理解任务甩给视频模型。

### 12.2 动作编译层

每个剧情节拍交给视频模型前，强制编译成：
`起始状态 → 谁先动 → 动什么 → 朝哪里动 → 与什么接触 → 接触后什么发生 → 谁看到 → 具体怎么反应 → 谁说什么 → 下一镜如何承接`

不能只写“人物更加怀疑/更加生气/更加搞笑”。
必须写清：
- 她先看谁；
- 手伸向什么；
- 拿起/放下/推开什么；
- 道具结果是什么；
- 看到结果后先停顿还是转头；
- 另一人物做什么反应。

### 12.3 反转编译层｜必须让视频模型拍得出来

主反转在进入最终提示词前，必须被拆成以下可见节点：

`错误答案首证据 → 强化证据1 → 强化证据2 → 微小异常 → 人物明确动作反应 → 短暂停顿 → 真相动作/短句 → 180°后新行动 → 情绪奖励/喜剧余震`

最终提示词中不得写：
- “此处发生180°反转”；
- “观众发现她其实不是……”；
- “剧情突然变得抓马”；
- “制造意料之外的效果”。

必须直接写可拍内容，例如：
`她摘下戒指放到桌上 → 丈夫向前一步伸手想解释 → 她抬手制止 → 她拿起$299账单说“Not you.” → 把账单丢进垃圾桶，说“Them.” → 丈夫肩膀明显放松并扶住桌沿。`

### 12.4 动作阶梯

凡剧情有 Escalation，最终提示词必须能逐级指出至少3个不同动作节点。
若连续镜头只是“看→再看→继续看”或“问→再问→继续问”，视为伪升级，返回剧情层重写。

### 12.5 首帧视觉化

Hook的核心冲突优先在首帧或前1秒被看见，而不是只靠台词解释。
价格异常就先让价格/账单/计算结果进入画面；产品破损就先让破损结果可见；空间异常就先建立异常状态。

反转型Hook还需要首帧帮助观众快速形成一个“看似正确”的方向。
静音观看前1秒既看不出“哪里不对”，也无法形成任何关系判断时，优先重写Hook。

### 12.6 Punchline → Reaction

喜剧结尾先拍笑点本体，再拍他人反应：
`动作/台词 Punchline → 0.2–0.8秒停顿 → 对方 Reaction/Aftershock`

不要把主要镜头提前给Reaction，导致真正的笑点动作没有被看见。

## 13. 可视化翻译测试

最终提示词完成后，删除其中所有风格和情绪形容词，只保留人物、动作、道具、结果、台词和镜头。

如果此时仍能清楚“看见”完整视频，并能看出：
`观众为什么会误判 → 哪些证据在强化 → 哪里出现异常 → 真相怎么翻转 → 人物之后做什么`
说明编译合格。

如果必须依赖“反转、荒诞、抓马、好笑”等词才能理解，返回提示词编译层重写。

示例：
- 不写“她越来越怀疑”；写“她先眯眼看朋友，再把计算器拉近重算，看到同样数字后抬头，再把计算器翻过来看背面”。
- 不写“对方越来越无语”；写“第一次正常回答，第二次只抬眉，第三次不回答并喝一口咖啡”。
- 不写“节奏越来越快”；写“3秒双人中景 → 2秒计算器特写 → 1.5秒人物反打 → 1秒反应硬切”。

## 14. 物理因果与穿模

所有人与产品/道具交互遵守：
`人先动作 → 发生接触 → 物体响应 → 结果出现`

明确：
- 哪只手
- 抓哪里
- 朝向
- 受力方向
- 接触区域
- 作用区域

禁止：
- 人物/产品瞬移
- 门、车门、道具自己运动
- 人物穿过关闭物体
- 人物与产品明显穿插
- 产品尺度漂移
- 相隔很远时手突然出现在另一人物近景

发现失败风险时，拆成真实因果链重写。

## 15. 镜头原则

每个镜头必须增加至少一种：
`新信息 / 新动作 / 新反应 / 新证据 / 新空间关系`

镜头只为信息服务：
- 建立事件：中景/中全景
- 人物关系：双人中景/过肩
- 误导证据：优先让观众能快速读懂关系/道具归属
- 微小异常：特写或反打，让异常本身清楚可见
- 反转瞬间：先拍触发动作/短句，再拍Reaction
- 产品证明：产品/动作特写
- 关键利益：必要时轻推近

避免无原因环绕、持续漂移、每镜都推拉。

## 16. TIMELINE格式

按时间顺序写：
- 首帧可见状态/异常
- 首个错误答案证据
- 景别/关系机位
- 人物位置
- 谁先动作
- 强化错误答案的动作/道具证据1
- 强化错误答案的动作/道具证据2
- Escalation动作
- Reversal Trigger：具体微小异常
- 谁先看到异常
- 人物明确反应动作
- 解释延迟/停顿
- 真相通过哪个动作/短句被揭示
- 180°后人物的新行动
- 产品/道具接触与Proof
- 情绪奖励/Punchline
- Reaction/Aftershock
- CTA
- 下一镜承接

禁止使用“荒诞升级、更加抓马、越来越紧张、反应更夸张、发生反转、意料之外”等词代替动作。

## 17. 时长规则

任何作为独立生成任务交付的单条视频提示词，总时长必须≥4秒。
内部镜头、动作节拍可以短于4秒。

单一时间段不能动作过载。
例如2秒内不要同时要求：开门 + 走进房间 + 拿产品 + 使用 + 长台词 + 反应 + 转场。

反转需要给观众建立错误答案的时间，但不能拖沓。优先用可见动作和道具完成误导，少用解释对白。

## 18. 最终提示词推荐结构

`FORMAT`
时长、画幅、平台、整体真实感。

`CHARACTER LOCK`
人物最少必要识别信息。

`PRODUCT LOCK`
产品一致性与尺度。

`LOCATION`
一句话空间结构。

`CONTINUITY`
人物左右关系、视线、产品位置、主运动方向。

`TIMELINE`
逐段使用动作编译后的可见指令；反转必须表现为实际证据、异常、动作、短句和结果，不写抽象“反转”。

`GLOBAL CONTROL`
只保留真正影响稳定性的短约束。

## 19. SILENT QA｜生成前静默审核

出现以下任一项，内部修正后再交付：
- 编造商业事实
- 不知道卖什么
- 产品只是露出，没有改变剧情
- 卖点只有口播没有Proof
- 人物行为没有原因
- 对白像说明书
- 没有主反转
- 反转前观众没有形成明确错误答案
- 错误答案没有至少2个独立证据强化
- 只是信息揭晓，不是180°改变事件性质
- 反转后剧情没有被继续发动
- 反转虽然意外，但没有爽/过瘾/解气/好笑/惊喜/释然中的任何一种情绪奖励
- 反转依赖突然出现且未铺垫的人物/规则/事实
- 产品与反转完全脱节，像反转结束后硬插广告
- 抓马只靠大喊大叫，没有关系、行动或公开风险变化
- 荒诞只靠夸张表情，没有处理方式升级
- 好笑只写“搞笑”，没有铺垫、笑点本体和Reaction/Aftershock
- 人物/产品瞬移
- 道具自己运动
- 穿模
- 产品尺度漂移
- 轴线/视线混乱
- 单一时间段动作过载
- 抽象导演词没有被翻译成可见动作
- Escalation只有情绪加码，没有动作/关系/证据升级
- 连续两级使用同一动作重复充数
- 首帧核心冲突只能靠台词理解
- Punchline没有拍到笑点本体，只拍Reaction
- 道具被当成角色但没有前置关系建立

### 强制自问

1. 观众在反转前到底会以为故事朝哪个明确方向发展？
2. 我是否至少用了2个可见证据，让观众越来越相信这个错误答案？
3. 反转是否真的让事件性质180°变化，而不是补充信息？
4. 删除反转后，后面的剧情是否会失去发动机？如果不会，这个反转是否只是装饰？
5. 反转后观众得到的具体情绪奖励是什么：爽、过瘾、解气、好笑、惊喜还是释然？
6. 新真相回头看是否合理，是否没有依赖突然救场？
7. 产品是否是反转原因、反转答案，或反转后新行动的必要因素？
8. 删除所有形容词后，我还能清楚看到这个视频吗？
9. Seedance是否只需要“执行”，而不需要替我“理解剧情”？
10. 每一级升级是否真的发生了新的动作、关系、证据或阻力？
11. 每个笑点是否有铺垫、笑点本体和Reaction/Aftershock？
12. 每个动作是否满足真实物理因果？

任一答案不合格，返回对应层重写，不向用户输出失败草稿。
