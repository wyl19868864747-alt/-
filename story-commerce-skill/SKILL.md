# 剧情带货 Skill 2.1｜动作编译增强版

## 1. 核心目标

把：
`真实产品事实 → 消费者问题 → 可见事件 → 剧情冲突 → 产品介入 → 卖点Proof → 转化`
变成可直接交给视频模型执行的镜头动作。

大语言模型负责“想”和“导演拆解”；Seedance等视频模型只负责“拍”。
禁止把剧情推理、情绪推演、反转设计交给视频模型自行理解。

## 2. 全局优先级

1. 用户本轮明确要求。
2. 产品真实事实与合规边界。
3. 单一核心卖点与主矛盾。
4. 可见Proof与剧情因果。
5. 动作可执行性与物理连续。
6. 人物/产品/空间一致性。
7. 风格、镜头、节奏与美感。

优先级原则：
`真实共鸣 > 剧情复杂度`
`可见Proof > 口头宣称`
`产品因果作用 > 产品露出次数`
`事件推进 > 广告式问答`
`清晰转化 > 电影炫技`

## 3. 单点聚焦

每条广告优先只锁定：
- 一个核心消费者问题；
- 一个主矛盾；
- 一个最强Proof；
- 一个主要购买阻力；
- 一个清晰转化目标。

不要为了“丰富”而塞入过多卖点、人物、反转和场景。

## 4. 剧情基本结构

按产品灵活组合：
`Hook → Problem → Escalation → Product Entry → Proof → Reaction → Objection/Second Proof → CTA`

### Hook
优先从事件中途、异常状态、尴尬、预测误差、强烈反应或视觉结果进入。
Hook必须与后续产品存在因果关系。

### Escalation｜升级不是形容词

Escalation 必须被设计成可见、连续、递进的事件链。

禁止只写：
- 荒诞逐渐升级
- 抓马感增强
- 人物越来越怀疑
- 气氛越来越紧张
- 喜剧感越来越强

这些只能用于内部创意判断，不能直接作为视频模型执行指令。

只要剧情出现“升级”，决策层必须先设计至少3级不同的可见变化。每一级至少改变一项：
- 人物动作
- 道具状态
- 人物关系/谁占上风
- 新证据
- 新阻力
- 空间位置
- 镜头信息

推荐阶梯：
`Level 1 正常处理 → Level 2 主动验证 → Level 3 关系/道具发生变化 → Level 4 处理方式变得荒谬 → Level 5 Punchline/Payoff`

同一动作重复、只把表情做得更大，不算升级。

例如不是：
`她越来越怀疑 → 更震惊 → 更荒诞`

而是：
`她看朋友 → 拉过计算器重算 → 结果仍相同 → 对计算器说“Don't take her side.” → 再次重算后敲计算器说“Seriously?” → 最后把计算器推走说“You're fired.”`

### Product Entry
产品必须因为剧情需要出现，而不是突然举到镜头前介绍。

### Proof
优先写成：
`初始状态 → 人物操作 → 接触/作用 → 可见变化 → 完成状态 → 人物即时反应`

### Reaction
反应必须与人物刚刚看到的结果对应，克制、可信，不用连续瞪眼代替剧情。

### CTA
只使用用户确认的价格、优惠、资格、链接、行动要求等事实。

## 5. 人物与对白

15–30秒广告默认1–2个主要人物。
每个人必须有剧情职责：使用者、怀疑者、知情者、观察者、问题制造者等。
没有功能的人不要加入。

对白必须绑定：
`当前动作/视线 → 说话方式 → 台词`

每句台词至少承担一个功能：推进事件、暴露问题、提出疑虑、回答疑虑、必要事实、强化反应或CTA。
避免连续念产品说明书。

## 6. 道具第三角色

真人数量受限时，可以让计算器、账单、收据、价格牌、电脑、包裹、咖啡机等承担第三角色功能。

道具成为“角色”必须通过连续互动建立关系：
`拿来求证 → 道具给出结果 → 结果改变人物判断 → 人物再次与道具互动 → 道具再次给出结果 → Punchline处理道具`

禁止道具无原因自行运动或真的像生命体一样行动。

若结尾要“开除/责怪/抛弃”某道具，前面必须先让人物与该道具形成至少两次有意义互动，否则视为笑点无铺垫。

## 7. PRODUCT LOCK

产品第一次出现即锁定：
- 类型
- 主色
- 关键形状/结构
- 材质
- 包装识别
- 相对尺度

有参考图时，参考图是产品外观最高优先依据。
后续统一引用同一产品，不重新设计。
精确Logo、包装文字、屏幕文字需要准确时，优先使用真实资产，不把纯生成文字当可靠证据。

## 8. 视频提示词编译｜最高优先级

### 8.1 抽象导演词禁止直投

以下词可以存在于内部分析，但不得独立出现在最终执行提示词中：
`荒诞 / 抓马 / 狗血 / 紧张 / 压迫 / 搞笑 / 情绪升级 / 关系反转 / 节奏加快 / 视觉冲击 / 夸张表演 / 高能`

每一个抽象词必须先转换成至少一种可见执行项：
`人物动作 / 道具动作 / 人物站位 / 视线 / 表情变化 / 台词 / 镜头变化 / 空间变化 / 声音变化`

无法转换的要求直接删除，不把理解任务甩给视频模型。

### 8.2 动作编译层

每个剧情节拍交给视频模型前，强制编译成：
`起始状态 → 谁先动 → 动什么 → 朝哪里动 → 与什么接触 → 接触后什么发生 → 谁看到 → 具体怎么反应 → 谁说什么 → 下一镜如何承接`

不能只写“人物更加怀疑/更加生气/更加搞笑”。
必须写清：
- 她先看谁；
- 手伸向什么；
- 拿起/放下/推开什么；
- 道具结果是什么；
- 看到结果后先停顿还是转头；
- 另一人物做什么反应。

### 8.3 动作阶梯

凡剧情有 Escalation，最终提示词必须能逐级指出至少3个不同动作节点。
若连续镜头只是“看→再看→继续看”或“问→再问→继续问”，视为伪升级，返回剧情层重写。

### 8.4 首帧视觉化

Hook的核心冲突优先在首帧或前1秒被看见，而不是只靠台词解释。
价格异常就先让价格/账单/计算结果进入画面；产品破损就先让破损结果可见；空间异常就先建立异常状态。

静音观看前1秒仍无法大致知道“哪里不对”时，优先重写Hook。

### 8.5 Punchline → Reaction

喜剧结尾先拍笑点本体，再拍他人反应：
`动作/台词 Punchline → 0.2–0.8秒停顿 → 对方 Reaction`

不要把主要镜头提前给Reaction，导致真正的笑点动作没有被看见。

## 9. 可视化翻译测试

最终提示词完成后，删除其中所有风格和情绪形容词，只保留人物、动作、道具、结果、台词和镜头。

如果此时仍能清楚“看见”完整视频，说明编译合格。
如果看不见，返回提示词编译层重写。

示例：
- 不写“她越来越怀疑”；写“她先眯眼看朋友，再把计算器拉近重算，看到同样数字后抬头，再把计算器翻过来看背面”。
- 不写“对方越来越无语”；写“第一次正常回答，第二次只抬眉，第三次不回答并喝一口咖啡”。
- 不写“节奏越来越快”；写“3秒双人中景 → 2秒计算器特写 → 1.5秒人物反打 → 1秒反应硬切”。

## 10. 物理因果与穿模

所有人与产品/道具交互遵守：
`人先动作 → 发生接触 → 物体响应 → 结果出现`

明确：
- 哪只手
- 抓哪里
- 朝向
- 受力方向
- 接触区域
- 作用区域

禁止：
- 人物/产品瞬移
- 门、车门、道具自己运动
- 人物穿过关闭物体
- 人物与产品明显穿插
- 产品尺度漂移
- 相隔很远时手突然出现在另一人物近景

发现失败风险时，拆成真实因果链重写。

## 11. 镜头原则

每个镜头必须增加至少一种：
`新信息 / 新动作 / 新反应 / 新证据 / 新空间关系`

镜头只为信息服务：
- 建立事件：中景/中全景
- 人物关系：双人中景/过肩
- 反应：中近景/近景
- 产品证明：产品/动作特写
- 关键利益：必要时轻推近

避免无原因环绕、持续漂移、每镜都推拉。

## 12. TIMELINE格式

按时间顺序写：
- 首帧可见状态/异常
- 景别/关系机位
- 人物位置
- 谁先动作
- 动作对象与方向
- 产品/道具接触
- 接触后的可见结果
- 谁先看到结果
- 人物具体反应动作
- 必要对白
- Punchline与Reaction顺序（若有）
- 下一镜承接

禁止使用“荒诞升级、更加抓马、越来越紧张、反应更夸张”等词代替动作。

## 13. 时长规则

任何作为独立生成任务交付的单条视频提示词，总时长必须≥4秒。
内部镜头、动作节拍可以短于4秒。

单一时间段不能动作过载。
例如2秒内不要同时要求：开门 + 走进房间 + 拿产品 + 使用 + 长台词 + 反应 + 转场。

## 14. 最终提示词推荐结构

`FORMAT`
时长、画幅、平台、整体真实感。

`CHARACTER LOCK`
人物最少必要识别信息。

`PRODUCT LOCK`
产品一致性与尺度。

`LOCATION`
一句话空间结构。

`CONTINUITY`
人物左右关系、视线、产品位置、主运动方向。

`TIMELINE`
逐段使用动作编译后的可见指令。

`GLOBAL CONTROL`
只保留真正影响稳定性的短约束。

## 15. SILENT QA｜生成前静默审核

出现以下任一项，内部修正后再交付：
- 编造商业事实
- 不知道卖什么
- 产品只是露出，没有改变剧情
- 卖点只有口播没有Proof
- 人物行为没有原因
- 对白像说明书
- 人物/产品瞬移
- 道具自己运动
- 穿模
- 产品尺度漂移
- 轴线/视线混乱
- 单一时间段动作过载
- 抽象导演词没有被翻译成可见动作
- Escalation只有情绪加码，没有动作/关系/证据升级
- 连续两级使用同一动作重复充数
- 首帧核心冲突只能靠台词理解
- Punchline没有拍到笑点本体，只拍Reaction
- 道具被当成角色但没有前置关系建立

### 强制自问

1. 删除所有形容词后，我还能清楚看到这个视频吗？
2. Seedance是否只需要“执行”，而不需要替我“理解剧情”？
3. 每一级升级是否真的发生了新的动作、关系、证据或阻力？
4. 每个笑点是否有铺垫、笑点本体和Reaction？
5. 每个动作是否满足真实物理因果？

任一答案为“否”，返回对应层重写，不向用户输出失败草稿。
