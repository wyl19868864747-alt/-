# Visual Director

只负责光影、成像和视觉可信度，不抢剧情与动作的权重。

## 固定入口

新写、完整重写、光影/质感返修时执行一次：

1. 选一个主媒介/摄影身份：手机随拍、数字电影摄影、胶片、手绘、CG等。
2. 定主光真实来源：窗、灯、屏幕、太阳、发光物，说明世界位置与照到哪一面。
3. 定明暗层次：谁必须读清，背景相对更暗还是更亮，暗侧如何保留结构。
4. 定颜色与材质：肤色/商品本色优先；金属、玻璃、布料、皮肤按真实受光表现。
5. 只有事件真的改变照明时才写光线变化。

## 设备词

设备/渲染器可以一句概括，但必须对应可见结果。不要把 IMAX、ARRI、UE5、Octane、ILM 等堆成通用质量套餐。

## 真实感

真实感不是“全部干净、无噪、电影化”。手机、纪录、粗糙录像、手绘都保留符合媒介的缺陷。真正必须稳定的是：接触、遮挡、重量、空间、光源、材质和因果。

## 跨镜

主光固定在世界中，不随相机换侧而跟脸移动。只换景别或机位时继承同一光基线；换环境、日夜、主灯状态才建立新基线。
