# QC Gate｜Anti-AI Video

Judge独立检查，不负责美化自己的方案。

## Hard Check

任一项明显失败就返回对应模块修正：

- 第一关键Beat只有概念，没有可见事件。
- 人物只是站着说台词，没有目的性动作。
- “震惊/荒诞/紧张/高级/超现实”只有形容词，没有可见证据。
- 关键交互缺少接近、接触、作用或完成态。
- 人物/产品/道具无因换位、换手、变大、恢复初始状态。
- 相机运动与人物动作互相打架，或所有镜头都用同一种缓慢推进/手持微震。
- 光源找不到真实出处，或机位一换灯就跟着脸走。
- 产品/关键证据被景深、构图、动作或特效遮掉。
- Prompt重复同一事实、设备词过多、负面项过长，挤压主要动作。
- 开场总控写进了具体剧情，污染分镜层。

## Repair Rule

先找**最早出现或影响最大的一个可见问题**，只回到对应模块修正：
- 动作不清 → Action / State
- 光影假 → Visual Director
- 信息过载/矛盾 → Prompt Compiler
- 专项知识不足 → 调原 `linfeng-video-prompt` 对应模块

不要因为一个局部问题整条重写。

## PASS

能用一句话说清本片核心事件；关键Beat都有状态变化；主要关系可执行；光影与空间一致；Prompt删除管理话后仍完整可成像，即可交付文字版。
