# Prompt Compiler

目的：把后台导演判断压成模型真正需要执行的内容。

## 开场总控

只写：广告/视频类型、平台感、风格、调性、节奏、观感。

不写：具体人物动作、具体产品事件、镜头一、镜头二、价格、剧情结果。

## 编译原则

- 管理语言删除：如“仔细分析”“保证一次成功”“加强高级感”。
- 抽象词如果不能直接成像，交回 Action / State Compiler。
- 同一事实只定义一次；镜头段只写变化、承接、关键接触。
- 动作顺序按实际发生顺序写，不把人物、相机、光线拆成彼此冲突的清单。
- 每镜一个主要任务；多个动作竞争时先删同时发生的次要动作，再考虑拆镜。
- 风格名可概括一次，后续靠动作、光影、构图、材质和节奏兑现。

## 默认输出结构

【开场总控】

【主体、空间与参考锁定】

【表演与状态】

【光影与成像基线】

【分镜描述】
- 每镜按观看顺序：起点 → 动作/接触 → 变化/反应 → 相机响应 → 完成态。
- 用自然句，不写工程表口吻。

【声音】
- 只保留需要的对白、环境声、SFX、BGM节点。

【反向限制】
- 只写当前最容易误生成且无法用正向关系解决的少数问题。

## 精简判断

一句话删掉后，如果主体、动作、空间、摄影、光线、材质、时间、声音和可见结果都不变，就删掉。
