# Action / State Compiler

目的：把导演语言翻译成视频模型能看见的变化，不增加新的创意负担。

## 最小状态链

关键Beat优先写：
`起始状态 → 触发 → 主动作 → 接触/作用 → 可见变化 → 反应 → 完成态`

不是每镜都要写满七项，只保留对因果和连续性有用的部分。

## 抽象词处理

以下词不能单独成为生成指令：荒诞升级、震惊、焦虑、高级、电影感、紧张、超现实、节奏更快、冲击更强。

遇到抽象词，至少落到一个可见证据：
- 人物：视线、停顿、呼吸、身体方向、手部动作、决定
- 物体：位置、开合、数量、形态、受力、结果
- 空间：进入、离开、遮挡、揭示、前中后景关系
- 相机：推、拉、甩、停稳、跟随、焦点转移
- 光线/材质：亮暗变化、互动光、反射、阴影、纹理变化

## 动作句

优先：`主体 + 准确动作 + 对象/位置 + 可见结果`。

例：
- 不写“她越来越震惊”；写“她先核对一遍数字，不信，又抽出第二台计算器重新输入；两块屏幕停在同一数字，她停住，抬头看对方。”
- 不写“荒诞升级”；写清楚第二个、第三个可见行为怎样比前一个更异常。
- 不写“避免穿模”；先写“右手握杯柄，杯底落稳桌面后再松手”。

## 连续性

跨镜只记需要继承的状态：人物位置/朝向、道具归属、产品状态、已揭示信息、相机侧、主光位置、完成态。下一镜从上一完成态继续。
